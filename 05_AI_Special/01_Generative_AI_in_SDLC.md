## 💡 주요 개념 정리
### 1. 대규모 언어 모델(LLM)의 작동 원리
* **통계적 언어 모델:** 인간의 추론 방식이 아닌 데이터 기반의 강력한 통계적 확률 계산 장치
* **다음 토큰 예측 (Next Token Prediction):** 현재 맥락(Context) 분석을 통한 차기 단어 확률의 수학적 산출
* **코딩 능력의 근거:** 프로그래밍 언어의 반복적이고 예측 가능한 패턴에 대한 통계적 학습 결과
* **GPT의 구성 요소:**
    * **Generative:** 학습 데이터 외 새로운 문장 및 코드 생성 능력
    * **Pre-trained:** 방대한 데이터 기반의 사전 학습 완료 상태
    * **Transformer:** 구글 발표 모델 아키텍처 기반

### 2. 프롬프트 엔지니어링과 창발적 능력
* **창발적 능력 (Emergent Abilities):** 모델 규모 및 데이터 증가에 따라 스스로 나타나는 요약, 번역, 추론 능력
* **주요 최적화 기법:**
    * **인컨텍스트 러닝 (In-Context Learning):** 재학습 없는 Zero/One/Few-shot 예시 제공을 통한 규칙 학습
    * **CoT (Chain of Thought):** 단계별 사고 지시를 통한 토큰 예측 정밀도 향상
    * **RAG (검색 증강 생성):** 외부 DB 검색 결과와 프롬프트의 결합 기술
    * **ReAct (Reasoning + Acting):** 외부 도구 사용 계획 수립 및 실행 능력

### 3. 에이전틱 AI (Agentic AI)의 등장
* **에이전트 정의:** 목표 달성을 위해 도구를 자율적으로 선택하고 행동하는 AI 시스템
* **핵심 요소:** 자율성(Autonomy)과 도구 사용 숙련도(Proficiency)의 결합
* **작동 사이클:** 환경 인지(Perception) → 계획(Planning) → 도구 사용(Action)의 반복 수행
* **에이전트 분류:**
    * **반독립적 에이전트:** 정해진 워크플로우 내에서의 국한된 작동 (예: 버그 탐지기)
    * **완전 자율 에이전트:** 파일 시스템, IDE, 터미널 직접 접근 및 코드 수정 수행 (예: Cursor)

### 4. AI 시대의 소프트웨어 개발 주기(SDLC) 변화
* **요구사항 분석 (중요도 급증):** 기계에 대한 명확한 지시를 위한 정교한 문서화 역량 필수
* **설계 및 아키텍처 (중요도 급증):** 구현 자동화에 따른 시스템 전체 조망 아키텍트 역할의 핵심화
* **구현 (자동화 및 가치 하락):** 직접 코딩 행위의 가치 하락 및 코드 최소화 지향
* **검증 (병목 구간 발생):** 인간의 판단이 필요한 '오라클 문제' 해결을 위한 검증 루프 설계의 중요성
* **유지보수 (패러다임 변화):** 코드 생성 비용 하락에 따른 유지보수보다 재작성 효율성 증대

### 5. 개발자의 미래와 핵심 역량
* **사고 범위 문제 (Frame Problem):** 상식이 결여된 AI를 제어하기 위한 비즈니스 도메인 및 상식 정의 능력
* **자동화의 역설:** AI 의존도 심화 시 장애 대응 및 시스템 통제 능력 상실 위험 존재
* **학습의 본질:** 통계적 결과물 검증 및 통제를 위한 코드 원리 이해와 직접 구현 경험의 필수성

## 💻 기능 구현 및 코드 실습
```python
# [LLM 코딩 원리] Next Token Prediction 예시
# 특정 맥락 기반의 차기 코드 통계적 예측 흐름 구현

context = "for"
# 학습 데이터를 바탕으로 차기 토큰 확률 계산 결과 예시
next_token_prediction = ["i", "in", "range(10):"]

# [결과물 생성]
# 통계적 확률 기반의 코드 이어 붙이기 수행
generated_code = f"{context} {next_token_prediction[0]} {next_token_prediction[1]} {next_token_prediction[2]}"
print(generated_code) # 출력: for i in range(10):
```
