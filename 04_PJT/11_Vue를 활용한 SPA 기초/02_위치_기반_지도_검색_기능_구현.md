# [관통 PJT] 위치 기반 지도 검색 기능 구현

---

## 1. Geolocation API

### 개념
**사용자의 현재 위치 정보**를 브라우저를 통해 간편하게 얻을 수 있는 인터페이스. 지도, 내비게이션, 위치 기반 서비스 등을 구현할 때 사용한다.

외부 라이브러리 없이 **브라우저 내장 기능**으로 바로 사용 가능하다.

### 위치 수집 방식 (복합 사용)

| 방식 | 특징 |
|------|------|
| IP 기반 | 간편하나 정확도 낮음 |
| GPS | 정확하나 배터리 소모 심하고 실내 위치 파악 어려움 |
| WiFi | 주변 AP 활용, 개인정보 이슈 존재 |
| Bluetooth Beacon | 정확하나 별도 장비 설치 필요 |

Geolocation API는 위 4가지를 **복합적으로 활용**한다.

> 위치 정보는 **사용자 동의 없이 사용 불가** ("사이트에 있는 동안 허용" 팝업)
>
> 단순 지도 표시 외에도 국가 판별 → 기본 언어 설정, 날씨 정보 제공 등 다양하게 활용 가능

## 2. navigator 객체

`navigator`는 자바스크립트에서 사용자 에이전트의 상태와 신원 정보를 담은 **전역 객체**이다. 브라우저가 자동으로 가지고 있는 객체이므로 별도 선언 없이 사용 가능하다.

주요 속성:

| 속성 | 설명 |
|------|------|
| `navigator.userAgent` | 사용자 브라우저 종류 확인 |
| `navigator.language` | 브라우저 설정 언어 |
| `navigator.onLine` | 인터넷 연결 여부 (boolean) |
| `navigator.geolocation` | **장치의 위치 정보에 접근할 수 있는 객체** |

## 3. getCurrentPosition 사용법

```
navigator.geolocation.getCurrentPosition(
  SuccessCallBack,   // 사용자가 위치 동의 시 실행되는 콜백
  ErrorCallBack,     // 사용자가 위치 거부 시 실행되는 콜백
  Options ...
)
```

- **SuccessCallBack**: 동의 시 `GeolocationPosition` 객체(`pos`)를 인자로 받고, `pos.coords`에서 위도·경도를 추출한다.
- **ErrorCallBack**: 거부 시 에러 객체(`err`)를 인자로 받는다.

```html
<!-- 순수 HTML 사용 예시 -->
<script>
  navigator.geolocation.getCurrentPosition(
    function (pos) {
      const { latitude, longitude } = pos.coords
      console.log(`위도: ${latitude}, 경도: ${longitude}`)
      // 위도: 37.4800384, 경도: 127.008768
    }
  )
</script>
```

실행 시 브라우저에서 위치 접근 권한을 요청하는 팝업이 표시된다.
**"사이트에 있는 동안 허용"** 선택을 권장한다.

## 4. Vue에서 위치 정보 가져오기

```vue
<script setup>
import { ref } from 'vue'

const lat = ref(null)
const lng = ref(null)
const error = ref('')

// 함수 실행 시 사용자의 현재 위치를 불러올 loadLocation 함수 정의
const loadLocation = () => {
  navigator.geolocation.getCurrentPosition(
    (pos) => {
      lat.value = pos.coords.latitude
      lng.value = pos.coords.longitude
    },
    (err) => error.value = err.message
  )
}
</script>

<template>
  <div>
    <!-- 버튼 클릭 시 함수 실행 → 접근 권한 허용 -->
    <button @click="loadLocation">내 위치 가져오기</button>
    <!-- 얻어온 위도, 경도 정보 화면에 렌더링 -->
    <p v-if="lat && lng">Lat: {{ lat }}, Lng: {{ lng }}</p>
    <p v-if="error">{{ error }}</p>
  </div>
</template>
```

> 컴포넌트 로드 시 바로 위치를 자동으로 가져오려면 `onMounted`에서 `loadLocation()`을 호출한다.

## 5. iframe (Inline Frame)

### 개념
**Inline Frame**의 줄임말. HTML 문서 안에 **또 다른 HTML 문서를 삽입**하는 태그. 외부 페이지를 현재 페이지에 임베드(embedded)할 때 사용한다.

### 기본 문법 — 주요 속성

| 속성 | 설명 |
|------|------|
| `src` | 삽입할 문서의 URL |
| `width`, `height` | iframe의 크기 |
| `allowfullscreen` | 전체화면 전환 허용 여부 |
| `loading="lazy"` | 화면에 보여야 할 때 최초 로딩 (성능 최적화) |

### 활용 예시

유튜브, 구글맵 등에서 **공유 → 퍼가기**를 누르면 자동으로 `<iframe>` 코드를 제공해준다.

| 서비스 | URL 형식 |
|--------|---------|
| YouTube | `https://www.youtube.com/embed/<video_id>` |
| Google Maps | `https://www.google.com/maps?output=embed&q=<keyword>` |
| Google Calendar | `https://calendar.google.com/calendar/embed?src=<ics>` |

```html
<!-- Google Maps iframe 예시 -->
<iframe
  src="https://www.google.com/maps?output=embed"
  width="600"
  height="400"
  allowfullscreen
  loading="lazy"
></iframe>
```

## 6. Vue에서 위치 기반 지도 검색 구현

Geolocation API로 가져온 위도·경도를 iframe의 `src`에 동적으로 바인딩한다.

### Vue 코드 (1/2) — 현재 위치로 지도 표시

```vue
<template>
  <iframe :src="mapUrl"></iframe>
</template>

<script setup>
// iframe 지도 업데이트
const updateMap = () => {
  mapUrl.value =
    `https://maps.google.com/maps` +
    `?ll=${lat.value},${lng.value}` +
    `&z=14` +
    `&output=embed`
}
</script>
```

### Vue 코드 (2/2) — 키워드 검색으로 지도 표시

사용자 입력 값을 `q` 파라미터(query)로 활용한다.

```vue
<template>
  <input v-model="keyword" @input="updateMap"/>
  ...
  <iframe :src="mapUrl"></iframe>
</template>

<script setup>
const keyword = ref('')

const updateMap = () => {
  mapUrl.value =
    `https://maps.google.com/maps` +
    `?q=${keyword.value.trim()}` +
    `&ll=${lat.value},${lng.value}` +
    `&z=14` +
    `&output=embed`
}
</script>
```

> 키워드가 비어있으면 현재 위치로, 입력이 있으면 해당 키워드로 검색하는 방식도 구현 가능하다.

## 7. diff 패키지 (jsdiff) — API 호출 최적화

### 문제 상황
`@input`으로 키워드가 바뀔 때마다 지도를 업데이트하면, 유료 API 사용 시 글자 하나에도 요청이 발생하여 과금 문제 발생.

### jsdiff 란?
JavaScript로 **텍스트 구분(차이 감지)**을 구현한 패키지. 이전 텍스트와 새 텍스트를 비교해 두 텍스트의 차이를 구분해준다.

```bash
npm install diff
```

스켈레톤 코드에는 이미 설치되어 있다 (`package.json`의 dependencies 확인).

### diff 메서드 종류

| 메서드 | 설명 |
|--------|------|
| `Diff.diffChars(old, new)` | 각 **문자**를 토큰으로 취급하여 비교 |
| `Diff.diffWords(old, new)` | 각 **단어**와 구두점을 토큰으로 취급하여 비교 |
| `Diff.diffWordsWithSpace(old, new)` | 각 단어, 구두점, 줄 바꿈, 공백까지 토큰으로 취급 |

### diffChars 사용법

```javascript
import { diffChars } from 'diff'

const oldStr = '변경 전'
const newStr = '변경 후 추가'
const changes = diffChars(oldStr, newStr)
```

반환되는 `changes` 배열의 각 항목 구조:

```json
{ "count": 3, "added": false, "removed": false, "value": "변경 " }
{ "count": 1, "added": false, "removed": true,  "value": "전" }
{ "count": 4, "added": true,  "removed": false, "value": "후 추가" }
```

### diffChars 활용 1 — 변경된 글자 색상 표시

```vue
<span
  v-for="(change, index) in changes"
  :key="index"
  :class="{ add: change.added, removed: change.removed }"
>
  {{ change.value }}
</span>
```

- `added: true` → `.add` 클래스 적용 (예: 초록색)
- `removed: true` → `.removed` 클래스 적용 (예: 빨간색 취소선)

### diffChars 활용 2 — 변경 글자 수 카운트

```javascript
// diffChars 활용 2
const diffCount = changes
  // 추가 되었거나 제거된 문자열만 filter
  .filter(function (char) {
    return char.added || char.removed
  })
  // 총 변경 단어 수를 count
  .reduce(function(sum, char) {
    return sum + char.count
  }, 0)
```

## 8. diff를 활용한 지도 업데이트 최적화 — 완성 코드

```javascript
// diff로 키워드 변화 판단 및 지도 갱신 시도
const tryUpdateMap = () => {
  const changes = diffChars(prevKeyword.value, keyword.value)
  const diffCount = changes
    .filter(function (char) {
      return char.added || char.removed
    })
    .reduce(function(sum, char) {
      return sum + char.count
    }, 0)

  const threshold = 2  // 최소 두 글자 이상 바뀌어야 지도 업데이트
  if (diffCount >= threshold) {
    updateMap()
  } else {
    error.value = '키워드가 크게 바뀌지 않았습니다.'
  }
}

// iframe 지도 업데이트
const updateMap = () => {
  // 키워드가 비어있으면 현재 위치로 설정
  const query = keyword.value.trim()
    ? keyword.value
    : `${lat.value},${lng.value}`

  mapUrl.value =
    `https://maps.google.com/maps` +
    `?q=${query}` +
    `&ll=${lat.value},${lng.value}` +
    `&z=14` +
    `&output=embed`

  prevKeyword.value = keyword.value
  error.value = ''
}
```

**전체 흐름 요약**

```
사용자 입력 → tryUpdateMap() 호출
  → diffChars로 이전/현재 키워드 비교
  → 변경 글자 수 ≥ 2 → updateMap() → iframe src 갱신 → 지도 변경
  → 변경 글자 수 < 2 → 에러 메시지 표시
```
