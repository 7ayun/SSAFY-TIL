## 1. ORM과 QuerySet API

**ORM(Object-Relational-Mapping)** 은 객체 지향 프로그래밍 언어를 사용해 호환되지 않는 유형의 시스템 간에 데이터를 변환하는 기술이다. Django에 내장된 ORM이 Python 객체와 DB 사이에서 중간 해석자 역할을 한다.

```
Python 코드 → ORM → SQL → Database
Database → ORM → QuerySet or Instance → Python 코드
```

**QuerySet API** 는 ORM에서 데이터를 검색, 필터링, 정렬 및 그룹화하는 데 사용하는 도구다. SQL을 직접 작성하지 않고 Python 코드로 데이터를 처리할 수 있다.

```python
# 예시: Article 전체 조회
Article.objects.all()
```

## 2. Field Lookups

Field lookups는 QuerySet에서 조건을 구성하는 방법이다. `filter()`, `exclude()`, `get()` 메서드에 키워드 인자로 지정한다.

```python
# 내용에 'dja'가 포함된 게시글 조회
Article.objects.filter(content__contains='dja')

# 제목이 'he'로 시작하는 게시글 조회
Article.objects.filter(title__startswith='he')
```

자주 쓰는 Field lookup 패턴은 `필드명__lookup종류=값` 형태다.

| Lookup | 의미 |
|---|---|
| `__contains` | 특정 문자열 포함 (대소문자 구분) |
| `__icontains` | 특정 문자열 포함 (대소문자 무시) |
| `__startswith` | 특정 문자열로 시작 |
| `__endswith` | 특정 문자열로 끝 |
| `__exact` | 정확히 일치 |
| `__gt` / `__lt` | 크다 / 작다 |
| `__gte` / `__lte` | 크거나 같다 / 작거나 같다 |

---

## 3. Q 객체가 필요한 이유

`filter()` 내에서 여러 조건을 AND로 연결하는 건 쉽다. 하지만 **OR 조건** 이나 **복잡한 조건 조합** 은 일반 `filter()`로 표현하기 어렵다.

> 예: "내용에 'dja' 포함" **AND** "제목이 'he'로 시작" → 두 조건을 모두 만족하는 게시글 조회

이럴 때 `Q()` 객체를 사용하면 된다. GPT나 Gemini한테 복잡한 필터를 물어봤을 때 Q 객체를 안내해주는 경우가 많은데, 어렵게 생각할 필요 없다.

## 4. Q 객체 사용법

### 기본 사용법

`django.db.models`에서 `Q`를 임포트한 후, 기존 Field lookup 조건을 `Q()` 안에 그대로 넣는다.

```python
from django.db.models import Q

Q(content__contains='dja')
Q(title__startswith='he')
```

### AND 조건 (`&`)

두 Q 객체를 `&`로 연결하면 두 조건을 **모두 만족**하는 결과를 반환한다.

```python
def and_query(request):
    articles = Article.objects.filter(
        Q(content__contains='dja') & Q(title__startswith='he')
    )
    serializer = ArticleSerializer(articles, many=True)
    return Response(serializer.data)
```

### OR 조건 (`|`)

두 Q 객체를 `|`로 연결하면 두 조건 중 **하나 이상 만족**하는 결과를 반환한다.

```python
articles = Article.objects.filter(
    Q(content__contains='dja') | Q(title__startswith='he')
)
```

### NOT 조건 (`~`)

Q 객체 앞에 `~`를 붙이면 해당 조건을 **부정**한다.

```python
articles = Article.objects.filter(
    ~Q(content__contains='dja')
)
```

---

## 5. 복합 조건 예시

Q 객체는 `&`, `|`, `~`를 자유롭게 조합해 복잡한 조건을 간결하게 표현할 수 있다.

```python
# "내용에 'dja'를 포함하지 않고, 제목이 'he'로 시작하거나 'st'로 시작하는 게시글"
articles = Article.objects.filter(
    ~Q(content__contains='dja') & (Q(title__startswith='he') | Q(title__startswith='st'))
)
```

일반 `filter()` 체이닝이나 SQL로 작성하면 복잡해지는 조건을 Q 객체로 직관적으로 표현할 수 있다.

## 💡 한 줄 요약
> Q 객체는 Django ORM에서 AND(`&`), OR(`|`), NOT(`~`) 연산자를 활용해 복잡한 조건의 쿼리를 파이썬 코드로 간결하게 표현할 수 있게 해주는 도구다.
