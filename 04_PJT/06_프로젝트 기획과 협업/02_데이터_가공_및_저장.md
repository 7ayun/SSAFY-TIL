# [관통 PJT] 데이터 가공 및 저장

---

## 1. 왜 데이터 가공이 필요한가?

외부 API에서 가져온 데이터는 API를 만든 쪽의 기준으로 컬럼명과 카테고리 구조가 정해져 있다. 우리가 만든 서비스의 DB 구조와 다르기 때문에, 이를 **우리 서비스에 맞게 가공해서 활용**해야 한다.

이번 실습에서는 알라딘(Aladin) API에서 받아온 도서 데이터와 카테고리 엑셀 파일을 가공해 Django fixture 형태의 JSON으로 변환하는 과정을 다룬다.

전체 흐름은 다음과 같다.

```
[알라딘 카테고리 엑셀] → 카테고리 가공 → categories.json
[알라딘 도서 원본 JSON] → 카테고리 맵핑 + 필드 추출 → extracted_books.json → 전처리 → books.json
```

---

## 2. 데이터셋 소개

- **aladin_Category_CID.xls**: 알라딘이 제공하는 카테고리 아이디(CID) 목록. 총 **4,781개**의 카테고리로 구성되며, 대주제(1Depth)부터 소주제(5Depth)까지 계층 구조를 가짐
- **books_raw.json**: 알라딘 API에서 받아온 도서 원본 데이터. 각 도서에 `categoryId`, `categoryName`, `title`, `author`, `description` 등의 필드를 포함

---

## 3. 데이터 가공: 카테고리 맵핑

4,781개의 카테고리를 그대로 사용하면 UX 측면에서 필터링이 불가능하다. 따라서 **1Depth 기준으로 CID를 묶어 33개로 줄이고, 다시 의미가 유사한 것끼리 합쳐 7개의 카테고리**로 축소한다.

### Step 0: 패키지 설치

```bash
pip install pandas
pip install openpyxl
```

- `pandas`: 정형 데이터(테이블 데이터) 처리
- `openpyxl`: 엑셀 파일 읽기/쓰기

### Step 1: 엑셀 파일 읽기

```python
import pandas as pd

df = pd.read_excel(excel_file, header=2)
```

- `header=2`: 첫 2행을 건너뛰고 3번째 행을 헤더로 사용

### Step 2: 1Depth 값을 기준으로 CID 그룹핑

```python
category_dict = {}

for index, row in df.iterrows():
    category = row['1Depth']
    cid = row['CID']

    if pd.isna(category):     # 결측값(빈 값) 건너뜀
        continue

    if category in category_dict:
        category_dict[category].append(cid)
    else:
        category_dict[category] = [cid]
```

- `iterrows()`: 각 행의 index와 row를 순회
- `pd.isna()`: 결측값 여부 확인

이렇게 하면 총 33개의 카테고리 그룹이 생성된다. 각 그룹에 PK를 부여한다.

```python
new_groups = []
for idx, (cat, cid_list) in enumerate(category_dict.items(), start=1):
    new_groups.append({
        'pk': idx,
        'name': cat,
        'cid_list': cid_list
    })
```

### Step 3: 새로운 그룹핑 (33개 → 7개)

33개도 여전히 많으므로, 의미가 유사한 카테고리끼리 합쳐 7개로 병합한다. 병합 매핑을 직접 정의하고 `extend`로 CID 리스트를 합친다.

```python
new_group_mapping = {
    1: {"name": "소설/시/희곡",  "old_pks": [12]},
    2: {"name": "경제/경영",    "old_pks": [3]},
    3: {"name": "자기계발",     "old_pks": [9, 19, 23]},
    4: {"name": "인문/교양",    "old_pks": [5, 11, 15, 17, 18, 21, 27, 28]},
    5: {"name": "취미/실용",    "old_pks": [1, 2, 10, 16]},
    6: {"name": "어린이/청소년", "old_pks": [14, 20, 30, 31]},
    7: {"name": "과학",         "old_pks": [6, 33]},
}

final_groups = []
for new_pk, mapping_data in new_group_mapping.items():
    merged_cid_list = []
    for old_pk in mapping_data["old_pks"]:
        for group in new_groups:
            if group["pk"] == old_pk:
                merged_cid_list.extend(group["cid_list"])  # CID 리스트 병합
                break
    final_groups.append({
        "pk": new_pk,
        "name": mapping_data["name"],
        "cid": merged_cid_list
    })
```

### Step 4: categories.json 저장

```python
import json

with open(json_file, 'w', encoding='utf-8') as f:
    json.dump(final_groups, f, ensure_ascii=False, indent=4)
```

- `ensure_ascii=False`: 한글 깨짐 방지

## 4. 데이터 추출: categoryId 맵핑 및 도서 추출

7개 카테고리 기준에 맞춰 `books_raw.json`에서 **카테고리별 도서 10권씩** 추출하고, Django fixture 형태로 변환한다.

### Step 1: JSON 파일 읽기

```python
with open(raw_json_file, "r", encoding="utf-8") as f:
    books = json.load(f)

with open(category_json_file, "r", encoding="utf-8") as f:
    categories = json.load(f)
```

### Step 2: 추출 준비

```python
category_counts = {category["pk"]: 0 for category in categories}  # 카테고리별 추출 수 추적
extracted_books = []
fixture_pk = 1
```

### Step 3: 도서 데이터 조회 - 맵핑 - 추출

```python
for book in books:
    item = book.get("item", {})
    fields = item[0]
    orig_cat = fields.get("categoryId")
    orig_cat_int = int(orig_cat)

    for category in categories:
        cid_list = category.get("cid", [])
        if orig_cat_int in cid_list:
            cat_pk = category.get("pk")
            if category_counts.get(cat_pk, 0) < 10:  # 10권 미만인 카테고리에만 추가
                fixture_fields = {"category": cat_pk}

                # 필요한 필드만 추출 + 컬럼명 변환
                keys_to_copy = ["title", "description", "cover", "publisher",
                                "isbn13", "pubDate", "author", "customerReviewRank"]
                for key in keys_to_copy:
                    if key in fields:
                        if key == "customerReviewRank":
                            fixture_fields["customer_review_rank"] = fields[key]
                        elif key == "pubDate":
                            fixture_fields["pub_date"] = fields[key]
                        elif key == "isbn13":
                            fixture_fields["isbn"] = fields[key]
                        else:
                            fixture_fields[key] = fields[key]

                # Django fixture 구조로 wrapping
                fixture_entry = {
                    "model": "books.book",
                    "pk": fixture_pk,
                    "fields": fixture_fields
                }

                extracted_books.append(fixture_entry)
                fixture_pk += 1
                category_counts[cat_pk] += 1
            break  # 카테고리 찾으면 inner loop 종료
```

> 컬럼명 변환이 필요한 이유: 알라딘 API가 제공하는 `customerReviewRank`, `pubDate`, `isbn13` 등의 키를 Django 모델의 필드명인 `customer_review_rank`, `pub_date`, `isbn`으로 맞춰주어야 한다. (카멜케이스 → 스네이크케이스)

### Step 4: 추출 데이터 저장

```python
with open(extracted_json_file, "w", encoding="utf-8") as f:
    json.dump(extracted_books, f, ensure_ascii=False, indent=4)
```

## 5. 데이터 전처리: 노이즈 제거

추출된 도서 데이터(`extracted_books.json`)에는 두 가지 노이즈가 있다.

- `description`: HTML 엔티티(`&lt;` 등)가 문자열에 섞여 있음
- `author`: 지은이뿐 아니라 옮긴이, 엮은이 등이 괄호로 묶여 함께 있음 (예: `헤르만 헤세 (지은이), 이미영 (옮긴이)`)

### Step 1: JSON 파일 읽기

```python
import re

input_file = "extracted_books.json"
with open(input_file, "r", encoding="utf-8") as f:
    books = json.load(f)
```

### Step 2: 도서 순회 및 전처리

```python
for book in books:
    fields = book.get("fields", {})

    # description 전처리: 정규표현식으로 &lt; 제거
    if "description" in fields:
        original_desc = fields["description"]
        processed_desc = re.sub(r'&lt;', '', original_desc)
        fields["description"] = processed_desc

    # author 전처리: 첫 번째 '(' 앞까지만 추출
    if "author" in fields:
        original_author = fields["author"]
        match = re.search(r'^(.*?)\(', original_author)
        if match:
            processed_author = match.group(1).strip()
        else:
            processed_author = original_author
        fields["author"] = processed_author
```

### Step 3: 전처리 데이터 저장

```python
output_file = "books.json"
with open(output_file, "w", encoding="utf-8") as f:
    json.dump(books, f, ensure_ascii=False, indent=4)
```

최종 `books.json`은 Django의 `loaddata` 명령으로 DB에 바로 삽입 가능한 fixture 형태다.

---

## 6. Django에서 fixture로 데이터 삽입

```bash
python manage.py loaddata books.json
```

`books.json`이 Django fixture 형태(model, pk, fields)로 작성되어 있으면, 위 명령 하나로 DB에 데이터를 한 번에 삽입할 수 있다.
