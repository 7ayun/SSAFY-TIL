## 3. 기본 크롤링 코드 작성

### 봇 차단 방지 헤더

일반적인 크롤링 요청은 서버에서 **봇**으로 감지해 차단된다. User-Agent 헤더에 일반 브라우저처럼 속이는 문자열을 넣어 우회한다.

```python
HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36"
}
```

### GeekNews 크롤링 코드

```python
# news-server/news.py

from mcp.server.fastmcp import FastMCP
import httpx
from bs4 import BeautifulSoup

mcp = FastMCP("news-server")

HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) ..."
}

@mcp.tool()
async def get_geeknews(limit: int = 5) -> str:
    """
    기술 뉴스 사이트 'GeekNews'의 기사를 가져옵니다.
    기술 트렌드나 개발 관련 소식이 필요할 때 사용하세요.
    """
    url = "https://news.hada.io/"

    async with httpx.AsyncClient(headers=HEADERS) as client:
        response = await client.get(url)

    soup = BeautifulSoup(response.text, 'html.parser')  # HTML 파싱 (스프 끓이기)

    # GeekNews의 기사 제목 목록 가져오기
    articles = []
    topics = soup.select('div.topic_row')[:limit]

    for topic in topics:
        title_tag = topic.select_one('div.topictitle a h1')  # 기사 제목 추출
        if title_tag:
            articles.append(title_tag.get_text(strip=True))

    return "\n".join(articles)
```

### AI SparkUp 크롤링 코드

```python
@mcp.tool()
async def get_ai_sparkup(limit: int = 5) -> str:
    """
    'AI SparkUp' 아카이브에서 최신 인공지능(AI) 및 LLM 트렌드 기사를 가져옵니다.
    AI 모델, 프롬프트 엔지니어링, AI 도구 관련 심층 정보가 필요할 때 사용하세요.
    """
    url = "https://aisparkup.com/archive"

    async with httpx.AsyncClient(headers=HEADERS, follow_redirects=True) as client:
        response = await client.get(url)

    soup = BeautifulSoup(response.text, 'html.parser')

    titles = soup.select('h2')[:limit]  # 기사 제목 추출

    results = []
    for t in titles:
        text = t.get_text(strip=True)
        results.append(text)

    return "\n".join(results)


def main():
    mcp.run()

if __name__ == "__main__":
    main()
```

> **참고**: `follow_redirects=True` 옵션은 AI SparkUp 사이트가 리다이렉트를 사용하기 때문에 추가한다.

## 6. 리팩토링 — 중복 구조 제거

세 개의 크롤링 함수(`get_geeknews_popular`, `get_geeknews_new`, `get_ai_sparkup`)에서 HTTP 요청 코드가 중복된다. 공통 함수로 분리해 코드를 간결하게 만든다.

### HTTP 요청 공통 함수

```python
async def _fetch_html(url: str) -> str:
    """URL에 접속하여 HTML 텍스트를 반환하는 공통 함수"""
    async with httpx.AsyncClient(headers=HEADERS, follow_redirects=True) as client:
        response = await client.get(url)
    return response.text
```

> 함수명 앞에 `_`(언더바)를 붙이는 이유: 내부에서만 사용하는 함수라는 **가독성을 위한 표시**. Python 컨벤션.

### GeekNews 파싱 공통 함수

GeekNews 인기글과 최신글은 **동일한 HTML 구조**를 공유하므로 파싱 로직도 하나로 묶는다.

```python
def _parse_geeknews(html: str, limit: int) -> str:
    """GeekNews의 HTML 구조를 파싱하여 기사 목록을 반환하는 공통 함수"""
    soup = BeautifulSoup(html, 'html.parser')

    articles = []
    topics = soup.select('div.topic_row')[:limit]

    for topic in topics:
        title_tag = topic.select_one('div.topictitle a')   # h1 태그 없이 선택
        if title_tag:
            articles.append(title_tag.get_text(strip=True))

    return "\n".join(articles)
```

### 리팩토링 결과

```python
@mcp.tool()
async def get_geeknews_popular(limit: int = 5) -> str:
    """GeekNews 인기글을 가져옵니다."""
    url = "https://news.hada.io/"
    html = await _fetch_html(url)
    return _parse_geeknews(html, limit)

@mcp.tool()
async def get_geeknews_new(limit: int = 5) -> str:
    """GeekNews 최신글을 가져옵니다."""
    url = "https://news.hada.io/new"
    html = await _fetch_html(url)
    return _parse_geeknews(html, limit)

@mcp.tool()
async def get_ai_sparkup(limit: int = 5) -> str:
    """AI SparkUp 최신 기사를 가져옵니다."""
    url = "https://aisparkup.com/archive"
    html = await _fetch_html(url)

    soup = BeautifulSoup(html, 'html.parser')
    titles = soup.select('h2')[:limit]
    return "\n".join(t.get_text(strip=True) for t in titles)
```

두 GeekNews 함수는 **URL만 다르고** 나머지는 완전히 동일하다는 점이 포인트.

완성된 뉴스 크롤링 MCP 서버를 이용해 매일 아침 보고서를 자동으로 생성할 수 있다.

```
"aisparkup 뉴스랑 GeekNews 도구 둘 다 실행해서 뉴스 가져와.
그리고 가져온 내용을 바탕으로 보고서를 써줘.
말투는 아주 정중하게 하고, 중복은 제거해. 마지막엔 네 생각도 한 줄 넣어줘"
```

동작 결과:
1. `get_ai_sparkup` 실행 ✓
2. `get_geeknews_new` 실행 ✓
3. `get_geeknews_popular` 실행 ✓
4. 세 개의 결과를 합쳐 중복 제거 후 정중한 보고서 생성

→ 이 구조에서 **더 나아가면** AI Agent를 만들 수 있다. 긴 프롬프트를 매번 입력하지 않고, "보고서 만들어"만 입력해도 자동으로 실행되도록 하는 것이 AI Agent 강의의 목표다.
