# [데이터 기초] 기초 통계량

---

## 1. 기초 통계량이 필요한 이유

데이터를 표현하는 변수는 보통 수천~수백만 개의 값을 가진다. 이렇게 많은 값을 하나하나 확인하는 것은 현실적으로 불가능에 가깝기 때문에, 데이터를 압축적으로 요약해서 살펴볼 필요가 있다.

데이터 분석의 첫 단계는 다음 네 가지를 파악하는 것이다.
- 데이터의 크기
- 데이터의 분포
- 데이터의 중심 (대표값)
- 데이터의 퍼짐 (변동성)

이 중 중심과 퍼짐을 숫자로 요약한 것이 **기초 통계량**이며, 크게 **위치(대표값)** 와 **변이(퍼짐)** 두 축으로 나뉜다.

## 2. 위치 - 데이터를 대표하는 값

각 변수를 대표하는 하나의 값을 구해서 데이터를 요약하는 방법이다.

| 종류 | 정의 | 특징 |
|---|---|---|
| 평균 (mean) | 모든 값을 더해 개수로 나눈 값 | 전체적인 중심을 나타내지만 이상치에 민감 |
| 절사평균 (trimmed mean) | 상·하위 극단값 일부를 제거하고 계산한 평균 | 이상치의 영향을 줄이는 데 유용 |
| 가중평균 (weighted mean) | 각 값의 중요도(가중치)를 반영해 계산한 평균 | 값들의 영향력이 동일하지 않을 때 사용 |
| 중간값 (median) | 정렬된 데이터의 정중앙에 있는 값 | 왜곡된 분포에서도 안정적으로 중심을 나타냄 |
| 가중 중간값 (weighted median) | 가중치를 고려해 중앙 위치를 결정 | 표본 비중이 다른 조사에서 활용 |
| 백분위수 (percentile) | 데이터를 100등분했을 때 특정 위치의 값 | 분포의 형태와 위치 파악에 사용 (Q1=25번째, Q3=75번째) |

> 평균은 데이터 하나가 극단적으로 크거나 작아지는 것만으로도 크게 흔들린다. 값이 1, 2, 1, 2로 고르게 분포하다가 하나가 갑자기 매우 커지면 평균 자체가 확 커지는 식이다. 그래서 이상치가 있거나 분포가 한쪽으로 치우친 경우에는 중앙값을 대신 사용하는 경우가 많다.

## 3. 변이 - 데이터가 퍼진 정도

대표값이 같다고 해서 데이터의 특성이 같다고 볼 수는 없다. 평균이 동일한 두 집단이라도, 한쪽은 값들이 평균 근처에 몰려 있고 다른 한쪽은 넓게 퍼져 있을 수 있기 때문이다. 이 차이를 설명하는 것이 **변이(퍼짐의 정도)** 다.

| 종류 | 정의 |
|---|---|
| 분산 (Variance) | 평균으로부터 얼마나 퍼져 있는지를 나타내는 지표 |
| 표준편차 (Standard deviation) | 분산에 제곱근을 씌운 값. 편차(각 값 - 평균)의 기준이 되는 값 |
| 사분위 범위 (IQR) | 제3사분위수(Q3) - 제1사분위수(Q1) |

- 데이터가 평균 근처에 모여 있으면 분산이 작고, 멀리 퍼져 있으면 분산이 크다.
- IQR은 Q1~Q3 범위를 벗어나는 값을 이상치로 판단하는 기준으로도 활용된다. 이상치가 많거나 데이터가 한쪽으로 쏠려 있을 때는 분산·표준편차보다 IQR을 쓰는 것이 더 안정적이다.

## 4. 기초 통계량의 활용

**① 이상치 발견**
평균이나 분산을 계산했을 때 극단적으로 크거나 작은 값(이상치)이 있는지 확인할 수 있다. 예를 들어 평균 몸무게가 60kg인 집단에 120kg인 값이 섞여 있다면 이상치일 가능성이 있고, 200kg처럼 더 극단적인 값이라면 이 값 하나 때문에 전체 평균이 흔들릴 수 있다.

**② 비교와 예측**
평균·중앙값·표준편차를 이용하면 두 개 이상의 그룹 간 차이를 빠르게 비교할 수 있다. 예를 들어 남학생과 여학생의 키 분포를 각각의 평균으로 비교하면, 두 집단의 특성 차이를 즉각적으로 파악할 수 있다.

**③ 적절한 분석 방법 선택**
데이터의 분포 형태에 따라 어떤 대표값을 쓸지 달라진다.
- 대칭형으로 분포되어 있다면 → **평균**을 사용
- 왜곡된 분포라면 → **중앙값**이 더 안정적

> 연봉이나 집값처럼 소수의 고소득자·고가 매물이 평균을 크게 왜곡하는 경우, 평균보다 중앙값을 사용하는 것이 데이터의 실제 특성을 더 잘 반영한다.

## 💡 한 줄 요약
> 기초 통계량은 위치(평균·중앙값 등 대표값)와 변이(분산·표준편차·IQR)로 데이터를 압축해서 요약하며, 이상치 발견·집단 비교·분석 방법 선택에 두루 활용된다.
