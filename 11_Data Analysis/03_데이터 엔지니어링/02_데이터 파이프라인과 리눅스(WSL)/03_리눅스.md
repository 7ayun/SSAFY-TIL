# [데이터 엔지니어링] 리눅스

---

## 1. 유닉스(UNIX)와 리눅스(Linux)

리눅스를 다루기 전에 그 뿌리가 된 **유닉스**를 먼저 이해할 필요가 있다.

- **유닉스**: 굉장히 오래된 운영체제로, 오늘날 우리가 쓰는 많은 시스템의 기반이 된 "기업용 운영체제" 성격을 가진다. (예: HP-UX, IBM AIX, Oracle Solaris, macOS 등)
- 문제는 **유용하지만 유료**였다는 점 — 사용에 높은 비용이 필요했다.

이 문제를 해결하기 위해 유닉스의 **구조와 설계 철학**을 기반으로 만들어진 것이 **리눅스**다. 다만 리눅스는 유닉스의 소스 코드를 그대로 가져온 것이 아니라, 설계 철학과 사용 방식을 따른 별개의 운영체제다. 누구나 자유롭게 쓸 수 있는 **오픈소스** 형태로 공개되었고, 지금은 오히려 유닉스보다 훨씬 널리 쓰이며 특히 서버·클라우드 환경에서는 사실상 기본값으로 사용된다.

## 2. 리눅스 커널(Kernel)

리눅스를 구성하는 핵심 요소 중 하나가 **커널**이다.

> 커널은 운영체제의 핵심 구성 요소로, **하드웨어와 응용 프로그램 사이를 중재**하는 역할을 한다.

프로그램을 실행할 때 CPU, 메모리 같은 하드웨어 자원을 프로그램이 직접 사용하는 것이 아니라, 그 요청을 커널을 통해 주고받는다. 터미널에서 명령을 입력하는 것도 결국 하드웨어를 직접 건드리는 게 아니라 **커널을 통해 동작**하는 것이다. 만약 커널이 없다면 프로그램이 하드웨어를 직접 제어해야 하므로, 사실상 운영체제가 없는 상태나 다름없다.

```
사용자(터미널 명령) → 쉘(Shell) → 커널(Kernel) → 하드웨어(CPU, 메모리 등)
```

## 3. 리눅스 커널의 역사

- **리누스 토르발스(Linus Torvalds)**가 1991년 리눅스 커널 0.01 버전을 처음 개발
- 1992년, 0.02 버전 소스를 공개하면서 **오픈소스 운동**이 본격화 → 리눅스의 시작
- 리눅스 배포판은 토르발스가 만든 **커널 + 다양한 오픈소스 프로그램**(라이브러리, 명령 해석기 등)으로 구성된다
- 좁은 의미의 "리눅스"는 커널을 가리키지만, 넓은 의미로는 웹 서버, DB 서버 등 다양한 소프트웨어가 결합된 배포판 전체를 의미하기도 한다

## 4. 리눅스의 장점

| 장점 | 설명 |
|---|---|
| 무료 & 오픈소스 | 누구나 자유롭게 사용·수정·배포 가능. 라이선스 비용 부담 없이 교육/개발에 적합 |
| 가볍고 빠른 성능 | 불필요한 GUI 없이 CLI만으로 동작 가능해 구형 하드웨어에서도 효율적 |
| 높은 서버 점유율 | 전 세계 웹 서버의 상당수가 리눅스 기반. 클라우드·데이터센터·웹호스팅에서 사실상 필수 |
| 개발 친화적 환경 | 대부분의 개발 도구·패키지가 리눅스 친화적으로 만들어져 있어 자동화·백엔드 개발에 최적 |

클라우드에서 서버를 띄울 때도 그 서버 자체가 대부분 리눅스 기반이며, 도커(Docker)로 컨테이너를 띄울 때도 내부적으로는 리눅스 기반의 작은 운영체제가 동작한다.

## 5. 우분투(Ubuntu) 리눅스

리눅스는 여러 계보의 배포판이 있는데, 그중 이번 과정에서는 **우분투**를 사용한다.

- **데비안(Debian)** 기반의 배포판으로, 다양한 파생 버전(Flavor)이 존재
- 릴리스 주기: 일반 버전(6개월), **LTS 버전(2년)**
- **LTS(Long Term Support)**: 어느 정도 안정화된 형태로 장기간 지원되는 버전 → 이번 과정에서는 **우분투 22.04 LTS**를 사용
- 우분투를 선택하는 이유: 설치와 사용이 쉽고, 참고할 수 있는 자료가 압도적으로 많기 때문 (윈도우 환경에서 WSL로 세팅하기에도 적합)

## 6. 리눅스 파일 시스템 구조

리눅스는 윈도우의 C드라이브처럼 하나의 최상위 디렉토리인 **`/` (root 디렉토리)**에서 전체 구조가 시작된다. 세부 구조를 전부 외울 필요는 없지만, 전체적인 형태와 자주 등장하는 디렉토리 정도는 익혀두면 좋다.

```
/
├── bin    # 기본적인 명령어(실행 파일)들이 위치
├── etc    # 시스템 설정 파일들이 위치
├── home   # 사용자별 홈 디렉토리 (예: /home/사용자명)
├── tmp    # 임시 파일들이 저장되는 공간
└── ...    # boot, dev, var 등 다양한 디렉토리 존재
```

- **`/`**: 최상위 root 디렉토리
- **`/etc`**: 시스템 설정 파일
- **`/bin`**: 기본 명령어 실행 파일
- **`/tmp`(temp)**: 임시 파일 저장소
- **`/home`**: 각 사용자의 홈 디렉토리 (윈도우의 사용자 폴더와 유사)

## 💡 한 줄 요약
> 리눅스는 유료였던 유닉스의 설계 철학을 이어받아 무료·오픈소스로 만들어진 운영체제로, 커널이 하드웨어와 응용 프로그램을 중재하는 핵심 구조를 가지며 서버·클라우드 환경의 사실상 표준이 되었다.
