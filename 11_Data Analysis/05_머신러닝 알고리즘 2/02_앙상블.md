# [데이터 기초] 앙상블

## 1. 의사결정 트리(Decision Tree) 복습

앙상블 기법을 이해하기 전에, 트리 기반 모델의 기본 구조를 다시 살펴본다. 의사결정 트리는 입력 변수를 특정 기준으로 분기해 트리 형태의 구조로 데이터를 분류하는 모델이며, 분류·회귀 문제 모두에 사용할 수 있다.

| 노드 | 역할 |
|---|---|
| Root Node | 첫 번째 질문(분기 기준)이 들어가는 지점 |
| Decision Node | 중간에서 추가로 데이터를 나누는 기준 |
| Leaf Node | 더 이상 나눌 것이 없어 최종 결정이 내려지는 지점 |

- 장점: 어떤 기준으로 분류됐는지 흐름을 눈으로 볼 수 있어 **해석이 쉽다**.
- 단점: 예측력이 상대적으로 떨어진다. 단순 평균·다수결로 예측하기 때문에, 회귀에서는 이상치에 영향을 크게 받는다.
  > 예: 타겟값이 5, 6, 7이면 평균 예측값은 6 정도지만, 5, 6, 100이면 평균이 37로 왜곡된다.

## 2. 앙상블(Ensemble)이란?

앙상블은 하나의 강력한 모델 대신 **여러 개의 모델을 만들어 예측을 결합**함으로써 더 정확한 예측을 하고자 하는 기법이다. 앙상블 자체가 하나의 모델은 아니며, 여러 모델을 조합하는 전략에 가깝다. 대표적으로 **보팅(Voting), 배깅(Bagging), 부스팅(Boosting)** 세 가지 방식이 있다.

## 3. 보팅(Voting)

서로 **다른 알고리즘**을 여러 개 결합해서, 각 모델의 예측 결과를 투표로 결정하는 방식이다.

| 방식 | 설명 |
|---|---|
| 하드 보팅(Hard Voting) | 다수의 분류기가 예측한 클래스(결과값)를 최종 결과로 채택 |
| 소프트 보팅(Soft Voting) | 각 분류기가 예측한 클래스별 확률을 평균 내서, 가장 확률이 높은 클래스를 최종 결과로 채택 |

> 예: 분류기 4개가 각각 1, 2, 1, 1로 예측했다면 하드 보팅은 다수결로 1을 선택한다. 소프트 보팅은 각 분류기의 클래스별 예측 확률(예: [0.7, 0.3])을 평균 내어 확률이 가장 높은 클래스를 선택한다.

## 4. 배깅(Bagging)

배깅은 **Bootstrap AGGregating**의 줄임말로, **같은 알고리즘**을 여러 번 학습시키는 방식이다. 보팅과의 핵심 차이는 여기에 있다 — 보팅은 서로 다른 모델을 조합하지만, 배깅은 동일한 모델을 데이터만 다르게 해서 여러 번 학습시킨다.

- 원본 데이터에서 **중복을 허용**하며 무작위로 샘플링(부트스트랩)해 여러 데이터 뭉치를 만든다.
- 각 데이터 뭉치로 동일한 모델을 반복 학습시킨다.
- 결과를 집계(Aggregation)한다 — 범주형은 다수결 투표, 연속형은 평균값을 사용.
- 모델은 같아도 데이터가 다르므로 결과가 조금씩 달라지고, 이를 종합하면 **과적합이 줄고 일반화 성능이 좋아진다.**
- 과적합이 잘 일어나는 결정 트리 같은 모델에 특히 효과적이며, **랜덤 포레스트**가 대표적인 배깅 알고리즘이다.

## 5. 부스팅(Boosting)

부스팅은 여러 분류기를 **순차적으로** 학습시키면서, 이전 모델이 틀린 데이터에 가중치를 부여해 다음 모델이 그 부분을 집중적으로 학습하도록 만드는 방식이다.

- 틀린 문제를 반복적으로 풀면서 점진적으로 성능을 개선한다.
- 예측 성능이 매우 뛰어나 앙상블 학습을 주도하며, 딥러닝이 대중화되기 전 케글(Kaggle) 등 머신러닝 대회에서 강세를 보였다. (대표 모델: XGBoost, AdaBoost, Gradient Boosting)
- 단, 순차적으로 학습해야 하므로 배깅·보팅처럼 병렬 처리가 어려워 **속도가 느리고**, 틀린 데이터 위주로 계속 학습하다 보니 **과적합 위험이 상대적으로 높다.**

## 6. 랜덤 포레스트(Random Forest)

랜덤 포레스트는 여러 개의 결정 트리를 배깅 방식으로 학습시킨 뒤, 그 결과를 결합해 최종 예측을 만드는 모델이다. "나무(Tree)" 하나 대신 "숲(Forest)" 전체의 결과를 종합한다. 트리마다 서로 다른 데이터 샘플과 일부 피처만 무작위로 선택해 학습하기 때문에 "랜덤"이라는 이름이 붙는다.

| 특징 | 설명 |
|---|---|
| 임의성 | 데이터 샘플링이 트리마다 달라, 서로 조금씩 다른 특성의 트리들로 구성됨 |
| 비상관화 | 트리 간 예측이 서로 연관되지 않아, 한 트리가 틀려도 다른 트리가 보완 |
| 견고성 | 오류가 전체 모델로 크게 전파되지 않아 노이즈에 강함 |
| 일반화 | 임의화를 통해 단일 트리보다 과적합 위험이 줄어듦 |

- 장점: 과적합이 잘 일어나지 않고, 결측치·이상치에 강하며, 트리 기반이라 스케일링·정규화가 필요 없고, 비선형 데이터도 잘 처리한다.
- 단점: 수많은 트리를 계산해야 해서 연산량이 크고, 트리 하나하나가 가진 해석력이라는 장점을 잃게 된다 — 어떤 트리가 어떤 예측을 했는지 파악하기 어렵다.

## 7. 코드 예시 (손글씨 숫자 분류)

```python
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

model = RandomForestClassifier(n_estimators=100, random_state=42)  # 트리 100개
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

accuracy = accuracy_score(y_test, y_pred)
print(f"Accuracy: {accuracy * 100:.2f}%")
```

같은 데이터를 SVM으로 분류했을 때보다 정확도가 다소 낮게 나왔지만(약 96.67%), 이는 SVM이 더 우월하다는 뜻은 아니다. `n_estimators`(트리 개수)는 하이퍼파라미터이므로 값을 바꿔가며(50, 100, 130, 200 등) 최적값을 탐색해야 한다.

## 💡 한 줄 요약
> 앙상블은 여러 모델을 결합해 더 정확한 예측을 만드는 전략이며, 보팅(다른 모델 + 투표)·배깅(같은 모델 + 데이터 샘플링, 대표: 랜덤 포레스트)·부스팅(순차 학습 + 오답 집중)으로 나뉜다.
