# [데이터 기초] 머신러닝 평가지표

---

## 1. 과적합과 과소적합

평가지표를 이해하기 전에 먼저 알아야 할 개념이 과적합/과소적합이다.

| 구분 | 특징 |
|---|---|
| 과적합 (Overfitting) | 학습 데이터에서는 성능이 높지만, 새로운 데이터에서는 성능이 저하됨 (복잡한 패턴까지 과하게 학습한 상태) |
| 과소적합 (Underfitting) | 중요한 패턴조차 제대로 학습하지 못해, 학습 데이터·테스트 데이터 모두에서 성능이 낮음 |

성능이 100%인 모델은 현실적으로 어렵기 때문에, 오차를 어느 정도까지 허용할 것인지 판단하는 데 평가지표가 활용된다.

## 2. 회귀 모델 평가 지표

회귀는 실제값과 예측값 사이의 **오차(error)**를 기반으로 평가한다.

| 지표 | 계산 방식 | 특징 |
|---|---|---|
| MAE (평균 절대 오차) | \|실제값-예측값\|의 평균 | 이상치에 상대적으로 덜 민감 |
| MAPE | 오차를 실제값 대비 백분율(%)로 표현 | 오차의 상대적 크기를 퍼센트로 파악하고 싶을 때 사용 |
| MSE (평균 제곱 오차) | 오차를 제곱한 값의 평균 | 오차가 클수록 더 큰 페널티를 줌, 이상치에 민감 |
| RMSE | MSE에 제곱근을 씌운 값 | 오차의 단위를 원래 데이터와 동일하게 맞춰줌, MSE보다는 이상치에 덜 민감 |
| R² (결정계수) | 모델이 설명하는 변동성의 비율 | 1에 가까울수록 데이터를 잘 설명 |

```
MAE = Σ|y - ŷ| / n
```

- MAE·MSE·RMSE는 **값이 낮을수록 좋은 모델**을 의미한다.
- MSE는 오차를 제곱하기 때문에 모든 오차가 양수로 바뀌고, 오차가 큰 값일수록 더 크게 페널티를 준다. 이상치가 많은 데이터라면 MSE보다 MAE가 더 적합할 수 있다.
- R²는 전체 변동성(SST) 중 모델이 설명하는 부분의 비율로, 1에 가까울수록 모델이 데이터를 잘 설명한다는 뜻이다.

## 3. 분류 모델 평가 지표

분류는 예측 결과와 실제 정답이 얼마나 일치하는지를 기반으로 평가하며, **오차행렬(Confusion Matrix)**에서 출발한다.

| | 예측: Negative | 예측: Positive |
|---|---|---|
| **실제: Negative** | TN (True Negative) | FP (False Positive) |
| **실제: Positive** | FN (False Negative) | TP (True Positive) |

> 이름 규칙: 뒤쪽 단어(Positive/Negative)는 **모델이 예측한 값**, 앞쪽 단어(True/False)는 **그 예측이 실제로 맞았는지 여부**를 의미한다.

**정확도(Accuracy)** = 전체 샘플 중 모델이 맞춘 비율. 다만 데이터가 불균형한 경우 위험할 수 있다.

> 예: 환자를 판별하는 문제에서 데이터의 99%가 건강한 사람이라면, 무조건 "건강하다"고만 예측해도 정확도 99%가 나올 수 있다. 즉 정확도 하나만으로 모델을 판단하는 것은 위험할 수 있다.

이를 보완하는 지표가 **정밀도(Precision)**와 **재현율(Recall)**이다.

| 지표 | 계산 | 의미 | 중요하게 보는 상황 |
|---|---|---|---|
| 정밀도 (Precision) | TP / (TP+FP) | 참이라고 예측한 것 중 실제로 참인 비율 | 스팸 필터링 (정상 메일을 스팸으로 잘못 분류하면 안 됨) |
| 재현율 (Recall) | TP / (TP+FN) | 실제 참인 것 중 모델이 맞게 찾아낸 비율 | 암 진단 (실제 환자를 놓치면 안 됨) |

정밀도와 재현율은 **트레이드오프(Trade-off) 관계**에 있다. 정밀도를 높이면 재현율이 낮아지고, 재현율을 높이면 정밀도가 낮아지는 경향을 보인다 (Threshold 값을 조정하며 균형을 맞춘다).

이 둘의 균형을 하나의 숫자로 나타낸 것이 **F1-Score**(정밀도와 재현율의 조합 평균)다. 정밀도·재현율 중 하나라도 낮으면 F1-Score도 크게 낮아지도록 설계되어 있어, 어느 한쪽으로 치우치지 않는 성능을 보고 싶을 때 유용하다.

## 4. ROC Curve와 AUC

Threshold를 하나로 고정하지 않고 계속 바꿔가면서 모델의 성능이 전체적으로 어떻게 변하는지 보여주는 것이 **ROC Curve**다.

- X축: FPR (False Positive Rate, 실제 Negative인데 잘못 Positive로 예측한 비율) → 낮을수록 좋음
- Y축: TPR (True Positive Rate = Recall) → 높을수록 좋음
- 곡선이 왼쪽 위(좌상단)로 많이 휘어질수록 좋은 모델

**AUC(Area Under Curve)**는 이 곡선 아래의 면적을 수치화한 것으로, 1에 가까울수록 성능이 우수한 모델이다. (참고: FPR과 TPR이 각각 50:50 수준이라면, 이는 무작위로 찍는 것과 크게 다르지 않은 모델이라는 의미다.)

## 💡 한 줄 요약
> 회귀는 오차 기반 지표(MAE·MSE·RMSE·R²)로, 분류는 정확도·정밀도·재현율·F1·ROC-AUC로 평가하며, 특히 데이터가 불균형할 때는 정확도 하나만으로 판단하지 않는 것이 중요하다.
