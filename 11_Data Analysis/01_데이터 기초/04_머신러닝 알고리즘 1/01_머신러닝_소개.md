# [데이터 기초] 머신러닝 소개

---

## 1. 머신러닝이란?

머신러닝(기계학습)은 컴퓨터가 명시적으로 프로그래밍되지 않아도 스스로 학습할 수 있는 능력을 부여하는 학문이다. 핵심은 **사람이 규칙(rule)을 직접 만드는 것이 아니라, 데이터로부터 규칙을 학습**한다는 점이다. 기존의 if-else 기반 규칙 프로그래밍과 달리, 데이터를 주면 모델이 스스로 패턴을 찾아 문제를 해결해나간다.

톰 미첼(Tom Mitchell)은 이를 조금 더 형식적으로 정의했다.

> 어떤 작업(Task, T)에 대한 성능 척도(Performance, P)가 경험(Experience, E)을 통해 향상된다면, 이 프로그램은 학습을 한다고 할 수 있다.

| 요소 | 의미 | 예시 |
|---|---|---|
| E (Experience) | 데이터, 과거의 기록 | 과거 주택 거래 데이터 |
| T (Task) | 해결하고자 하는 문제 | 주택 가격 예측 |
| P (Performance) | 성능을 판단하는 척도 | 예측 오차 |

## 2. 피처(Feature)와 데이터 구조

정형 데이터에서 하나의 컬럼을 **피처(Feature)**라고 부른다. 머신러닝에서는 모델 못지않게 **어떤 피처를 쓰는가**가 중요하다.

- 여러 개의 피처(x1, x2, x3 ...)가 모여 하나의 입력 벡터를 구성한다.
- 각 행(row)은 피처의 인스턴스(값 쌍) 하나에 해당한다.
- 입력을 기반으로 나온 출력값은 실제 정답이 아니라 예측값이므로 **ŷ (y-hat)**로 표기한다. (전체 데이터인 모집단을 예측하기 위한 표본이라는 통계 개념과 이어진다.)

## 3. 피처 엔지니어링(Feature Engineering)

원본 데이터는 모델이 바로 이해하기 좋은 형태가 아닐 수 있다. 좋은 피처를 만들면 굳이 복잡한 모델을 쓰지 않아도 가벼운 모델로 높은 성능을 낼 수 있다.

**① 피처 선택 (Feature Selection)**

중요한 변수만 남기고 불필요한 변수를 제거하는 방법. 불필요한 변수가 많으면 오히려 모델이 헷갈려 성능이 떨어질 수 있고, 변수를 줄이면 연산 속도와 해석력도 좋아진다.

- 상관계수를 확인해 관련성이 낮은 변수를 제외
- 분산이 작은 피처 제거 (값의 변화가 거의 없으면 예측에 기여도가 낮을 가능성이 큼)
- RFE(Recursive Feature Elimination): 결과를 반복적으로 확인하면서 덜 중요한 변수를 하나씩 제거해나가는 방식

**② 피처 생성 (Feature Creation)**

기존 데이터의 의미를 확장해 새로운 변수를 만드는 방법.

- 예: 날짜 데이터 → 주말/평일, 계절 정보로 확장하면 날짜 자체보다 더 많은 정보를 줄 수 있음
- 예: 가격 × 판매량 → "매출"이라는 새로운 피처를 생성

**③ 피처 변환 (Feature Transformation)**

데이터의 형태나 분포를 모델이 학습하기 좋게 조정하는 것.

| 방법 | 내용 |
|---|---|
| 정규화 (Normalization) | 값의 범위를 0~1로 조정. 피처마다 값의 스케일이 다르면 결과에 불필요한 영향을 줄 수 있어 사용 |
| 표준화 (Standardization) | 평균을 0, 표준편차를 1로 조정 (Z-score, 표준정규분포와 연결되는 개념) |
| 로그 변환 (Log Transform) | 한쪽으로 치우친 분포를 정규분포에 가깝게 완화. 값의 영향력 자체를 줄여줌 (예: log₁₀(10)=1, log₁₀(100)=2 → 10배 차이가 1의 차이로 축소) |

**④ 범주형 인코딩 (Categorical Encoding)**

문자형·범주형 데이터를 숫자로 변환해 모델이 이해할 수 있도록 만드는 과정.

| 방법 | 방식 | 특징 |
|---|---|---|
| 원-핫 인코딩 (One-hot) | Red=(1,0,0), Blue=(0,1,0), Green=(0,0,1) | 카테고리 간 순서·크기 관계가 없을 때 사용. 카테고리 개수만큼 차원이 늘어남 |
| 라벨 인코딩 (Label) | Red=1, Blue=2, Green=3 | 차원은 늘지 않지만, 숫자의 크기가 실제로는 없는 의미(순서·크기)로 잘못 해석될 위험이 있음 |

**⑤ 결측치·이상치 처리**

- 결측치: 삭제, 대체(imputation), 혹은 예측 모델로 결측치 자체를 추정. 정확도는 올라가지만 계산 비용이 늘어나므로 상황에 맞게 선택
- 이상치: Z-score, IQR 등으로 데이터가 얼마나 벗어나 있는지 판단. 로그 변환은 이상치를 제거하진 않지만 그 영향력을 줄여주는 방법으로 활용 가능

## 4. 학습 방식에 따른 머신러닝의 분류

머신러닝은 학습 방식에 따라 크게 세 가지로 나뉜다. 다만 실제로는 이 세 가지가 명확히 분리되기보다 하나의 시스템 안에서 복합적으로 함께 쓰이는 경우가 많다.

| 종류 | 정답(label) | 핵심 아이디어 | 예시 |
|---|---|---|---|
| 지도학습 (Supervised) | 있음 | 정답과 예측의 차이를 줄여가며 학습 | 평방피트로 집값 예측 |
| 비지도학습 (Unsupervised) | 없음 | 데이터가 가진 구조·패턴을 스스로 발견 | 유전자 클러스터링 |
| 강화학습 (Reinforcement) | 없음 (보상으로 대체) | 행동에 대한 보상을 바탕으로 전략을 개선 | 알파고 vs 이세돌 |

**지도학습**은 입력 x와 정답 y가 쌍으로 주어진다. 입력 변수가 여러 개면 x는 벡터(x1, x2, ...)로 표현되며, 이 경우 입력 공간의 차원이 높아질 뿐 여전히 하나의 목표값을 예측하는 구조는 동일하다. 차원이 지나치게 커지면 피처 선택이나 차원 축소가 필요할 수 있다.

**비지도학습**은 라벨 없이 데이터만 주어지고, 모델이 스스로 구조나 패턴을 찾는다. 대표적으로 **군집화(Clustering)**가 있으며, 유전자 데이터를 주고 "몇 개의 군집으로 나눠봐"라고 하면 비슷한 유전자들끼리 스스로 패턴을 파악해 여러 개의 클러스터로 분류해내는 사례가 있다.

**자기지도학습(Self-supervised Learning)**은 지도학습과 비지도학습 사이에 있는 개념으로, 사람이 정답을 직접 주는 게 아니라 데이터 자체에서 스스로 정답을 만들어 학습한다.

- GPT의 사전학습: 대규모 말뭉치(corpus)에서 "다음 단어가 무엇일지" 예측하도록 학습 → 정답을 사람이 준 게 아니라 문장 안에서 자동으로 만들어짐
- BERT의 NSP(Next Sentence Prediction): 두 문장이 실제로 이어지는 문장인지 아닌지를 판단하는 과제로 학습

**강화학습**은 순차적인 의사결정을 내릴 수 있도록 학습하는 방식으로, 정답이 정해져 있다기보다 스스로 데이터를 수집하며 배운다.

- **에이전트(Agent)**: 행동을 수행하는 주체 (예: 알파고)
- **환경(Environment)**: 에이전트의 행동에 반응하고 보상을 주는 대상 (예: 바둑판과 규칙)
- 에이전트가 행동(Action)을 하면 환경이 그 결과에 대한 보상(Reward)을 주고, 에이전트는 이를 바탕으로 다음 행동을 점점 더 개선해나간다.

```
        행동(Action)
에이전트(Agent) ───────────→ 환경(Environment)
      ↑                              │
      └────────── 보상(Reward) ───────┘
```

대표적 사례가 알파고와 이세돌의 바둑 대국이다.

## 💡 한 줄 요약
> 머신러닝은 데이터로부터 규칙을 스스로 학습하는 것이며, 좋은 피처를 설계하는 것과 학습 방식(지도·비지도·강화학습)의 차이를 이해하는 것이 그 출발점이다.
