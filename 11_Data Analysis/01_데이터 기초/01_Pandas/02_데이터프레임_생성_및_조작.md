## 1. 파일로 데이터 불러오기·저장하기

정형 데이터를 다룰 때는 직접 선언하기보다 파일이나 DB에서 불러오는 경우가 대부분이다.

```python
titanic = pd.read_csv("titanic.csv")   # CSV 파일 읽기
# read_json(), read_excel() 등도 동일한 방식으로 사용

titanic.to_csv("titanic_new.csv")      # 다시 파일로 저장
```

## 2. 데이터 훑어보기 — 기본 확인 메서드

| 메서드 | 설명 |
|---|---|
| `head(n)` | 앞에서부터 n개 행 출력 (기본값 5) |
| `tail(n)` | 뒤에서부터 n개 행 출력 (기본값 5) |
| `sample(n)` | 무작위로 n개 행 추출 (실행할 때마다 결과가 달라짐) |
| `shape` | (행 개수, 열 개수) 튜플 반환 |
| `info()` | 컬럼명, 데이터 타입, 결측치 개수(non-null count), 전체 데이터 개수를 한눈에 확인 |
| `describe()` | 수치형 컬럼의 요약 통계(개수·평균·표준편차·사분위수) 제공. 문자형 컬럼은 표시되지 않음 |
| `value_counts()` | 범주형 컬럼에서 각 값이 몇 건씩 있는지 확인 |

```python
titanic.head()                   # 상위 5개 행
titanic.info()                   # 컬럼별 결측치·타입 확인
titanic['Age'].describe()        # 특정 컬럼만 통계 확인
titanic['Pclass'].value_counts() # 등급별 인원수
```

> **`info()`에서 object 타입이 자주 보이는 이유** — 문자열처럼 명확한 타입 판단이 어려운 컬럼은 기본적으로 object로 표시된다. 이 상태에서는 NumPy 기반의 통일된 연산(브로드캐스트)이 어려워지므로, 가능하면 datetime·category 등 구체적인 타입을 명시해주는 것이 성능상 유리하다.

## 3. 컬럼·행 추가 및 삭제

**새 컬럼 추가** — 딕셔너리에 값을 넣듯 선언하면 자동으로 컬럼이 생성되고, 값을 하나만 넣어도 기존 행 개수만큼 브로드캐스트되어 채워진다.

```python
titanic['AgeNew'] = 0   # 모든 행에 0이 채워진 새 컬럼 생성
```

**행/열 삭제 — `drop()`**

```python
DataFrame.drop(labels=None, axis=0, index=None, columns=None, inplace=False)
```

- `axis=0`(기본값): 행 삭제 / `axis=1`: 열 삭제 — DataFrame이 2차원으로 고정되어 있어 이 값은 사실상 암기해도 무방하다.
- `inplace=True`는 원본에 바로 반영하지만, 내부적으로 복사 후 재대입하는 방식이라 메모리·성능 이점이 없어 권장되지 않는다. **재할당(`df = df.drop(...)`) 방식이 권장된다.**

```python
df = df.drop('Age', axis=1)              # 컬럼 삭제 (권장 방식)
df.drop([0, 1, 2], axis=0, inplace=True) # 행 삭제 (인덱스 기준)
```

## 4. 조건으로 데이터 선택하기

### 불리언 인덱싱 (조건 필터링)

컬럼에 조건을 걸면 각 행에 대해 True/False가 계산되고, True인 행만 걸러진다.

```python
titanic[titanic['Age'] >= 30]            # 30세 이상만 필터링
titanic[titanic['Pclass'].isin([2, 3])]  # 여러 값 중 하나라도 해당하면 필터링
titanic[titanic['Age'].notna()]          # 결측치가 아닌 행만 필터링
```

### loc과 iloc — 이름 기반 vs 위치 기반

| 구분 | 기준 | 예시 |
|---|---|---|
| `loc` | 라벨(이름) 기반 | `df.loc[5, 'Pclass']` — 인덱스 5, 'Pclass' 컬럼 |
| `iloc` | 정수 위치 기반 | `df.iloc[0, 1]` — 첫 번째 행, 두 번째 열 |

```python
df['Age']                              # 단일 컬럼 → Series 반환
df[['Age']]                            # 리스트로 감싸면 → DataFrame 반환
df.loc[5, 'Pclass']                    # 단일 값 → 스칼라 반환
df.loc[5:7, ['Name', 'Age']]           # 범위 지정 → 여러 행·컬럼
df.iloc[0, 1]                          # 위치 기반 단일 값
df.loc[titanic['Age'] >= 60, 'Name']   # 조건 필터링 + 컬럼 선택 결합
```

> loc은 커스터마이징한 인덱스명이 있을 때 그 이름으로 조회하고, iloc은 인덱스명과 무관하게 항상 0부터 시작하는 위치로 조회한다는 차이를 기억해두면 헷갈리지 않는다.
