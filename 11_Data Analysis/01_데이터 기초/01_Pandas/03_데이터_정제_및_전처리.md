# [데이터 기초] 데이터 정제 및 전처리

---

## 1. 데이터 전처리가 필요한 이유

실제로 수집된 데이터는 대부분 바로 분석에 사용할 수 있는 깨끗한 상태가 아니다. 결측치, 이상치, 형식이 제각각인 값 등 문제가 섞여 있는 경우가 많다.

전처리(정제)는 이런 문제를 정리해서, 분석이나 머신러닝/딥러닝 모델링에 알맞은 형태로 데이터를 가공하는 과정이다. **전처리를 어떻게 하느냐에 따라 이후 분석 결과의 질이 크게 달라질 수 있다.**

## 2. 전처리의 주요 유형

| 유형 | 설명 | 예시 |
|---|---|---|
| **형식 통일** | 제각각인 데이터 형식을 하나로 맞춤 | 생년월일 표기가 여러 방식으로 섞여 있을 때 연-월-일 형식으로 통일 |
| **빈칸(결측치) 채우기** | 비어있는 값을 채움 | 범주형은 최빈값, 수치형은 평균값 등 — 근거 있는 값으로 채우는 것이 중요 |
| **파생 변수 생성 (피처 엔지니어링)** | 기존 데이터를 계산해 새로운 의미 있는 컬럼을 만듦 | 여러 컬럼의 영향력을 하나로 압축한 새 변수 생성 |
| **이상치 제거** | 통계적으로 존재할 수 없는 값을 제거 | 성별 코드가 1·2 외의 값, 키가 250m로 기록된 경우 등 |

## 3. 결측치 확인하기

```python
titanic.isna()               # 값이 NaN이면 True, 아니면 False 반환 (isnull()도 동일)
titanic.notna()               # NaN이 아닌 경우 True 반환
titanic.isna().sum()          # 컬럼별 결측치 개수 집계 — 가장 많이 쓰는 확인 방법
titanic['Age'].isna().sum()   # 특정 컬럼만 결측치 개수 확인
```

> Pandas에서는 `null`이라는 표현 대신 `NaN`(Not a Number)이라는 용어를 사용하므로, `isna()` / `notna()`처럼 na가 붙은 이름을 사용하는 것이 관례에 맞다.

## 4. 결측치 제거하기 — `dropna()`

```python
titanic.dropna()                                        # 결측치가 있는 행 전체 제거
titanic.dropna(subset=['Embarked'])                      # 특정 컬럼(Embarked) 기준으로만 결측치 제거
titanic.dropna(subset=['Age', 'Embarked'], how='any')     # 지정한 컬럼 중 하나라도 NaN이면 제거
```

- `subset`: 결측치 여부를 판단할 컬럼을 지정
- `how='any'`: 지정한 컬럼 중 하나라도 NaN이면 해당 행 제거

## 5. 결측치 채우기 — `fillna()`

단순히 임의의 값이 아니라, **근거 있는 값**으로 채우는 것이 중요하다. 예를 들어 범주형 컬럼은 최빈값(가장 많이 등장한 값)으로 채우는 방법을 쓸 수 있다.

```python
mode_value = titanic['Embarked'].value_counts().idxmax()   # 가장 많이 등장한 값 찾기
titanic['Embarked'] = titanic['Embarked'].fillna(mode_value)  # 최빈값으로 결측치 채우기
```

- `value_counts()`로 각 값의 빈도를 확인한 뒤, `idxmax()`로 그중 가장 큰 값의 인덱스(=최빈값)를 가져온다.

## 💡 한 줄 요약
> 실제 데이터는 결측치·이상치가 섞여 있기 마련이므로, isna/notna로 결측 여부를 확인하고 dropna(제거) 또는 fillna(근거 있는 값으로 채움)를 상황에 맞게 선택해 전처리하는 과정이 분석 품질을 좌우한다.
