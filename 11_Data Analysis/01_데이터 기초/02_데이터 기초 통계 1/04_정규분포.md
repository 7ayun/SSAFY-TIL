## 1. 정규분포란

**정규분포(Normal Distribution)**, 다른 말로 **가우시안 분포(Gaussian Distribution)** 는 평균을 중심으로 완전히 좌우 대칭을 이루는 종(bell) 모양의 분포다.

- 분포의 모양은 **평균(μ)** 과 **표준편차(σ)** 로 정확히 결정된다.
- 평균이 바뀌면 분포의 중심이 이동하고, 표준편차가 바뀌면 폭이 넓어지거나 좁아진다.
- 평균과 표준편차가 같으면 데이터가 달라도 동일한 모양의 분포를 갖는다.
- 사람의 키·몸무게·시험 점수처럼 자연스럽게 변동이 생기는 데이터, 그리고 여러 자연 현상·금융 데이터에서 현실적으로 가장 흔하게 나타나는 분포다.

## 2. 68-95-99.7 규칙

정규분포가 통계에서 자주 쓰이는 이유는 데이터의 퍼짐을 곧바로 확률로 해석할 수 있기 때문이다. 곡선 아래 전체 면적을 1(=100%)이라고 할 때, 평균으로부터 표준편차 몇 배 안에 데이터가 들어오는지는 아래와 같이 정해져 있다.

| 구간 | 데이터가 포함될 확률 |
|---|---|
| 평균 ± 1σ | 약 68.3% |
| 평균 ± 2σ | 약 95.4% |
| 평균 ± 3σ | 약 99.7% |

평균에서 멀어질수록 곡선의 높이가 낮아지고, 그 값이 나타날 확률도 함께 작아진다. 즉 표준편차는 "평균으로부터의 거리"이자 동시에 "그 값이 얼마나 드문 값인가"를 의미하는 척도로 볼 수 있다.

## 3. 표준정규분포와 Z-score

정규분포는 데이터마다 평균과 표준편차가 다르기 때문에, 매번 다른 분포에 대해 확률을 따로 계산해야 하는 번거로움이 있다. 이를 해결하기 위해 모든 정규분포를 **평균 0, 표준편차 1**인 하나의 분포로 통일해서 다루는데, 이를 **표준정규분포(Standard Normal Distribution)** 라고 한다.

원래 값을 표준정규분포 상의 값으로 변환하는 과정을 **표준화(Z-score)** 라고 하며, 공식은 다음과 같다.

```
z = (x - μ) / σ
```

- `x`: 원래 값
- `μ`: 평균
- `σ`: 표준편차

표준화를 해두면 서로 다른 정규분포를 하나의 기준으로 비교·분석할 수 있다. (머신러닝에서의 표준화(standardization)와도 같은 개념으로 이어진다.)

## 4. 코드로 확인하는 정규분포

```python
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt

# 평균 0, 표준편차 1인 표준정규분포를 따르는 난수 1000개 생성
data = np.random.normal(loc=0, scale=1, size=1000)

# 히스토그램 + 밀도 곡선(KDE)을 함께 그려서 확인
sns.histplot(data, kde=True)
plt.show()
```

- `np.random.normal()`은 이론적인 정규분포에 근거해 데이터를 무작위로 생성하므로, 실행할 때마다 정확히 같은 모양은 아니지만 전반적으로 종 모양에 가까운 데이터가 만들어진다.
- `seaborn`의 `histplot()`에서 `kde=True` 옵션을 주면 히스토그램과 함께 밀도 곡선도 같이 그려준다.

## 5. QQ-plot으로 정규성 확인하기

실제 데이터가 정규분포를 따르는지 눈으로 간단히 확인할 수 있는 방법이 **QQ-plot**이다.

- X축은 이론적인 정규분포, Y축은 Z-score로 표준화한 실제 데이터의 분위수를 나타낸다.
- 점들이 대각선(직선) 위에 가까이 나열되어 있으면 정규분포에 가깝다고 판단하고, 특정 구간에서 크게 벗어나 있으면 정규분포가 아닐 가능성이 높다.

```python
import numpy as np
import scipy.stats as stats
import matplotlib.pyplot as plt

data = np.random.normal(loc=0, scale=1, size=1000)
stats.probplot(data, dist="norm", plot=plt)
plt.show()
```

- `scipy.stats`는 파이썬에서 통계적인 모델을 제공하는 대표적인 라이브러리이며, `probplot()`을 사용하면 자동으로 QQ-plot을 그려준다.
- 다만 QQ-plot은 시각적으로 대략적인 형태를 파악하는 용도이며, 정규성을 명확하게 판별하려면 별도의 정규성 검정(모수적/비모수적 방식)이 필요하다.

## 6. 중심극한정리 (Central Limit Theorem, CLT)

실제 데이터가 정규분포인지 아닌지 확신할 수 없는 경우가 대부분인데도 정규분포를 기반으로 분석하는 경우가 많은 이유는 **중심극한정리** 때문이다.

> **모집단의 분포가 어떤 모양이든 상관없이, 충분히 큰 크기의 표본을 여러 번 추출해서 그 평균을 계산하면, 표본평균의 분포는 정규분포에 가까워진다.**

즉, 모집단 자체가 한쪽으로 치우쳤거나 불규칙한 분포를 가지고 있어도, 표본평균들을 모아서 만든 분포는 표본 크기(n)가 커질수록 정규분포에 근사한다. (앞서 본 펭귄 데이터셋의 표본평균 분포가 바로 이 예시였다.)

**활용 사례 — 주식 수익률**: 어떤 회사의 하루 수익률은 들쭉날쭉해서 정규분포를 따르지 않는다. 하지만 30일간의 평균 수익률을 여러 번 구하면, 그 평균값들은 정규분포를 따르게 되어 확률 계산과 리스크 평가에 활용할 수 있다.

## 7. 코드로 확인하는 중심극한정리

```python
import numpy as np
import matplotlib.pyplot as plt

# 지수분포(exponential distribution)처럼 비대칭적인 분포를 따르는 모집단 가정
population = np.random.exponential(scale=1.0, size=100000)

# 표본을 여러 번 뽑아 평균을 계산 (표본 크기와 반복 횟수를 늘릴수록 정규분포에 가까워짐)
sample_means = [
    np.random.choice(population, size=30, replace=False).mean()
    for _ in range(1000)
]

plt.hist(sample_means, bins=30)
plt.show()
```

지수분포는 원래 한쪽으로 치우친 비대칭 분포이지만, 표본을 충분히 큰 크기로 여러 번 뽑아 평균을 구하면 그 표본평균들의 분포는 정규분포에 가까운 종 모양으로 수렴한다. 표본 크기와 반복 횟수가 커질수록 이 경향은 더 뚜렷해진다.
