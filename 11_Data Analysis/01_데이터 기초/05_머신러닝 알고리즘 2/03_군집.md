## 1. 군집(Clustering)이란?

군집 분석은 **비슷한 특성을 가진 데이터를 자동으로 그룹화하는 비지도 학습** 기법이다. 지금까지 다룬 KNN 등은 정답(라벨)이 있는 지도학습이었지만, 군집화는 라벨 없이 데이터 내에 존재하는 구조와 패턴을 스스로 찾아 그룹으로 묶는다는 점이 결정적으로 다르다.

- 활용 분야: 마케팅 세분화, 이상치 탐지, 추천 시스템 등 정답이 없는 문제에 주로 사용된다.

## 2. Cluster 간 거리 계산 방법

군집화의 핵심은 **군집 간의 거리를 어떤 기준으로 정의할 것인가**이다. 데이터의 특성과 분석 목적에 따라 아래 5가지 방법 중 적절한 것을 선택해야 한다.

| 연결법 | 거리 정의 | 특징 |
|---|---|---|
| 단일 연결법 (Single linkage) | 각 군집에서 가장 가까운 두 점 사이의 거리(최단 거리) | 군집 간 거리를 짧게 보는 경향 → 가늘고 긴 형태의 군집 생성 |
| 완전 연결법 (Complete linkage) | 각 군집에서 가장 먼 두 점 사이의 거리(최장 거리) | 군집 간 간격을 넓게 유지 → 덩어리(뭉친) 형태의 군집 생성 |
| 평균 연결법 (Average linkage) | 두 군집의 모든 점 쌍 사이 거리의 평균 | 전체 거리 분포를 고려해 비교적 균형 잡힌 군집 생성 |
| 중심 연결법 (Centroid linkage) | 각 군집 중심점(Centroid) 간의 거리 | 직관적이고 빠르지만, 데이터가 추가되면 중심점이 바뀌어 군집이 왜곡될 수 있음 |
| Ward 연결법 (Ward linkage) | 군집을 합쳤을 때 (중심점-데이터 거리)²의 합이 최소가 되는 조합을 선택 | 군집 내 데이터가 퍼지지 않도록(응집도 최대화) 유지 → 균일한 형태의 군집 생성 |

## 3. K-평균(K-means) 알고리즘

K-평균은 가장 대표적인 군집화 알고리즘이다. 사용자가 지정한 K개의 군집 중심점을 초기화한 뒤, 아래 과정을 반복해 군집을 만든다.

1. 사용자가 지정한 K개의 중심점을 임의로 초기화한다.
2. 각 데이터 포인트를 가장 가까운 중심점에 할당한다.
3. 할당된 데이터들을 기준으로 중심점의 위치를 다시 계산(평균)한다.
4. 중심점이 더 이상 거의 변하지 않을 때까지 2~3을 반복한다.

> 예: 데이터 A~E와 중심점 2개로 시작 → A, B는 중심점1에, C, D, E는 중심점2에 할당 → 각 그룹의 평균 위치로 중심점 이동 → 재할당 시 C가 더 가까운 중심점1로 옮겨감 → 중심점이 다시 이동 → 더 이상 변화가 없으면 종료.

- 장점: 간단하고 빠르다.
- 단점: 군집의 개수(K)를 사용자가 사전에 직접 지정해야 한다.

## 4. 코드 예시 (Iris 데이터셋)

```python
from sklearn.cluster import KMeans
from sklearn.datasets import load_iris
import pandas as pd

data = load_iris()
X = data.data  # 원래 라벨은 사용하지 않음 (비지도 학습)

kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
y_kmeans = kmeans.fit_predict(X)  # 학습과 동시에 각 데이터의 군집 라벨 반환

df = pd.DataFrame(X, columns=data.feature_names)
df['Cluster'] = y_kmeans
```

- `fit_predict()`는 학습과 동시에 각 데이터가 속한 군집 라벨을 반환한다.
- 실습에서는 원래 라벨이 있는 Iris 데이터(클래스 3개)를 활용해, 군집화 결과가 실제 클래스와 얼마나 맞아떨어지는지 검증했다. 새로운 데이터 포인트 3개를 입력했을 때도 각각 가까운 군집으로 올바르게 분류되는 것을 확인할 수 있었다.
- K값만 지정하면 scikit-learn으로 간단하게 구현할 수 있다.

## 💡 한 줄 요약
> 군집화는 라벨 없이 비슷한 데이터를 자동으로 그룹화하는 비지도 학습이며, 군집 간 거리 정의 방식(단일/완전/평균/중심/Ward)과 K-means 알고리즘이 핵심이다.
