## 1. 통계적 검정이 필요한 이유와 유의성 검정

데이터를 분석하지 않고 직관이나 경험만으로 의사결정을 내리면, 겉보기엔 그럴듯해도 실제로는 잘못된 결론을 내릴 위험이 있다.

> **예시** — 새로운 광고 A의 전환율이 3.4%, 기존 광고 B가 3.1%로 나왔다. 전환율이 올라간 것처럼 보이지만, 이 차이가 정말 광고 효과 때문인지 아니면 우연히 그렇게 나온 것인지는 별도로 판단해야 한다.

이렇게 데이터 기반으로 비교·검증하는 과정이 **통계적 실험**이며, 신약 개발의 임상 실험이나 마케팅의 A/B 테스트가 대표적인 예다.

**유의성 검정(Significance Testing)**이란 우리가 관측한 차이가 우연히 발생했을 확률을 계산하는 과정이다.

> **신약 개발 예시** — 기존 약의 평균 회복일수는 5.2일(표준편차 ±1.5일), 신약은 4.9일(표준편차 ±1.4일)이다. 단순 평균 비교로는 0.3일 줄어든 것처럼 보이지만, 표준편차가 꽤 큰 편이라 개인별 회복일수 편차가 크다. 이 0.3일의 차이가 통계적으로 의미가 있는지는 유의성 검정을 거쳐야 판단할 수 있다.

뒤에서 다룰 p-value가 0.05보다 작으면 "우연이 아닐 확률이 높다" → 통계적으로 유의미하다고 판단한다.

## 2. 가설 설정 — 귀무가설과 대립가설

가설(Hypothesis)이란 특정한 주장을 검증하기 위한 가정이다. 통계적 검정의 핵심은 "이 가설이 맞는지 아닌지 검증하는 과정"이며, 보통 두 가지 가설을 세운다.

| 가설 | 표기 | 의미 |
|---|---|---|
| 귀무가설 (Null Hypothesis) | H₀ | "차이가 없다" 또는 "효과가 없다"는 기본 가설 |
| 대립가설 (Alternative Hypothesis) | H₁ | "차이가 있다" 또는 "효과가 있다"는, 검증하고 싶은 가설 |

**예시**

| 상황 | 귀무가설(H₀) | 대립가설(H₁) |
|---|---|---|
| 신약 개발 | 신약이 기존 약과 효과 차이가 없다 | 신약이 기존 약보다 효과가 더 좋다 |
| A/B 테스트 | 기존/새 웹사이트의 클릭률이 차이가 없다 | 새 웹사이트가 클릭률이 더 높다 |
| 교통 연구 | 특정 지역 승용차 이용률이 다른 지역과 차이가 없다 | 특정 지역 승용차 이용률이 다른 지역과 다르다 |

검정 결과 귀무가설이 **기각되면 대립가설을 채택**한다고 표현한다. 반대로 귀무가설을 기각하지 못했다고 해서 귀무가설이 참이라고 증명된 것은 아니다 — 대립가설이 옳다고 말할 만큼 충분한 근거를 찾지 못했다는 의미로, 이때는 "귀무가설을 기각하지 못한다"라고 표현한다.

## 3. 신뢰구간 (Confidence Interval)

신뢰구간(CI)은 표본에서 얻은 평균을 바탕으로, **모집단의 참된 평균(모수)이 포함될 것으로 예상되는 값의 범위**다. 모집단 전체를 알 수 없기 때문에 표본을 근거로 이 범위를 추정한다. 보통 95% 또는 99% 신뢰수준을 사용한다.

> **예시 (95% 신뢰구간)** — "새로운 마케팅 전략이 고객 구매율을 평균 2~5% 증가시킬 것이다"라고 분석되었다면, 95% 확신을 가지고 "구매율 증가 범위는 2~5% 사이"라고 말할 수 있다는 뜻이다.
>
> 이는 "95% 확률로 정답"이라는 의미가 아니라, **같은 방식으로 표본을 반복해서 뽑았을 때 약 95%의 경우 실제 모수가 그 구간 안에 포함된다**는 의미로 이해해야 한다.

**신뢰구간과 가설 검정의 관계**
- 신뢰구간이 **0을 포함하지 않으면** → 차이가 유의미하다고 판단 (예: [2%, 5%])
- 신뢰구간이 **0을 포함하면** → 차이가 유의미하지 않다고 판단 (예: [-1%, 3%])

## 4. 유의수준(α)과 1종·2종 오류

**유의수준(α)**은 우리가 허용할 "우연한 결과"의 최대 확률을 의미하며, 보통 0.05(5%) 또는 0.01(1%)을 사용한다. α=0.05는 "5%의 확률로 우연한 결과를 허용하겠다"는 뜻이다.

| 판단 \ 실제 | H₀가 참일 때 | H₀가 거짓일 때 |
|---|---|---|
| H₀ 기각 안 함 | 옳은 결정 | 제2종 과오 |
| H₀ 기각 | 제1종 과오 | 옳은 결정 |

- **1종 오류**: 실제로는 차이가 없는데 있다고 잘못 판단 — 유의수준 α로 이 오류를 제한한다.
- **2종 오류**: 실제로는 차이가 있는데 없다고 잘못 판단.
- 유의수준을 낮출수록(α=0.01) 검정은 더 엄격해지지만, 2종 오류의 위험은 증가한다.

> **어떤 오류를 더 조심해야 할까?** 무엇이 더 치명적인지에 따라 기준이 달라진다.
> - 백신처럼 **안정성이 중요한 경우** → 잘못된 약이 나가면 안 되므로 1종 오류를 더 조심해야 한다.
> - 희귀병·난치병처럼 **대안이 없는 경우** → 효과 있는 치료제를 놓치면 환자가 기회를 잃으므로, 2종 오류를 더 조심하며 유의수준을 다소 높일 필요가 있다.

## 5. t-검정(t-test)의 개념과 p-value

**t-검정**은 두 집단의 평균 차이가 통계적으로 유의미한지를 검정하는 방법이다. 데이터가 정규성을 만족해야 하며, 표본 수가 적더라도 비교적 정확한 결과를 제공한다.

- 귀무가설(H₀): 두 집단의 평균이 같다 (차이가 없다)
- 대립가설(H₁): 두 집단의 평균이 다르다 (차이가 있다)

**t-통계량**은 두 집단의 평균 차이가 우연인지, 실제로 의미 있는 차이인지를 판단하기 위한 지표다.
```
t = 두 집단의 평균 차이 / 데이터의 퍼짐 정도  =  신호 / 잡음
```
- 평균 차이가 크면 → t ↑
- 데이터가 들쭉날쭉(표준편차 ↑)하면 → t ↓
- 표본이 많을수록 → t ↑
- **t가 클수록 두 집단이 다를 가능성이 커진다.**

**p-value**는 귀무가설이 참이라고 가정했을 때, 현재 관측된 결과보다 더 극단적인 결과가 나올 확률이다. "이 차이가 단순한 우연일 가능성이 얼마나 되는지"를 나타내며, p-value가 작을수록 우연일 가능성이 낮다는 뜻이다.

| 조건 (α=0.05) | 판단 |
|---|---|
| p-value ≤ 0.05 | 귀무가설 기각 → "차이가 유의미하다!" |
| p-value > 0.05 | 귀무가설 유지 → "차이가 우연일 가능성이 크다." |

> **예시** — 기존 약의 평균 효과 70점, 신약 75점. t-검정 수행 결과 p-value = 0.03. 이는 "귀무가설이 참이라고 가정했을 때(차이가 없다고 가정했을 때), 지금 관측한 정도이거나 그보다 극단적인 결과가 나올 확률이 3%"라는 뜻이다. 0.03 ≤ 0.05이므로 귀무가설을 기각하고, 신약의 효과가 통계적으로 유의미하다고 판단한다. (단, "97% 확률로 신약이 의미 있다"는 뜻은 아니다.)

## 6. 가설 검정 프로세스, 정규성 검정과 등분산 검정

데이터를 기반으로 통계적 결론을 도출하는 과정은 다음 순서로 진행된다.
```
데이터 수집 → 데이터 전처리 → 정규성 검정 → 가설 검정 → 결과 해석
```

| 순서 | 설명 |
|---|---|
| 1. 가설 설정 | 귀무가설(H₀)과 대립가설(H₁) 설정 |
| 2. 유의수준 결정 | 보통 α = 0.05(5%) 사용 |
| 3. 검정 통계량 계산 | t-검정, ANOVA 등 적절한 방법 선택 |
| 4. p-value 확인 | p-value < 0.05이면 귀무가설 기각 |
| 5. 결론 도출 | 가설 채택 여부 결정 |

수집한 데이터는 바로 분석에 쓰기보다, 결측치·이상치를 먼저 확인하고 **정규성 검정**을 거쳐 어떤 검정 방법(모수적 vs 비모수적)을 쓸지 정한다.

**정규성 검정(Normality Test)**은 (엄밀히는) 표본 데이터가 정규분포를 따르는 모집단에서 나왔다고 볼 수 있는지를 확인하는 과정이다.

| 방법 | 특징 |
|---|---|
| Shapiro-Wilk Test | 소규모 표본(50개 이하)에 적합, 가장 일반적으로 사용됨 |
| Kolmogorov-Smirnov Test | 정규성과 다른 분포 간 차이를 검정 |
| Anderson-Darling Test | 정규성 검정 시 민감도가 높음 |
| QQ-Plot | 정규성을 시각적으로 확인 |

**Shapiro-Wilk Test**: H₀(데이터는 정규분포를 따름) vs H₁(따르지 않음). p-value > 0.05이면 귀무가설을 유지 → 정규성을 만족한다고 판단한다.

정규성 검정 외에 **등분산 검정**도 함께 확인하면 좋다 — 두 집단의 분산이 비슷한지 보는 과정이다. 일반적인 t-검정은 두 집단의 분산이 같다는 가정을 깔고 가기 때문에, 이 가정이 성립하는지 미리 확인해두면 훨씬 신뢰할 수 있는 결과를 얻을 수 있다.

| 방법 | 특징 |
|---|---|
| Levene's Test (레빈 검정) | 가장 일반적으로 사용됨 |
| Bartlett's Test | 정규성을 가정할 때 적절 |
| Fligner-Killeen Test | 정규성을 가정하지 않아도 사용 가능 |

**Levene's Test**: H₀(두 집단의 분산이 동일 = 등분산) vs H₁(분산이 다름 = 이분산). p-value > 0.05이면 등분산으로 보고 일반 t-검정을, p-value ≤ 0.05이면 이분산으로 보고 Welch's t-test를 사용한다.

> 정규성·등분산 검정이 반드시 필수는 아니지만, 거치면 훨씬 안정적인 형태로 통계 검정을 진행할 수 있다.

## 7. 단측 검정과 양측 검정

유의성 검정에는 **단측 검정(One-tailed test)**과 **양측 검정(Two-tailed test)**이라는 유형이 있다.

| 유형 | 설명 | 가설 설정 |
|---|---|---|
| 양측 검정 | 방향을 정하지 않고 단순히 차이가 있는지만 검정 | H₀: 차이 없음 vs H₁: 차이 있음 |
| 단측 검정 | 특정 방향으로 차이가 있는지를 검정 | H₀: 한쪽 방향 아님 vs H₁: 한쪽 방향으로 차이 있음 |

예를 들어 A구와 B구의 승용차 이용률을 비교할 때, 어느 쪽이 높은지 모르는 상태에서 "차이가 있는지"만 보면 양측 검정이고, "A구가 B구보다 낮다"처럼 방향을 정해서 보면 단측 검정이다. 검정 절차 자체는 동일하지만, p-value를 해석할 때 기각역이 한쪽 끝에만 존재하게 된다는 차이가 있다.

**실습 코드 — A구/B구 승용차 이용률 비교**

```python
import numpy as np
import pandas as pd
import scipy.stats as stats
import matplotlib.pyplot as plt
import seaborn as sns
plt.rc('font', family='Malgun Gothic')  # Windows 사용자의 경우

np.random.seed(42)

# 가상의 승용차 이용률 데이터 생성 (평균 35%, 40%)
a_district = np.random.normal(loc=35, scale=5, size=30)  # A구
b_district = np.random.normal(loc=40, scale=5, size=30)  # B구

df = pd.DataFrame({'승용차 이용률': np.concatenate([a_district, b_district]),
                    '자치구': ['A구'] * 30 + ['B구'] * 30})

plt.figure(figsize=(8, 5))
sns.boxplot(x='자치구', y='승용차 이용률', data=df)
plt.title("A구와 B구의 승용차 이용률 비교")
plt.show()

# 양측 검정 (두 집단 평균 비교)
t_stat, p_value = stats.ttest_ind(a_district, b_district, equal_var=True)
print(f"양측 검정 결과: t-통계량: {t_stat:.4f}, p-value: {p_value:.4f}")
if p_value <= 0.05:
    print("귀무가설 기각 → A구와 B구의 승용차 이용률 차이가 유의미함")
else:
    print("귀무가설 유지 → 차이가 우연일 가능성이 큼")

# 단측 검정 (A구가 B구보다 작은지 검정)
t_stat, p_value_one_sided = stats.ttest_ind(a_district, b_district, alternative='less', equal_var=True)
print(f"단측 검정 결과 (A구 < B구): t-통계량: {t_stat:.4f}, p-value: {p_value_one_sided:.4f}")
if p_value_one_sided <= 0.05:
    print("귀무가설 기각 → A구의 승용차 이용률이 B구보다 유의미하게 낮음")
else:
    print("귀무가설 유지 → 차이가 우연일 가능성이 큼")
```

두 검정 모두 t-통계량 -4.5129, p-value 0.0000으로 나타나 귀무가설을 기각하며, A구의 승용차 이용률이 B구보다 유의미하게 낮다는 결론에 도달한다.

## 8. 독립표본 t-검정 실습

**독립표본 t-검정**은 서로 독립적인 두 집단의 평균을 비교할 때 사용한다. 여기서 "독립적"이라는 건 두 집단이 아예 다른 대상(관측값이 겹치지 않음)이라는 뜻이다.

**사용 목적**
- 서로 다른 집단의 평균 차이를 비교하고 싶을 때
- 두 집단이 서로 독립적이며 관측값이 중복되지 않을 때
- 데이터가 정규성을 만족할 때

**예시**: A구와 B구 주민들의 승용차 이용률 비교, 남학생과 여학생의 성적 차이 검정, 두 브랜드의 고객 서비스 만족도 비교

앞서 사용한 A구/B구 데이터에 이어서, 정규성과 등분산까지 확인한 뒤 t-검정을 수행하면 다음과 같다.

```python
# 정규성 검정 수행 (Shapiro-Wilk Test)
shapiro_a = stats.shapiro(a_district)
shapiro_b = stats.shapiro(b_district)
print(f"Shapiro-Wilk test (A구): p-value = {shapiro_a.pvalue:.4f}")
print(f"Shapiro-Wilk test (B구): p-value = {shapiro_b.pvalue:.4f}")

if shapiro_a.pvalue > 0.05 and shapiro_b.pvalue > 0.05:
    print("두 그룹 모두 정규성을 만족함")
else:
    print("정규성이 만족되지 않음, 비모수 검정 필요")

# 등분산 검정 수행 (Levene's Test)
levene_test = stats.levene(a_district, b_district)
print(f"Levene's 등분산 검정 결과: W-statistic = {levene_test.statistic:.4f}, p-value = {levene_test.pvalue:.4f}")

if levene_test.pvalue > 0.05:
    print("두 그룹의 분산이 동일함 (등분산 가정 가능)")
else:
    print("두 그룹의 분산이 다름 (이분산 가정 필요)")

# t-검정 수행 (등분산 여부에 따라 결정)
if levene_test.pvalue > 0.05:
    print("등분산을 가정한 독립표본 t-검정 수행")
    t_stat, p_value = stats.ttest_ind(a_district, b_district, equal_var=True)
else:
    print("등분산을 가정하지 않는 Welch's t-test 수행")
    t_stat, p_value = stats.ttest_ind(a_district, b_district, equal_var=False)

print(f"t-통계량 = {t_stat:.4f}, p-value = {p_value:.4f}")

if p_value < 0.05:
    print("두 집단의 평균 차이가 유의미함 (귀무가설 기각)")
else:
    print("두 집단의 평균 차이가 유의미하지 않음 (귀무가설 유지)")
```

**결과 정리**

| 분석항목 | 결과 |
|---|---|
| 검정 유형 | 독립표본 t-검정 (등분산 검정) |
| T-통계량 | -4.5129 |
| p-value | 0.0000 |
| 귀무가설(H₀) | A구와 B구의 승용차 이용률 평균 차이는 없음 |
| 대립가설(H₁) | A구와 B구의 승용차 이용률 평균 차이는 있음 |
| 기각 여부 | 기각 (p-value < 0.05) |
| 해석 | A구와 B구의 승용차 이용률 평균 차이는 유의미함 |

## 9. 대응표본(Paired) t-검정 실습

**대응표본 t-검정**은 같은 집단(개체)에서 **두 시점 또는 두 조건**의 평균 차이를 비교할 때 사용한다. 독립표본과 달리 집단 간 비교가 아니라, 같은 대상에서 일어난 변화를 분석하는 것이 핵심이다.

**예시**: 같은 지역의 교통 정책 시행 전후 승용차 평균 속도 변화, 같은 학생들의 교육 프로그램 수강 전후 성적 차이, 한 브랜드의 서비스 개선 전후 고객 만족도 차이

```python
# 정책 시행 전후의 평균 속도 데이터 생성
before_policy = np.random.normal(loc=50, scale=5, size=30)  # 시행 전 평균 속도 50km/h
after_policy = before_policy + np.random.normal(loc=-3, scale=2, size=30)  # 시행 후 속도 감소

df_paired = pd.DataFrame({'속도': np.concatenate([before_policy, after_policy]),
                           '시점': ['정책 시행 전'] * 30 + ['정책 시행 후'] * 30})

plt.figure(figsize=(8, 5))
sns.boxplot(x='시점', y='속도', data=df_paired)
plt.title("정책 시행 전후 승용차 속도 비교")
plt.show()

# 정규성 검정
shapiro_before = stats.shapiro(before_policy)
shapiro_after = stats.shapiro(after_policy)
print(f"Shapiro-Wilk test (정책 시행 전): p-value = {shapiro_before.pvalue:.4f}")
print(f"Shapiro-Wilk test (정책 시행 후): p-value = {shapiro_after.pvalue:.4f}")

# 대응표본 t-검정 (독립표본과 달리 ttest_rel 사용)
t_stat, p_value = stats.ttest_rel(before_policy, after_policy)
print(f"t-통계량 = {t_stat:.4f}, p-value = {p_value:.4f}")

if p_value < 0.05:
    print("정책 시행 전후 속도 차이가 유의미함 (귀무가설 기각)")
else:
    print("정책 시행 전후 속도 차이가 유의미하지 않음 (귀무가설 유지)")
```

> 독립표본은 `ttest_ind`(independent), 대응표본은 `ttest_rel`(related)로 서로 다른 메서드를 사용한다는 점이 핵심 차이다.

**결과 정리**

| 분석항목 | 결과 |
|---|---|
| 검정 유형 | 대응표본 t-검정 |
| T-통계량 | 9.5365 |
| p-value | 0.0000 |
| 귀무가설(H₀) | 정책 시행 전후 속도 차이는 없음 |
| 대립가설(H₁) | 정책 시행 전후 속도 차이는 있음 |
| 기각 여부 | 기각 (p-value < 0.05) |
| 해석 | 정책 시행 전후 속도 차이는 유의미함 |

## 10. Welch's t-test — 등분산이 아닐 때

일반적인 독립표본 t-검정은 두 집단의 분산이 같다(등분산)는 가정이 필요하다. **Welch's t-test**는 이 등분산 가정 없이, 각 집단의 표준편차를 따로 고려해 계산하는 t-검정의 변형이다.

**필요한 상황**
- 두 집단의 표본 크기가 다를 때
- 두 집단의 분산이 다를 때 (Levene's test의 p-value < 0.05인 경우)

```python
import numpy as np
import scipy.stats as stats

np.random.seed(42)
group1 = np.random.normal(loc=50, scale=10, size=30)  # 평균 50, 표준편차 10
group2 = np.random.normal(loc=55, scale=15, size=30)  # 평균 55, 표준편차 15 (이분산)

# Levene's test로 등분산 확인
levene_test = stats.levene(group1, group2)
print(f"Levene's test p-value: {levene_test.pvalue:.4f}")

# Welch's t-test 수행 (equal_var=False)
t_stat, p_value = stats.ttest_ind(group1, group2, equal_var=False)
print(f"Welch's t-test: t-statistic = {t_stat:.4f}, p-value = {p_value:.4f}")

if p_value < 0.05:
    print("두 그룹의 평균 차이가 유의미함 (귀무가설 기각)")
else:
    print("두 그룹의 평균 차이가 유의미하지 않음 (귀무가설 유지)")
```

일반 독립표본 t-검정과 사용법은 거의 동일하며, `equal_var` 인자 하나만 다르다 — 등분산이면 `True`, 이분산이면 `False`를 지정하면 된다.

## 💡 한 줄 요약
> 가설 검정은 귀무가설·대립가설을 세우고 유의수준(보통 0.05)을 기준으로 p-value를 확인해 차이가 우연인지 실제 차이인지 판단하는 과정이며, 정규성·등분산 검정을 거쳐 독립표본/대응표본 t-검정이나 Welch's t-test 중 상황에 맞는 방법을 선택해 적용한다.
