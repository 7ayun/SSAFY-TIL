# [데이터 기초] 비율 검정

---

## 1. 베르누이 시행에서 표본비율까지

지금까지는 두 집단의 **평균**을 비교하는 t-검정을 다뤘다. 하지만 실무에서는 클릭률, 전환율처럼 **비율**을 기반으로 비교해야 하는 경우가 많다.

**베르누이 시행(Bernoulli Trial)**은 결과가 성공/실패처럼 0 또는 1로만 나오는 한 번의 실험이다.

> 예시: 클릭함/클릭하지 않음, 구매함/구매하지 않음, B 그룹에 배정됨/아님 — 한 사용자의 `converted` 값이 1이면 전환, 0이면 미전환.

A/B 테스트의 CTR, CVR, 구매 여부는 대부분 베르누이 데이터로 볼 수 있다. 이 베르누이 시행이 **여러 번 반복**되면 이항분포로 연결되고, 이항분포에서의 **성공 횟수를 전체 시행 횟수로 나눈 값**이 바로 **표본비율**이 된다.

**비율 검정의 흐름**
```
베르누이 시행 → 이항분포 → 표본비율 → Z-test
```

## 2. 표본비율과 표준오차

**표본비율**은 전체 시도 중 성공이 발생한 비율이며, 모비율(모집단 전체의 실제 비율)을 추정하는 데 사용한다.
```
p-hat = 성공 횟수 / 전체 시행 횟수
```

| 실무 지표 | 계산식 |
|---|---|
| CTR (클릭률) | Click / Impression |
| CVR (전환율) | Purchase / Impression (또는 Purchase / User) |
| Traffic Split | B 그룹 사용자 수 / 전체 사용자 수 |

표본비율은 표본을 다시 뽑을 때마다 흔들리는 값이다 — 예를 들어 1,000명 중 50명이 클릭해 클릭률 5%가 나왔더라도, 같은 실험을 다시 하면 정확히 5%가 아니라 48명, 53명이 클릭할 수도 있다. 이 흔들림의 정도를 나타내는 것이 **표준오차(Standard Error)**다.
```
SE = √( p(1-p) / n )
```
- **표본 수(n)가 커질수록 표준오차는 작아진다** → 표본이 클수록 작은 차이도 더 잘 검출할 수 있다.
- 실제 분석에서는 모비율 p를 모르기 때문에 관측 비율 p-hat을 대신 사용한다.
- 두 집단을 비교할 때는 **통합 비율(pooled proportion)**을 사용하기도 한다.

> 표본 수가 적으면 표본비율의 분포가 넓게 퍼지고, 표본 수가 많아지면 평균 근처로 촘촘하게 모인다 — 표본평균의 표준오차가 표본 크기에 따라 줄어드는 것과 같은 원리다.

## 3. 정규근사와 Z-score

**정규근사**는 표본 수가 충분히 클 때 표본비율의 분포를 정규분포로 보는 방법이다. 표본 수가 충분히 크면 중심극한정리에 의해 표본비율의 분포도 정규분포에 가까워지기 때문이다.

**Z-score**는 관측값이 기대값에서 표준오차 몇 개만큼 떨어져 있는지를 나타낸다.
```
Z = (관측 비율 - 기대 비율) / 표준오차
```
- |Z|가 클수록 우연히 나온 차이라고 보기 어렵다.
- 95% 기준 양측 검정에서는 보통 **|Z| > 1.96**이면 귀무가설을 기각한다.

표본비율이 정규분포로 근사되기 때문에, 이 정규근사를 활용해 **Z-test**로 비율에 대한 가설 검정을 수행할 수 있다.

## 4. 단일 비율 Z-test (One-proportion Z-test)

**단일 비율 Z-test**는 관측된 비율이 기대 비율과 다른지를 검정하는 방법이다.

- 귀무가설 H₀: 실제 비율 p = 기대 비율 p₀
- 대립가설 H₁: 실제 비율 p ≠ 기대 비율 p₀

> **예시** — A/B 테스트에서 무작위 배정을 50:50으로 설계했는데, 실제로는 48:52로 배정되었다. 기대 비율(50%)보다 2%p 높은 셈인데, 이 차이가 우연히 발생한 것인지 아니면 무작위 배정 자체가 제대로 이루어지지 않은 것인지 확인이 필요하다.

**계산 흐름**

| 단계 | 내용 |
|---|---|
| 1 | 기대 비율 p₀와 표본 수 n을 정함 (예: p₀ = 0.5) |
| 2 | 관측 비율 p-hat 계산 (예: 전체 10,000명 중 B 그룹 5,200명 → p-hat = 0.52) |
| 3 | 표준오차 SE = √(p₀(1-p₀) / n) 계산 |
| 4 | Z = (p-hat - p₀) / SE 로 기대값에서 얼마나 벗어났는지 판단 |

계산된 Z값을 기반으로 p-value를 구하고, 이 값이 유의수준보다 작으면 귀무가설을 기각한다.

## 5. 두 비율 Z-test (Two-proportion Z-test)

**두 비율 Z-test**는 두 집단의 비율 차이가 유의미한지를 검정하는 방법이며, A/B 테스트에서 CTR·CVR·가입률·구매율 같은 0/1 지표를 비교할 때 주로 사용한다.

- 귀무가설 H₀: pA = pB
- 대립가설 H₁: pA ≠ pB (또는 pB > pA)

> **예시** — A 전환율 10%, B 전환율 12%일 때, B가 실제로 더 좋다고 바로 결론 내릴 수 있는지를 Z-score를 계산해 판단한다.

**계산 흐름**

| 단계 | 내용 |
|---|---|
| 1 | 각 그룹의 표본비율 계산: pA = xA/nA, pB = xB/nB |
| 2 | 귀무가설에서는 두 그룹의 실제 비율이 같다고 가정 → 통합 비율 계산: p_pool = (xA + xB) / (nA + nB) |
| 3 | 표준오차 계산: SE = √( p_pool(1-p_pool) × (1/nA + 1/nB) ) |
| 4 | Z = (pB - pA) / SE 로 두 비율 차이의 유의성 판단 |

두 비율 Z-test는 단일 비율 Z-test와 달리, 귀무가설의 전제(두 그룹의 비율이 같다)를 반영해 **통합 비율(pooled proportion)**로 표준오차를 계산한다는 점이 핵심 차이다.

---

## 💡 한 줄 요약
> 비율 검정은 베르누이 시행 → 이항분포 → 표본비율의 흐름 속에서, 표본비율이 정규근사됨을 활용해 Z-score로 관측 비율이 기대 비율(단일 비율 Z-test)이나 다른 집단의 비율(두 비율 Z-test)과 유의미하게 다른지를 판단하는 방법이다.

- 표본 크기가 작을 때(np 또는 n(1-p)가 5 미만) Z-test 대신 사용하는 정확검정(Fisher's exact test)
