## 1. 인덱스와 자료형 다루기

**날짜 기반 인덱스 만들기 — `date_range()`**

```python
dates = pd.date_range('20260701', periods=6)   # 6일간의 날짜 범위 생성
df = pd.DataFrame(..., index=dates)             # 날짜를 인덱스로 지정
```

**명시적 dtype 선언** — 컬럼을 선언할 때 `datetime`, `float`, `category` 등 구체적인 타입을 지정해주면, 모호한 `object` 타입보다 연산 성능이 좋아질 수 있다. 최신 버전에서는 문자열 전용 `string` 타입도 지원되며, 기존 object보다 기능이 더 풍부하다.

**NumPy로 변환 — `to_numpy()`**

수치 계산이나 벡터·행렬 연산을 빠르게 처리해야 할 때는 DataFrame을 NumPy의 ndarray로 변환해서 사용할 수 있다.

```python
df.to_numpy()
```

**전치 — `T` (transpose)**

행과 열을 서로 뒤바꿔서 확인하고 싶을 때 사용한다.

```python
df.T
```

## 2. 인덱스 재구성 — `reindex()`

기존 인덱스를 새로운 기준으로 재배치하거나, 새 컬럼을 추가하며 순서를 다시 지정할 수 있다. 이때 값이 채워지지 않은 자리는 자동으로 NaN이 된다.

```python
df.reindex(columns=['A', 'B', 'C', 'D', 'E'])  # 기존 A~D에 E 컬럼 추가, 값 없는 곳은 NaN
```

## 3. 빠른 단일 값 조회 — `at`

정확히 하나의 스칼라 값만 필요할 때는 `loc`보다 `at`이 더 빠른 방식이다.

```python
df.at['20260702', 'A']   # 특정 인덱스·컬럼의 값 하나만 빠르게 조회
```

## 4. 정렬과 고유값 확인

**다중 조건 정렬**

```python
titanic.sort_values(by=['Pclass', 'Name'], ascending=False)
```

- `by`에 여러 컬럼을 리스트로 넘기면, 앞 컬럼을 기준으로 먼저 정렬하고 같은 값 안에서 다음 컬럼으로 다시 정렬한다.
- `ascending` 기본값은 오름차순(`True`)이며, 내림차순은 `False`로 지정한다.

**고유값 확인 — `unique()` vs `nunique()`**

| 메서드 | 반환 값 |
|---|---|
| `unique()` | 실제 고유값 목록 (배열) |
| `nunique()` | 고유값의 **개수** |

```python
titanic['Survived'].unique()    # array([0, 1]) — 실제 값
titanic['Survived'].nunique()   # 2 — 개수
```

> 이름(Name)처럼 대부분 값이 중복되지 않는 컬럼에 `unique()`를 쓰면 큰 의미가 없다. 범주형·분류형 데이터에서 몇 가지 값이 있는지 확인할 때 유용하다.

## 5. 집계 함수와 `groupby`

기본 집계 함수(`count`, `mean`, `sum`, `min`, `max` 등)로 전체 데이터를 요약할 수도 있지만, 실무에서는 **특정 그룹 기준으로 나눠서** 요약하는 경우가 훨씬 많다.

```python
titanic.groupby('Pclass')[['Age', 'Fare']].mean()   # 객실 등급별 평균 나이·요금
```

- `groupby()`로 그룹을 묶으면, 그 결과를 기반으로 다양한 집계 함수를 적용할 수 있는 객체가 만들어진다.
- 집계 시 결측치는 자동으로 제외되고 계산된다.

**여러 집계를 한 번에 — `agg()`**

```python
# 리스트로 여러 함수 적용
titanic.groupby('Pclass')['Age'].agg(['min', 'max'])

# 컬럼별로 다른 함수 + 이름 지정
titanic.groupby('Pclass').agg(
    age_max=('Age', 'max'),
    age_min=('Age', 'min'),
    fare_mean=('Fare', 'mean'),
)
```

## 6. 함수를 일괄 적용하기 — `apply()`

람다식이나 직접 정의한 함수를 데이터에 일괄 적용할 때 사용한다.

```python
titanic['NameLength'] = titanic['Name'].apply(lambda x: len(x))
```

> **주의 — `apply()`는 권장되는 방식이 아니다.** 내부적으로 파이썬 함수가 행/열마다 반복 호출되는 방식이라 for문을 도는 것과 비슷하게 느려지고, NumPy 기반 연산 최적화의 이점을 살리지 못한다. 데이터가 작거나 처리 속도가 크게 중요하지 않은 경우에 한해, 코드 작성의 편의성 때문에 사용하는 정도로 이해하면 된다.

## 7. 데이터 병합하기

| 방식 | 기준 | 비고 |
|---|---|---|
| `concat()` | 단순 연결 | `axis=0`: 행 방향(위아래) 병합 / `axis=1`: 열 방향(양옆) 병합 |
| `merge()` | **컬럼(key)** 기준 | SQL의 JOIN과 동일한 개념 (`how='inner'/'outer'/'left'/'right'`) |
| `join()` | **인덱스** 기준 | merge와 개념은 같지만 인덱스를 기준으로 병합 |

```python
pd.concat([df1, df2], axis=0)   # 행으로 이어붙이기
pd.concat([df1, df2], axis=1)   # 열로 옆에 붙이기

pd.merge(df1, df2, on='key', how='inner')              # key 기준 교집합만 병합
pd.merge(df1, df2, on='key', how='outer')              # 합집합, 없는 값은 NaN
pd.merge(df1, df2, on=['key1', 'key2'], how='inner')   # 복합키 병합

df1.join(df2, how='left')       # 인덱스 기준 병합
```

- 겹치는 컬럼명이 있을 경우 `suffixes=('_left', '_right')` 옵션으로 접미사를 붙여 구분할 수 있다.
- `merge`는 RDB에서의 JOIN, `join`은 인덱스 기준이라는 점이 핵심 차이다.

**값 치환 — `replace()`**

```python
titanic['Sex'] = titanic['Sex'].replace({'male': 'M', 'female': 'F'})
```

- 딕셔너리 형태로 여러 값을 한 번에 치환할 수 있으며, 결측치를 특정 값으로 바꾸는 용도로도 활용 가능하다 (`fillna`의 대안).

## 8. 데이터 구조 변환하기 — long ↔ wide

`groupby` 결과처럼 세로로 길게 나열된 형태를 **long format**, 표처럼 가로로 펼쳐진 형태를 **wide format**이라고 한다.

**`pivot_table()` — long → wide (집계 포함)**

```python
titanic.pivot_table(index='Sex', columns='Pclass', values='Age', aggfunc='mean')
```
→ 행: 성별, 열: 객실 등급, 값: 평균 나이로 표 형태 재구성

**`pivot()` — 구조만 변경 (집계 없음)**

`pivot()`은 순수하게 행/열을 재배치만 할 뿐 계산 기능이 없어서, 동일 조합에 값이 여러 개 존재하면 에러가 발생한다. 집계까지 함께 하려면 `pivot_table()`을 사용해야 한다.

**`melt()` — wide → long**

```python
titanic.melt(id_vars='Survived', value_vars=['Sex', 'Pclass'],
             var_name='FamilyType', value_name='Count')
```
- `id_vars`: 기준이 되는(변하지 않는) 열
- `value_vars`: 하나의 열로 모을 대상 컬럼들
- 결과적으로 지정한 컬럼들이 두 개의 열(변수명·값)로 정리되며 세로로 길어진다.
