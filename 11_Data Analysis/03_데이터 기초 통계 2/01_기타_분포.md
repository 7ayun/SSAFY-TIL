## 1. 균등분포 (Uniform Distribution)

균등분포는 **특정 범위 내에서 모든 값이 동일한 확률**을 가지는 가장 단순한 형태의 분포다. 어떤 값이 더 많이 나오거나 덜 나오는 경향 없이, 결국 모든 값이 같은 확률로 나타난다.

**확률밀도함수**
```
f(x) = 1 / (b - a),   a ≤ x ≤ b
```
- `a`: 최소값(시작점), `b`: 최대값(끝점), `b - a`: 전체 구간의 길이
- 밀도함수 아래 전체 넓이(확률의 합)가 1이 되어야 하므로, 너비(`b-a`)와 높이(`1/(b-a)`)를 곱하면 1이 되는 구조다. 그래서 특정 값이 나올 확률은 항상 `1/(b-a)`로 일정하다.

**예시 — 로또 번호 추첨 (이산형 균등분포)**

로또(1~45번)에서 특정 숫자가 나올 확률은 모두 동일하게 1/45다. 1번이든 45번이든 당첨될 확률은 같다.

> **복원추출 vs 비복원추출** — 첫 번째 숫자를 뽑을 때는 1/45의 확률이지만, 뽑은 숫자를 다시 넣지 않는 비복원추출이라면 그다음 숫자를 뽑을 확률은 1/44로 바뀐다. 다만 이 경우에도 "남은 숫자들 중에서는 모두 같은 확률"이라는 균등분포의 성질 자체는 매번 유지된다.

즉, 랜덤하게 숫자를 추첨할 때 모든 숫자가 같은 확률로 선택된다면 이를 균등분포라고 부른다.

## 2. 이항분포 (Binomial Distribution)

이항분포는 **성공/실패처럼 두 가지 결과(이진 결과)를 다루는 확률 모델**이다. 합격/불합격, 클릭함/클릭하지 않음처럼 결과가 두 가지뿐인 경우가 대표적이다.

한 번의 시행 결과(0 또는 1)만 보는 것을 **베르누이 시행**이라 하고, 이 베르누이 시행을 **여러 번 반복했을 때 성공이 몇 번 나왔는지**를 확률적으로 설명하는 분포가 이항분포다.

**확률질량함수**
```
P(X=k) = C(n, k) × p^k × (1-p)^(n-k)
```

| 기호 | 의미 |
|---|---|
| n | 총 시행 횟수 |
| k | 성공 횟수 |
| p | 성공 확률 |

**성립 조건**
- 독립적인 실험이 반복된다 (한 시행의 결과가 다른 시행에 영향을 주지 않음)
- 각 실험은 성공 또는 실패, 두 가지 결과 중 하나만 가능
- 각 실험의 성공 확률은 항상 일정함

**주요 특성**

| 항목 | 수식 | 설명 |
|---|---|---|
| 평균(기대값) | E(X) = n·p | 예: 10번 시도, 성공확률 50% → 평균 5번 성공 |
| 분산 | Var(X) = n·p·(1-p) | 실험 횟수(n)가 커질수록 분산도 커짐 |
| 표준편차 | σ(X) = √(n·p·(1-p)) | — |

- 성공 확률 **p = 0.5일 때 분산이 가장 크다.** (p·(1-p)는 p=0.5에서 최댓값 0.25 — p=0.7이면 0.7×0.3=0.21, p=0.9면 0.9×0.1=0.09로 더 작아진다)
- p = 0.5일 때 분포는 대칭적인 모양을, p가 작거나 크면 비대칭적인 모양을 가진다.
- 실험 횟수(n)와 성공 확률(p)에 따라 이항분포의 형태가 달라진다.

> 표본 크기(n)가 충분히 크다면 이항분포를 정규분포로 근사할 수도 있다.

## 3. 이항분포 실습 예제

**동전 던지기 (n=10, p=0.5)**

동전을 10번 던졌을 때 앞면이 나오는 횟수는 이항분포를 따른다.
```
P(X=5) = C(10,5) × (0.5)^5 × (0.5)^5 = 0.246
```
1,000번 반복 실험한 히스토그램은 앞면 5회 근처를 중심으로 대칭적인 종 모양을 그린다 — 성공확률이 0.5이기 때문에 정규분포에 가까운 형태다.

**주사위 굴리기 (n=10, p=1/6)**

주사위를 10번 던져 특정 숫자(예: 6)가 나오는 횟수를 볼 때:
```
P(X=2) = C(10,2) × (1/6)^2 × (5/6)^8 ≈ 0.29
```
특정 숫자가 나올 확률(1/6) 자체가 작기 때문에, 성공 횟수는 0~2회 근처에 몰리고 6회 이상 나오는 경우는 매우 드물게 나타난다 — 동전 던지기보다 비대칭적인 분포가 된다.

## 4. 포아송 분포 (Poisson Distribution)

포아송 분포는 **일정한 시간 또는 공간에서 특정 사건이 발생하는 횟수를 모델링**하는 확률분포다.

**확률질량함수**
```
P(X=k) = (λ^k × e^(-λ)) / k!
```

| 기호 | 의미 |
|---|---|
| λ (람다) | 단위 시간(공간)당 평균 발생 횟수 |
| k | 실제 발생한 사건 수 (0, 1, 2, 3, …) |
| e | 자연상수 (약 2.718) |

**성립 조건**
- 사건 발생이 독립적이다 (예: 은행 방문자가 서로 영향을 주지 않음)
- 일정한 단위 안에서 사건이 발생할 확률이 일정하다 (예: 1시간 동안 발생하는 전화 문의 수)

**주요 특성**
- **평균과 분산이 같다**: E(X) = λ, Var(X) = λ
- λ가 작으면 그래프가 왼쪽으로 치우친(비대칭) 모양이 되고, λ가 커지면 정규분포와 비슷한 모양이 된다.
- **이항분포와의 관계**: 시행 횟수(n)가 크고 성공 확률(p)이 매우 작을 때, 이항분포는 포아송분포로 근사할 수 있다.
  > 예시: 1,000명 중 극소수만 특정 질병에 걸리는 경우 → 포아송 분포로 근사 가능

## 5. 포아송 분포 실습 예제

**은행 방문자 수 (λ=10)**

한 은행에 평균적으로 1시간에 10명의 고객이 방문한다고 할 때, 정확히 8명이 방문할 확률:
```
P(X=8) = (10^8 × e^(-10)) / 8! ≈ 0.1126
```

**웹사이트 방문자 수 (λ=20)**

평균적으로 1시간에 20명이 방문하는 웹사이트에서, 정확히 25명이 방문할 확률도 같은 방식으로 계산할 수 있다.
```
P(X=25) = (20^25 × e^(-20)) / 25!
```
두 경우 모두 "어떤 사건이 몇 번 발생할지"를 예측하는 데 포아송 분포가 사용된 사례다.

## 💡 한 줄 요약
> 균등분포는 모든 값이 동일 확률을 가지는 가장 단순한 분포이고, 이항분포는 반복된 베르누이 시행에서의 성공 횟수를, 포아송분포는 단위 시간·공간당 사건 발생 횟수를 모델링하며, 셋 다 조건에 따라 서로 근사되거나 정규분포로 근사될 수 있다.
