# 부분집합(Subset) 수업 정리

## 1. 오늘 강의 핵심 요약

### **핵심 메시지 3개**
1.  **완전탐색의 완성:** 부분집합은 순열, 조합과 함께 완전탐색(A형)을 관통하는 가장 중요한 도구이며, 모든 경우의 수를 트래킹하는 기초
2.  **이분법적 사고:** 각 원소를 **"선택하느냐(1), 마느냐(0)"**라는 단순한 논리가 모여 $2^n$개의 모든 경우의 수 생성
3.  **재귀 vs 비트연산:** 가독성과 가지치기(Pruning)가 필요할 때는 **재귀(DFS)**를, 압도적인 연산 속도가 필요할 때는 **비트 연산(바이너리 카운팅)**을 선택

---

## 2. 구현 방식 비교

| 구분 | 반복문 (For) | 재귀 (DFS) | 바이너리 카운팅 |
| :--- | :--- | :--- | :--- |
| **특징** | 원소 개수만큼 루프 중첩 | 선택/미선택의 상태 트리 | 비트 연산자를 이용한 최적화 |
| **장점** | 구조가 직관적임 | **가지치기(Pruning)** 가능 | 코드가 간결하고 연산이 매우 빠름 |
| **단점** | N이 변하면 대응 불가 | 스택 오버플로우 주의 | 비트 연산 숙련도 필요 |

---

## 3. 핵심 원리와 공식

* **부분집합의 개수:** $2^n$ (공집합 포함)
    * 예: $\{1, 2, 3\}
        2^3 = 8$개
* **재귀적 인덱스(`depth`):** 현재 함수가 '어떤 원소'를 결정하고 있는지를 나타내는 인덱스
* **비트 마스킹(Bit Masking):** $i$번째 비트가 1인지 확인하여 $i$번째 원소의 포함 여부를 결정
    * `i & (1 << j)`: $i$라는 숫자(경우의 수)에서 $j$번째 비트가 켜져 있는지 확인하는 수식

## 4. 코드 구현 패턴

### (1) 재귀(DFS) 방식: 포함/미포함 누적
```python
def generate_subset(depth, current_sum):
    # 1. 종료 조건: 모든 원소를 다 결정했을 때
    if depth == N:
        if current_sum == target_sum:
            return 1
        return 0

    # 2. 가지치기: 이미 목표를 넘었으면 더 볼 필요 없음 (양수 기준)
    if current_sum > target_sum:
        return 0

    count = 0
    # 현재 원소를 선택한 경우 (Included)
    count += generate_subset(depth + 1, current_sum + arr[depth])
    # 현재 원소를 선택하지 않은 경우 (Excluded)
    count += generate_subset(depth + 1, current_sum)

    return count
```

### (2) 바이너리 카운팅 방식: 비트 연산
```python
n = len(arr)
for i in range(1 << n):  # 2^n개의 모든 경우의 수 순회 (0 ~ 2^n-1)
    subset = []
    for j in range(n):   # 각 원소의 자릿수 비트 검사
        if i & (1 << j): # i의 j번째 비트가 1이면 해당 원소 포함
            subset.append(arr[j])
    print(subset)
```

## 5. 실전 응용: 부분집합의 합(Subset Sum)

* **문제 구조:** $N$개의 원소 중 합이 $K$가 되는 부분집합 찾기.

* **최적화 전략 (가지치기):**
    * 재귀 파라미터로 현재까지의 합(`current_sum`)을 계속 넘겨줌
    * 진행 도중 합이 이미 목표값을 초과했다면, 그 아래의 수많은 자식 노드들은 실행조차 하지 않고 `return`
    * **'가지치기'가 10억 번의 연산을 수만 번으로 줄여주는 핵심 기법**
