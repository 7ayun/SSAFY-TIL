## 1. exists() 메서드

QuerySet에 결과가 하나 이상 존재하는지 여부를 `True`/`False`로 반환하는 메서드다.

- 전체 QuerySet을 평가하지 않고 데이터베이스 수준에서 존재 여부만 빠르게 확인한다.
- `in` 연산자보다 효율적이며, 대량 데이터에서 특정 객체를 검색할 때 유용하다.

**좋아요 기능에 적용**

```python
# articles/views.py
@login_required
def likes(request, article_pk):
    article = Article.objects.get(pk=article_pk)

    # 기존 방식 (전체 QuerySet 평가 후 비교)
    # if request.user in article.like_users.all():

    # 개선 방식 (exists()로 존재 여부만 확인)
    if article.like_users.filter(pk=request.user.pk).exists():
        article.like_users.remove(request.user)
    else:
        article.like_users.add(request.user)

    return redirect('articles:index')
```

**팔로우 기능에 적용**

```python
# accounts/views.py
@login_required
def follow(request, user_pk):
    User = get_user_model()
    person = User.objects.get(pk=user_pk)

    if person != request.user:
        # 기존 방식
        # if request.user in person.followers.all():

        # 개선 방식
        if person.followers.filter(pk=request.user.pk).exists():
            person.followers.remove(request.user)
        else:
            person.followers.add(request.user)

    return redirect('accounts:profile', person.username)
```

## 2. 한꺼번에 dumpdata 하기

여러 모델을 한 번의 명령어로 하나의 JSON 파일에 추출할 수 있다.

```bash
# 여러 모델을 JSON 파일 1개로 추출
python manage.py dumpdata --indent 4 articles.article articles.comment accounts.user > data.json

# 프로젝트 전체 모델을 JSON 파일 1개로 추출
python manage.py dumpdata --indent 4 > data.json
```

모든 데이터를 한 번에 추출하면 파일 용량이 커질 수 있으므로, DB 변경이 잦은 경우 앱 단위 또는 모델 단위로 나눠 관리하는 편이 유지보수에 유리하다.

## 3. loaddata 인코딩 에러

Windows 환경에서 생성한 JSON 파일을 Linux/Mac 환경에서 로드하거나 반대 상황에서 한글 등 비 ASCII 문자가 포함된 경우 인코딩 에러가 발생할 수 있다.

```
UnicodeDecodeError: 'utf-8' codec can't decode byte 0xc0 in position ...
```

**해결 방법 1 — dumpdata 시 옵션 추가 (근본 해결)**

```bash
python -Xutf8 manage.py dumpdata --indent 4 articles.article > articles.json
```

**해결 방법 2 — 이미 생성된 파일 재저장**

메모장(Windows) 또는 VS Code에서 해당 JSON 파일을 열고, 인코딩을 `UTF-8`로 지정해 다시 저장한다.
