## 1. 데이터 무결성 (Data Integrity)

- 데이터베이스에 저장된 데이터가 사용자에게 제공될 때 **정확도, 일관성, 유효성**이 보장되어야 한다는 원칙
- 외래키로 참조를 하면 반드시 참조한 데이터가 실제로 존재해야 함

### on_delete가 필수인 이유

- 데이터 무결성 원칙 때문에 `ForeignKey`에서 `on_delete`는 필수 옵션
- 참조하는 게시글(1)이 삭제됐을 때, 남아있는 댓글(N)을 어떻게 처리할지 반드시 명시해야 함

| 옵션 | 설명 |
|---|---|
| `CASCADE` | 참조 대상 삭제 시 함께 삭제 |
| `SET_NULL` | 참조 대상 삭제 시 NULL로 설정 (null=True 필요) |
| `PROTECT` | 참조 대상 삭제 시 에러 발생 (삭제 방지) |
| `SET_DEFAULT` | 참조 대상 삭제 시 기본값으로 설정 |

## 2. admin site에 댓글 등록

```python
# articles/admin.py
from .models import Article, Comment

admin.site.register(Article)
admin.site.register(Comment)
```

- admin 페이지에서 댓글 데이터를 관리하려면 Comment 모델을 별도로 등록해야 함

## 3. 다음 시간 예고

- 오늘: Article(1) ↔ Comment(N) 관계 구현
- 다음: **User** 등장

  - User(1) ↔ Comment(N): 한 명의 유저가 여러 댓글 작성
