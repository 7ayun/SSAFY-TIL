## 2. 탐욕(Greedy) 알고리즘 핵심 개념

### 정의
- 매 순간 **지금 당장 최선이라고 생각하는 선택**을 하는 방식
- 이런 선택을 끝까지 반복해 전체 해답을 만드는 접근
- 특정 알고리즘이 아니라 **문제 해결 방법론**

---

### 장점
- 모든 경우의 수를 보지 않아도 됨
- 구현이 단순한 경우가 많음
- 실행 속도가 빠른 경우가 많음

---

### 단점 (시험에서 가장 중요한 부분)
- 항상 최적해를 보장하지 않음
- 반례가 존재할 수 있음
- 원래는 수학적 증명이 필요함

시험 관점 핵심
- IM: 제출 후 수정 가능 → 그리디 시도 가능
- A형: 검증 어려움 → 그리디는 최후의 선택

---

### 그리디 성립 핵심 키워드
1. 탐욕적 선택 속성
→ 지금 선택이 이후에도 안전한 선택이어야 함

2. 최적 부분 구조
→ 작은 문제에서도 같은 선택 기준이 유지되어야 함

## 4. 대표 예시 1: 동전 교환

### 문제 핵심
- 거스름돈을 최소 동전 개수로 만들기

### 그리디 직관
- 큰 동전부터 최대한 사용

### 반례 존재
예시 동전: 500, 400, 100
거스름돈: 800

그리디 선택
- 500 + 100 + 100 + 100 → 4개

최적해
- 400 + 400 → 2개

→ 항상 최적이 아님

### 그리디가 안전해지는 조건(수업 언급)
- 큰 동전이 작은 동전들의 배수 관계일 때

### 코드
```python
# 사용할 동전 단위(큰 것부터)
coins = [500, 100, 50, 10]

# 거슬러 줄 금액 입력
amount = int(input())

# 사용한 동전 개수
count = 0

# 큰 동전부터 처리
for coin in coins:
    # 현재 동전으로 몇 개 쓸 수 있는지
    count += amount // coin

    # 남은 금액 갱신
    amount %= coin

# 최소 동전 개수 출력
print(count)
```

## 5. 대표 예시 2: 배낭(Knapsack)

### 목표
- 무게 제한 내에서 가치 합 최대

---

### 0/1 Knapsack
- 물건을 통째로 넣거나 안 넣거나만 가능
- 부분집합 문제 → 시간복잡도 2^N
- 그리디 기준
  - 비싼 것부터
  - 가벼운 것부터
  - 가치/무게 비율 순
→ 모두 반례 존재

결론
→ **DP가 정석**

---

### Fractional Knapsack
- 물건을 쪼개서 담을 수 있음
- 가치/무게 비율 높은 순으로 담으면 됨
→ 그리디 가능

## 6. 대표 예시 3: 활동 선택(회의 배정)

### 목표
겹치지 않게 최대 개수 선택

### 잘못된 직관
- 시작 시간이 빠른 순 정렬 → 반례 존재

### 정답 전략
- 종료 시간이 빠른 순 정렬
- 가능한 것만 선택

### 코드
```python
# 작업 개수 입력
n = int(input())

# (시작, 종료) 입력 받기
jobs = [list(map(int, input().split())) for _ in range(n)]

# 종료시간 기준 정렬
jobs.sort(key=lambda x: x[1])

# 첫 작업 선택
result = 1
end_time = jobs[0][1]

# 이후 작업 확인
for i in range(1, n):
    start = jobs[i][0]
    end = jobs[i][1]

    # 겹치면 선택 불가
    if start < end_time:
        continue

    # 선택 가능
    result += 1
    end_time = end

# 결과 출력
print(result)
```

## 7. 실전 문제 1: 스위치 조작

### 규칙
- i번 스위치를 누르면
→ i ~ N 전구가 모두 반전

### 핵심 아이디어
- 앞에서부터 비교
- 다르면 그 자리에서 누른다

이유
- i를 누르면 i 이전은 영향을 받지 않음
- 따라서 앞을 확정시키는 방식이 가능

### 코드
```python
# 전구 개수 입력
n = int(input())

# 현재 상태
prev_switch = list(map(int, input().split()))

# 목표 상태
next_switch = list(map(int, input().split()))

# 스위치 누른 횟수
result = 0

# 앞에서부터 비교
for i in range(n):
    # 이미 같으면 넘어감
    if prev_switch[i] == next_switch[i]:
        continue

    # 다르면 현재 위치 스위치를 누름
    result += 1

    # i부터 끝까지 전구 상태 반전
    for j in range(i, n):
        prev_switch[j] = 1 - prev_switch[j]

# 총 누른 횟수 출력
print(result)
```

## 9. 실전 문제 3: 배수 스위치

### 규칙
- i번 스위치를 누르면
→ i의 배수 전구만 반전

### 목표
- 모든 전구를 0으로 만들기
- 불가능하면 -1

### 구현 핵심
- 문제 번호는 1부터 시작
- 리스트 인덱스는 0부터 시작
→ i번 전구는 switch[i-1]

### 코드
```python
# 테스트 케이스 개수
t = int(input())

for tc in range(1, t + 1):
    # 전구 상태 문자열 입력 (Y/N)
    arr = list(input().strip())
    n = len(arr)

    # Y → 1, N → 0 변환
    switch = [1 if ch == 'Y' else 0 for ch in arr]

    # 스위치 누른 횟수
    result = 0

    # 1번 스위치부터 n번 스위치까지 확인
    for i in range(1, n + 1):

        # 이미 꺼져 있으면 넘어감
        if switch[i - 1] == 0:
            continue

        # 스위치 누름
        result += 1

        # i의 배수 전구 반전
        for j in range(i, n + 1):
            if j % i == 0:
                switch[j - 1] = 1 - switch[j - 1]

    # 전부 꺼졌는지 확인
    if 1 in switch:
        result = -1

    # 테스트 케이스 결과 출력
    print(f"#{tc} {result}")
```
