# [JS] 데이터타입

---

## 1. 원시 자료형과 참조 자료형

자바스크립트의 데이터 타입은 크게 **원시 자료형(Primitive type)**과 **참조 자료형(Reference type)**으로 나뉜다.

| 구분 | 원시 자료형 | 참조 자료형 |
|------|------------|------------|
| 저장 방식 | 값(value) 자체를 변수에 직접 저장 | 데이터가 저장된 메모리 **주소**를 변수에 저장 |
| 변경 가능 여부 | 불변(immutable) | 가변(mutable) |
| 복사 방식 | 변수 간 할당 시 **값이 복사됨** | 변수 간 할당 시 **주소가 복사됨** |
| 종류 | Number, String, Boolean, null, undefined | Objects (Object, Array, Function) |

### 원시 자료형 예시 — 서로 독립적

```js
// 값 자체가 복사되므로 독립적으로 동작
let a = 10
let b = a
b = 20
console.log(a) // 10
console.log(b) // 20

// 문자열도 불변 — 부분 수정 불가
const str = 'bar'
str.toUpperCase()       // 대문자로 바뀐 새 값을 리턴할 뿐
console.log(str)        // 'bar' (원본은 그대로)

const upper = str.toUpperCase()
console.log(upper)      // 'BAR'
```

> **주의:** `str[0] = 'B'` 처럼 인덱스로 직접 수정을 시도해도 에러도 안 뱉고 그냥 무시된다. JS가 에러를 조용히 삼키는 대표적 케이스.

### 참조 자료형 예시 — 주소를 공유하므로 서로 영향을 줌

```js
const obj1 = { name: 'Alice', age: 30 }
const obj2 = obj1        // 같은 주소를 가리킴

obj2.age = 40

console.log(obj1.age)    // 40 ← obj1도 영향 받음
console.log(obj2.age)    // 40
```

> **비유:** 사물함 번호를 두 사람이 같이 들고 있는 것. 한 명이 사물함 안의 물건을 바꾸면 다른 사람도 바뀐 내용을 보게 된다. 파이썬에서 리스트를 복사할 때와 완전히 동일한 원리.

## 2. 원시 자료형 종류

### Number

- 정수와 실수 **구분 없이** 모두 단일 Number 타입으로 처리 (64비트 부동소수점)
- 파이썬의 int와 float이 JS에서는 전부 Number 하나

```js
const a = 13          // 정수
const b = 13.0        // 실수
console.log(a === b)  // true — 같은 Number 타입

const c = 2.998e8     // 지수 표현 (= 299,800,000)
const d = Infinity    // 무한대
const e = -Infinity   // 음의 무한대
const f = NaN         // Not a Number (잘못된 수 연산 결과)
```

- 문자열과 `+` 연산 시 숫자가 문자열로 자동 형변환되어 연결됨
- 0.1 + 0.2 같은 부동소수점 문제는 파이썬과 동일하게 발생

> **NaN 특징:** 타입은 `number`지만 자기 자신과 비교해도 `false`가 나오는 유일한 값 (`NaN === NaN // false`)

### String

- 텍스트 데이터를 표현하는 자료형
- `+` 연산으로 문자열 결합 가능
- 뺄셈, 곱셈, 나눗셈은 불가 (파이썬에서 문자열 곱셈이 되는 것이 오히려 예외적인 케이스)

```js
const firstName = 'Tony'
const lastName = 'Stark'
console.log(firstName + lastName)  // 'TonyStark'
```

#### Template literals (템플릿 리터럴) — 파이썬의 f-string

- 백틱(`` ` ``)으로 감싸고, `${변수명}` 형태로 변수를 문자열 안에 삽입
- 백틱은 키보드에서 숫자 `1` 왼쪽에 위치 (작은따옴표와 모양이 비슷하니 주의)
- ES6+부터 지원

```js
const age = 100
const message = `홍길동은 ${age}세입니다.`
console.log(message)  // '홍길동은 100세입니다.'
```

### null과 undefined

파이썬의 `None` 하나와 달리, JS에서는 **두 가지**가 존재한다.

| | null | undefined |
|---|---|---|
| 의미 | 프로그래머가 **의도적으로** 값이 없음을 나타낼 때 | 시스템/JS 엔진이 **값이 할당되지 않았음**을 나타낼 때 |
| 예시 | `let a = null` (일부러 비워둠) | `let b` → `console.log(b) // undefined` |
| typeof | **"object"** (역사적 버그) | "undefined" |
| 산술 연산 | 0으로 취급 (`null + 10 === 10`) | NaN 반환 (`undefined + 10 === NaN`) |

> **비유:** 화장실 휴지걸이에서 `null`은 걸이는 있는데 휴지를 다 쓴 상태(0개), `undefined`는 아예 걸이 자체를 설치하지 않은 상태.

> **null의 typeof가 "object"인 이유:** JS 초기 버전에서 값의 타입을 32비트로 표현할 때 하위 3비트가 `000`이면 object를 의미했는데, null은 모든 비트가 0인 NULL 포인터라 object로 잘못 분류됐다. 수정하려 했지만 이미 너무 많은 웹사이트가 이 동작에 의존하고 있어 그대로 유지.

```js
let a = null
console.log(a)        // null
console.log(typeof a) // "object"

let b
console.log(b)        // undefined
console.log(typeof b) // "undefined"

console.log(null == undefined)   // true  (동등 연산자: 암묵적 형변환)
console.log(null === undefined)  // false (일치 연산자: 타입까지 비교)
```

### Boolean

- 참(`true`)과 거짓(`false`)을 나타내는 논리 자료형
- **주의:** 파이썬은 `True` / `False` (대문자 시작), JS는 `true` / `false` (소문자)
- Boolean이 아닌 타입이 조건문 등에서 사용될 때 **자동 형변환** 규칙에 따라 true/false로 변환됨

## 3. Boolean 자동 형변환 규칙

아래 값들은 조건문에서 **`false`**로 취급된다:

| 타입 | false로 취급되는 값 |
|------|-------------------|
| undefined | 항상 false |
| null | 항상 false |
| Number | `0`, `-0`, `NaN` |
| String | `''` (빈 문자열) |

그 외의 모든 값은 **`true`**로 취급됨.

> **함정:** 빈 배열 `[]`와 빈 객체 `{}`는 내용이 없어도 **true**다. 파이썬에서 빈 리스트가 falsy인 것과 다르니 주의.

```js
console.log(Boolean([]))   // true
console.log(Boolean({}))   // true
console.log(Boolean(''))   // false
console.log(Boolean(0))    // false
console.log(Boolean(null)) // false
```

**권장 습관:** 암묵적 형변환에 의존하지 말고 **명시적으로** 조건을 작성하자.

```js
// 비권장 (암묵적)
if (students) { ... }

// 권장 (명시적)
if (students.length > 0) { ... }
```

## 4. 연산자

### 할당 연산자

파이썬과 동일하게 단축 연산자(`+=`, `-=`, `*=`, `%=`)를 지원.

```js
let a = 0
a += 10  // 10
a -= 3   // 7
a *= 10  // 70
a %= 7   // 0
```

### 증가 & 감소 연산자 (`++`, `--`)

파이썬에는 없고 C, Java 등 대부분의 언어에서 지원하는 연산자. **연산자 위치에 따라 결과 타이밍이 다름**.

```js
let x = 3
const y = x++       // 먼저 3을 y에 할당하고, 그 다음 x가 4가 됨
console.log(x, y)   // 4 3

let a = 3
const b = ++a       // 먼저 a를 4로 증가시키고, 그 값을 b에 할당
console.log(a, b)   // 4 4
```

> **권장:** 헷갈리는 부작용을 방지하기 위해 `a += 1`, `a -= 1`처럼 명시적 표현을 사용하는 것을 권장.

### 비교 연산자

숫자는 수의 크기로, 문자는 ASCII 코드 값으로 비교.

```js
3 > 2      // true
'A' < 'B'  // true  (ASCII: A=65, B=66)
'Z' < 'a'  // true  (ASCII: Z=90, a=97)
'가' < '나' // true
```

### 동등 연산자(`==`) vs 일치 연산자(`===`)

| | 동등(`==`) | 일치(`===`) |
|---|---|---|
| 비교 방식 | 암묵적 타입 변환 후 값 비교 | 타입과 값 모두 비교 |
| 권장 여부 | ❌ 사용 금지 | ✅ 항상 이것만 사용 |

```js
// 동등 연산자 — 예상치 못한 결과 발생
console.log('1' == 1)    // true  (문자열이 숫자로 형변환됨)
console.log(0 == false)  // true

// 일치 연산자 — 엄격한 비교
console.log('1' === 1)   // false
console.log(0 === false) // false
```

> **결론: JS에서는 비교할 때 무조건 `===`만 사용한다.**

### 논리 연산자와 단축 평가

- `&&` (AND): 앞이 false면 앞 값 반환, 앞이 true면 뒤 값 반환
- `||` (OR): 앞이 true면 앞 값 반환, 앞이 false면 뒤 값 반환
- `!` (NOT): 값을 반전

```js
// 단축 평가 활용 예시 (실무에서 자주 사용)
const user = null
const displayName = user || 'Guest'
console.log(displayName)  // 'Guest'
```

#### null 병합 연산자 (`??`) — ES2020

`||`는 `0`, `''` 같은 falsy 값도 false로 취급하는 문제가 있다. `??`는 **null 또는 undefined일 때만** 오른쪽 값을 사용한다.

```js
let score = 0
console.log(score || 50)   // 50 (의도하지 않은 결과)
console.log(score ?? 50)   // 0  (0은 유효한 값이므로 그대로 반환)

const user = null
console.log(user ?? 'Guest')  // 'Guest'
```

## 💡 한 줄 요약

> JS 데이터 타입의 핵심은 **원시 자료형은 값이 복사**되고 **참조 자료형은 주소가 복사**된다는 것이며, 비교 연산은 항상 `===`를 사용해 암묵적 형변환을 피해야 한다.
