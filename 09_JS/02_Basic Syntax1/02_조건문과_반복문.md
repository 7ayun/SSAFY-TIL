# [JS] 조건문과 반복문

---

## 1. 조건문 — `if / else if / else`

파이썬과 로직은 동일하지만 문법이 다르다.

| 파이썬 | 자바스크립트 |
|--------|------------|
| `elif` | `else if` |
| 들여쓰기로 코드 블록 구분 | **중괄호 `{}`** 로 코드 블록 구분 |
| 조건식에 괄호 없음 | 조건식을 **소괄호 `()`** 로 감쌈 |

```js
const name = 'customer'

if (name === 'admin') {
  console.log('관리자님 환영해요')
} else if (name === 'customer') {
  console.log('고객님 환영해요')
} else {
  console.log(`반갑습니다. ${name}님`)
}
```

> **`else if`가 더 일반적인 형태다.** 파이썬이 `elif`로 특수하게 줄인 것이고, C / Java / JS 등 대부분의 언어는 `else if`를 사용한다.

---

## 2. 삼항 연산자

간단한 조건 분기를 **한 줄**로 표현하는 연산자. 프론트엔드(React, Vue 등)에서 특히 많이 사용됨.

```
조건 ? 참일 때 실행 : 거짓일 때 실행
```

파이썬과 순서가 약간 다르다.

```python
# 파이썬
result = '성인' if age >= 18 else '미성년자'
```

```js
// 자바스크립트
const age = 20
const message = (age >= 18) ? '성인' : '미성년자'
console.log(message)  // '성인'
```

> **주의:** 복잡한 로직에는 가독성이 떨어지므로 단순한 조건에만 사용하는 것이 좋다.

## 3. 반복문 종류

자바스크립트의 반복문에는 `while`, `for`, `for...in`, `for...of` 네 가지가 있다.
모든 반복문은 **블록 스코프**를 가진다.

### while

조건문이 참인 동안 코드 블록을 반복 실행. 파이썬과 구조가 같고 소괄호/중괄호만 추가됨.

```js
let i = 0
while (i < 6) {
  console.log(i)
  i += 1
}
// 0 1 2 3 4 5
```

### for

C, Java 등 대부분의 언어에서 공통으로 사용하는 형태. `[초기문]; [조건문]; [증감문]` 세 부분으로 구성.

```js
for (let i = 0; i < 6; i++) {
  console.log(i)
}
// 0 1 2 3 4 5
```

동작 순서:
1. 반복문 진입 및 변수 `i` 선언 (`let i = 0`)
2. 조건문 평가 후 코드 블록 실행 (`i < 6`)
3. 코드 블록 실행 완료 후 `i` 값 증가 (`i++`)
4. 2-3 반복, 조건이 false가 되면 종료

> **`let` 사용 이유:** 초기문에서 `i`를 반복마다 재할당해야 하므로 반드시 `let`을 사용해야 한다. `const`를 쓰면 에러 발생.

## 4. for...in

객체(Object)의 **열거 가능한 속성의 키(key)**에 대해 반복한다.

```js
for (variable in object) {
  statement
}
```

```js
const fruits = { a: 'apple', b: 'banana' }
for (const property in fruits) {
  console.log(property)          // a, b  (키)
  console.log(fruits[property])  // apple, banana  (값)
}
```

### ⚠️ for...in 사용 시 주의 및 비권장 이유

- 배열에도 사용 가능하지만, **인덱스가 문자열 타입**으로 반환됨 (`'0'`, `'1'`, ...)
- 내부적으로 배열의 반복자가 아닌 **속성 열거**를 사용하므로 **순서 보장 불가**
- 배열이 상속받은 **프로토타입의 속성까지 순회**할 수 있어 예상치 못한 버그 유발

```js
const arr = ['a', 'b', 'c']
for (const i in arr) {
  console.log(i)     // '0' '1' '2' (숫자가 아닌 문자열 인덱스!)
}
```

> **결론: `for...in`은 존재만 알아두고 배열 순회에는 사용하지 않는다.** 배열은 `for` 또는 `for...of`를 사용하자.

---

## 5. for...of

반복 가능한(iterable) 객체(배열, 문자열 등)의 **값(value)**에 대해 반복한다. 파이썬의 `for ... in`과 동작이 가장 유사하다.

```js
for (variable of iterable) {
  statement
}
```

```js
const numbers = [0, 1, 2, 3]
for (const number of numbers) {
  console.log(number)  // 0, 1, 2, 3
}
```

> **파이썬 대응:** 파이썬의 `for x in list:`는 JS에서 `for (const x of list)`로 작성한다.

### for...in vs for...of 비교

```js
const arr = ['a', 'b', 'c']

// for...in: 인덱스(키)를 가져옴
for (const i in arr) {
  console.log(i)  // '0', '1', '2' (문자열 인덱스)
}

// for...of: 값을 가져옴
for (const elem of arr) {
  console.log(elem)  // 'a', 'b', 'c'
}
```

객체(Object)에 `for...of`를 사용하면 TypeError가 발생한다. 객체는 iterable이 아니기 때문.

```js
const capitals = { korea: '서울', japan: '도쿄' }
for (const capital of capitals) {  // TypeError: capitals is not iterable
  ...
}
```

## 6. 반복문에서 const 사용 여부

| 반복문 | const 사용 |
|--------|-----------|
| `for` | ❌ 불가 — 초기문의 변수를 매 반복마다 재할당하기 때문 |
| `for...in` | ✅ 가능 — 매 반복마다 새로운 속성 이름이 새로 지정(재할당 X) |
| `for...of` | ✅ 가능 — 매 반복마다 새로운 값이 새로 지정(재할당 X) |

기본 원칙(const 우선)에 따라 `for...in` / `for...of`에서는 `const`를 쓴다. 단, 반복문 내부에서 해당 변수의 값을 수정해야 한다면 `let`으로 바꾼다.

---

## 7. 반복문 종합 정리

| 키워드 | 특징 | 사용 대상 |
|--------|------|----------|
| `while` | 조건이 참인 동안 반복 | 범용 |
| `for` | 초기/조건/증감 직접 제어 | 범용 (C 스타일) |
| `for...in` | 객체의 key 순회 (**비권장**) | Object |
| `for...of` | iterable의 value 순회 | Array, String 등 |

> **실무 권장:** `for...of`와 `for` 위주로 사용하고, `for...in`은 가급적 지양한다.

---

## 💡 한 줄 요약

> JS 조건문은 `else if` + 소괄호 + 중괄호 구조를 쓰고, 배열 순회에는 파이썬의 `for...in`에 대응하는 `for...of`를 사용한다.

## ❓ 더 찾아볼 것

- `break` / `continue` 문의 활용
- `Array.prototype.forEach()` — 배열 순회에서 가장 많이 쓰이는 메서드
- `for...of`로 객체를 순회하고 싶을 때: `Object.keys()`, `Object.values()`, `Object.entries()` 활용
