## 1. 배열(Array) 기초

**배열**은 순서가 있는 데이터 집합을 저장하는 자료구조로, 파이썬의 리스트와 동일한 개념이다.

- 객체: key로 데이터를 관리, 순서 없음
- 배열: index(숫자)로 데이터를 관리, **순서 있음**

> 자바스크립트에서 배열도 내부적으로는 객체다. 인덱스(숫자)를 키로 갖는 특수한 객체.

```javascript
const names = ['Alice', 'Bella', 'Cathy']

console.log(names[0])       // Alice
console.log(names[1])       // Bella
console.log(names.length)   // 3  (파이썬의 len(names)에 해당)
```

## 2. 배열 기본 조작 메서드

네 가지 모두 **원본 배열을 직접 수정**한다.

### push / pop (배열 끝)

```javascript
const names = ['Alice', 'Bella', 'Cathy']

// push: 끝에 추가, 반환값 = 새로운 배열의 길이
names.push('Dan')
console.log(names) // ['Alice', 'Bella', 'Cathy', 'Dan']

// pop: 끝 요소 제거, 반환값 = 제거한 요소
console.log(names.pop()) // 'Dan'
console.log(names)       // ['Alice', 'Bella', 'Cathy']
```

### unshift / shift (배열 앞)

```javascript
// unshift: 앞에 추가, 반환값 = 새로운 배열의 길이
names.unshift('Eric')
console.log(names) // ['Eric', 'Alice', 'Bella', 'Cathy']

// shift: 앞 요소 제거, 반환값 = 제거한 요소
console.log(names.shift()) // 'Eric'
console.log(names)         // ['Alice', 'Bella', 'Cathy']
```

> `unshift`와 `shift`는 **가급적 사용하지 않는다.** 배열의 모든 요소를 한 칸씩 이동시켜야 하므로 배열이 클수록 성능이 크게 저하된다.

## 3. 콜백 함수 (Callback Function)

**콜백 함수**: 다른 함수의 인자로 전달되어, 특정 시점에 호출되는 함수.

- 그냥 함수와 동일하지만, **다른 함수로부터 호출된다**는 점이 핵심이다.
- "함수의 실행 권한을 다른 함수에게 위임하는 것"

### 진동벨 비유

| 단계 | 의미 |
|------|------|
| 카페에서 커피 주문 | 요청 |
| 직원이 진동벨을 줌 | 콜백 함수 전달 |
| "커피 완성 시 벨을 울려주세요" | 특정 시점에 실행 예약 |
| 커피 완성 → 직원이 벨을 울림 | 콜백 함수 실행 |

자리에 앉아 다른 일을 할 수 있는 것처럼, 콜백 함수는 "특정 시점에 실행될 일을 미리 등록해두는 개념"이다.

### 콜백 함수 동작 원리

```javascript
// 1. 콜백으로 쓸 함수 정의
const greeting = function (name) {
  console.log(`Hello, ${name}!`)
}

// 2. 콜백 함수를 인자로 받는 메인 함수
const processUserInput = function (callback) {
  const name = 'Anna'
  callback(name)  // 넘겨받은 함수를 여기서 실행
}

// 3. 실행: 함수를 데이터처럼 전달
processUserInput(greeting) // 출력: Hello, Anna!
```

### 콜백 함수 활용: 뼈대 함수 + 부품 교체 패턴

콜백 함수를 활용하면 **뼈대는 그대로 두고 로직(부품)만 교체**하는 유연한 설계가 가능하다.

```javascript
// 뼈대 함수
const calculator = function (a, b, action) {
  return action(a, b)
}

// 부품 함수들 (콜백 함수)
const add = (a, b) => a + b
const sub = (a, b) => a - b

console.log(calculator(10, 20, add))  // 30 (덧셈으로 동작)
console.log(calculator(10, 20, sub))  // -10 (뺄셈으로 동작)
```

### 비동기 처리 맛보기 (`setTimeout`)

콜백 함수는 비동기 처리에도 활용된다. 작업에 시간이 걸릴 때 그 작업이 끝난 직후에 실행할 함수를 미리 등록한다.

```javascript
console.log('1. 주문하기')

// "3초 뒤에 이 함수를 실행해줘"
setTimeout(function () {
  console.log('2. 커피 나왔습니다! (콜백 실행)')
}, 3000)

console.log('3. 자리에 앉기')

// 실행 결과:
// 1. 주문하기
// 3. 자리에 앉기
// 2. 커피 나왔습니다! (3초 뒤에 출력)
```

> 비동기 처리는 JavaScript의 핵심 개념으로, 추후 비동기 수업에서 자세히 다룬다.

## 4. 콜백 함수와 배열의 연결

지금까지 배운 콜백 함수의 특징 정리:
1. 함수를 인자로 넘긴다
2. 받은 쪽에서 그 함수를 실행한다
3. **반복적인 작업을 시킬 때 아주 유용하다**

이 특징들이 배열의 헬퍼 메서드와 결합될 때 강력한 힘을 발휘한다 → Array Helper Method
