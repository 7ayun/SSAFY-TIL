# [JS] Basic Syntax2 - 객체

## 1. 객체(Object) 기초

객체는 **키(key)로 구분된 데이터 집합을 저장하는 자료형**이다. 파이썬의 딕셔너리와 동일한 개념이다.

```javascript
const user = {
  name: 'Alice',         // key: value
  'key with space': true,
  greeting: function () {
    return 'hello'
  }
}
```

### 구조 특징
- 중괄호 `{}`로 작성
- `key: value` 쌍으로 구성된 속성(property)을 여러 개 작성 가능
- **key는 문자형만 허용** → 숫자를 key로 입력해도 자동으로 문자열로 변환됨
  - 주의: `{ 1: 20, 1: 30 }` 처럼 숫자 key가 중복되면 뒤의 값이 덮어쓰기됨
- value는 모든 자료형 허용 (함수도 가능)
- 코드 작성 시 key의 따옴표는 생략하는 것이 관례

### 속성 접근 방법

| 방법 | 예시 | 비고 |
|------|------|------|
| 점 표기법 | `user.name` | 일반적 |
| 대괄호 표기법 | `user['key with space']` | 공백 등 특수문자 포함 시 필수 |

```javascript
// 조회
console.log(user.name)              // Alice
console.log(user['key with space']) // true

// 추가
user.address = 'korea'

// 수정
user.name = 'Bella'

// 삭제
delete user.name
```

## 2. `in` 연산자 vs `hasOwnProperty()`

`in` 연산자는 속성 존재 여부를 확인하지만, **프로토타입 체인까지 검색**하는 문제가 있다.

```javascript
const user2 = { name: 'Alice' }

console.log('name' in user2)       // true (의도한 결과)
console.log('toString' in user2)   // true (프로토타입에 있어서 의도치 않게 true!)
```

> 프로토타입: 객체들이 공통 기능을 물려받는 원본 객체. 모든 JS 객체는 프로토타입을 가진다.

**권장 방법: `hasOwnProperty()`**
```javascript
console.log(user2.hasOwnProperty('name'))     // true
console.log(user2.hasOwnProperty('toString')) // false ← 정확히 동작
```

## 3. 메서드와 `this`

**메서드**란 객체 속성에 정의된 함수를 말한다. 단순 함수와 달리 자신이 속한 객체의 다른 속성에 접근할 수 있다.

```javascript
const person = {
  name: 'Alice',
  greeting: function () {
    return `Hello my name is ${this.name}`  // this → person 객체
  }
}
console.log(person.greeting()) // Hello my name is Alice
```

### `this` 동작 방식

파이썬의 `self`와 비슷하지만, JS의 `this`는 **호출 방식에 따라 동적으로 결정**된다는 점이 핵심 차이다.

| 호출 방법 | `this`가 가리키는 대상 |
|-----------|----------------------|
| 일반 함수 호출 | 전역 객체 (`window`) |
| 메서드 호출 | 메서드를 호출한 객체 |

```javascript
// 일반 함수 → window
const myFunc = function () { return this }
console.log(myFunc()) // window

// 메서드 → 해당 객체
const myObj = {
  data: 1,
  myFunc: function () { return this }
}
console.log(myObj.myFunc()) // myObj
```

### 중첩 함수에서의 `this` 문제와 해결책

`forEach` 내부 콜백은 **일반 함수로 호출**되므로 `this`가 `window`를 가리킨다.

```javascript
// 문제: 내부 콜백의 this가 window
const myObj2 = {
  numbers: [1, 2, 3],
  myFunc: function () {
    this.numbers.forEach(function (number) {
      console.log(this) // window ← 의도와 다름
    })
  }
}

// 해결: 화살표 함수 사용 (자신만의 this를 갖지 않고 외부 스코프의 this를 참조)
const myObj3 = {
  numbers: [1, 2, 3],
  myFunc: function () {
    this.numbers.forEach((number) => {
      console.log(this) // myObj3 ← 의도대로 동작
    })
  }
}
```

> 헷갈릴 땐 **"누가 점(.)을 찍어 호출했는가?"** 를 확인하자. 점 앞의 객체가 `this`가 된다.

## 4. JSON

**JSON (JavaScript Object Notation)**: 키-값 형태로 이루어진 **문자열** 데이터 표기법. 특정 언어에 종속되지 않아 API 통신에 널리 사용된다.

JS의 Object와 구조는 같지만, JSON은 **문자열**이므로 JS에서 사용하려면 Object로 변환해야 한다.

```javascript
const jsObject = {
  coffee: 'Americano',
  iceCream: 'Cookie and cream',
}

// Object → JSON 문자열
const objToJson = JSON.stringify(jsObject)
console.log(objToJson)          // {"coffee":"Americano","iceCream":"Cookie and cream"}
console.log(typeof objToJson)   // string

// JSON 문자열 → Object
const jsonToObj = JSON.parse(objToJson)
console.log(jsonToObj)          // { coffee: 'Americano', iceCream: 'Cookie and cream' }
console.log(typeof jsonToObj)   // object
```

| JS | Python |
|----|--------|
| `JSON.stringify()` | `json.dumps()` |
| `JSON.parse()` | `json.loads()` |

## 5. 추가 객체 문법

### 1) 단축 속성 (Shorthand Property)
key 이름과 변수 이름이 같을 때 생략 가능하다.

```javascript
const name = 'Alice'
const age = 30

// 기존
const user = { name: name, age: age }

// 단축 속성
const user = { name, age }
```

### 2) 단축 메서드 (Shorthand Method)
`function` 키워드 생략 가능하다.

```javascript
// 기존
const myObj = { myFunc: function () { return 'Hello' } }

// 단축 메서드
const myObj = { myFunc() { return 'Hello' } }
```

### 3) 계산된 속성 (Computed Property Name)
대괄호 `[]`를 사용해 변수값을 key로 사용할 수 있다.

```javascript
const product = prompt('물건 이름을 입력해주세요')
const prefix = 'my'
const suffix = 'property'

const bag = {
  [product]: 5,
  [prefix + suffix]: 'value',
}
console.log(bag) // { 연필: 5, myproperty: 'value' }
```

> 동적 key 사용 시 의도치 않은 덮어쓰기가 발생할 수 있으므로 주의.

### 4) 구조 분해 할당 (Destructuring Assignment)
객체의 속성을 변수로 쉽게 할당하는 문법이다.

```javascript
const userInfo = {
  firstName: 'Alice',
  userId: 'alice123',
  email: 'alice123@gmail.com'
}

// 기존
const firstName = userInfo.firstName
const userId = userInfo.userId

// 구조 분해 할당
const { firstName, userId, email } = userInfo
console.log(firstName, userId, email) // Alice alice123 alice123@gmail.com
```

**함수 매개변수에서도 활용 가능**:
```javascript
const person = { name: 'Bob', age: 35, city: 'London' }

function printInfo({ name, age, city }) {
  console.log(`이름: ${name}, 나이: ${age}, 도시: ${city}`)
}

printInfo(person) // 이름: Bob, 나이: 35, 도시: London
```

### 5) 전개 구문 (Spread Syntax)
객체를 복사하거나 병합할 때 사용. **얕은 복사**에 활용된다.

```javascript
const obj = { b: 2, c: 3, d: 4 }
const newObj = { a: 1, ...obj, e: 5 }
console.log(newObj) // { a: 1, b: 2, c: 3, d: 4, e: 5 }
```

### 6) Object.keys() / values() / entries()
```javascript
const profile = { name: 'Alice', age: 30 }

console.log(Object.keys(profile))    // ['name', 'age']
console.log(Object.values(profile))  // ['Alice', 30]
console.log(Object.entries(profile)) // [['name', 'Alice'], ['age', 30]]
```

### 7) Optional Chaining (`?.`)
중첩 객체의 속성에 에러 없이 안전하게 접근하는 방법. 참조 대상이 `null` 또는 `undefined`이면 에러 대신 `undefined`를 반환한다.

```javascript
const user = {
  name: 'Alice',
  greeting: function () { return 'hello' }
}

console.log(user.address.street)   // TypeError 발생!
console.log(user.address?.street)  // undefined (에러 없이 처리)

console.log(user.nonMethod())      // TypeError 발생!
console.log(user.nonMethod?.())    // undefined (에러 없이 처리)
```

**옵셔널 체이닝 사용 시 주의사항:**
- 존재하지 않아도 **괜찮은 대상**에만 사용 (남용 금지)
- 반드시 있어야 하는 값(버그여야 하는 상황)에는 `?.`를 붙이면 안 됨
- 앞의 변수는 반드시 선언되어 있어야 함

```javascript
// Bad: user가 반드시 존재해야 하는 상황
user?.address?.street

// Good: address만 없을 수 있는 상황
user.address?.street
```

## 💡 한 줄 요약
> JS의 객체는 파이썬 딕셔너리와 유사하지만, `this`는 호출 방식에 따라 동적으로 결정되므로 메서드 내 중첩 함수에서는 화살표 함수로 `this` 문제를 해결한다.
