## 1. JavaScript 문법 학습 기준

- **ES6(ECMAScript 2015) 이후**의 문법을 기준으로 학습
- 이전 버전 문법은 레거시로 취급하며 다루지 않음
- 권장 스타일 가이드: [JavaScript Standard Style](https://standardjs.com/rules-kokr.html)
  - 들여쓰기: **2칸 공백** (파이썬은 4칸)
  - 문자열: **작은따옴표(`'`)** 사용
  - 사용하지 않는 변수 선언 금지 등

---

## 2. 변수 작성 규칙 (식별자 규칙)

| 규칙 | 설명 |
|------|------|
| 시작 문자 | 반드시 **문자, `$`, `_`** 로 시작 |
| 대소문자 구분 | `name`과 `Name`은 다른 변수 |
| 예약어 사용 불가 | `for`, `if`, `function`, `class` 등 |
| 의미 있는 이름 | `userName`, `phoneNumber` 처럼 의미가 드러나도록 |

---

## 3. Naming Convention (네이밍 컨벤션)

JavaScript에서 용도에 따라 다른 표기법을 사용한다.

| 표기법 | 형태 | 사용 대상 |
|--------|------|-----------|
| **camelCase** | `myName`, `phoneNumber` | 변수, 객체, 함수 |
| **PascalCase** | `UserProfile`, `MyClass` | 클래스, 생성자 |
| **SNAKE_CASE** | `MAX_RETRY_COUNT` | 상수(constants) |

> **파이썬과의 차이:** 파이썬은 변수에 `snake_case`(소문자 + 언더바)를 쓰지만, JavaScript는 `camelCase`(띄어쓰기 위치를 대문자로)가 기본이다.

**상수(constant)란?** 한 번 선언하면 값을 바꿀 수 없도록 잠가버리는 특별한 변수.
예) API 키, 최대 재시도 횟수처럼 코드에서 고정적으로 쓰이는 값.

> ⚠️ 네이밍 컨벤션은 '소통의 규칙'이다. 가장 중요한 것은 **팀의 스타일 가이드를 따르는 것** — 입사한 회사의 규칙이 법이다.

## 4. 변수 선언 키워드

파이썬은 변수 선언 시 아무것도 붙이지 않지만, JavaScript는 변수 앞에 반드시 키워드를 붙여야 한다.

```js
// 파이썬 방식 (JS에서는 사용 불가)
// name = '홍길동'

// JavaScript 방식
let name = '홍길동'
const age = 25
```

### `let` — 재할당 가능한 변수

```js
let number = 10  // 선언 및 초기값 할당
number = 20      // ✅ 재할당 가능

let number = 30  // ❌ 재선언 불가 (에러 발생)
```

- 블록 스코프(block scope)를 가지는 지역 변수를 선언
- **재할당 가능**, **재선언 불가**
- ES6에서 추가됨

### `const` — 재할당 불가능한 상수

```js
const number = 10  // 선언 및 초기값 할당
number = 20        // ❌ 재할당 불가 (에러 발생)

const number = 30  // ❌ 재선언 불가 (에러 발생)

const number       // ❌ 초기값 없이 선언 불가 (에러 발생)
// 'const' declarations must be initialized
```

- 블록 스코프(block scope)를 가지는 지역 변수를 선언
- **재할당 불가**, **재선언 불가**
- ES6에서 추가됨

### 어떤 키워드를 써야 할까?

> **"const를 기본으로, 필요할 때만 let으로"**

1. 일단 `const`로 선언
2. 나중에 값을 바꿔야 한다는 걸 알게 되면 그때 `let`으로 변경

**이유:**
- `const`는 "이 변수는 바뀌지 않는다"는 의도를 코드로 명확하게 표현
- 의도치 않은 값 변경으로 인한 버그를 예방
- 코드 읽는 사람이 변수의 용도를 더 쉽게 이해

## 5. 블록 스코프 (Block Scope)

`let`과 `const`는 **블록 스코프**를 가진다.
블록이란 `if`, `for`, 함수 등의 `{ }` 중괄호 내부를 말한다.

```js
let x = 1

if (x === 1) {
  let x = 2
  console.log(x)  // 2 — 블록 내부의 x
}

console.log(x)  // 1 — 블록 밖의 x (블록 안에서 선언한 x는 사라짐)
```

**파이썬과의 중요한 차이점:**

파이썬은 `if`, `for`, `while` 안에서 선언한 변수를 **바깥에서도 접근 가능**하다. 이는 파이썬이 특이한 것이며, 대부분의 언어에서는 블록 내 변수가 블록 밖에서 접근 불가능한 것이 표준이다.

```python
# Python — 블록 스코프 없음 (파이썬이 특이한 것)
if True:
    y = 10
print(y)  # 10 — 에러 없이 접근 가능
```

```js
// JavaScript — 블록 스코프 있음 (일반적인 규칙)
if (true) {
  let y = 10
}
console.log(y)  // ❌ ReferenceError — 블록 밖에서 접근 불가
```

> **TIP:** `var`는 이 블록을 무시하고 파이썬처럼 동작한다. 그래서 `var` 사용을 권장하지 않는다.

## 6. `var` — 사용을 권장하지 않는 이유

`var`는 ES6 이전에 변수를 선언할 때 사용했던 키워드로, 현재는 사용을 지양한다.

```js
var number = 10
number = 20        // ✅ 재할당 가능
var number = 30    // ✅ 재선언도 가능 — 이것이 문제!
```

**`var`의 문제점:**

1. **재선언 가능** → 실수로 같은 이름 변수를 다시 선언해도 에러가 나지 않음
2. **함수 스코프** → `if`, `for` 같은 블록을 무시하고 함수 전체에서 접근 가능
3. **호이스팅 시 `undefined`로 초기화** → 선언 전에 접근해도 에러가 아닌 `undefined` 반환

> 브라우저 환경에서는 다양한 외부 라이브러리가 함께 동작하는데, `var`는 재선언이 가능해 변수 이름이 충돌하는 심각한 문제를 일으킬 수 있다.

---

## 💡 한 줄 요약

> JavaScript에서 변수는 `const`를 기본으로 선언하고, 재할당이 필요한 경우에만 `let`을 사용한다 — 블록 스코프와 재할당 가능 여부가 핵심 차이점이다.
