# [JS] Controlling Event - 이벤트

---

## 1. 이벤트(Event)란?

웹 페이지에서 **'무언가 일어났다는 신호 또는 사건'** 을 의미한다.

일상 속 예시와 웹에서의 대응 관계는 다음과 같다.

| 일상 | 웹 |
|------|-----|
| 전화벨이 울림 | 스크롤 이동 |
| 키보드를 눌러 텍스트 입력 | 버튼 클릭 → 팝업 출력 |
| 리모컨으로 채널 변경 | 마우스 드래그 앤 드롭 |

웹에서의 거의 모든 상호작용은 이벤트와 함께 동작한다.

> 키를 한 번 누르는 것도 **keydown**과 **keyup** 두 개의 서로 다른 이벤트로 분리되어 있다. 마우스를 요소 위에 올리는 것은 **hover** 이벤트다. 이처럼 사용자의 모든 행동이 하나하나 개별 이벤트로 존재한다.

---

## 2. DOM 요소와 이벤트

- 모든 **DOM 요소**(HTML 문서의 각 태그를 객체로 변환한 것)는 다양한 형태의 이벤트를 발생시킬 수 있다.
- 예) `button` 클릭 → `click` 이벤트 / `input` 값 변경 → `input` 이벤트

이벤트의 종류는 MDN 공식 문서에서 확인할 수 있다.  
→ [https://developer.mozilla.org/en-US/docs/Web/API/Event](https://developer.mozilla.org/en-US/docs/Web/API/Event)

주요 이벤트 유형:
- `mouse`: mouseover, click, mousedown, mouseup 등
- `keyboard`: keydown, keyup
- `input`: 입력 값 변경

> 이벤트 종류를 모두 외울 필요는 없다. 필요할 때 MDN에서 찾아서 적용하면 된다.

---

## 3. Event Object (이벤트 객체)

DOM에서 이벤트가 발생하면, 브라우저는 해당 이벤트에 관한 정보를 담은 **event object**를 자동으로 생성한다.

이벤트 객체에 담긴 정보:
- 이벤트가 발생한 요소
- 이벤트 타입 (click, input 등)
- 마우스 좌표, 눌린 키 등 상세 정보

```javascript
const btn = document.querySelector('#btn')

const detectClick = function (event) {
  console.log(event)        // PointerEvent { ... }
  console.log(event.type)   // 'click'
}

btn.addEventListener('click', detectClick)
```

---

## 4. Event Handler (이벤트 핸들러)

**특정 이벤트가 발생했을 때 실행되는 (콜백) 함수**를 의미한다.

> 카페 비유로 이해하자.  
> - 손님의 **주문(클릭, 입력)** → 이벤트  
> - 주문을 받는 **키오스크** → 이벤트 리스너  
> - 커피를 만드는 **바리스타** → 이벤트 핸들러 (콜백 함수)

보통 `addEventListener`를 통해 DOM 요소에 이벤트 핸들러를 등록한다.

---

## 5. addEventListener 메서드

**특정 DOM 요소에, 지정한 이벤트가 발생했을 때 실행할 이벤트 핸들러를 등록하는 메서드**

### 구조

```javascript
element.addEventListener(type, handler)
```

| 인자 | 설명 |
|------|------|
| `type` | 수신할 이벤트 유형. 문자열로 작성 (`'click'`, `'input'` 등) |
| `handler` | 이벤트 발생 시 호출되는 콜백 함수. 반환값 없음 |

- handler 함수는 **이벤트 객체(event)를 첫 번째 매개변수로 자동 수신**한다.

### 기본 예시

```javascript
const button = document.querySelector('button')

// 이벤트 핸들러
const handleClick = function () {
  window.alert('버튼이 클릭 되었습니다!')
}

// addEventListener 메서드를 이용해 버튼에 이벤트 핸들러를 등록
button.addEventListener('click', handleClick)
```

### 이벤트 객체 전달 예시

```javascript
<button id="btn">버튼</button>

// 1. 버튼 요소 선택
const btn = document.querySelector('#btn')

// 2. 이벤트 핸들러
const detectClick = function (event) {
  console.log(event)        // PointerEvent
  console.log(event.type)   // 'click'
}

// 3. 버튼에 이벤트 핸들러를 등록
btn.addEventListener('click', detectClick)
```

### 이벤트 핸들러에서의 this

일반 함수를 핸들러로 사용할 때, `this`는 이벤트 리스너가 연결된 요소를 가리킨다(`event.currentTarget`과 동일).

```javascript
const btn = document.querySelector('#btn')

const detectClick = function (event) {
  console.log(event.currentTarget) // <button id="btn">버튼</button>
  console.log(this)                // <button id="btn">버튼</button>
}

btn.addEventListener('click', detectClick)
```

> 이벤트 레벨에서는 `this`보다 `event.currentTarget`을 사용하는 것이 더 명확하고 혼란이 적다.

---

## 6. 오늘 수업의 3단계 패턴

이벤트를 다루는 과정은 항상 이 3단계의 반복이다.

```
1. 요소 선택       → document.querySelector()
2. 핸들러 작성     → const handler = function(event) { ... }
3. 리스너 등록     → element.addEventListener('이벤트타입', handler)
```

## 💡 한 줄 요약
> 웹에서 발생하는 모든 사용자 행동은 '이벤트'이며, `addEventListener`로 DOM 요소에 이벤트 핸들러(콜백 함수)를 등록해 원하는 로직을 실행시킨다.
