# [JS] Controlling Event - 이벤트 활용

---

## 1. 실습 패턴 — 항상 3단계 반복

이벤트 핸들러 구현은 항상 아래 3단계를 반복한다.

```
1. 요소 선택       → document.querySelector()
2. 핸들러 작성     → const handler = function(event) { ... }
3. 리스너 등록     → element.addEventListener('타입', handler)
```

---

## 2. click 이벤트 실습 — 숫자 1씩 증가

버튼을 클릭할 때마다 화면에 클릭 횟수를 출력하는 예제.

```html
<button id="btn">버튼</button>
<p>클릭 횟수 : <span id="counter">0</span></p>
```

```javascript
// 1. 초기값 할당 (재할당이 필요하므로 let 사용)
let counterNumber = 0

// 2. 버튼 요소 선택
const btn = document.querySelector('#btn')

// 3. 콜백 함수 (이벤트 핸들러)
const clickHandler = function () {
  // 3.1 초기값 += 1
  counterNumber += 1

  // 3.2 span 요소를 선택
  const spanTag = document.querySelector('#counter')

  // 3.3 span 요소의 컨텐츠를 증가한 값으로 설정
  spanTag.textContent = counterNumber
}

// 4. 버튼에 이벤트 핸들러 등록 (클릭 이벤트)
btn.addEventListener('click', clickHandler)
```

## 3. input 이벤트 실습 — 실시간 출력

사용자가 입력한 값을 실시간으로 `<p>` 태그에 출력하는 예제.

```html
<input type="text" id="text-input">
<p></p>
```

```javascript
// 1. input 요소 선택
const inputTag = document.querySelector('#text-input')

// 2. p 요소 선택
const pTag = document.querySelector('p')

// 3. 핸들러
const inputHandler = function (event) {
  // 입력 값은 event.currentTarget.value 에 누적됨
  pTag.textContent = event.currentTarget.value
}

// 4. input 요소에 이벤트 핸들러 등록 (input 이벤트)
inputTag.addEventListener('input', inputHandler)
```

> **주의사항**: `console.log(event)`로 이벤트 객체 전체를 출력하면 `currentTarget` 값이 `null`로 보인다.  
> 이는 `currentTarget`이 이벤트 처리 중에만 유효하기 때문이다.  
> 대신 `console.log(event.currentTarget)`으로 직접 확인하거나, `event.target`을 사용한다.

## 4. click & input 이벤트 실습 — CSS 스타일 동적 변경

입력 값을 실시간으로 출력하고, 버튼 클릭 시 CSS 클래스를 추가해 글자 색상을 바꾸는 예제.

```html
<head>
  <style>
    .blue { color: blue; }
  </style>
</head>
<body>
  <h1></h1>
  <button id="btn">클릭</button>
  <input type="text" id="text-input">
</body>
```

```javascript
// input 구현
const inputTag = document.querySelector('#text-input')
const h1Tag = document.querySelector('h1')

const inputHandler = function (event) {
  h1Tag.textContent = event.currentTarget.value
}
inputTag.addEventListener('input', inputHandler)

// click 구현
const btn = document.querySelector('#btn')

const clickHandler = function () {
  // 방법 1. add — 클래스 추가
  h1Tag.classList.add('blue')

  // 방법 2. toggle — 누를 때마다 on/off

  // 방법 3. if/else — 조건부 처리

  //   h1Tag.classList.remove('blue')
  // } else {
  //   h1Tag.classList.add('blue')
  // }
}
btn.addEventListener('click', clickHandler)
```

## 5. Todo 프로그램 구현

입력 후 `+` 버튼 클릭 시 리스트에 실시간으로 항목을 추가하는 예제.

```html
<input type="text" class="input-text">
<button id="btn">+</button>
<ul></ul>
```

```javascript
// 1. 필요한 요소 선택
const inputTag = document.querySelector('.input-text')
const btn = document.querySelector('#btn')
const ulTag = document.querySelector('ul')

const addTodo = function (event) {
  // 2.1 사용자 입력 데이터 저장
  const inputData = inputTag.value

  if (inputData.trim()) {  // 빈 문자열 및 공백 방지 (trim)
    // 2.2 li 요소 생성
    const liTag = document.createElement('li')

    // 2.3 li 요소에 데이터 삽입
    liTag.textContent = inputData

    // 2.4 li를 부모 ul에 추가
    ulTag.appendChild(liTag)

    // 2.5 input 초기화
    inputTag.value = ''
  } else {
    alert('할 일을 입력하세요..')
  }
}

btn.addEventListener('click', addTodo)
```

> `trim()`을 함께 사용하면 스페이스바만 입력한 경우도 빈 값으로 처리할 수 있다.

## 6. 로또 번호 생성기 구현

Lodash 라이브러리를 활용해 1~45 중 6개의 랜덤 번호를 생성하는 예제.

```html
<script src="https://cdn.jsdelivr.net/npm/lodash@4.17.21/lodash.min.js"></script>
<script>
  // 1. 필요한 요소 선택
  const btn = document.querySelector('#btn')
  const divTag = document.querySelector('div')

  // 2. 로또 번호를 생성하는 함수
  const getLottery = function (event) {
    // 2.1 1부터 45까지의 배열 생성
    const numbers = _.range(1, 46)

    // 2.2 45개 중 6개 번호 추출
    const sixNumbers = _.sampleSize(numbers, 6)

    // 2.5 6개의 li 요소를 담을 ul 요소 생성
    const ulTag = document.createElement('ul')

    // 2.3 추출한 번호 배열을 반복하면서 li 요소 생성 후 추가
    sixNumbers.forEach((number) => {
      // 2.4 번호를 담을 li 요소 생성
      const liTag = document.createElement('li')
      liTag.textContent = number

      // 2.6 만들어진 li를 ul 요소에 추가
      ulTag.appendChild(liTag)
    })

    // 2.7 완성한 ul 요소를 div 요소에 추가
    divTag.appendChild(ulTag)
  }

  // 3. 버튼 요소에 이벤트 핸들러를 등록
  btn.addEventListener('click', getLottery)
</script>
```

### Lodash 소개

모듈성, 성능 및 추가 기능을 제공하는 JavaScript 유틸리티 라이브러리. `_`(언더바)로 사용한다.  
공식 문서: [https://lodash.com/](https://lodash.com/)

| 메서드 | 설명 |
|--------|------|
| `_.range(start, end)` | start부터 end-1까지의 숫자 배열 생성 |
| `_.sampleSize(collection, n)` | 컬렉션에서 n개의 랜덤 요소 추출 |
| `_.cloneDeep(object)` | 객체 깊은 복사 (파이썬의 `copy.deepcopy`와 동일) |
| `_.isEmpty(value)` | 빈 배열·빈 객체 여부를 직관적으로 판단 |
| `_.debounce(func, wait)` | 마지막 호출 후 wait ms가 지난 뒤 실행 (검색 입력 최적화에 유용) |
| `_.throttle(func, wait)` | wait ms마다 한 번씩 실행 (스크롤·마우스 이동 추적에 유용) |

> Lodash의 `debounce`는 사용자가 타이핑을 멈추고 일정 시간 뒤에 API를 호출할 때 사용한다. `throttle`은 마우스 이동처럼 빈번한 이벤트를 일정 주기로 제한할 때 사용한다. 시험 범위는 아니지만 실무에서 자주 쓰이므로 존재를 알아두면 좋다.

## 7. 이벤트 기본 동작 취소하기 — `event.preventDefault()`

HTML 각 요소가 기본적으로 가지고 있는 이벤트 동작을 취소하는 메서드.

**해당 이벤트에 대한 기본 동작을 실행하지 않도록 지정한다.**

주요 활용 사례:

| 기본 동작 | 취소 방법 |
|-----------|-----------|
| `<form>` 제출 시 페이지 새로고침 | submit 이벤트에 `preventDefault()` |
| `<a>` 태그 클릭 시 페이지 이동 | click 이벤트에 `preventDefault()` |
| 특정 영역 복사 방지 | copy 이벤트에 `preventDefault()` |

### copy 이벤트 취소

```html
<h1>중요한 내용</h1>
<script>
  const h1Tag = document.querySelector('h1')
  h1Tag.addEventListener('copy', function (event) {
    event.preventDefault()
    alert('복사 할 수 없습니다.')
  })
</script>
```

### form 제출 시 새로고침 취소

```html
<form id="my-form">
  <input type="text" name="username">
  <button type="submit">Submit</button>
</form>

<script>
  const formTag = document.querySelector('#my-form')
  const handleSubmit = function (event) {
    event.preventDefault()  // 페이지 새로고침 방지
  }
  formTag.addEventListener('submit', handleSubmit)
</script>
```

## 8. addEventListener와 화살표 함수 주의사항

화살표 함수는 자신만의 `this`를 가지지 않고, **선언된 상위 스코프의 `this`를 물려받는다.**

따라서 이벤트 핸들러로 화살표 함수를 사용하면 `this`가 전역 객체(`window`)를 가리키게 된다.

```javascript
// 일반 함수: this = 이벤트 리스너가 연결된 요소
element.addEventListener('click', function () {
  console.log(this)  // <button id="function">function</button>
})

// 화살표 함수: this = window (전역 객체)
element.addEventListener('click', () => {
  console.log(this)  // window
})
```

### 해결책

- **일반 함수**를 핸들러로 사용하기
- 화살표 함수를 써야 할 경우 `this` 대신 **`event.currentTarget`** 사용하기

> 이벤트 핸들러에서는 `this` 사용을 최대한 피하고, 항상 `event.currentTarget`을 쓰면 혼란 없이 일관된 코드를 작성할 수 있다.

## 💡 한 줄 요약
> 이벤트 활용의 핵심은 '요소 선택 → 핸들러 작성 → addEventListener 연결'의 3단계 반복이며, `preventDefault()`로 기본 동작을 제어하고, 화살표 함수 사용 시 `this` 대신 `event.currentTarget`을 활용해야 한다.
