# [Web] HTML, CSS 및 박스 모델

## 1. 웹 개발 학습 마인드셋
* **정답은 하나가 아니다:** 완벽한 단 하나의 정답을 찾기보다, 여러 기술을 조합해 최적의 화면을 만드는 과정입니다.
* **How to보다 Why:** 단순히 '어떻게 만드는가'보다 '왜 이 기술을 쓰는가', '어떤 원리인가'를 고민하며 검색하는 것이 중요합니다.
* **MDN 문서 활용:** 구글링할 때는 항상 기술명 뒤에 **MDN**을 붙여서 공식 문서(예: `CSS background-color MDN`)를 확인하는 습관을 들여야 합니다.

## 2. HTML (웹의 뼈대와 구조)
HTML(HyperText Markup Language)은 웹페이지의 의미와 뼈대를 잡는 마크업 언어입니다.

### HTML 문서의 기본 뼈대
VS Code에서 `!`를 입력하고 `Tab`이나 `Enter`를 누르면 아래 뼈대가 자동 완성됩니다.

    <!DOCTYPE html>
    <html lang="ko">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>문서 제목</title>
    </head>
    <body>
        </body>
    </html>

### 필수 HTML 태그 모음
| 태그 | 역할 | 사용 예시 및 특징 |
| :--- | :--- | :--- |
| `<h1>` ~ `<h6>` | 제목 (Heading) | `<h1>대제목</h1>` (h1은 페이지당 1개만 권장) |
| `<p>` | 문단 (Paragraph) | `<p>여기에 본문을 작성합니다.</p>` |
| `<a>` | 링크 (Anchor) | `<a href="https://google.com">구글로 이동</a>` |
| `<img>` | 이미지 (Image) | `<img src="이미지경로" alt="대체 텍스트">` (닫는 태그 없음) |
| `<strong>` | 강조 (Bold) | `<strong>중요한 내용</strong>` (단순 굵기가 아닌 '의미적 중요성' 부여) |
| `<ul>` / `<ol>` | 목록 (List) | `ul`은 순서 없는 목록(점), `ol`은 순서 있는 목록(숫자) |
| `<li>` | 목록 요소 (List Item) | `ul`이나 `ol` 태그 안쪽에 자식으로 사용됨 |

## 3. CSS (웹의 디자인과 인테리어)
CSS(Cascading Style Sheets)는 HTML로 만든 뼈대에 색상, 크기, 여백 등 디자인과 배치를 담당합니다.

### CSS 적용 방법 3가지
1. **인라인 스타일 (비권장):** 태그 안에 직접 작성 (`<h1 style="color: blue;">`)
2. **내부 스타일:** `<head>` 태그 안의 `<style>` 태그에 작성
3. **외부 스타일 (가장 권장):** 별도의 `.css` 파일을 만들고 `<head>`에서 `<link>` 태그로 연결

### CSS 선택자 (어떤 요소를 꾸밀지 선택)
| 선택자 기호 | 이름 | 설명 |
| :--- | :--- | :--- |
| `*` | 전체 선택자 | 문서 내 모든 태그 선택 |
| `태그명` | 요소 선택자 | 특정 태그 모두 선택 (예: `h1 { color: red; }`) |
| `.클래스명` | **클래스 선택자** | **가장 많이 사용!** 중복 사용 가능 (예: `.box { width: 100px; }`) |
| `#아이디명` | 아이디 선택자 | 문서 내 1개만 존재해야 함 (예: `#header { background: black; }`) |
| `공백` | 자손 결합자 | 부모 아래의 모든 하위 요소 선택 (예: `ul li` -> ul 안의 모든 li) |
| `>` | 자식 결합자 | 부모 바로 한 단계 아래의 직계 요소만 선택 (예: `ul > li`) |

> **명시도 (스타일 충돌 시 우선순위)**
> `!important` (필승) > 인라인 스타일 > `#아이디` > `.클래스` > `태그` > `*전체`
> 실무에서는 유지보수를 위해 가중치가 같은 **클래스(.class) 선택자 위주로 사용하는 것을 강력히 권장**합니다.

### CSS 크기 단위
* `px` (절대 단위): 고정된 크기
* `em` (상대 단위): **부모 요소**의 폰트 크기를 기준으로 배수 계산
* `rem` (상대 단위): **문서 최상위(`<html>`)** 폰트 크기를 기준으로 배수 계산 (중첩 문제를 해결하여 가장 많이 씀)

## 4. CSS 박스 모델 (핵심 레이아웃 원리)
웹페이지의 모든 HTML 요소는 눈에 보이지 않는 **사각형 박스**로 이루어져 있습니다.

### 박스의 4가지 구성 요소
1. **Content (내용):** 실제 텍스트나 이미지가 들어가는 실질적인 내용물
2. **Padding (내부 여백):** 내용물과 테두리 사이의 여백
3. **Border (테두리):** 패딩을 감싸는 선
4. **Margin (외부 여백):** 내 박스의 테두리와 다른 박스 사이의 거리

### 주의사항: Box-Sizing
기본적으로 `width: 100px;`을 주면 Content만 100px이 되어 패딩과 테두리가 추가될 때마다 상자가 커집니다. 테두리까지 포함해서 상자 크기를 고정하려면 아래 코드를 반드시 적용해야 합니다.

    * {
        box-sizing: border-box;
    }

## 5. 실전 개발 꿀팁
* **에러가 안 날 때는 개발자 도구(F12):** HTML/CSS는 문법이 틀려도 에러를 띄워주지 않습니다. 브라우저에서 `F12`나 `우클릭 -> 검사`를 눌러 요소 탭에서 직접 추적하세요.
* **값이 0일 때는 단위 생략:** `margin: 0px;` 대신 `margin: 0;`으로 작성하는 것이 표준 스타일 가이드입니다.
