## 1. 선형 회귀 (Linear Regression)

### 1-1. 단순 선형 회귀

단순 선형 회귀(Simple Linear Regression)는 설명 변수 X가 하나인 가장 기본적인 형태이다. 예를 들어 TV 광고비(X)와 매출(Y)의 관계를 직선으로 나타내는 것이다. 선형 회귀는 단순해 보이지만 실무에서 여전히 매우 널리 쓰이며, 더 복잡한 모델을 이해하는 기반이 된다.

트루 모형은 다음과 같이 정의된다.

```
y = β₀ + β₁x + ε

β₀: 절편 (y절편). 광고를 하나도 안 했을 때의 기본 매출.
β₁: 기울기. 광고비가 1단위 늘면 매출이 평균적으로 이만큼 변한다.
ε: 관측 오차. 이 값이 없다면 모든 x, y 쌍이 정확히 직선 위에 있을 것이다.
```

어제 배운 참 함수의 개념과 동일하되, 참 함수가 **선형**이라고 가정하는 것이다. 트루 β 값들은 관측 불가능하며, 관측 오차도 모른다. 관측 오차는 학습 대상이 아니라 그저 노이즈일 뿐이다. 우리가 관측하는 것은 X와 Y 데이터 쌍뿐이며, 학습의 목표는 β₀과 β₁의 추정치(β̂)를 찾는 것이다. hat(^) 기호가 추정치를 의미한다.

### 1-2. 선형 회귀로 답할 수 있는 질문들

광고비-매출 데이터가 주어지면 다음과 같은 질문에 답할 수 있다.

- 광고비와 매출 사이에 관계가 있는지, 없는지
- 관계가 있다면 그 강도는 얼마큼인지 (선형성이 얼마나 뚜렷한지)
- 여러 매체 중 어떤 매체가 매출에 더 기여하는지
- 미래에 광고비를 특정 금액만큼 쓰면 기대되는 매출이 얼마인지 (데이터에 없는 값도 예측 가능)
- 여러 매체들 간에 상호작용이 있는지

### 1-3. RSS와 잔차

추정치가 주어지면 임의의 X에 대해 예측값 ŷ을 구할 수 있다. 데이터 단위가 100만 원이고 광고비가 1억(=100)일 때, ŷ = β₀̂ + β₁̂ × 100으로 매출 추정값을 구한다. 이 예측값은 데이터 안에 있는 실제 y가 아니라 **직선 위의 값**이다.

**잔차(Residual)**: i번째 데이터 포인트에서 실제 관측값 yi와 예측값 ŷi의 차이이다. 직선에서 데이터 점까지의 세로 거리(회색 실선)에 해당한다.

```
ei = yi - ŷi  (잔차)
```

잔차의 **크기**가 작을수록 예측을 잘한 것이다. 크기이므로 제곱하여 음수·양수 상쇄를 방지한다.

**RSS(Residual Sum of Squares)**: 모든 데이터에 대해 잔차를 제곱하여 합한 값이다.

```
RSS = Σ ei²
    = Σ (yi - ŷi)²
    = Σ (yi - β̂₀ - β̂₁xi)²   ← ŷi의 정의를 풀어쓴 것
```

어제 배운 MSE에서 1/n을 곱하지 않은 것과 동일하다.

### 1-4. 최소제곱법 — 어떻게 최적값을 찾는가

학습 목표는 **RSS를 최소화하는 기울기와 절편을 찾는 것**이다. 가능한 기울기와 절편 후보는 무한히 많다(실수 집합). 10개면 일일이 대입해보겠지만 무한히 많으므로 불가능하다.

핵심 관찰: RSS는 β에 대한 **2차식(포물선)**이다. β₁ 기준으로 나머지를 상수 취급하면 포물선이고, β₀ 기준으로도 마찬가지이다. 포물선의 최솟값은 미분하여 기울기가 0인 점에서 찾을 수 있다.

```python
# 기울기 추정치: X와 Y의 공분산 / X의 분산
beta1_hat = Σ((xi - x̄)(yi - ȳ)) / Σ((xi - x̄)²)

# 절편 추정치
beta0_hat = ȳ - beta1_hat * x̄
```

이것이 닫힌 해(closed-form solution)이다. 데이터의 X, Y만 있으면 한 번에 계산 가능하다.

> **교수님 강조**: "AI라고 했지만 별거 아니다. 2차식이고 2차식에 대한 미분값만 구하는 것이다. 중고등학교 수학으로 풀 수 있는 문제이다. 고등학교에서 배운 미분의 쓰임을 드디어 AI에서 알게 됐다."

### 1-5. 회귀 결과 해석

선형 회귀를 실행하면 다음과 같은 결과표를 얻게 된다.

```
             Coefficient  Std.Error  t-statistic  p-value
Intercept       7.03        0.46       15.36      <0.001
TV              0.0475      0.003      17.67      <0.001
```

**Coefficient(계수)**: β̂ 추정치. 기울기(0.0475)와 절편(7.03)의 값.

**Standard Error(표준 오차)**: 추정치의 분산. 데이터로 추정한 값이므로 어느 정도 분산이 존재한다. 작을수록 안정적(stable)인 추정치.

**t-statistic(t 통계량)**: Coefficient ÷ Standard Error. 별거 아니라 두 값의 비율이다. t-statistic이 크면 클수록 계수값이 표준 오차에 비해 상대적으로 크다는 뜻으로, 유의미한 관계를 나타낸다.

**p-value**: 만약 트루 β가 0이라고 가정했을 때(선형성이 전혀 없다고 가정), 이만큼 극단적인 t-statistic이 관측될 확률. p-value가 0.05(5%) 미만이면 유의미하다고 판단한다. 위 예시에서 p-value < 0.001이므로 TV 광고비와 매출 사이에 **유의미한 선형 관계가 존재**한다.

### 1-6. 계수 크기에 현혹되지 않기

기울기 0.0475를 보고 "선형성이 약하다"고 판단하는 것은 **오류**이다.

데이터 단위가 100만 원이어서 0.0475가 나온 것이다. 만 원 단위였으면 4.75, 원 단위였으면 47,500. 같은 데이터인데 표기 단위만 바꾸면 기울기 값이 완전히 달라진다.

> **교수님 강조**: "기울기 값의 크기에 현혹되면 안 된다. 이 값이 작고 크고는 Standard Error에 상대적으로 비교해서 봐야 한다. 선형관계가 뚜렷한지는 p-value를 봐야 한다."

선형성이 뚜렷한지는 데이터 플롯만 눈으로 봐서도 판단하기 어렵다. 플롯을 어떻게 보여주느냐에 따라 더 뚜렷하게 보이기도 하고 덜 보이기도 한다. **정량적으로(p-value, R²) 봐야 한다.**

모델 전체 적합도: R² = 0.612. TV 광고비 하나만으로 매출 변동의 61.2%를 설명한다. 하나의 변수만으로 이 정도면 실무에서 상당히 높은 값이다.

### 1-7. 다중 선형 회귀

독립 변수가 여러 개(P개)인 경우이다. TV, 라디오, 신문 광고비 3개를 동시에 넣어 매출과의 관계를 본다.

```
y = β₀ + β₁x₁ + β₂x₂ + ... + βₚxₚ + ε
```

파라미터 수는 P+1개(P개의 기울기 + 1개의 절편). 각 계수 해석: β₂는 다른 모든 X(x₁, x₃, ..., xₚ)가 **고정되었을 때**, x₂가 1단위 증가하면 Y가 평균적으로 β₂만큼 변한다.

RSS를 최소화하는 방법은 동일하다. 각 파라미터 기준으로 편미분(나머지를 상수 취급하고 해당 변수에 대해서만 미분)하여 0이 되는 점을 찾는다. P+1개의 미지수에 P+1개의 식이 나오므로 **연립방정식**으로 풀 수 있다.

벡터·행렬 형태로 Y를 벡터로, X를 행렬로, β를 벡터로 스택하면 닫힌 해 `β̂ = (XᵀX)⁻¹Xᵀy`로 한 줄 코드로 구할 수 있다. X 행렬의 첫 열에 1을 넣는 이유는 절편(β₀)을 포함시키기 위해서이다.

X가 2개 이상이면 직선이 아니라 **하이퍼플레인(초평면)**을 찾는 문제가 된다. X가 2개면 3D 공간의 평면, 3개 이상이면 시각화 불가능한 고차원 하이퍼플레인이다. 4차원 이상의 직관은 없지만, 2D→3D 확장의 직관을 가지고 있으면 고차원도 유추할 수 있다.

### 1-8. 다중 회귀 결과 예시

TV, 라디오, 신문 3개 변수로 매출을 예측한 결과:

```
              Coefficient  Std.Error  t-stat    p-value
Intercept       2.939       0.312      9.42    <0.001
TV              0.046       0.001     32.81    <0.001
Radio           0.189       0.009     21.89    <0.001
Newspaper      -0.001       0.006     -0.18     0.860
```

TV와 라디오는 p-value가 매우 작아서 유의미하지만, **신문은 p-value가 0.860으로 유의미하지 않다**. 트루 β₃가 0일 가능성이 높으며, 매출과 신문 광고비 사이에 관계가 거의 없다. 신문의 계수가 -0.001로 작아서가 아니라, Standard Error(0.006)에 비해 상대적으로 작아서 t-statistic(-0.18)이 매우 작은 것이다.

전체 모델 R² = 0.897. 단순 회귀(TV만)의 0.612보다 훨씬 높아서, 3개 변수가 매출 변동의 약 90%를 설명한다.

### 1-9. 선형 회귀의 주의사항

**과적합 가능성**: 선형 모델이라고 과적합이 안 생기는 것이 아니다. 피처 수가 많거나 고차항으로 표현력을 키우면 발생하며, 교차 검증이 필요하다. 훈련 데이터만으로 적합한 것은 테스트 성능을 과소평가할 수 있다.

**다중공선성 문제**: 입력 변수들 간에 높은 상관관계가 있으면 계수 추정이 불안정(높은 분산)해진다.

> **교수님 팁**: 다중공선성의 직관 — "판자 비유". 선형 회귀는 데이터가 지탱해주는 **판자**를 찾는 문제이다. 데이터를 **실**로 연결해서 판자를 잡아준다고 상상하면: 데이터가 3D 공간에서 **골고루 퍼져 있으면** 실들이 여러 군데서 잡아줘서 판자가 안정적으로 서 있다. 그러나 데이터가 **일렬(선상)에만 있으면**, 마치 아기 모빌처럼 판자가 쉽게 흔들린다. 데이터 하나만 바꿔도 기울기가 완전히 달라질 수 있다(variance가 크다). "스케일을 줄이면 안 되냐"는 질문 — Coefficient와 Standard Error가 같이 줄어들므로 해결 안 된다.

**상관관계 ≠ 인과관계**: 선형 회귀의 결과는 연관관계만 나타낼 뿐 인과관계를 증명하지 않는다.

> **교수님 강조**: "아이스크림 소비량(X)과 상어 공격 빈도(Y)를 회귀하면 양의 기울기가 나온다. 아이스크림을 많이 먹으면 상어에 물릴 확률이 높다? 아니다. 둘 다 여름이라는 숨겨진 요인 때문이다. X와 Y 사이에 선형성이 있다고 해서 인과관계를 얘기하는 게 절대 아니다. 두 개가 연관되어 있다 뿐이다."

## 2. 로지스틱 회귀 (Logistic Regression)

### 2-1. 분류 문제란

분류 문제는 Y값이 카테고리(범주)인 경우이다. 눈동자 색(4가지 중 하나), 스팸 여부(스팸/정상), 신용카드 연체 여부(연체/정상) 등이 해당한다. 클래스에는 순서가 없고, 분류 함수는 입력 X를 카테고리 중 하나로 매핑하는 것이다. 직접 카테고리로 매핑하는 것 외에 **각 범주에 속할 확률**을 구할 수 있다면 더 유용할 때가 있다(예: 카드 연체 확률).

### 2-2. 신용카드 연체 데이터 탐색

사용할 데이터는 신용카드 연체 데이터이다. 피처로 밸런스(지난달 카드 사용량)와 인컴(소득)이 있고, 라벨은 연체 여부(디폴트)이다.

산점도를 보면 밸런스가 높을수록 연체자(주황색 크로스)가 많고, 밸런스가 낮은 사람들은 거의 연체하지 않았다. 반면 인컴(소득)은 연체 여부와 뚜렷한 관계가 보이지 않는다. 박스플롯으로 봐도 연체자와 비연체자의 밸런스 분포 차이는 뚜렷하지만, 인컴은 두 그룹 간 차이가 거의 없다.

### 2-3. 왜 선형 회귀로 분류를 하면 안 되는가

선형 회귀는 직선이라서 예측값에 제약이 없다. 확률은 0~1 사이여야 하는데, 선형 회귀의 예측값은 1.5나 -0.3 같은 값이 나올 수 있다. 0.5를 기준으로 잘라서 분류하더라도 확률 해석 자체가 부적절하다.

### 2-4. 시그모이드 함수

시그모이드 함수는 어떤 입력이든 0과 1 사이 값으로 변환하는 S자 함수이다.

```
σ(z) = eᶻ / (1 + eᶻ) = 1 / (1 + e⁻ᶻ)
```

두 표현은 분자·분모에 e⁻ᶻ를 곱해준 것으로 동일하다. e는 오일러 상수(약 2.718)이며, 로그는 자연로그(ln)를 사용한다.

z가 양으로 커지면 분모의 e⁻ᶻ가 0에 가까워져 σ(z) → 1. z가 음으로 커지면 분자의 eᶻ가 0에 가까워져 σ(z) → 0. **어떤 z를 넣든 출력이 무조건 0과 1 사이**인 것이 핵심이다.

### 2-5. 로지스틱 회귀 모형

시그모이드의 z 자리에 **선형식**(β₀ + β₁x)을 넣은 것이다.

```
P(Y=1|X) = σ(β₀ + β₁x)
```

어떤 X건, 어떤 β건 출력이 무조건 0과 1 사이이다. 통상적으로 Y=1이 될 확률을 이 식으로 정의하고, Y=0이 될 확률은 1에서 빼면 된다(1 - P(Y=1|X)). 어떤 걸 1로 두는지는 일관적이기만 하면 된다.

### 2-6. 오즈와 로그오즈(로짓) — 선형식과의 관계

**오즈(Odds)**: 성공 확률 / 실패 확률. 도박이나 경기에서 많이 쓰는 개념이다.

```
Odds = P(Y=1|X) / P(Y=0|X) = P(Y=1|X) / (1 - P(Y=1|X))
```

**로그오즈(Logit)**: 오즈에 자연로그를 씌운 것이다.

```
Logit = log(Odds)
```

로그오즈를 실제로 풀어보면 재미있는 결과가 나온다. P(Y=1)에 시그모이드 식을 대입하고 P(Y=0) = 1 - P(Y=1)을 대입하여 정리하면:

```
Logit = log(P(Y=1) / P(Y=0))
      = log(P(Y=1) / (1 - P(Y=1)))
      = β₀ + β₁x  ← 딱 선형식이 나온다!
```

즉 확률은 시그모이드(비선형)이지만, 로그오즈로 변환하면 **선형 모형**이 된다. 이 왔다 갔다 할 수 있는 관계 덕분에 로지스틱 회귀의 결과가 선형 회귀와 비슷한 형태로 나온다.

### 2-7. 계수 해석 — 확률이 아니라 로그오즈!

로지스틱 회귀의 계수 β₁은 "X가 1단위 증가할 때 **로그오즈가 β₁만큼 증가**한다"는 의미이다. 확률이 β₁만큼 증가한다는 의미가 **아니다**.

신용카드 연체 데이터 결과:

```
             Coefficient  Std.Error  z-stat    p-value
Intercept     -10.65       0.361    -29.49    <0.001
Balance        0.0055      0.0002    24.95    <0.001
```

"카드 사용량이 1단위 증가할 때 연체의 로그오즈가 0.0055만큼 증가한다"가 올바른 해석이다. 확률이 0.0055 증가한다는 것은 **틀린 해석**이다.

실제 확률 변화를 알려면 시그모이드 식에 직접 대입해야 한다. 밸런스 1000일 때 연체 확률은 약 0.006(0.6%), 2000일 때는 약 0.586(58.6%). 카드 사용량이 2배 늘었는데 확률은 약 **97배** 증가했다. 시그모이드가 비선형이기 때문이다.

### 2-8. MLE (최대우도추정)

선형 회귀에서는 RSS를 최소화했지만, 로지스틱 회귀에서는 확률 모델이므로 **우도(Likelihood)를 최대화**한다.

우도의 직관은 매우 간단하다.

1. 데이터에서 Y=1인 것들(연체한 사람)을 쫙 모은다 → 이 사람들의 예측 확률이 **1에 가까웠으면 좋겠다**
2. Y=0인 것들(연체 안 한 사람)을 쫙 모은다 → 이 사람들의 예측 확률이 **0에 가까웠으면 좋겠다**
3. Y=1인 것들의 확률을 전부 곱한 값(Π)을 최대화하고, Y=0인 것들은 (1-확률)을 전부 곱한 값을 최대화한다
4. 두 가지를 **동시에 달성하는 β**를 찾는 것이 MLE이다

> **교수님 팁**: "수식이 복잡해 보여도 직관은 별거 아니다. 1인 애들은 1에 가깝게, 0인 애들은 0에 가깝게 만드는 β를 찾겠다는 것이다. 이 직관만 가지고 있으면 별거 아니다."

그러나 이 곱(product)을 직접 최대화하기 어려우므로 **로그를 씌워서 로그우도를 최대화**한다. 로그의 핵심 성질: **곱셈을 덧셈으로 바꿔준다.** 곱을 다루기는 어렵지만 덧셈은 다루기 쉽다.

로그는 단조 증가 함수이므로 로그우도를 최대화하는 β와 우도를 최대화하는 β가 **동일**하다. 선형 회귀처럼 닫힌 해가 존재하지 않으므로 수치적 최적화(경사 하강법)로 β를 점진적으로 찾아간다.

다중 변수 확장도 선형 회귀 확장과 동일한 방식이다. 선형식에 변수만 더 추가하면 된다. 여전히 MLE로 β를 구하며, 결과표의 해석도 동일하다.

## 3. 뉴럴 네트워크

### 3-1. 선형 모델에서 뉴럴 네트워크로

선형 회귀를 모수적 함수로 바라보면 f(x, φ) = φ₀ + φ₁x이다. 파라미터 공간에서 RSS는 볼(bowl) 모양의 2차 함수이며, 초기 직선에서 시작하여 순차적으로 파라미터를 조정하면서 로스를 줄여가는 과정으로도 학습할 수 있다. 뉴럴 네트워크는 이 선형 함수에 **비선형 활성화 함수**를 씌워 표현력을 확장한 것이다.

### 3-2. 활성화 함수 — ReLU

ReLU(Rectified Linear Unit)는 가장 널리 쓰이는 기본 활성화 함수이다.

```python
ReLU(z) = max(0, z)
# z > 0 이면 z 그대로 출력
# z ≤ 0 이면 0 출력 (음수 부분을 잘라냄)
```

ReLU가 비선형을 만드는 핵심 요소이다. 꺾이는 점이 ReLU로 인해 생기고, 이것이 네트워크를 비선형 함수로 만든다.

### 3-3. 얕은 신경망 — 수식 구조

히든 레이어가 1개인 네트워크이다. 히든 유닛이 3개인 경우의 수식:

```
y = φ₀ + φ₁·a(θ₁₀ + θ₁₁·x) + φ₂·a(θ₂₀ + θ₂₁·x) + φ₃·a(θ₃₀ + θ₃₁·x)
```

하나하나 뜯어보면 별거 아니다.

괄호 안의 θ₁₀ + θ₁₁·x는 **선형식**(기울기 θ₁₁, 절편 θ₁₀). a()는 **활성화 함수**(ReLU). 각 덩어리를 H₁, H₂, H₃(히든 유닛)이라 부른다. φ₁, φ₂, φ₃는 각 히든 유닛에 곱해지는 상수. 마지막에 φ₀(절편)를 더해 합산한다.

뒷자리 1이 오면 기울기, 0이 오면 절편이다. 앞자리는 몇 번째 덩어리인지를 나타낸다.

총 파라미터: θ가 6개(각 유닛당 기울기+절편 × 3) + φ가 4개(φ₀~φ₃) = **10개**.

### 3-4. 얕은 신경망 — 단계별 시각화

**1단계 — 선형 변환**: 3개의 서로 다른 직선을 만든다. 각각 다른 기울기와 절편.

**2단계 — 활성화(ReLU)**: 각 직선의 음수 부분을 잘라낸다. 결과물은 0 이하가 잘린 꺾인 선. 이것들이 히든 유닛 H₁, H₂, H₃.

**3단계 — 상수(φ) 곱하기**: 각 히든 유닛에 φ를 곱한다. φ₁이 음수면 선이 뒤집히고(아래로 향하게), φ₂가 1보다 크면 기울기가 더 가파르게 된다. 그래프 모양을 보면 φ가 음수인지 양수인지, 1보다 큰지 작은지를 추론할 수 있다.

**4단계 — 합산 + 절편**: 3개의 φH 결과를 다 더하고 φ₀(절편)를 더한다. 이것이 최종 출력 Y. 합산하는 과정에서 각 꺾인 선이 서로 더해져 복잡한 모양이 만들어진다.

결과는 **피스와이즈 선형(Piecewise Linear)** 함수이다. 조각별로 보면 각 구간이 직선이고, 꺾이는 점들이 있어서 전체적으로는 비선형 함수이다.

### 3-5. 히든 유닛 수와 표현력

히든 유닛이 3개면 피스와이즈 리니어 리전이 적다. 5개, 10개, 20개, 100개로 늘리면 리전이 점점 많아져서 더 복잡한 곡선을 근사할 수 있다. 피스와이즈 리전의 개수는 활성화 함수의 개수(= 히든 유닛의 개수)에 비례한다.

**보편적 근사 정리(Universal Approximation Theorem)**: 히든 유닛이 충분히 많다면 얕은 네트워크만으로도 임의의 연속 함수를 원하는 정밀도로 근사할 수 있다. 이것은 **표현력**에 대한 이론이지, 과적합과는 별개이다.

### 3-6. 출력·입력이 여러 개인 경우

**출력이 여러 개**: Y₁과 Y₂ 두 개의 출력이 있으면, 각각 별도의 피스와이즈 선형 함수이다. 두 함수의 모양은 다르지만 **꺾이는 점의 위치는 동일**하다. 같은 활성화 함수를 공유하기 때문이다(우연이 아니라 항상 그렇다). φ 값들이 다르니 함수 형태는 다르지만 꺾이는 위치는 같다.

**입력이 여러 개**: X가 2차원이면 히든 유닛의 선형식이 하이퍼플레인이 된다. 컨투어맵에서 ReLU를 적용하면 0이 되는 경계선 기준으로 한쪽이 플랫(0)해진다. 여기에 φ를 곱해 방향·기울기를 조절하고, 다 합산하면 3D 공간에서 **종이를 접어놓은 것 같은** 피스와이즈 선형 서피스가 만들어진다.

### 3-7. 깊은 신경망 (Deep Network)

얕은 네트워크 두 개를 합성(연결)하면 깊은 네트워크가 된다. 첫 번째 네트워크(X→Y)의 출력이 두 번째 네트워크(Y→Y')의 입력이 되는 구조이다.

핵심: **같은 수의 히든 유닛이라도 깊은 네트워크가 피스와이즈 리전이 훨씬 많다.**

```
히든 유닛 6개 기준:
- 얕은 네트워크 (6개 × 1레이어): 최대 7개 리전
- 깊은 네트워크 (3개 × 2레이어): 최대 16개 리전
(파라미터 수는 깊은 쪽이 겨우 1개 더 많을 뿐)
```

> **교수님 팁**: 종이접기 비유 — 종이를 여러 번 접은 뒤 한 번 가위질하면, 펼쳤을 때 꺾인 선이 엄청 많아진다. 깊은 네트워크가 합성 함수를 통해 리전을 늘리는 원리와 동일하다. 한 쪽 구간이 압축(squeeze)되고 다른 쪽이 확장(expand)되면서 기존 리전이 더 세분화된다.

딥 네트워크를 사용하는 이유: 주어진 파라미터 숫자(또는 히든 유닛 개수)에 대해 **표현력(capacity)이 훨씬 높다**. 얕은 네트워크도 충분히 유닛을 늘리면 어떤 함수든 근사할 수 있지만, 효율성이 깊은 네트워크가 훨씬 높다.

> **교수님 강조**: "뉴럴 네트워크가 별거냐? 별거 아니다. 선형 함수에 활성화를 씌운 합성 함수이고, 결국 피스와이즈 선형 함수이다. 레이어를 쌓을수록 피스와이즈 리전이 잘게 쪼개져서 표현력이 풍부해진다."

### 3-8. 네트워크의 일반적 표현과 단순화

수식을 X 기준으로 완전히 풀어쓰면 엄청 복잡하지만, 아무도 그렇게 쓰지 않는다. 합성 함수를 단순화하면 중간 다리(Y)가 없어지고, 히든 유닛에서 히든 유닛으로 바로 연결되는 형태가 된다.

각 레이어의 연산:

```
프리 액티베이션: f = Ωh + β  (웨이트 행렬 × 이전 히든 유닛 + 바이어스 벡터)
히든 유닛: h = ReLU(f)       (활성화 함수 적용, 비선형 도입)
```

첫 레이어에서는 h 대신 X(입력)가 들어간다. 이후 레이어에서는 이전 레이어의 히든 유닛이 입력이다. 마지막 레이어에서만 활성화 없이 선형 연산으로 출력을 만든다. 이 구조를 원하는 깊이(레이어 수)와 너비(히든 유닛 수)로 구성할 수 있다.

네트워크 그림에서 1이 표시되는 경우는 **절편(바이어스)을 학습하기 위한 것**이다. 1 × β₀ = β₀ 계산을 위해 넣는 것이지, 절편 값이 1이라는 뜻이 아니다. 대부분의 네트워크 그림에서는 이 1을 생략하지만 항상 절편이 숨어 있다.

## 4. 경사 하강법 (Gradient Descent)

### 4-1. 왜 경사 하강법이 필요한가

선형 회귀에서는 닫힌 해로 한 번에 최적값을 구할 수 있었다. 그러나 로지스틱 회귀나 뉴럴 네트워크에서는 닫힌 해가 존재하지 않으므로 순차적 최적화가 필요하다.

### 4-2. 선형 회귀에서의 시각적 과정

선형 회귀의 파라미터 공간(기울기, 절편)에서 RSS는 볼(bowl) 모양의 2차 함수이다. 컨투어맵에서 어두운 색이 로스가 작은 곳이다. 초기 직선(로스 큰 곳)에서 시작하여 경사를 따라 내려가면 직선이 점점 개선된다.

```
1번 직선 (초기, 로스 큼) → 2번 직선 (조금 개선) → 3번 직선 (더 개선) → 4번 직선 (최적, 로스 최소)
```

각 단계에서 기울기와 절편이 업데이트되어 다른 직선이 생기고, 이 과정을 반복하면 RSS가 최소인 지점에 도달한다.

### 4-3. 기본 원리 — 미분의 반대 방향으로 이동

f(x) = x² - 4x + 5라는 포물선에서 최솟값을 찾는 예시. 미분하면 f'(x) = 2x - 4이다.

**x=3에서**: f'(3) = 2. 기울기가 +2이므로 오른쪽으로 올라가고 있다. 최솟점은 왼쪽 → 미분의 반대 방향(-)으로 이동.

**x=4에서**: f'(4) = 4. 기울기가 더 크다(더 가파름). 역시 반대 방향으로 이동. 기울기가 클수록 더 많이 이동할 수 있다.

**x=1에서**: f'(1) = -2. 기울기가 음수이므로 왼쪽으로 내려가고 있다. 최솟점은 오른쪽 → 미분의 반대 방향(+)으로 이동.

**결론**: 어느 위치에 있든 **미분의 반대 방향으로 이동**하면 최솟값을 향해 간다. 미분을 모르더라도 "현재 위치의 기울기를 구하고 반대 방향으로 걷는다"는 직관이면 충분하다.

```
θ_new = θ_old - α × ∇L(θ_old)

θ: 파라미터, α: 학습률, ∇L: 손실 함수의 미분값(그래디언트)
```

### 4-4. 학습률 (Learning Rate)

학습률 α는 한 번에 얼마나 크게 이동할지를 결정한다. 너무 크면 최솟점을 지나쳐 발산할 수 있고, 너무 작으면 수렴이 느리다.

### 4-5. 경사 하강법의 종류

**배치 경사 하강법(Full Batch GD)**: 전체 데이터로 그래디언트 계산. 가장 정확한 방향이지만 데이터 크면 매 스텝 계산량 많다. 컨벡스 함수에서는 직진하여 최소 이터레이션으로 수렴한다.

**확률적 경사 하강법(SGD)**: 미니 배치(일부 데이터)만으로 그래디언트 계산. 매 스텝 계산량은 적지만 방향이 부정확하여 **지그재그**로 움직인다. 학습률을 줄여가면 지그재그 양이 줄어들며 수렴하고, 수렴한다는 보장도 있다.

### 4-6. SGD의 속도에 대한 정확한 이해

> **교수님 강조**: "'SGD가 수렴이 빠르다' 또는 'SGD가 속도가 빠르다'라고 단정해서 얘기하면 아주 아마추어적인 얘기이다. 속도가 빠르다고 할 때는 무엇 기준의 속도인지를 면밀히 따져야 한다."

확실하게 말할 수 있는 것: **SGD는 매 이터레이션당(per-step) 계산량이 적다.** 미니 배치만 보니까.

확실하게 말할 수 **없는** 것들:
- "이터레이션 수가 적다" — 지그재그 때문에 오히려 더 많은 이터레이션이 필요할 수 있다. 풀 배치는 컨벡스에서 직진하므로 이터레이션 수 기준으로는 더 빠를 수 있다.
- "총 계산량이 적다" — per-step 계산량 × 이터레이션 수가 총 계산량인데, 이터레이션이 훨씬 많으면 총합은 더 클 수 있다.
- "수렴이 빠르다" — 이것도 이터레이션 기준인지, 총 시간 기준인지에 따라 다르다.

SGD의 실질적 장점: **로컬 미니멈에 빠지는 확률이 낮다.** 이상한 데이터를 뽑아서 지그재그로 가다 보면 빠져나올 수 있다. 실전에서는 대부분 SGD 또는 Adam 옵티마이저를 사용하며, 미니 배치 기반의 확률적 걸음을 걷는다.

## 5. 역전파 (Backpropagation)

### 5-1. 왜 역전파가 필요한가

뉴럴 네트워크는 여러 레이어가 중첩된 합성 함수이다. 각 레이어에 파라미터(웨이트 행렬, 바이어스 벡터)가 존재하고, 한 레이어의 파라미터를 바꾸면 이후 모든 다운스트림 레이어의 중간값과 최종 출력이 바뀐다. 경사 하강법으로 업데이트하려면 각 파라미터에 대한 미분값(그래디언트)이 필요하다.

### 5-2. 체인 룰 (연쇄 법칙)

네트워크는 합성 함수이므로 합성 함수의 미분인 체인 룰을 사용한다. 바깥 함수를 안쪽에 대해 미분하고, 안쪽을 더 안쪽에 대해 미분하여 곱하는 것을 반복한다.

```
∂Loss/∂f₀ = (∂Loss/∂f₁) × (∂f₁/∂h₁) × (∂h₁/∂f₀)
```

### 5-3. 역전파의 상세 과정

각 레이어의 프리 액티베이션(f₀, f₁, f₂, ...)에 대한 Loss의 미분값을 구한다.

**f₂에 대한 미분**: Loss를 f₂에 대해 직접 미분.

**f₁에 대한 미분**: Loss를 f₂에 대해 미분한 것(이미 구함) × f₂를 h₂에 대해 미분 × h₂를 f₁에 대해 미분. 이전 단계의 결과를 **재활용**한다.

**f₀에 대한 미분**: f₁에 대한 미분값(이미 구함)을 그대로 가져와서 × h₁을 f₀에 대해 미분. 역시 이전 결과를 **통으로 넣으면** 된다.

중간중간 히든 유닛 기준으로 미분한 값들은 **웨이트 행렬**이다. 이미 알고 있는 값들의 곱 형태로 나온다. 프리 액티베이션에 대한 미분값을 구하면, 실제 파라미터(웨이트, 바이어스)에 대한 미분값은 **히든 유닛 값을 곱해주기만** 하면 된다.

### 5-4. 역전파의 핵심

그래프를 거꾸로 따라가면서(출력→입력 방향), 연쇄 법칙을 따라 각 노드별로 미분값을 계산하는 절차가 역전파이다. 뒤에서부터 차곡차곡 미분값이 곱해져서 앞으로 전달된다.

미분값을 구하면 SGD나 경사 하강법으로 **미분의 반대 방향으로 파라미터를 업데이트**한다. 이것이 뉴럴 네트워크의 학습 전체 과정이다.

> **교수님 팁**: "역전파는 어려운 부분이다. 하지만 여러분이 직접 구현할 일은 없다. 패키지가 자동으로 해준다. 원리가 체인 룰이라는 것만 이해하면 된다."

## 정리

| 구분 | 핵심 포인트 |
|------|-------------|
| 단순 선형 회귀 | y = β₀ + β₁x + ε. RSS를 최소화하는 기울기·절편을 최소제곱법으로 구함 (2차식 미분) |
| 다중 선형 회귀 | 피처 P개 → P+1개 파라미터. 하이퍼플레인을 찾는 문제. 행렬 형태로 한 줄에 풀 수 있음 |
| 회귀 결과 해석 | 계수 크기에 현혹 금지 → p-value와 Standard Error 기준으로 유의미성 판단. 정량적으로 봐야 함 |
| 다중공선성 | 변수 간 상관 높으면 판자가 흔들리듯 추정 불안정. 데이터가 잘 퍼져야 안정적 |
| 상관 vs 인과 | 선형 회귀는 연관관계만 나타냄. 인과관계 증명이 절대 아님 (아이스크림-상어 예시) |
| 로지스틱 회귀 | 선형식 + 시그모이드. 출력이 0~1 확률. 로그오즈가 선형식이 되는 관계 |
| 계수 해석 | 로그오즈가 β만큼 증가. 확률이 β만큼 증가한다는 건 틀린 해석 |
| MLE | Y=1인 데이터의 확률은 1에 가깝게, Y=0은 0에 가깝게. 곱→로그로 덧셈 변환 |
| 뉴럴 네트워크 | 선형 변환 + ReLU 활성화의 합성 함수 → 피스와이즈 선형 함수 |
| 얕은 vs 깊은 | 같은 히든 유닛 수에서 깊은 네트워크가 리전이 훨씬 많음 (6유닛: 7 vs 16) |
| 경사 하강법 | 기울기(미분)의 반대 방향으로 이동 반복. 컨투어맵에서 경사 따라 내려가기 |
| SGD | per-step 계산량 적음. "더 빠르다"고 단정 불가. 로컬 미니멈 탈출에 유리 |
| 역전파 | 출력→입력 방향으로 체인 룰. 이전 미분값 재활용하여 효율적 계산. 패키지가 자동 처리 |
