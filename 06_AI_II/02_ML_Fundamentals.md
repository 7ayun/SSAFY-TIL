## 1. AI, 머신러닝, 딥러닝

### 1-1. 포함 관계

AI는 가장 넓은 범주의 개념으로, 주어진 환경이나 데이터를 인지하고 학습하여 예측, 행동 선택, 계획 등을 수행하는 시스템을 말한다. 머신러닝은 AI의 부분집합이며, **데이터를 기반으로 학습**하여 목적을 달성하는 접근 방식이다. 딥러닝은 머신러닝의 부분집합으로, 특정 함수인 인공신경망(Neural Network)을 활용하여 학습하는 방법론이다.

```
AI ⊃ 머신러닝 ⊃ 딥러닝
```

이 포함 관계에서 중요한 점은 다음과 같다.

**딥러닝이 아닌 머신러닝**이 존재한다. 뉴럴 네트워크를 사용하지 않는 학습 방법(선형 회귀, 의사결정나무 등)이 여기에 해당한다. **머신러닝이 아닌 AI**도 존재한다. 규칙을 사람이 직접 하드코딩하여 동작시키는 시스템이 그 예이다. 다만 현대에서 AI라고 하면 대부분 데이터 기반 학습인 머신러닝을 의미한다.

### 1-2. 머신러닝의 핵심과 일상 속 사례

머신러닝은 규칙을 직접 코딩하는 것이 아니라 **데이터에서 규칙(패턴)을 학습**하도록 하는 것이다. 유튜브에서 사용자의 취향을 알아맞춰 콘텐츠를 추천하거나, 이메일에서 스팸을 자동 분류하는 것이 대표적 사례이다. 이런 응용의 공통점은 사람이 모든 규칙을 미리 코딩하는 룰 베이스가 아니라, 데이터에서 규칙을 학습하며 데이터가 많아질수록 더 고도화된다는 것이다.

머신러닝의 대표적 응용 분야로는 ChatGPT 같은 생성 AI(언어 모델), 이미지 분류 모델(강아지/고양이 분류), 추천 알고리즘(유튜브, 넷플릭스) 등이 있다. 이 모든 것이 축적된 데이터를 바탕으로 모델이 학습하여 성능을 향상시키는 것이다.

## 2. 데이터의 구성 요소

### 2-1. 피처와 라벨

피처(Feature)는 모델이 예측에 사용하는 입력 정보로, 예측이나 판단의 근거와 단서가 된다. 라벨(Label)은 모델이 예측하려는 정답값 또는 목표값으로, 학습의 목표가 되는 값이다.

```
피처(입력) → 모델(함수) → 라벨(출력/정답)
```

### 2-2. 실생활 예시

**유튜브 추천** — 피처: 콘텐츠 장르, 크리에이터 정보, 조회수, 좋아요 수, 사용자 시청 이력, 구독 채널 등. 라벨: 사용자가 실제로 시청했는지, 좋아요를 눌렀는지, 썸즈다운을 눌렀는지 등의 피드백 정보.

**스팸 메일 분류** — 피처: 메일 제목, 발신자 주소, 특정 단어의 빈도, 이메일 내용 안의 여러 정보. 라벨: 해당 이메일이 정상인지 스팸인지의 구분.

**이미지 분류** — 피처: 이미지 자체(픽셀 정보). 라벨: 강아지인지, 고양이인지 등의 범주.

## 3. 학습의 과정

### 3-1. 1차원 피처 기반 학습

피처가 하나뿐인 가장 단순한 학습 형태이다. 예를 들어 교육 연수(x)로 수입(y)을 예측하는 문제에서, 30명의 교육 연수와 수입 데이터가 있다면 x-y 좌표 평면에 빨간색 점 30개로 나타낼 수 있다.

여기서 세 가지 핵심 개념이 등장한다.

**참 함수(f*)**: 피처와 라벨의 평균적인 관계를 나타내는 미지의 함수이다. 파란색 커브로 존재하지만 **절대 관측이 불가능**하다.

**관측 오차(epsilon)**: 실제 데이터가 참 함수에서 떨어져 있는 정도이다. 측정 기계의 한계, 환경적 노이즈 등으로 인해 데이터가 참 함수 위에 정확히 놓이지 않고 조금씩 벗어나 있다. 관측 오차 역시 직접 관측이 불가능하다.

**데이터(D)**: 우리가 실제로 관측할 수 있는 유일한 것으로, 빨간색 점들(데이터 포인트)이다. 각각의 점은 (피처, 라벨)의 쌍이다.

> **교수님 강조**: f*도 모르고 관측 오차도 모른다. 빨간색 점의 위치를 알고 관측 오차도 알면 사실 f*를 아는 것이나 마찬가지이다. 우리가 관측할 수 있는 것은 오직 빨간색 점(데이터)뿐이며, 학습이란 이 데이터만으로 피처와 라벨 간의 관계를 잘 나타내는 함수 f를 찾는 문제이다.

### 3-2. 2차원 피처 기반 학습

피처가 두 개인 경우로 확장하면, 예를 들어 교육 연수 + 경력(시니어리티)으로 수입을 예측할 때, 피처가 2차원이고 라벨이 1차원이므로 데이터는 3차원 공간에 존재한다. 참 함수 f*는 선이 아니라 **서피스(곡면)**로 표현되며, 관측 오차는 각 데이터가 이 서피스에서 떨어져 있는 정도이다.

1차원에서의 개념을 그대로 확장할 수 있다. 파란색 서피스(f*)는 여전히 관측 불가능하고, 우리는 빨간색 점(데이터)만 관측 가능하며, 서피스에서 데이터가 떨어져 있는 정도가 관측 오차이다.

### 3-3. 모델 후보와 가설 공간

데이터의 피처-라벨 관계를 설명할 수 있는 함수는 무한히 많을 수 있다. 여기서 핵심 질문이 나온다 — "어디에서, 어느 후보군에서 함수를 찾느냐?"

**가설 공간(Hypothesis Space)**이란 우리가 고려할 함수의 후보 모음이다. 피처 공간과 라벨 공간에서 정의된 함수들의 집합이며, 분석하는 사람이 설정한다. "선형 함수 중에서 찾겠다"고 하면 선형 함수가 가설 공간이 되고, 비선형 함수까지 포함하면 더 넓은 가설 공간이 된다.

예를 들어, 다음과 같은 후보 모델 3개가 있다고 하자.

```
모델 1: 기울기가 작은 직선 (선형)
모델 2: 기울기가 적절한 직선 (선형)
모델 3: 곡선이 있는 비선형 함수
```

이때 많은 사람이 모델 3을 선택하는데, 그 이유가 "아까 본 참 함수(f*)의 모양과 비슷해서"라면 잘못된 접근이다.

> **교수님 강조**: 참 함수(f*)는 절대 관측이 불가능하다. 모델을 선택할 때 f*와의 유사성을 기준으로 판단하면 안 된다. 실전에서는 f*가 어떻게 생겼는지 자체를 모르기 때문이다. 여러 후보 모델 중에서 선택하려면 "어떤 기준으로 선택할지(선택 기준)"가 필요하다.

선형 함수라고 하면 기울기와 y절편으로 정의된 직선들이다. 곡선(비선형)은 선형이 아니다. 가설 공간이 선형 함수로 제한되면 그 무한히 많은 직선들 중에서 데이터를 가장 잘 적합하는 특정 직선을 찾는 것이 테스크이고, 비선형까지 포함하면 더 넓은 후보군에서 찾게 된다. 뉴럴 네트워크는 가장 유연한 함수이므로 가장 넓은(제약이 적은) 가설 공간에 해당한다.

### 3-4. 손실 함수와 학습 과정 정리

가설 공간 내에서 어떤 함수가 더 좋은지 판단하려면 정량적 선택 기준이 필요하다. 이것이 **손실 함수(Loss Function)**로, 예측값과 실제값의 차이를 측정하는 지표이다.

학습 과정을 정리하면 다음과 같다.

```
1. 데이터 확보 — 피처와 라벨의 쌍 (빨간색 점들)
2. 가설 공간 설정 — 선형, 비선형, 뉴럴 네트워크 등 후보군 결정
3. 손실 함수 정의 — 예측값과 실제값의 차이를 정량화
4. 손실 함수가 가장 작은 모델 선택 — 가설 공간 내 최적 함수
```

> **교수님 팁**: "나는 선형 모델에서 찾겠다", "나는 로지스틱 모형에서 찾겠다", "나는 뉴럴 네트워크에서 찾겠다"와 같이 가설 공간을 먼저 선택한 뒤, 그 안에서 손실 함수 기준으로 최적 모델을 찾는 것이 전체 학습의 프레임워크이다.

## 4. 평가 지표 — 회귀

### 4-1. MSE (Mean Squared Error)

평균 제곱 오차는 예측값과 실제값 차이의 제곱 평균이다.

```
MSE = (1/n) × Σ(yi - ŷi)²
```

값이 작을수록 좋으며, 항상 양수이다. 단위가 원래 데이터의 제곱 형태이므로, 루트를 씌운 RMSE를 사용하면 실제 데이터 단위로 해석할 수 있다.

### 4-2. R² (결정 계수)

결정 계수는 y값에 존재하는 전체 분산 중에서 모델이 설명하는 비율이다.

```
R² = 1 - (Σ(yi - ŷi)² / Σ(yi - ȳ)²)
```

분자는 모델의 예측 오차 제곱합이고, 분모는 y의 평균(ȳ)으로부터의 편차 제곱합이다. 분모는 모델링과 무관하게 데이터 자체가 가지고 있는 분산이다.

**R²의 직관적 이해**: 모델링을 잘해서 예측값이 실제값에 가까우면 분자가 0에 가까워지고, R²는 1에 가까워진다. 반대로 모델링을 못하면 분자가 커지고 R²는 작아진다. 즉 R²는 "y값의 분산 중 내 모델이 설명하는 비율"이다.

**R²의 상한 — 1을 넘을 수 있는가?** 불가능하다. 분자와 분모가 모두 양수(제곱합)이고, 분자가 최소 0이므로 R²의 최댓값은 1이다. 다만, 데이터에 노이즈가 존재하면 실제로 1이 달성 가능하지 않을 수 있다.

**R²의 하한 — 음수가 나올 수 있는가?** 가능하다. 모델의 예측값이 단순히 y의 평균(ȳ)으로 예측하는 것보다도 못할 경우, 분자가 분모보다 커져서 R²가 음수가 된다.

> **교수님 팁**: 실제 사례 — 어떤 학생이 뉴럴 네트워크로 복잡한 모델을 만들어왔는데 R²가 음수가 나왔다고 했다. "소프트웨어 오류 같다"고 했지만, 실제로는 y 평균보다도 못 맞추는 모델을 만든 것이다. 현업에서도 발생하는 상황이므로, R²가 음수라면 모델을 다시 점검해야 한다.

### 4-3. MSE와 R²의 비교

MSE는 절대적인 오차 크기를 보여주지만, 그 값만으로 잘한 건지 못한 건지 판단하기 어렵다. MSE가 36이 나왔을 때, 다른 모델이 300이면 잘한 것이고, 다른 모델이 10이면 못한 것이다. R²는 데이터 단위에 상관없이 상대적 비율이므로, 0.8이 나오면 "전체 분산의 80%를 설명한다"고 해석할 수 있다. 그러나 R²만으로는 구체적인 오차 크기를 알 수 없다.

두 지표는 상호 보완적이다. 분석할 때 **두 개를 함께 보는 것이 좋은 습관**이다. MSE로 구체적 오차 크기를 파악하고, R²로 상대적 설명력을 파악한다.

## 5. 평가 지표 — 분류

### 5-1. 분류 문제란

분류 문제는 라벨이 연속적 숫자가 아니라 카테고리(범주)인 경우이다. 이진 분류(정상/스팸, 양성/음성)일 수도 있고, 다중 분류(강아지/고양이/햄스터, 학점 A/B/C/F)일 수도 있다. 분류란 결국 데이터 공간에서 **결정 경계(Decision Boundary)**를 찾는 문제이다.

분류에서는 MSE나 R²를 사용하기 어렵다. 라벨이 숫자가 아니라 범주이므로 다른 척도가 필요하다.

### 5-2. 정확도와 그 한계

정확도(Accuracy)는 전체 중 맞춘 비율이다.

```
정확도 = (1/n) × Σ I(ŷi = yi)
```

여기서 I()는 지시 함수(Indicator Function)로, 안의 조건이 참이면 1, 거짓이면 0이다. 즉 예측한 범주와 실제 범주가 같을 때만 1이므로, 전체에서 정답을 맞춘 비율(적중률)을 계산하는 것이다.

그런데 **정확도가 99%인 모델이 좋은 모델인가?** 반드시 그렇지는 않다.

불균형 데이터 예시: 1000명의 데이터에서 실제 질병 환자가 10명이고 건강한 사람이 990명이라면, 피처를 전혀 보지 않고 무조건 "건강하다"라고 예측하는 바보 같은 모델도 정확도 99%를 달성한다. 이 모델은 인풋을 완전히 무시하고 한쪽으로만 예측하는 모델인데도 정확도는 높다. 정확도만 보면 속을 수 있다.

> **교수님 강조**: 정확도는 단순히 전체 중 맞춘 비율만 계산하는 것이니, 정확도만 보지 말고 다른 지표를 함께 봐야 안전하다.

### 5-3. 혼동 행렬

혼동 행렬(Confusion Matrix)은 예측값과 실제값 사이의 관계를 행렬 형태로 나타낸 것이다.

| | 예측: 양성 | 예측: 음성 |
|---|---|---|
| 실제: 양성 | TP (참 양성) | FN (누락, False Negative) |
| 실제: 음성 | FP (오탐, False Positive) | TN (참 음성) |

**TP (True Positive)**: 실제 양성이고 예측도 양성. 좋은 것.
**TN (True Negative)**: 실제 음성이고 예측도 음성. 좋은 것.
**FP (False Positive, 오탐)**: 실제 음성인데 양성이라고 잘못 예측. 작았으면 좋겠다.
**FN (False Negative, 누락)**: 실제 양성인데 음성이라고 잘못 예측. 작았으면 좋겠다.

좋은 모델은 대각선(TP, TN)이 높고, 비대각선(FP, FN)이 작은 것이다.

### 5-4. 정밀도, 재현율, F1 스코어

**정밀도(Precision)**: 양성이라고 예측한 것 중에서 진짜 양성의 비율.

```
정밀도 = TP / (TP + FP)
```

모델이 "양성이다"라고 판정한 것들 중에서 진짜로 양성인 비율이다. FP(오탐)가 작을수록 정밀도가 높다.

**재현율(Recall, Sensitivity)**: 실제 양성 중에서 양성으로 잡아낸 비율.

```
재현율 = TP / (TP + FN)
```

실제 양성인 것들 중에서 모델이 제대로 양성이라고 예측한 비율이다. FN(누락)이 작을수록 재현율이 높다.

**F1 스코어**: 정밀도와 재현율의 조화 평균이다.

```
F1 = 2 × (정밀도 × 재현율) / (정밀도 + 재현율)
```

정밀도와 재현율 모두 높으면 F1도 높다. 불균형 데이터에서 무조건 한쪽으로 예측하는 모델은 F1 스코어가 낮게 나오므로, **정확도보다 F1 스코어가 더 신뢰할 수 있는 지표**이다.

## 6. 과적합과 일반화

### 6-1. 학습의 목적

학습의 목적은 훈련 데이터에서만 잘하는 것이 아니라 **새로운 데이터에서도 정확한 예측을 수행**하는 것이다. 이를 일반화(Generalization)라 하며, 학습된 모델의 성능 평가는 모델이 처음 보는 데이터로 수행해야 한다.

### 6-2. 과적합(Overfitting)의 정확한 정의

과적합은 훈련 데이터에 있는 **우연한 패턴이나 잡음(관측 오차)까지 다 외워 버려서**, 훈련 데이터에서는 오류가 작지만 테스트 데이터(같은 분포에서 오는 새로운 데이터)에서 오류가 커지는 현상이다.

분류 예시로 보면, 파란색과 빨간색 클래스가 있을 때 훈련 데이터의 에러를 0으로 만들겠다는 일념으로 아주 복잡한 결정 경계(초록색 곡선)를 만들면, 훈련 데이터에서 하나도 오류가 없다. 그러나 실제 참 결정 경계(검정색 실선)는 이보다 단순하고, 노이즈 때문에 일부 데이터가 경계를 넘어간 것일 뿐이다. 이 상태에서 같은 분포의 새로운 데이터가 오면 오히려 에러가 더 크다.

### 6-3. 과적합에 대한 흔한 오해

> **교수님 강조**: 과적합에 대한 오해가 머신러닝을 공부한 사람들도 잘못 얘기하는 경우가 있다. "분포가 변해서(훈련과 다른 테스트 분포에서) 성능이 떨어지는 것"은 과적합이 **아니다**. 이는 테스트 분포가 달라져서 당연히 발생하는 오류이며, 과적합이 없어도 발생한다.

비유로 설명하면 다음과 같다.

**과적합인 것**: 국어 기출 문제의 답만 달달 외워서, 같은 범위의 새로운 국어 시험 문제에 적응력이 없는 것.

**과적합이 아닌 것**: 국어 시험을 준비했는데 갑자기 영어/일본어 시험을 보라는 것. 이건 테스트 분포가 바뀐 것이지 과적합이 아니다.

또 다른 예시 — 실사 사진으로 개/고양이 분류 모델을 학습시킨 뒤, 카툰 형식의 이미지로 테스트하면 분류를 못한다. 이것은 과적합이 아니라 분포의 변화로 인한 오류이다.

과적합의 핵심 조건 두 가지를 기억해야 한다. 첫째, **같은 분포에서 오는** 새로운 데이터에 대해 성능이 나쁜 것. 둘째, 그 원인이 **훈련 데이터의 잡음까지 다 외워버렸기 때문**인 것.

### 6-4. 언더피팅과 적절한 복잡도

언더피팅(Underfitting)은 모델이 너무 단순해서 학습이 덜 된 상태이다. 비유하면 내일 시험인데 공부를 안 하고 노는 것이다. 과적합(기출 답만 외우는 것)만큼이나 피해야 하며, **적절한 복잡도**를 갖는 모델을 찾는 것이 학습의 핵심 과제이다.

요즘은 뉴럴 네트워크라는 매우 유연한 함수를 주로 사용하기 때문에 언더피팅보다 과적합의 위험이 더 크지만, 두 가지 모두 피해야 하는 것이다.

### 6-5. 훈련 오류 vs 테스트 오류 곡선

모델 복잡도(유연성)를 x축, 오류를 y축에 놓으면 다음과 같은 관계가 나타난다.

```
         오류
          │   ╲  테스트 오류
          │    ╲___________╱
          │                  ← 적절한 복잡도 (Right Fit)
          │     ___________
          │    ╱  훈련 오류
          └──────────────── 모델 복잡도 →
       언더피팅              오버피팅
```

모델이 복잡해질수록 훈련 오류는 계속 감소한다. 충분히 복잡한 모델은 훈련 데이터의 노이즈까지 다 학습할 수 있기 때문이다. 그러나 테스트 오류는 처음에는 감소하다가 어느 시점부터 오히려 증가한다. 적절한 복잡도에서 테스트 오류가 최소가 되는 지점이 우리가 찾아야 할 Right Fit이다.

> **교수님 주의**: 훈련 오류가 매우 작다고 해서 무조건 과적합인 것은 아니다. 테스트 오류와 비교해야 한다. 훈련 오류도 작고 테스트 오류도 작으면 최고의 경우(Golden Case)이다. 과적합은 훈련 오류가 작은데 테스트 오류가 큰 경우에 해당한다.

## 7. 교차 검증

### 7-1. 왜 교차 검증이 필요한가

이상적으로는 충분히 큰 별도의 테스트 데이터셋이 있으면 가장 좋다. 훈련 데이터로 학습하고, 독립된 테스트 데이터로 성능을 평가하면 된다. 그러나 현실에서는 학습에 쓸 데이터조차 부족한 경우가 많아, 별도 테스트셋을 확보하기 어렵다.

훈련 오류로 테스트 오류를 가늠하려 하면 과소 평가하게 된다. 기출 문제를 다 풀어본 사람이 기출 문제에서의 점수로 내일 시험 점수를 예측하면 실제보다 높게 추정하는 것과 같다.

교차 검증은 **별도의 테스트셋이 없을 때**, 훈련 데이터만으로 테스트 성능을 추정하는 방법이다. 만약 현업에서 테스트 데이터가 충분히 많다면 교차 검증이 필요 없을 수도 있다.

### 7-2. 검증셋(Validation Set) 방법

가용 데이터를 셔플링한 뒤 두 부분으로 나눈다(반드시 반일 필요는 없다). 한쪽은 훈련셋으로 모델을 학습시키고, 나머지는 검증셋으로 오류만 계산한다. 검증셋에서의 오류를 테스트 오류의 추정치로 사용한다.

예를 들어 392개 데이터가 있는 자동차 데이터셋에서 반으로 나누어 196개로 학습, 196개로 검증한다. 다항식 1차부터 10차까지 10개 후보 모델에 대해 각각 검증 오류를 계산하면, 어떤 복잡도의 모델이 테스트에서 더 나을지 가늠할 수 있다. 예를 들어 2차항 모델의 검증 오류가 약 19, 1차항 모델의 검증 오류가 약 23.8이라면 2차항이 더 나은 것으로 추정한다.

단점은 **어떻게 나누느냐에 따라 결과의 변동(variance)이 크다**는 것이다. 셔플링할 때마다 다른 결과가 나올 수 있다.

### 7-3. K-fold 교차 검증

검증셋 방법의 변동 문제를 해결하기 위해, 데이터를 K개의 폴드로 나누어 각 폴드를 한 번씩 검증셋으로 사용하고 나머지로 학습하는 것을 K번 반복한다.

```
5-fold 교차 검증 예시:

[Fold1 검증 | Fold2 훈련 | Fold3 훈련 | Fold4 훈련 | Fold5 훈련] → 오류1
[Fold1 훈련 | Fold2 검증 | Fold3 훈련 | Fold4 훈련 | Fold5 훈련] → 오류2
[Fold1 훈련 | Fold2 훈련 | Fold3 검증 | Fold4 훈련 | Fold5 훈련] → 오류3
[Fold1 훈련 | Fold2 훈련 | Fold3 훈련 | Fold4 검증 | Fold5 훈련] → 오류4
[Fold1 훈련 | Fold2 훈련 | Fold3 훈련 | Fold4 훈련 | Fold5 검증] → 오류5

최종 추정 = (오류1 + 오류2 + 오류3 + 오류4 + 오류5) / 5
```

이 최종 추정값이 작으면 테스트 성능이 좋을 것으로 기대할 수 있다. 회귀에서는 MSE, 분류에서는 정확도나 F1 스코어를 검증 오류로 사용한다.

### 7-4. Leave-One-Out 교차 검증

K를 데이터 개수 n으로 설정한 극단적 케이스이다. 검증셋이 딱 1개이고, 나머지 n-1개로 학습한 뒤 1개에 대해 예측하는 것을 n번 반복한다. 셔플링이 의미 없다(어차피 모든 데이터가 한 번씩 검증셋이 되므로). 결과가 고정되어 변동이 없다는 장점이 있지만, **모델을 n번 적합시켜야 하므로 계산량이 매우 크다**. 데이터가 100만 개면 모델을 100만 번 학습시켜야 한다. 실전에서는 거의 사용하지 않는다.

### 7-5. 실전에서의 선택

10-fold 교차 검증만으로도 Leave-One-Out과 거의 비슷한 결과를 얻을 수 있으며, 실제 테스트 오류의 경향을 잘 포착한다. 10-fold는 데이터 크기에 상관없이 모델을 10번만 적합시키면 되므로 계산 효율적이다.

> **교수님 팁**: 검증셋 방법은 한 번만 나누면 변동이 크다. 10-fold 교차 검증이면 실전에서 충분하며, 이 값이 작은 모델을 선택하면 테스트에서도 성능이 좋을 것으로 기대할 수 있다.

여러 데이터셋에서 실험한 결과, 10-fold 교차 검증으로 추정한 오류 곡선은 실제 테스트 오류 곡선(관측 불가)과 거의 일치하며, 특히 오류가 최소가 되는 모델 복잡도 지점을 잘 캡처한다.

## 8. 비지도 학습

### 8-1. 비지도 학습이란

비지도 학습은 라벨(정답) 없이 **데이터의 구조나 패턴 자체를 학습**하는 것이다. 지도 학습에서는 피처와 라벨의 관계를 찾았지만, 비지도 학습은 피처만 가지고 구조를 학습한다. 대표적으로 군집화(Clustering)와 차원 축소가 있다.

중요한 점은 정답이 없으므로 "더 잘한다/못한다"를 명확히 구분하기 어렵다는 것이다. 따라서 **단일 시도가 아닌 여러 번 시도**와 **도메인 지식 활용**이 중요하다.

### 8-2. 클러스터링 개요

클러스터링은 데이터 안에서 하위 집단(군집, 클러스터)을 찾아내는 기법이다. 각 클러스터 안에서는 서로 유사하고, 다른 클러스터 간에는 서로 상이하도록 데이터를 나누는 것이 목표이다. 예를 들어 고객 데이터의 가구 소득, 직업, 도심 거리, 구매 내역 등의 피처를 가지고 비슷한 고객끼리 묶어 고객 세그먼테이션(시장 세분화)을 하는 것이 대표적 활용이다.

클러스터링의 핵심 원칙은 다음과 같다. 모든 데이터 포인트는 정확히 하나의 군집에 속해야 한다(파티션). 즉 어떤 데이터도 빠지면 안 되고, 복수의 클러스터에 속할 수도 없다. 좋은 클러스터링이란 **각 클러스터 내부의 변동(분산)이 작은 것**을 의미한다. 다만 내부 분산을 0으로 만들려면 K=n(데이터 수만큼 클러스터)으로 놓으면 되지만, 그것은 우리가 원하는 것이 아니다.

### 8-3. K-means 클러스터링

K-means는 사전에 클러스터 개수 K를 정한 뒤 데이터를 나누는 가장 널리 쓰이는 방법이다. K는 알고리즘의 인풋으로 들어가므로, 사용자가 먼저 "나는 몇 개로 나눌 것이다"를 선언해야 한다.

알고리즘은 다음과 같다.

```python
# K-means 알고리즘
# 1. 초기화: 각 데이터 포인트에 무작위로 1~K 클러스터 배정
# 2. 반복 (재배정이 바뀌지 않을 때까지):
#    a. 센트로이드 계산: 각 클러스터의 중심점(평균값) 계산
#    b. 재배정: 각 데이터를 가장 가까운 센트로이드의 클러스터로 재배정
#       (유클리디안 거리 기준)
# 3. 종료: 재배정이 이전과 동일하면 멈춤
```

**단계별 예시 (K=3)**: 처음에 모든 데이터에 무작위로 3색(오렌지, 초록, 핑크)을 흩뿌린다. 무작위이므로 세 센트로이드가 서로 가까이 몰려 있다. 이 상태에서 센트로이드 기준으로 재배정하면, 오렌지 센트로이드에 가까운 데이터는 모두 오렌지로, 핑크에 가까운 건 핑크로, 초록에 가까운 건 초록으로 바뀐다. 재배정 후 센트로이드를 다시 계산하면 위치가 이동한다. 이를 반복하면 점점 센트로이드가 각 클러스터의 실제 중심으로 수렴하고, 결국 재배정이 더 이상 바뀌지 않아 멈춘다.

종료 조건은 재배정이 이전과 동일하거나 모든 센트로이드가 하나도 안 바뀔 때이다. 매 이터레이션마다 중심점과의 평균 거리가 줄어들기 때문에 결과는 계속 개선된다.

### 8-4. K-means의 주의점 — 초기값 의존성

**같은 데이터, 같은 K로 돌려도 결과가 달라질 수 있다.** 초기 무작위 배정이 다르면 다른 결과로 수렴할 수 있기 때문이다(로컬 미니멈 문제). 실제로 같은 데이터에서 K=3으로 6번 돌리면 일부는 같은 결과, 일부는 다른 결과가 나온다. 4개는 동일한 클러스터링이었고 2개는 다른 결과였다.

참고로 클러스터의 **색깔은 아무런 의미가 없다**. 두 결과에서 색깔이 다르더라도 나누는 방식이 같으면 동일한 결과이다. 색깔은 단지 "서로 다른 클러스터"임을 표시하기 위한 것일 뿐이다.

따라서 K-means는 **한 번만 돌리면 안 된다**. 여러 번 반복 실행하여 클러스터 내부 분산(Within-Cluster Variation)이 가장 작은 결과를 선택해야 한다. 내부 분산은 계산할 수 있는 정량적 값이므로, 여러 번 돌린 뒤 비교하면 된다.

### 8-5. 계층적 군집 (Hierarchical Clustering)

K-means와 달리 K를 미리 정하지 않는 방법이다. K-means의 단점인 "K를 사전에 알아야 한다"를 해소하지만, 계산량이 더 많다(페어와이즈로 모든 클러스터 쌍의 거리를 계산해야 하므로 n²에 비례).

상향식(Agglomerative) 방식은 다음과 같이 동작한다.

```
1. 각 데이터 포인트가 각각 하나의 클러스터로 시작 (n개 클러스터)
2. 반복:
   a. 모든 클러스터 쌍의 거리를 계산 (페어와이즈)
   b. 가장 유사한(가까운) 두 클러스터를 병합
   c. 병합된 상태 유지 (뭉친 뒤에는 떨어지지 않음)
3. 최종적으로 하나의 덩어리가 될 때까지 반복
```

매우 중요한 점: **데이터 포인트끼리 뭉치는 것이 아니라 항상 클러스터끼리 뭉치는 것**이다. 처음에 각 데이터 포인트가 1개짜리 클러스터인 것이고, 이후에는 여러 개가 포함된 클러스터끼리 병합된다.

**9개 데이터 포인트 예시**: 처음에 모든 포인트가 개별 클러스터이다. 5와 7이 가장 가까우므로 먼저 병합된다. 그 다음 1과 6이 가장 가까워 병합된다. 그 다음 8이 {5,7} 클러스터에 가장 가까워 병합된다. 이 과정이 순차적으로 반복되어 최종적으로 하나의 덩어리가 된다.

이 병합 순서를 **덴드로그램(Dendrogram)**으로 시각화한다. 가장 밑에 개별 데이터 포인트가 있고, 위로 올라갈수록 병합되는 나무를 뒤집은 형태이다. 다 뭉친 뒤 사후적으로 "어디서 자를지"를 결정한다. 두 개로 자르면 2개 클러스터, 세 개로 자르면 3개 클러스터가 된다.

덴드로그램에서 **가지의 높이 차이(낙차)**가 큰 지점이 좋은 절단 후보이다. 높이 차이가 크다는 것은 그 단계에서 내부 분산의 감소가 크다는 뜻이다. 반면 높이 차이가 거의 없는 구간은 나누나 마나 비슷하다는 의미이다.

### 8-6. 링키지(Linkage) — 클러스터 간 거리 정의

두 데이터 포인트의 거리는 명확하지만, 두 클러스터 간의 거리는 정의 방식에 따라 달라진다. "8이 {5,7} 클러스터와 가깝다"고 할 때, 8이 5와 가까워서인지, 7과 가까워서인지, 5와 7의 평균과 가까워서인지에 따라 결과가 달라진다.

**싱글 링크(Single Linkage)**: 두 클러스터에서 가장 가까운 점 쌍의 거리. 가장 낙관적(관대한) 기준. 웬만하면 붙이고 싶을 때 적합.

**컴플릿 링크(Complete Linkage)**: 두 클러스터에서 가장 먼 점 쌍의 거리. 가장 보수적인 기준. 확실히 가까운 것만 붙이고 싶을 때 적합.

**에버리지 링크(Average Linkage)**: 두 클러스터의 모든 점 쌍 거리의 평균. 중간적 기준.

어떤 링키지를 사용하느냐에 따라 **같은 데이터라도 클러스터링 결과가 달라진다**. 정답이 있는 것이 아니므로 여러 링키지를 시도해보고, 그중에서 더 맥센스한(합리적인) 결과를 선택하는 것이 권장된다.

### 8-7. K-means vs 계층적 군집 비교

K-means는 계산량이 적지만 K를 사전에 정해야 한다. 센트로이드와 각 데이터 포인트만 비교하면 되므로 효율적이다. 계층적 군집은 K를 몰라도 되지만 모든 클러스터 쌍의 거리를 계산해야 하므로 계산량이 더 많다(n²에 비례). 두 방법 모두 장단점이 있으며, 상황에 따라 선택한다.

### 8-8. 클러스터링에서의 스케일링

> **교수님 주의**: 클러스터링은 거리 기준으로 계산하기 때문에, 피처의 단위가 다르면 결과가 크게 달라질 수 있다. 어떤 피처는 수천 단위로 움직이는데 다른 피처는 0.1이 최댓값이라면, 값이 큰 피처에 치우쳐서 클러스터링된다. 모든 피처를 평균 0, 표준편차 1로 스케일링(평균을 빼고 표준편차로 나누기)하는 것이 좋은 습관이다. 이를 통해 변수의 단위 차이에 영향받지 않는 클러스터링이 가능하다.

## 9. 참고 — 비지도 학습의 철학 (읽을거리)

비지도 학습은 정답이 없다. 정답이 없으므로 하나의 정해진 지표를 최적화하는 것이 목적이 아니라, 데이터에서 인사이트를 얻는 과정이다. "무조건 어떤 하나의 기준으로 정답을 찾으려는 접근"에서 벗어나야 한다. K-means에서 클러스터 내부 분산이 작은 게 좋다고 했지만, K를 n(데이터 수)으로 놓으면 내부 분산이 0이 된다. 각 클러스터에 데이터가 딱 1개씩만 들어가기 때문이다. 그것은 우리가 원하는 것이 아니다. 비지도 학습은 이런 철학적 이해를 바탕으로, 여러 번 시도하고 도메인 지식을 활용하여 접근하는 것이 중요하다.

## 정리

| 구분 | 핵심 포인트 |
|------|-------------|
| AI/ML/DL | AI ⊃ 머신러닝 ⊃ 딥러닝의 포함 관계, 현대 AI는 대부분 데이터 기반 학습(ML) |
| 피처/라벨 | 피처는 모델의 입력 정보, 라벨은 예측 목표값. 참 함수(f*)와 관측 오차는 관측 불가 |
| 학습 과정 | 데이터 → 가설 공간 설정 → 손실 함수 기준으로 최적 모델 선택 |
| 회귀 평가 | MSE(작을수록 좋음)와 R²(1에 가까울수록 좋음)를 함께 사용. R²는 음수 가능 |
| 분류 평가 | 정확도만으로는 불균형 데이터에서 속을 수 있음 → 혼동행렬, F1 스코어 함께 확인 |
| 과적합 | 훈련 데이터의 잡음까지 학습 → 같은 분포의 새 데이터에서 성능 저하. 분포 변화와 반드시 구분! |
| 언더피팅 | 모델이 너무 단순해서 학습이 덜 된 상태. 과적합만큼이나 피해야 함 |
| 교차 검증 | 테스트셋이 없을 때 훈련 데이터를 K개로 나누어 성능 추정. 10-fold이면 실전에서 충분 |
| K-means | K를 미리 정해야 함. 여러 번 실행 후 내부 분산 작은 결과 선택. 초기값에 따라 결과 다름 |
| 계층적 군집 | K 사전 결정 불필요. 덴드로그램으로 사후 결정. 링키지(싱글/컴플릿/에버리지)에 따라 결과 상이 |
| 스케일링 | 클러스터링 전 피처 스케일링 필수 — 평균 0, 표준편차 1로 맞추기 |
