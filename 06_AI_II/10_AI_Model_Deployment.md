## 1. AI 가속기 구동과 정수 연산 양자화

### 1-1. 엣지 AI(온 디바이스 AI)가 필요한 이유

클라우드 AI가 충분히 잘 동작함에도 불구하고 스마트폰, 로봇, 임베디드 디바이스처럼 제한된 환경에서 AI를 직접 구동해야 하는 이유는 크게 세 가지다.

**첫 번째: 프라이버시**  
ChatGPT나 Gemini를 사용할 때 사용자는 업무 정보뿐만 아니라 연애 상담, 심리 상담, 진로 상담 등 민감한 개인정보를 클라우드에 전송한다. 의료 데이터나 국가 수준의 기밀 정보는 클라우드 의존이 더욱 어렵다. 온 디바이스 AI는 데이터를 외부로 전송하지 않고 로컬에서 처리·소비 후 삭제하므로 프라이버시를 보호할 수 있다.

**두 번째: 실시간 반응성**  
데이터 전송 속도는 아무리 빨라도 빛의 속도(광통신)까지다. 빛은 지구를 초당 7.5바퀴 돌므로 한 바퀴에 약 133ms가 걸린다. 태평양 건너 구글 클라우드에 데이터를 보내고 받으면 수십 ms 이상의 지연이 발생한다. VR/AR 게임, 로봇 제어 등 수 ms 수준의 실시간 반응이 필요한 응용에는 클라우드 AI가 근본적으로 불가능하다.

**세 번째: 인터넷 의존성**  
클라우드 AI는 인터넷이 끊기면 동작하지 않는다. 실제로 ChatGPT나 AWS 클라우드가 수 시간~하루 동안 먹통이 된 사례가 있으며, 이 경우 해당 서비스에 의존하는 개인과 기업이 막대한 손실을 입는다. 온 디바이스 AI는 인터넷 연결과 무관하게 독립적으로 동작한다.

> **교수님 강조**: 클라우드에 AI를 다 의존하면 인터넷이 끊길 때 내 뇌도 같이 멈추는 부작용이 발생한다. AI를 유용하게 쓰되, 인터넷 의존을 최소화하는 방향도 고민해야 한다.

### 1-2. CPU, GPU, NPU(AI 가속기)의 차이

| 구분 | 특징 | 장단점 |
|------|------|--------|
| CPU | 범용 연산기 | 모든 연산 가능, 상대적으로 느림 |
| GPU | 병렬/행렬 연산 특화 | CPU보다 빠른 행렬 연산, 원래는 그래픽용 |
| NPU | 뉴럴 네트워크 연산 전용 | GPU보다 더 특화, 매우 빠르지만 지원 연산 한정 |

GPU는 원래 게임 그래픽 처리를 위해 개발됐다. 그래픽이란 본질적으로 가로×세로 픽셀의 병렬 행렬 정보이므로, GPU는 병렬 행렬 연산에 특화됐다. 딥러닝이 등장했을 때 뉴럴 네트워크 연산도 행렬 곱이었기 때문에 GPU가 자연스럽게 채택됐다. 엔비디아는 AI를 위해 GPU를 만든 게 아니었지만 AI 시대에 잘 맞아떨어져 큰 이득을 보고 있다.

NPU는 GPU보다 더 뉴럴 네트워크 연산에 특화된 가속기다. 특화된 만큼 지원하는 연산 종류가 제한되고, **정수(integer) 연산만 지원한다**. 실수 연산을 지원하지 않기 때문에 AI 모델을 NPU에서 구동하려면 모든 연산이 정수로만 이루어져야 한다.

### 1-3. 일반적인 값의 양자화 (Value Quantization)

이미 배운 내용의 리캡이다. 실수 r을 정수 q로 표현하는 것이 값의 양자화다.

**관심 범위 설정:** 실수는 무한한 범위를 가지므로, 뉴럴 네트워크의 파라미터/액티베이션 분포를 관찰해 가장 빈번하게 나타나는 범위 [rmin, rmax]를 지정한다.

**8비트 양자화 예시:**
- rmin → 0, rmax → 255 에 매핑
- 스케일링 파라미터: **S = (rmax - rmin) / 255**
- Offset 파라미터: **Z = floor(-rmin / S)**
- 역변환: r = S × (q - Z)
- rmin보다 작은 값은 전부 0, rmax보다 큰 값은 전부 255로 클리핑

> **교수님 강조**: 여기서 핵심은 스케일링 파라미터 S가 실수라는 점이다. rmax와 rmin이 실수이고 나눗셈을 수행하므로 S는 반드시 실수가 된다.

### 1-4. 일반 양자화의 한계: 연산 과정까지 실수가 개입

값을 양자화해서 Q(정수)로 표현하더라도, Q로 연산을 수행할 때 스케일링 파라미터 S가 개입한다.

행렬 곱 R3 = R1 × R2를 생각해보자. 각 행렬이 양자화된 상태라면:
- R1의 원소: r1 = S1 × (q1 - Z1)
- R2의 원소: r2 = S2 × (q2 - Z2)
- R3의 원소: r3 = S3 × (q3 - Z3)

R3의 한 원소를 정수 q3으로 구하려면 결국 중간 계산 과정에 **S1 × S2 / S3** 라는 실수 곱이 등장한다. 이것이 문제다.

값은 전부 정수(Q)로 표현돼 있지만, 연산 과정에 실수가 개입하므로 NPU에서 돌릴 수 없다. 그래서 **연산 과정까지 정수화하는 것이 필요하다**.

> **교수님 강조**: 값을 정수로 양자화하면 모델의 크기(메모리)를 줄이는 데는 좋다. 하지만 연산 속도를 빠르게 하기 위해 가속기에 넣으려면 연산까지 정수화해야 한다. 이 두 가지는 목적이 다른 별개의 작업이다.

### 1-5. 비트 쉬프팅: 실수 스케일 파라미터의 정수화

S1, S2, S3가 실수이므로 M = S1 × S2 / S3도 실수다. 이 M을 정수 연산으로 근사하는 방법이 **비트 쉬프팅(Bit Shifting)**이다.

**원리:** 임의의 실수 M은 `M ≈ 2^(-n) × m` 형태로 근사할 수 있다. 여기서 m은 정수, n도 정수다.
- `× 2^(-n)` 연산은 2진수에서 비트를 오른쪽으로 n칸 이동(right shift)하는 것과 같다.
- 비트 쉬프팅은 덧셈/곱셈보다 훨씬 빠르고 하드웨어 구현이 효율적이다.

```
# 예시: M = 0.125 = 2^(-3)
# n=3, m=1로 근사
# 실수 곱셈 대신: 정수 곱셈(×m) + 비트 쉬프팅(>>n)
result = (accumulated_integer_sum * m) >> n
```

**행렬 곱 정수 연산 흐름:**
1. Q1, Q2 (정수)로 내적(dot product) 수행 → 정수 누산값 도출
2. offset 항(Z1, Z2 관련) 계산 → 역시 정수 연산
3. M = S1×S2/S3 를 비트 쉬프팅으로 근사 적용
4. Z3 offset 추가 → Q3 (정수 출력)

전체 과정에 실수가 전혀 등장하지 않는다.

### 1-6. Batch Normalization 폴딩 (BN Folding)

CNN에는 Batch Normalization 레이어가 있다. BN은 두 단계로 이루어진다:
1. **정규화**: 배치 통계(평균 μ, 분산 σ)로 정규화
2. **스케일/쉬프트**: 학습된 파라미터 γ(감마), β(베타) 적용

이 두 단계를 별도로 수행하면 연산 중간에 실수가 개입한다. **BN Folding**은 이 두 단계를 하나로 합쳐서 정수 연산화하는 기법이다.

정규화와 γ/β 적용을 수식으로 전개하면 결국 `y = a × x + b` 형태의 아핀 변환이 되는데, 이 계수(a, b)를 미리 계산해 값에 합쳐버리면 BN 레이어 자체를 없앨 수 있다. 학습이 끝난 후(추론 시) 배치 통계가 고정되므로 이 병합이 가능하다.

> **교수님 강조**: 묶어서 패는 것이 기본 철학이다. 실수 파트를 한곳에 모아서 비트 쉬프팅으로 한 번에 해결하는 방식이 정수 연산 양자화의 핵심이다.

### 1-7. 연산 양자화 적용 범위

행렬 곱과 BN 폴딩 외에도 다음 연산들이 추가로 양자화된다:
- **ReLU**: 정수 입력에 직접 적용 가능 (0 미만 클리핑), 별도 변환 불필요
- **Bias 덧셈**: Bias도 정수로 양자화 후 누산
- **잔차 연결(Residual Add)**: 두 정수 텐서의 스케일 파라미터를 맞춰 정수 덧셈

기존 연산의 양자화가 이루어지면 그것을 포함하는 네트워크는 추가 양자화 없이 돌릴 수 있다. 새로운 연산 구조가 등장할 때마다 해당 연산의 정수화 기법을 새로 개발하는 방식으로 점진적으로 커버리지를 확장한다.

### 1-8. 비전 트랜스포머(ViT) 연산 양자화

CNN 연산 양자화를 마쳤다고 끝이 아니다. 요즘은 트랜스포머 계열 모델이 주류이고, ViT에는 CNN에 없는 새로운 연산들이 등장한다. 동일한 두 가지 철학(묶어서 패기 + 비트 쉬프팅)을 적용해 하나씩 정복한다.

**Softmax 양자화**

소프트맥스는 지수함수(e^x)를 포함한다. e^x는 정수로 직접 표현하기 어려운데, 해법은 **밑(base)을 e에서 2로 바꾸는 것**이다. 밑이 2이면 2^x 형태가 되고, 이는 비트 쉬프팅과 직접 연결된다.

그 다음 지수 x를 정수 파트와 소수 파트로 분리한다. 정수 파트는 비트 쉬프팅으로 바로 처리하고, 소수 파트(0~1 사이)만 별도로 정수 근사한다.

**GELU 활성화 함수 양자화**

GELU는 `(1/√2π) × ∫e^(-t²/2)dt` 형태로 적분까지 포함하는 복잡한 함수다. ReLU처럼 간단히 양자화하기 어렵다. 해법은 먼저 **수학적 근사**를 쓰는 것이다.

GELU(x) ≈ 1.702 × x × sigmoid(x) 로 근사할 수 있다. 이렇게 되면:
- sigmoid 부분: 이미 양자화 기법이 개발된 소프트맥스와 동일한 구조이므로 재활용
- 1.702 계수: 애매한 실수이므로 비트 쉬프팅으로 근사

**Layer Normalization 양자화**

ViT에서는 BN 대신 Layer Normalization을 쓴다. 분모에 `√분산` 즉 루트 연산이 들어가는데, 루트 값은 정수로 딱 떨어지지 않는다. 이때는 **뉴턴 메소드(Newton's Method)**를 활용한다. 정답에 수렴하도록 반복 탐색하는 수치 해석 기법으로, 각 반복 과정에서 비트 쉬프팅을 통해 정수 연산만으로 구현된다.

> **교수님 강조**: CNN이든 ViT든 철학은 동일하다. 새로운 연산이 등장할 때마다 실수 파트를 묶어서 최소화하고, 묶은 실수를 비트 쉬프팅으로 근사하는 과정을 반복한다. 이 두 가지 철학이 정수 연산 양자화의 근간이다.

**1부 요약:**
- 값의 양자화: 메모리 절약 목적. 그러나 가속기 구동은 불가.
- 연산의 양자화: 가속기(NPU) 구동 가능. 핵심 철학은 ① 실수 묶기 + ② 비트 쉬프팅.
- CNN: 행렬 곱 → M 묶기 → 비트 쉬프팅, BN → 폴딩(Conv/Bias에 흡수)
- ViT 추가 연산: Softmax(밑 2로 변환), GELU(1.702×x×sigmoid로 근사), LayerNorm(뉴턴 메소드)

## 2. 테스트 타임 도메인 적응 (TTA)

### 2-1. 분포 이동 (Distribution Shift)

AI 모델이 학습 완료 후 실전에 투입됐을 때, **학습 데이터에서 경험하지 못한 낯선 데이터 분포를 맞닥뜨리는 현상**이 분포 이동이다.

**비유:** 교수가 가르친 범위에서 열심히 공부했는데, 시험에 가르치지 않은 범위에서 문제가 나왔을 때의 상황과 같다.

**실제 예시:** 깨끗한 이미지로 97% 정확도를 달성한 분류 모델을, 사용자가 카메라를 흔들면서 찍어 흐릿해진 이미지에 적용하면 68%로 성능이 급락할 수 있다.

물리 AI(로봇, 스마트 글래스 등)에서 분포 이동은 더욱 심각하다. 챗봇은 언어 패턴의 차이 정도이지만, 물리 환경에서는 빛, 날씨, 카메라 각도, 주변 환경의 변화가 끊임없이 발생한다.

> **교수님 강조**: 분포 이동은 AI가 현실에서 망하는 만악의 근원이다. 아무리 학습을 잘 해도 이 세상의 모든 테스트 상황을 학습 데이터로 커버하는 것은 불가능하다.

### 2-2. TTA의 어려움

테스트 타임에 분포 이동을 극복하기 위한 적응이 필요한데, 이것이 어려운 이유는 세 가지다.

1. **레이블이 없다**: 테스트 데이터에는 정답이 없다. 역전파 학습을 위한 크로스 엔트로피 로스를 계산할 수 없다.
2. **제한된 컴퓨팅**: AI 가속기나 임베디드 디바이스에서는 추론도 빠듯한데, 학습(역전파)은 더욱 부담스럽다.
3. **로스 설계의 어려움**: 레이블 없이 어떤 신호로 학습 방향을 정할지 불명확하다.

### 2-3. TENT (Test Entropy Minimization)

TENT는 CNN 기반 모델에 대한 가장 기본적인 TTA 기법이다.

**핵심 아이디어:** BN 레이어의 통계량(평균 μ, 분산 σ)을 테스트 데이터의 통계로 갱신하고, BN의 γ/β 파라미터를 **엔트로피 최소화**로 업데이트한다.

**BN 파라미터 업데이트의 두 단계**

BN에는 성격이 다른 두 종류의 파라미터가 있고, 업데이트 방식도 다르다.

1. **μ, σ (배치 통계량)**: 역전파 없이 포워드 패스에서 즉시 갱신 가능하다. 테스트 데이터가 들어올 때마다 계산하면 된다. 갱신 방식에는 두 가지 선택지가 있다.
   - **완전 교체**: 학습 때 구해둔 소스 통계를 버리고, 테스트 데이터에서 모은 통계(예: 100개 배치)로 완전히 갈아끼운다. 소스 도메인 정보를 완전히 포기하는 대신 빠르게 적응한다.
   - **Moving Average**: 기존 통계를 90% 유지하고 새 테스트 통계를 10% 반영하는 식으로 부드럽게 업데이트한다. 소스 도메인 정보를 어느 정도 보존하면서 점진적으로 적응한다.

2. **γ, β (어파인 파라미터)**: 소스 데이터 기반으로 학습된 스케일·쉬프트 파라미터다. 얘네도 테스트 도메인에 맞게 미세 조정하면 성능이 더 올라가는데, 로스와 역전파가 필요하다.

**왜 엔트로피인가?**
- 레이블이 없으므로 크로스 엔트로피를 쓸 수 없다.
- 모델이 어떤 클래스인지 확신이 높을수록(엔트로피가 낮을수록) 올바를 가능성이 높다는 가정을 활용한다.
- 엔트로피(불확실성)를 로스로 삼아 역전파하면, 모델이 더 확신 있는 예측을 내놓도록 γ/β가 업데이트된다.

```
# TENT 의사코드
for each test batch:
    # 1단계: μ/σ를 테스트 배치 통계로 갱신 (역전파 불필요)
    output = model(test_batch)
    # 2단계: 엔트로피 로스로 γ/β 업데이트 (역전파 필요)
    entropy = -(output * log(output)).sum()  # Shannon Entropy
    entropy.backward()
    optimizer.step()  # γ, β만 업데이트 (나머지 파라미터는 frozen)
```

**한계:** 테스트 데이터에 이상치나 노이즈가 많으면 잘못된 방향으로 적응해 성능이 오히려 저하될 수 있다.

### 2-4. SAR (Sharpness-Aware and Reliable TTA)

TENT의 불안정성을 해결하기 위해 **신뢰도가 높은 데이터만 선별해 적응에 사용**하는 기법이다.

**개선 포인트 두 가지:**

1. **이상치 필터링**: 엔트로피가 특정 임계값보다 큰 샘플은 아예 업데이트에 사용하지 않는다. 모델이 매우 불확실한 데이터는 어떤 방향으로 적응해야 할지 신뢰하기 어렵기 때문이다.

2. **로스 스무딩**: 급격한 변화를 방지하기 위해 로스 값을 부드럽게 처리(스무딩)한다. 특정 배치의 이상한 로스 값이 전체 방향을 바꾸지 못하도록 억제한다.

이 두 가지로 TENT 대비 더 안정적인 TTA를 수행한다.

### 2-5. TPT (Test-time Prompt Tuning) — 비전-언어 모델용

CLIP 같은 비전-언어 모델(VLM)에 TTA를 적용하는 기법이다. VLM은 BN이 없기 때문에 TENT/SAR 방식을 그대로 쓸 수 없다.

**CLIP 구조 복습:**
- 이미지 인코더 + 텍스트 인코더 두 가지 경로가 있다.
- 이미지 벡터와 텍스트 벡터의 유사도를 비교해 분류한다.
- "a photo of a [class]" 같은 텍스트 프롬프트를 클래스 레이블로 사용한다.

**TPT 방식:**
1. 테스트 이미지 하나를 약 30가지로 **증강**(크롭, 회전 등)
2. 모든 증강 이미지를 인코더에 통과시켜 소프트맥스 결과 도출
3. **엔트로피가 낮은 TOP-6** 증강 이미지만 선별 (신뢰도 높은 것만 사용)
4. 이 6개의 엔트로피 평균을 로스로 삼아 **텍스트 프롬프트만 업데이트**
5. 모델 파라미터(인코더)는 전혀 바꾸지 않음

왜 6개인지는 하이퍼파라미터로, 필수적으로 6이어야 할 이유는 없다.

> **교수님 강조**: 이미지 하나밖에 없는 극한의 상황에서도 증강으로 데이터를 다양하게 만들고, 그 중 신뢰도 높은 것만 골라 적응한다. 모델은 고정, 프롬프트만 바꾼다는 점이 핵심이다.

### 2-6. PROMPT ALIGN — 이미지 인코더 프롬프트까지 업데이트

TPT는 텍스트 쪽 프롬프트만 업데이트했다. PROMPT ALIGN은 **이미지 인코더 앞의 프롬프트도 함께 업데이트**하는 확장 버전이다.

다이어그램에서 불꽃(fire) 표시가 업데이트 대상, 얼음(freeze) 표시가 고정 대상이다. PROMPT ALIGN은 텍스트 프롬프트와 이미지 프롬프트 모두를 업데이트한다.

**이미지 프롬프트 업데이트 방법:**
- 소스(학습) 데이터로 학습된 인코더는 각 레이어마다 특정 평균·분산 통계를 가진다.
- 테스트 데이터를 넣었을 때 각 레이어의 평균·분산은 다를 것이다.
- 이 두 통계를 일치시키는 것을 로스로 삼아 이미지 프롬프트를 업데이트한다.
- 효과적으로는 테스트 데이터 분포를 학습 데이터 분포로 당겨오는(정렬하는) 것과 같다.

결과적으로 텍스트+이미지 양방향 프롬프트 적응이 이루어지므로 TPT 단독보다 성능 향상폭이 더 크다.

### 2-7. TTA 기법 비교

| 기법 | 적용 모델 | 업데이트 대상 | 로스 |
|------|-----------|--------------|------|
| TENT | CNN | BN γ/β | 엔트로피 최소화 |
| SAR | CNN | BN γ/β | 엔트로피 최소화 + 필터링 + 스무딩 |
| TPT | VLM(CLIP 등) | 텍스트 프롬프트 | 엔트로피 최소화 (TOP-K 선별) |
| PROMPT ALIGN | VLM(CLIP 등) | 텍스트 + 이미지 프롬프트 | 엔트로피 + 통계 정렬 |

## 3. 적응적 센싱 (Adaptive Sensing)

### 3-1. 초거대 AI 패러다임의 근본 원리: 스케일링 법칙

초거대 AI는 **스케일링 법칙(Scaling Law)**에 기댄다. 세 가지 요소 — **모델 크기(파라미터 수), 학습 데이터량, 컴퓨팅 자원** — 이 세 가지가 같이 커질수록 성능도 같이 오른다는 것이다.

- **모델 크기**: 파라미터 = AI의 뇌세포 개수. 클수록 더 많은 지식을 담을 수 있는 용량이 커진다.
- **학습 데이터량**: 그 용량을 채울 실제 지식의 양. 데이터가 많을수록 다양한 분포를 커버한다.
- **컴퓨팅 자원**: GPU 수천 개 규모로 수개월에 걸쳐 학습. GPT 계열 최신 모델은 학습에만 반년 가까이 걸린다.

이 전략이 분포 이동 문제에 어떻게 대응하는지는 명확하다. **온실(학습 환경)을 야생 수준으로 키워버리면** 웬만한 테스트 상황도 이미 학습 분포 안에 포함된다. 즉 규모로 보험을 드는 것이다.

> **교수님 강조**: 스케일링 법칙은 어떻게 보면 무식한 전략이다. 그냥 돈과 자원을 퍼부으면 성능이 오른다는 얘기니까. 하지만 현재로서는 가장 예측 가능하고 리스크가 적은 투자 전략이다. 자본력이 있는 빅테크만 가능한 싸움이기도 하다.

### 3-2. 초거대 AI 패러다임의 한계

규모를 무한정 키울 수는 없고, 두 가지 근본적 한계가 남는다.

1. **분포 이동 문제는 여전히 존재한다**: 아무리 많은 데이터로 학습해도 야생의 모든 상황을 커버하는 것은 불가능하다. 특히 물리 환경(로봇, 의료기기 등)에서는 센서 파라미터, 조명, 날씨 등 변수가 무한하다.
2. **인간 인지체계와의 차이**: 인간은 안경을 쓰면 흐릿하게 보이던 세상이 선명해진다. 안경은 뇌(모델)를 바꾸는 것이 아니라 **입력(눈으로 들어오는 빛)을 변환**하는 것이다. AI도 마찬가지로 모델을 키우는 것 외에, **입력(센서) 자체를 변환해 분포 이동을 억제**하는 접근이 가능하다.

### 3-2. 적응적 센싱의 핵심 개념

TTA는 "모델이 새로운 분포에 적응"하는 접근이다. 적응적 센싱은 다른 관점에서 접근한다: **센서(카메라 등)가 AI 모델에 유리한 입력을 만들어줌으로써 분포 이동 자체를 억제**한다.

**비유:** 사교육(족집게 강의)과 비슷하다. 시험 범위를 예측해서 그것만 공부시키면, 학생(모델) 자체는 바뀌지 않아도 성능이 오른다. 센서가 모델에 맞춤 튜닝된 입력을 제공하는 것이 이 역할이다.

**센서의 역할 비유:** 센서는 AI가 세상을 바라보는 창문이다. 창문 너머 세상은 다양하고 복잡하지만, 창문을 통과하는 순간 학습 데이터와 비슷한 형태로 단순화될 수 있다.

> **교수님 강조**: 모델 일반화(TTA)와 적응적 센싱은 상호 보완적이다. 모델을 똑똑하게 만드는 것과 입력을 정렬해 주는 것을 함께 쓰면 시너지 효과가 있다.

### 3-3. 적응적 센싱 연구: 데이터셋 구축

적응적 센싱 효과를 검증하려면 **센서 파라미터 변화가 포함된 실제 데이터셋**이 필요하다. 기존 ImageNet 강건성 데이터셋들은 줌, 위치 변화, 디지털 변환 위주로, 아날로그 물리 환경을 시뮬레이션한 것은 없었다.

**데이터셋 구축 과정:**
- Tiny ImageNet에서 200개 클래스, 클래스당 5개 샘플 = 1,000개 이미지 샘플 선택
- **암실 설치**: 블루투스 제어 조명 + DSLR 카메라(SDK로 원격 파라미터 제어)
- 조명 밝기, ISO, 셔터 스피드, 조리개(Aperture), 오토 익스포저 등을 다양하게 변화시키며 촬영
- **TV 스크린 버전** (발광체): 약 20만 장
- **종이 프린트 버전** (반사체): 약 60만 장
- 총 약 **80만 장** 데이터셋 구축

디지털 포토샵 처리가 아닌 **실제 아날로그 물리 광학 환경**을 측정한 최초의 데이터셋으로, 이를 통해 논문을 발표했다.

> **교수님 팁**: AI 연구에서 논문을 쓰는 방법은 두 가지다. 새로운 알고리즘·기법을 만드는 것, 그리고 유의미한 데이터셋을 새로 구축하는 것. 인내심 있게 데이터를 모을 수 있다면 데이터셋 논문도 훌륭한 기여다.

### 3-4. LENS 기법

LENS(Learned Exposure for Neural Systems, 비슷한 이름)는 적응적 센싱의 핵심 기법이다.

**동작 원리:**
1. 하나의 장면(scene)에 대해 카메라 파라미터를 랜덤하게 변화시켜 여러 이미지 촬영
2. 촬영된 이미지들을 **배치로 묶어 한 번에 모델에 입력** (원샷)
3. 각 이미지에 대해 소프트맥스 결과 도출
4. **Confidence Score(소프트맥스 최대값)가 가장 높은 이미지**를 선택
5. 선택된 이미지의 예측 결과를 최종 출력으로 사용

모델은 전혀 변하지 않는다. 업데이트도, 학습도 없다. 단순히 **어떤 입력을 줄 것인지를 선택**하는 방식이다.

**성능 결과:**

| 조건 | 모델 | 정확도 |
|------|------|--------|
| 분포 이동 없음 | ResNet | ~90%대 |
| 분포 이동 발생 (AE) | ResNet | ~30% |
| 분포 이동 + LENS | ResNet | ~48% (+18%p) |
| 분포 이동 없음 | DINOv2 (초거대 AI) | 높음 |
| 분포 이동 + LENS | DINOv2 | +8.5% 추가 향상 |

**가장 주목할 결과:** OpenCLIP(파라미터 수 X) 단독 vs. EfficientNet(파라미터 수 X/50, 학습 데이터 X/200만) + LENS를 비교했을 때, EfficientNet + LENS가 정확도가 오히려 4~10% 더 높았다. 초거대 AI 없이도 센서 제어만으로 더 좋은 결과를 낼 수 있다.

> **교수님 강조**: 초거대 AI만이 전부가 아니다. 경우에 따라서는 센서 제어를 잘 하고 작은 모델을 쓰는 것이 더 좋을 수 있다. 모델과 센서는 상호 보완 관계다.

### 3-5. AI의 취향

적응적 센싱을 연구하면서 자연스럽게 드는 질문: AI가 좋아하는 이미지는 무엇인가?

**구체적인 실험 결과:** 개구리 이미지 두 장을 ResNet에 제시했다. 왼쪽은 초록 배경과 몸 색이 자연스럽게 잘 표현된, 사람이 보기에 더 좋은 이미지다. 오른쪽은 눈알이 선명하게 부각된, 사람이 보기엔 덜 자연스러운 이미지다. 결과는 **오른쪽(눈알 이미지)을 압도적으로 더 잘 맞췄다**.

이유는 간단하다. 모델이 학습 데이터에서 개구리를 판별하는 단서로 눈알 모양을 핵심 feature로 학습한 것이다. AI는 사람처럼 전체적인 형태와 맥락을 보는 게 아니라, 학습 과정에서 찾아낸 통계적 단서에 집중한다.

> **교수님 강조**: 사람이 보기에 좋은 이미지를 만들었다고 AI 성능이 올라가진 않는다. 적응적 센싱을 잘 하려면 해당 모델이 어떤 feature를 단서로 쓰는지 이해하고, 그 기준에 맞는 입력을 만들어 줘야 한다. 최적의 센서 파라미터는 모델, 학습 데이터, 환경, 피사체에 따라 모두 달라진다.

## 4. 도메인 전문 지식 주입 — 의료 AI 적용 사례

### 4-1. AX 패러다임과 전문 지식 주입의 필요성

AI만 잘 안다고 AI를 잘 활용할 수 있을까? 교수님의 대답은 "어느 정도 가능하지만, 어느 정도 아니다"이다.

AI를 실전에 적용하려면 반드시 **특정 응용 분야(도메인)**에 연결해야 한다. 데이터는 그 도메인에서 나오고, 모델의 사용처도 그 도메인이다. 그 도메인의 전문 지식을 모르면 데이터 수집 방향도, 모델 설계 방향도 잡기 어렵다.

이것이 요즘 주목받는 **AX(AI Transformation) 패러다임**이다. AI 자체 기술(AI core)보다 **AI를 특정 분야 X에 결합하는 역량**이 중요해지고 있다는 것이다.

> **교수님 강조**: 비전공자라서 AI를 잘 모른다는 생각은 오히려 역방향일 수 있다. 여러분이 기존에 가진 도메인 전문성 + AI를 조합하면 차별성 있는 포지션이 생긴다. AI 코어만 잘하는 사람보다 특정 분야에서 AI를 실전에 연결할 수 있는 사람이 더 희소하다.

도메인 전문 지식을 모델 설계에 반영했을 때의 효과는 두 가지다. 첫째, 이미 그 분야에서 발견된 지식을 직접 주입하므로 데이터로 학습해 발견할 필요가 없어 **경량 모델로도 우수한 성능**이 나온다. 둘째, 그 도메인에 직접 적용 가능한 **설명 가능성**을 얻을 수 있다.

### 4-2. 사례 1: 수면 단계 자동 채점 AI

**배경: 수면 다원검사(PSG, Polysomnography)**  
수면 질환 진단의 표준 방법으로, 환자에게 뇌파(EEG), 안전도(EOG), 심전도(ECG), 호흡 신호 등 수십 개의 전극/센서를 붙여 밤새 신호를 기록한다.

수면 단계는 5단계로 분류한다:
- **Wake**: 깨어 있는 상태
- **REM(Rapid Eye Movement)**: 꿈을 꾸는 수면. 눈이 빠르게 움직이는 단계.
- **N1**: 가장 얕은 Non-REM 수면
- **N2**: 중간 깊이의 Non-REM 수면 (Sleep Spindle, K-Complex 등 특징적 파형)
- **N3**: 가장 깊은 Non-REM 수면 (서파 수면, Slow Wave)

30초 단위(에폭, epoch)로 5단계 중 하나로 채점한다. 불면증, 수면 무호흡증 등 수면 질환 진단의 기초가 된다.

**문제점:**
- 전문 수면 기사가 수동으로 채점: 1인당 약 2시간 소요
- 수면 기사 간 동의율 82%에 불과 (채점 기준의 주관성)
- 검사 대기가 몇 개월씩 밀리는 경우 발생 (특히 미국, 개발도상국)
- 첫날밤 효과: 낯선 병원 환경에서 수면 패턴이 일상과 달라짐

**전문 지식 주입 1: 시계열 문제 → 컴퓨터 비전 문제로 패러다임 전환**

AI 개발자라면 자연스럽게 시계열 AI 모델(LSTM, Transformer)로 접근할 것이다. 그러나 의사 선생님이 중요한 관찰을 제공했다:

> "나는 파형의 수치(0.5인지 0.7인지)를 보는 게 아니라, **파형의 모양**을 눈으로 보고 채점한다. 이건 시계열 문제가 아니라 컴퓨터 비전 문제 아닌가?"

이 관점을 받아들여, **PSG 신호를 화면에 띄운 스크린샷을 이미지 분류 모델에 입력**하는 방식으로 전환했다. Y축은 신호 종류, X축은 시간인 특수한 흑백 이미지를 생성한다.

> **교수님 강조**: 이것이 전문 지식 주입의 핵심이다. 수면기사가 눈으로 보고 채점했으므로, AI도 눈으로 보는(컴퓨터 비전) 방식으로 하는 게 맞다.

**전문 지식 주입 2: CNN이 아닌 Vision Transformer 선택**

의료 AI에서는 아직 CNN이 많이 쓰이지만, 이 특수한 이미지에는 CNN의 두 가지 귀납적 편향이 적합하지 않다.

- **Spatial Locality(공간 지역성)**: CNN은 공간적으로 가까이 있는 픽셀이 더 연관된다고 가정한다. 그런데 이 이미지에서 Y축(신호 종류)이 가까이 배치된 신호들이 반드시 연관성이 높지 않다. 예를 들어 Flow 신호 바로 아래에 ECG 신호가 있어도 이 둘이 가장 연관성이 높다고 볼 수 없다.
- **Positional Invariance(위치 불변성)**: CNN은 같은 필터를 이미지 전체에 공유한다. 그러나 이 이미지의 위치별로 신호 종류가 다르므로 위치마다 다른 해석 메커니즘이 필요하다.

따라서 **Positional Embedding**을 사용해 각 위치의 의미를 구분할 수 있는 **Vision Transformer**를 선택했다. 패치 크기를 각 신호를 충분히 포함하도록 설계해, 어텐션으로 시간축·신호축 모든 패치 간 관계를 탐색할 수 있게 했다.

**전문 지식 주입 3: 에폭 간 맥락(Context) 고려**

수면기사는 30초 에폭 하나만 보는 것이 아니라 **전후 에폭의 맥락을 함께 고려**한다. 특정 에폭이 REM 수면으로 강력하게 판단되면, 그 이전 에폭들을 백트래킹(Back-tracking)해 동일하게 수정하기도 한다.

이를 반영하기 위해 **에폭 시퀀스에 추가 Transformer를 적용**했다. 각 에폭 이미지를 ViT로 분석한 결과를 시간축으로 엮어 어텐션을 수행함으로써 전후 맥락을 반영한 최종 수면 단계를 출력한다.

**결과:**
- **설명 가능성**: ViT 어텐션 히트맵으로 모델이 어느 신호, 어느 시점에 주목했는지 시각화 가능. 수면 단계마다 어텐션이 집중되는 신호가 의학 가이드라인(AASM)과 일치했다.
  - Wake: 뇌파(EEG)의 다양한 활동
  - REM: 안전도(EOG) — 래피드 아이 무브먼트
  - N3: 뇌파의 서파(Slow Wave) 패턴
- **맥락 반영**: 단독 에폭 분석에서 틀렸던 레이블이 전후 맥락 어텐션 이후 정확하게 수정되는 사례 확인

### 4-3. 사례 2: 비접촉식 수면 무호흡증 진단 AI

**배경: 수면 무호흡증(OSA, Obstructive Sleep Apnea)**  
기도가 막혀 수면 중 호흡이 멈추는 질환이다.
- **저호흡(Hypopnea)**: 기도가 부분적으로 막혀 호흡이 불완전한 상태
- **무호흡(Apnea)**: 기도가 완전히 막혀 호흡이 멈춘 상태
- **AHI 지수**: 수면 시간당 무호흡+저호흡 이벤트 횟수. 중증도 지표.

조기 진단이 어려운 이유: 무호흡은 잠자는 중 발생하므로 본인이 인지하지 못한다. 이미 증상을 느낄 때는 이미 상당히 진행된 상태다.

**기존 진단 방법의 한계:**
- 수면 다원검사: 병원 입원 필요, 첫날밤 효과
- 웨어러블(스마트워치 등): 착용 거부감 높음

→ **비접촉식 적외선 영상** 활용 시도

**도전 과제:**
- 영상 AI는 큰 움직임에 강하다. 그런데 수면 중 인간은 거의 움직이지 않는다.
- 무호흡과 저호흡의 미세한 움직임 차이를 영상으로 구분하기 어렵다.
- 프라이버시: 수면 중 영상을 클라우드로 전송하면 사용 거부

**도메인 전문 지식 주입: 전략 전환**

의학 전문가와의 협업에서 핵심 지식을 얻었다: **호흡각성 이벤트(Respiratory Arousal Event)**

무호흡 상태가 지속되면 인체가 생존 본능으로 몸을 뒤척여 기도를 열려고 한다. 본인은 잠든 채로 이 행동을 한다. 이것이 호흡각성이다. 호흡각성은 두 가지 특성이 있다:

1. **큰 움직임**: 기도를 열기 위해 격렬하게 몸을 뒤척이므로 영상에서 잘 포착된다.
2. **짧은 시간**: 대부분 30초 이내 완료된다. → 짧은 클립으로 판별 가능 → 경량 모델로 처리 가능

이 지식을 활용해 전략을 바꿨다: **무호흡·저호흡을 직접 감지하는 대신, 호흡각성을 감지하고 백트래킹으로 무호흡 발생 여부를 역추적**한다.

**파이프라인:**
1. 수면 적외선 영상을 30초 단위로 클립 구성
2. 경량 비디오 모델(MobileNet 계열 구글 개발 모델)로 호흡각성 이벤트 감지
3. 진단 결과만 저장, 원본 영상 즉시 삭제 (프라이버시 보호)
4. 수면 전체의 호흡각성 이벤트 빈도로 AHI 계산

**성능 결과:**
- 30초 클립 처리 시간: CPU로 16초 → **실질적 실시간 처리 가능**
  - 30초 촬영하는 동안 이전 클립 분석(16초) 완료 → 14초 여유
- 이전 접근 방식(무호흡 직접 감지): 5시간 수면 분석에 8시간 소요

> **교수님 강조**: AI 알고리즘을 고도화한 게 아니다. 의학 지식 하나를 주입함으로써 실시간이 됐다. 도메인 전문 지식이 AI 설계에 얼마나 큰 영향을 미치는지 보여주는 사례다.

**추가 세부사항: 호흡각성 vs 자발적 각성 구분**

모든 움직임이 호흡각성인 것은 아니다. 불편함, 악몽 등으로 인한 자발적 뒤척임(자발적 각성)도 있다. 연구팀이 분석한 결과, 호흡각성에 의한 움직임은 **가슴/상체 부위에서 더 강하게 나타났다**. 이 단서를 모델링에 반영해 두 종류의 각성을 구분했다.

## 5. 참고 — Ambient AI와 물리 AI (읽을거리)

Ambient AI는 AI가 특정 인터페이스(스마트폰, 화면)에 국한되지 않고 주변 환경 속에 자연스럽게 녹아 들어가는 개념이다. 로봇, 스마트 글래스, 의료 기기 등 물리적 환경에서 AI가 동작하는 것이 Physical AI 혹은 Embodied AI라고도 불린다. 이 강의에서 다룬 세 가지 주제(정수 연산 양자화, TTA, 적응적 센싱)는 모두 이 Ambient AI를 현실화하기 위한 기반 기술이다.

## 정리

| 구분 | 핵심 포인트 |
|------|-------------|
| 엣지 AI 필요성 | 프라이버시 / 실시간 반응성 / 인터넷 의존성 세 가지 이유 |
| CPU vs NPU | NPU는 정수 연산 전용 특화 가속기. 실수 연산 지원 안 함 |
| 값의 양자화 | 실수 r → 정수 q 변환. S(스케일링)와 Z(오프셋) 두 파라미터 필요 |
| 연산 양자화 필요성 | S가 실수이므로 행렬 곱 중간에 실수 연산이 개입함 |
| 비트 쉬프팅 | 실수 M을 2^(-n) × m 형태로 근사. 정수 연산으로 대체 |
| BN 폴딩 | 정규화 + γ/β를 Conv 가중치와 Bias에 흡수시켜 BN 레이어 자체를 제거 |
| ViT 연산 양자화 | Softmax(밑을 2로 변환+정수/소수 분리), GELU(sigmoid 근사+비트쉬프팅), LayerNorm(뉴턴 메소드) |
| 분포 이동 | 학습 분포와 테스트 분포의 차이. Physical AI에서 특히 심각 |
| TENT BN 업데이트 | μ/σ는 포워드 패스에서 즉시 갱신(완전교체 or Moving Average), γ/β는 엔트로피 역전파로 갱신 |
| TENT / SAR | CNN용 TTA. 엔트로피 로스로 BN 파라미터 업데이트. SAR은 이상치 필터링 + 스무딩 추가 |
| TPT / PROMPT ALIGN | VLM용 TTA. 이미지 증강 + 엔트로피로 프롬프트 업데이트 |
| 스케일링 법칙 | 모델 크기 + 데이터량 + 컴퓨팅 세 가지가 커질수록 성능 향상. 규모로 분포 이동을 억제 |
| 적응적 센싱 | 모델 적응이 아닌 센서 입력 최적화로 분포 이동 억제 |
| AI의 취향 | 사람이 보기 좋은 이미지 ≠ AI 성능이 좋은 이미지. 모델이 학습한 feature 단서 기준으로 결정 |
| LENS 기법 | 여러 카메라 파라미터로 찍고 Confidence 최고인 이미지 선택 |
| AX 패러다임 | AI core 기술 + 도메인 전문성 결합이 차별화 포인트. 비전공자도 기존 도메인으로 강점 가능 |
| 도메인 지식 주입 | 전문가 지식을 모델 설계에 직접 반영 → 경량 모델로도 충분 |
| 수면 채점 AI | PSG → 스크린샷 이미지 분류 (ViT, 에폭 간 맥락) |
| 수면 무호흡 AI | 무호흡 직접 감지 → 호흡각성 감지 후 백트래킹으로 전환 |
