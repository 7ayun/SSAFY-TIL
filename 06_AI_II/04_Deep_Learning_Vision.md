## 1. 이미지 모델이 필요한 이유

산업 현장에서 불량 검출, 스크래치·이물질 탐지 같은 반복 작업을 AI로 자동화하는 흐름이 가속되고 있다. 인구 감소로 인해 사람에게 반복적이고 지루한 일을 시키기 어려워지면서, 이런 일들을 AI 기술로 자동화시키는 건 너무 당연한 흐름이다.

보안·감시(서베일런스) 시스템에서도 이미지 모델이 활용되고 있으며, 자율주행 분야에서는 비주얼 데이터에 온전하게 의지하여 차량의 이동 경로를 예측하는 모델이 등장하고 있다. 웨이모(Waymo) 같은 무인 택시가 이미 상용화되었고, 중국에서도 상하이 등 여러 도시에서 무인 택시가 운행되고 있다.

> **교수님 강조**: 자율주행처럼 비주얼 데이터에 온전하게 의지해서 차량 이동 경로를 예측하는 모델이 나오고 있다. 이것이 우리 사회와 개개인, 미래 산업에 미치는 영향력은 어마어마하다.

## 2. CNN(Convolutional Neural Network) 기초

### 2-1. FCN(완전 연결층)의 구조

FCN(Fully Connected Network)은 가장 기본적인 신경망 모듈이다. 입력을 받아서 출력으로 변환하는 역할을 한다. W라는 매트릭스가 있고, 한 축은 출력 사이즈, 다른 축은 입력과 동일한 사이즈를 가진다.

이미지(32×32×3)를 FCN에 넣으려면 픽셀 하나하나를 떼어서 한 줄로 세워야 한다. 이렇게 하면 3,072개(32×32×3)의 원소를 가진 1차원 벡터가 된다. W 매트릭스(출력 크기 × 3,072)와 내적하여 출력 벡터를 만든다.

### 2-2. CNN의 핵심 차이: 이미지 구조 유지

CNN은 입력을 1차원으로 펼치지 않고, 이미지의 원래 구조(높이, 너비, 채널)를 그대로 유지한 채로 연산을 수행한다.

왜 구조를 유지하는 게 유리한가? 이미지에서 하나의 픽셀은 바로 앞뒤 화소만 유관한 것이 아니라, 위와 아래, 대각선까지 모두 관련이 높은 화소이다. FCN처럼 한 줄 세우기를 하면 바로 옆 픽셀은 나의 앞뒤에 위치하겠지만, 위에 있는 픽셀이나 아래 있는 픽셀은 굉장히 멀리 배치될 확률이 높다. 이미지 구조를 유지하면 이런 공간적 관련성을 그대로 활용할 수 있다.

> **교수님 강조**: FCN에서 픽셀 줄 세우기를 하면 위아래 픽셀이 굉장히 멀리 배치될 확률이 높다. 이미지 구조를 제대로 활용하기 어려워진다.

### 2-3. 합성곱 연산의 메커니즘

합성곱 레이어는 작은 필터(예: 3×5×5)를 이미지 위에 올려놓고 연산한다. 필터의 중심을 타겟 픽셀 위에 배치한 뒤, 같은 위치에 있는 필터와 이미지 값을 곱하고, 곱한 값을 전부 더한다. 이것은 벡터 내적과 유사하지만, 이미지의 원본 구조를 유지하면서 수행한다.

```
출력값 = W^T · X + b
```

- **W**: 필터(커널)의 가중치 — FCN의 큰 W에 비해 훨씬 작다 (예: 75개 상수)
- **X**: 필터 영역에 해당하는 이미지 패치 (5×5 작은 영역)
- **b**: 바이어스 (편향) — 값 전체가 갖고 있는 편향을 보정하는 추가 상수

W와 b 모두 모델 상수(파라미터)로서 학습 대상이다. 내적 + 바이어스의 결과는 하나의 스칼라 값이며, 이 값이 타겟 픽셀과 같은 위치에 저장된다. 이 과정을 이미지의 모든 화소에 대해 수행하면 **활성화 맵(Activation Map)**이 완성된다.

**중요 제약**: 필터의 채널(깊이) 수는 반드시 입력 이미지의 채널 수와 동일해야 한다. 입력이 3채널(RGB)이면 필터도 깊이가 3이어야 한다. 예를 들어 7×5×5 필터를 3채널 입력에 쓸 수는 없다.

### 2-4. 출력 해상도와 패딩

패딩 없이 합성곱을 수행하면 출력 크기가 줄어든다. 32×32 입력에 5×5 필터를 적용하면 좌우 2픽셀, 위아래 2픽셀이 빠져서 28×28이 된다. 가장자리 픽셀에서는 필터를 올리면 이미지 밖으로 나가서 정의할 수 없는 영역이 생기기 때문이다.

두 가지 방법이 있다:
- **밸리드(valid) 모드**: 패딩 없이 안쪽만 처리 → 출력 크기 감소
- **패딩**: 가장자리에 0이나 가장 가까운 값을 채워넣어 입출력 해상도 유지

출력 해상도 공식:

```
출력 크기 = (입력 크기 - 필터 크기 + 2 × 패딩) / 스트라이드 + 1
```

패딩 적용 여부는 디자인 초이스다. 어차피 풀링으로 사이즈를 확 줄일 거라 굳이 맞추지 않는 경우도 많고, 매번 출력 크기를 신경 쓰기 싫어서 아예 맞추는 경우도 있다.

**필터 크기가 항상 홀수인 이유**: 센터가 하나여야 하기 때문이다. 짝수(4×4, 6×6)를 쓰면 중앙이 두 곳이 되어 기준 픽셀을 명확히 정의할 수 없다.

### 2-5. 다중 필터와 배치 처리

실질적으로 하나의 필터만으로는 부족하다. FCN의 큰 W 매트릭스처럼 모델 상수가 충분히 많아야 다양한 특징을 배울 수 있다. 그래서 여러 개의 필터를 사용한다.

예를 들어 6개의 필터를 쓰면, 각 필터별로 활성화 맵이 하나씩 나오므로 출력은 **6×28×28** 형태가 된다. 필터의 개수는 아키텍처 설계자의 선택이다.

하나의 합성곱 레이어의 전체 모델 상수 = (필터 개수 × 입력 채널 × 필터 높이 × 필터 너비) + 필터 개수(바이어스). 예를 들어 6개의 3×5×5 필터 + 바이어스 6개 = 456개의 상수.

배치 처리 시에는 입력 이미지가 여러 장이 되어 텐서 차원이 하나 늘어나지만, 합성곱 레이어 자체는 그대로 유지된다. 입력 이미지 n장이면 출력 활성화 맵도 n세트가 나온다.

일반적으로 합성곱 레이어의 입력은 **(배치 크기, 채널, 높이, 너비)** 형태이고, 출력의 채널 수는 필터 개수와 동일하다.

### 2-6. 비선형 활성화의 필요성

합성곱 레이어는 리니어(선형) 연산이다. 출력이 입력의 선형 조합으로 결정되기 때문이다. 선형 연산을 여러 개 순서대로 쌓으면 w1, w2, w3의 곱이 또 다른 하나의 선형 연산자를 만들 수 있다. 그러면 세 개 쌓는 의미가 없다.

이 문제를 해결하기 위해 각 합성곱 레이어 뒤에 **비선형 활성화 함수**(ReLU 등)를 삽입한다. 비선형성이 들어가는 순간 여러 레이어를 대체하는 하나의 모델이 존재한다는 우려를 불식시킬 수 있고, 모델 상수를 추가하면 추가하는 만큼 모델링 파워를 끌어올릴 수 있다.

기본 CNN 모듈 구조: **합성곱 → 비선형 활성화 → 합성곱 → 비선형 활성화 → ...** 형태의 반복.

### 2-7. CNN의 계층적 특징 추출

FCN 하나로 학습하면 각 클래스를 대표하는 가장 "평균적인 템플릿"을 하나씩 만들게 된다. 예를 들어 자동차 클래스의 W를 시각화하면 가장 전형적인 자동차(정면뷰) 이미지처럼 보인다. 하지만 자동차의 변형이 매우 다양하므로 하나의 템플릿으로는 정확도가 높을 수 없다. FCN을 여러 개 쌓으면 템플릿이 여러 개 나오지만(각도, 색깔 등 조금씩 변화), 여전히 이미지 전체를 대표하는 템플릿을 찾아야 해서 한계가 있다.

CNN은 이와 달리 **부분을 본다**. 학습된 필터를 시각화하면 바운더리 정보, 격자 무늬, 세로·가로 경계 등이 나타난다. 이것들은 전통적인 이미지 처리 기법의 필터와 매우 유사하다. 필터가 하는 일은 "이미지에 이런 특징이 있나요?"라는 질문을 던지는 것이다.

CNN의 각 레이어는 점진적으로 큰 스케일의 특징을 학습한다:
- **첫 번째 레이어**: 엣지, 코너, 색상 — 아주 작은 부분에 집중해서 얻을 수 있는 특징
- **중간 레이어**: 텍스처, 패턴 — 작은 특징들을 모아서 좀 더 큰 단위를 모델링
- **깊은 레이어**: 객체 단위 — 이미지 전체를 관통하는 고수준 특징

> **교수님 강조**: CNN은 순차적으로 점진적으로 작은 스케일에서부터 큰 스케일의 특징으로 이동한다. 부분을 다 보고 전체를 보는 방식이다.

### 2-8. 수용 영역(Receptive Field)

수용 영역은 CNN이 이미지를 처리하면서 **한 번에 볼 수 있는 영역의 크기**를 의미한다. 출력의 한 픽셀이 입력 이미지의 어느 범위에서 영향을 받았는지를 역추적하여 계산한다.

예를 들어 3×3 필터를 사용하는 합성곱 레이어 2개를 중첩한 경우: 출력의 중앙 픽셀은 바로 이전 레이어의 3×3에서 영향을 받고, 그 3×3의 각 픽셀은 다시 이전 레이어의 3×3에서 영향을 받으므로, 가장자리까지 역추적하면 원본 이미지의 상당 영역(경우에 따라 전체)을 커버한다.

레이어가 깊을수록 수용 영역이 넓어지고, 필터 사이즈가 클수록 수용 영역이 커진다. 이미지 전체 맥락을 다 고려하려면 수용 영역이 이미지 전체 사이즈가 되도록 설계하는 경우가 많다. 수용 영역 평가 시에는 출력의 **중앙 픽셀**을 기준으로 계산한다 (가장 넓은 수용 영역).

가장자리 출력값도 무의미하지 않다. 출력은 공간뿐 아니라 채널도 쌓이고, 각 채널이 본 영역을 모두 합쳐서 디시전을 내리므로 모든 픽셀이 기여한다. 입력의 중앙 픽셀이 결과에 더 큰 영향을 미치는 것도 아니다. 이미지 어떤 영역에 특징이 될 만한 정보가 있느냐가 중요하다.

> **교수님 강조**: 수용 영역을 잘 이해하는 것이 되게 중요하다. 레이어가 많아지면 수용 영역도 커지고, 필터 사이즈도 영향을 미친다.

### 2-9. 풀링(Pooling)과 스트라이드 합성곱

풀링은 공간 해상도를 줄이는 연산이다. 224×224 입력이 합성곱 통과 후 풀링을 거치면 해상도가 절반으로 줄어 1/4 크기가 된다.

해상도를 줄이는 이유: (1) 연산량 감소, (2) **위치 불변성(Translation Invariance)** — 고양이가 가운데 있든 두 픽셀 옆으로 이동해 있든 본질이 바뀌지 않는다. 해상도가 절반으로 줄면 한두 픽셀 이동이 무시된다.

**맥스 풀링(Max Pooling)**: 2×2 영역에서 가장 큰 값 선택. 학습 파라미터 없음. 이미지에서 작은 값(0~15)은 거의 검은색에 가까운 노이즈일 확률이 높고, 큰 값은 노이즈에 덜 영향받는다는 가정.

**스트라이드 합성곱(Strided Convolution)**: 필터를 n칸씩 건너뛰며 적용(예: 스트라이드 2). 풀링과 같이 해상도를 줄이지만, 학습 가능한 파라미터를 가진다. 해상도가 줄 것을 알고 있는 상태에서 필터가 학습되므로, 정보 손실에 방어적인 필터를 만들 수 있다. 최근에는 풀링 대신 스트라이드 합성곱이 더 선호된다.

## 3. CNN 모델 변천사

### 3-1. ImageNet Challenge

스탠포드의 페이페이 리 교수가 대규모 이미지 데이터셋을 구축했다. 2012년 AlexNet 등장 이후 Top-5 오류율이 급격히 감소했다. 사람의 정확도는 5.1%(스탠포드 석사 학생들이 실제로 이미지를 보고 클래스를 맞춘 결과)이며, 2015년 이후 모델이 사람보다 높은 정확도를 달성했다.

### 3-2. AlexNet (2012)

최초로 성공한 CNN 모델이다. 5개의 합성곱 레이어 + 3개의 FC 레이어로 총 8층 구조이다.

**입출력 구조**: 입력 227×227×3, 출력 1,024차원(1,000 클래스, 원핫 벡터와 비교). 마지막에 소프트맥스로 확률 분포 변환 후 원핫 벡터와 오차를 구해 역전파.

**레이어별 상세 구조**:
1. **Conv1**: 11×11 필터, 스트라이드 4, 커널 96개 → 출력 55×55×96. 계산: (227-11)/4+1 = 55
2. **Pool1**: 3×3 맥스 풀링, 스트라이드 2 → 해상도 감소
3. **Conv2**: 5×5 필터, 패딩 적용(해상도 유지), 커널 256개 → 더 복잡한 패턴 추출
4. **Pool2**: 해상도 추가 감소
5. **Conv3**: 3×3, 커널 384개. 뒤로 갈수록 커널 수 증가, 공간 해상도 13×13까지 감소
6. **Conv4**: 3×3, 커널 384개 (해상도 유지)
7. **Conv5**: 3×3, 커널 256개
8. **Pool3**: 6×6×256까지 축소
9. **FC1~3**: 6×6×256=9,216 → 한 줄 세우기 → 4,096 → 4,096 → 1,000

GPU 메모리가 3GB(초기 1.5GB)라 모델을 2개 브랜치로 나눠서 GPU 2개에 올렸다. 커널 개수 384 같은 선택에 대해서는 구체적 이론적 근거가 없는 엔지니어링적 선택인 경우가 많다.

**역할 분리**: 합성곱 레이어들은 특징(representation)을 뽑는 역할, FC 레이어 3개는 분류(classification) 역할. 전체가 한 번에 학습되지만 의도는 그렇다.

**메모리/파라미터/연산 계산 방법**:
- 활성화 메모리 = 출력 높이 × 출력 너비 × 출력 채널 × 4바이트(32비트)
- 파라미터 수 = (입력 채널 × 출력 채널 × 필터H × 필터W) + 출력 채널(바이어스)
- 연산량(곱만) = 출력 원소 수 × (입력 채널 × 커널H × 커널W). 더하기까지 고려하면 ×2

**트렌드**: 합성곱 레이어 초반에 활성화 메모리가 크고(공간 해상도가 크므로), FC에 파라미터가 집중되며, 연산은 주로 합성곱에서 발생한다.

### 3-3. VGGNet (2014)

같은 해 1등은 GoogLeNet이었으나, 사람들은 VGG에 더 열광했다. 두 모델 모두 오픈소스/무료인데도, VGG의 **직관적이고 반복적인 디자인 패턴** 때문에 더 채택되었다. GoogLeNet은 복잡한 구조라 재현이 어려웠고, 이 비직관성이 채택률을 낮췄다. VGG는 아키텍처 설계의 철학을 최초로 제시했다.

**핵심 철학 — "작고 단순한 필터를 깊게 쌓겠다"**:
- 모든 합성곱: 3×3 필터, 스트라이드 1, 패딩 1 (고정)
- 풀링: 2×2 맥스 풀링 (고정)
- 풀링 시 채널 2배 증가: 64 → 128 → 256 → 512
- VGG-16(16층), VGG-19(19층) 변형 존재

**3×3 합성곱 2개의 이점**: 5×5 하나와 같은 수용 영역이지만, 파라미터 25C² → 18C², 연산 25C²HW → 18C²HW. 같은 효과인데 파라미터와 연산이 줄어든다. 굳이 커널 사이즈를 키울 필요 없이 깊게 쌓으면 된다는 것이다.

**채널 증가 전략**: 해상도를 줄일 때마다 채널을 늘려서 레이어별로 균질화된 연산을 유지하겠다는 의도.

**AlexNet vs VGG 비교**: 메모리 약 25배, 상수 약 2배, 연산량 약 19배 VGG가 더 크다.

**현재도 VGG가 쓰이는 이유**: VGG의 풀링 단계 출력(feature)이 모델 해석에 매우 유용하다. **Perceptual Loss**가 오직 VGG 위에서 정의된다. 스타일 전이(고흐 스타일 적용 등) 어플리케이션에서 VGG의 feature 값으로 스타일을 정의하고 전달한다. VGG가 뽑아내는 특징의 설명 가능성과 직관성이 뛰어나서, 다른 모델이 많지만 이런 용도에선 꼭 VGG를 쓴다.

### 3-4. ResNet (2015)

**배치 정규화(Batch Normalization)** 등장: 학습 안정화에 매우 효과적. VGG에도 사후 장착(VGG-BN).

**문제**: BN을 넣어도 56 레이어가 20 레이어보다 트레이닝/테스트 에러가 높다. 더 힘센 모델이 성능이 떨어지는 이상 현상.

**원인 — 기울기 소실(Gradient Vanishing)**: 역전파 시 기울기를 앞으로 전달해야 하는데, 깊으면 뒤에서 다 나눠 갖고 앞에는 남는 게 없다.

**잔차 블록(Residual Block)**: 입력(x)을 그대로 출력에 더하는 **스킵 커넥션** 추가.

```
출력 = F(x) + x
```

F(x) = Conv → ReLU → Conv → ReLU. 학습이 안 되면 F(x)를 0으로 만들어 출력 = x, 최소한 이전 성능을 보장. 원래 경로에 입력이 직접 출력으로 더해지는 숏컷이 추가된 것이다.

**보틀넥 잔차 블록**: 기본 블록(3×3 두 개)을 1×1 → 3×3 → 1×1 세 개 층으로 확장.

- 1×1 Conv: 채널 1/4로 축소 (4C → C). 픽셀별 채널 방향 연산. 공간 해상도 유지
- 3×3 Conv: 축소된 채널에서 공간 연산
- 1×1 Conv: 채널 복원 (C → 4C)

연산량: 기본 블록 18C²HW vs 보틀넥 17C²HW. 더 깊으면서 효율적. 이것이 **ResNet-50**.

**추가 기법**: 초반 해상도 1/2 줄이기(연산 효율), 마지막에 FC 대신 **글로벌 평균 풀링** 사용(각 채널의 공간 해상도를 평균내어 하나의 값으로 축소).

**성능**: ResNet-34 > VGG (정확도 높고 연산 가벼움). ResNet-50 > ResNet-34 (보틀넥으로 더 깊고 정확). 논문에서 152층까지 제시. 처음으로 사람(5.1%)을 넘어서고, 분류/검출/분할 모든 벤치마크 1위.

이후 DenseNet에서는 하나의 레이어에서 멀리 떨어진 레이어까지 스킵 커넥션을 다는 아이디어로 발전했다.

> **교수님 강조**: CNN 기반 모델 중 강력한 베이스라인 하나만 가져오라면 ResNet-50. 지금도 가장 많이 쓰이는 강력한 베이스라인이다.

### 3-5. MobileNet

기존 대비 약 10배 빠르게 만들면서 성능을 소폭 희생하는 효율적 모델. 실제 디바이스에서는 오히려 더 중요한 문제.

**분리 전략**:
1. **깊이별 합성곱(Depthwise Conv)**: 채널별 독립적으로 3×3 수행 → 연산: 9C·HW
2. **화소별 합성곱(Pointwise Conv)**: 1×1 Conv로 채널 방향만 연산 → 연산: C²·HW

기존: 9C²·HW. MobileNet: (9C + C²)·HW. C가 9보다 훨씬 크면 약 **9배** 차이.

성능 1~2% 하락, 연산 9배 이상 절감. 알고리즘 테스트 시 모바일 같은 경량 모델도 포함시켜 테스트해야 한다.

### 3-6. CNN 발전 흐름 요약

깊게 만드는 라인(AlexNet → VGG → ResNet)과 가볍게 만드는 라인(MobileNet), 넓게 만드는 라인(GoogLeNet)이 존재. 깊게+넓게 합치는 방향으로도 발전. 큰 트렌드는 깊게 쌓는 것이 유효. ImageNet 챌린지는 사람 초과 성능 달성 후 종료.

## 4. CNN의 한계와 시퀀스 모델

### 4-1. CNN의 장점 정리

로컬 패턴 추출에 우수, 가중치 공유로 파라미터 효율적, 풀링으로 위치 불변성 확보, 합성곱+풀링+비선형함수+배치정규화(2015~)+FC의 표준 구성.

### 4-2. CNN의 한계

**순서 무시**: 얼굴에서 눈·코·입 위치를 바꿔도 각 로컬 영역의 특징만 보고 판단. 순서(order)가 의미를 완전히 바꿔버리는 문제 발생 가능.

**장거리 의존성 부족**: 바다 패턴이 반복되거나 건물 창문이 멀리서도 비슷한 것처럼, 이미지에는 멀리 떨어진 반복 패턴이 존재. 인간이 만든 구조물에 특히 많고 자연도 멀리서 보면 유사 패턴 반복. CNN은 로컬만 보므로 이런 관계를 직접 학습하기 어렵다.

### 4-3. RNN(Recurrent Neural Network)

순차적 데이터를 처리하기 위해 **은닉 상태(Hidden State)**를 도입한 신경망 구조. 입력과 출력 외에 추가적인 정보를 담는 방을 만들어서 시간/순서를 반영한다.

**동작 원리** (H-E-L-L-O 예측):
1. 캐릭터를 원핫 벡터로 변환 (딕셔너리 약속)
2. W_xh로 입력 → 은닉 상태 변환
3. W_hh로 이전 은닉 상태 → 현재 은닉 상태에 반영
4. W_hy로 은닉 상태 → 출력 변환

```
h_t = tanh(W_xh · x_t + W_hh · h_{t-1} + b)
y_t = W_hy · h_t
```

tanh 사용 이유: RNN은 학습이 불안정하므로 출력을 -1~1 사이로 제어. 모든 시점에서 **동일한 가중치(W)를 공유**한다. 입력이 바뀌니 은닉 상태는 바뀌지만 상수는 동일.

**학습 vs 추론**: 학습 시에는 예측이 틀려도 정답 입력을 다음에 넣는다 (알고 있는 정답을 쓰지 않을 이유 없음). 추론 시에는 정답을 모르므로 이전 예측값을 입력으로 사용.

**역전파**: 모든 시점의 기울기를 다 더해서 최종 로스와 기울기를 계산한다.

**활용 형태**: One-to-Many(이미지→캡션), Many-to-One(감정분류, 비디오행동분류), Many-to-Many(번역, 비디오프레임별 분류). 시퀀스를 압축→확장하는 형태(Seq-to-One + One-to-Seq 병합)도 많이 사용.

**병렬 처리 불가**: 이전 상태를 봐야 다음을 계산하므로 순차 처리만 가능.

### 4-4. RNN의 치명적 한계

**기울기 폭발/소실**: 시퀀스 통과 시 W가 반복 곱해짐. 놈 > 1이면 폭발, < 1이면 소실. 딱 1로 만들 수 없다. 기울기 폭발은 클리핑으로 대처 가능하나 소실은 해결 불가.

**장기 기억 없음**: 바로 직전만 영향. 한두 단계만 넘어가도 초기 정보를 잊음. 캐시만 있는 것과 같다. 시퀀스를 다루려고 태어났는데 긴 시퀀스에서 문제가 있다.

### 4-5. LSTM(Long Short-Term Memory)

장기 기억 문제 해결을 위해 **셀 상태(Cell State)**와 **게이트** 도입. 이름 자체가 "장단기 기억".

**셀 상태**: 중요한 정보를 유지하는 고속도로. 덧셈 형태로 업데이트되어 곱하기 반복의 RNN보다 기울기 전파가 안정적. ResNet 스킵 커넥션과 유사.

**세 가지 게이트** (모두 학습 대상):
1. **입력 게이트**: 새 정보 중 저장할 것 결정
2. **망각 게이트**: 과거 정보 중 삭제할 것 결정
3. **출력 게이트**: 셀 상태에서 필요한 정보만 은닉 상태로 전달

뭐가 중요하고 뭐가 중요하지 않은지를 모델이 스스로 학습한다.

**병렬 처리 불가**: RNN과 동일.

**한계**: 시퀀스가 매우 길면 셀 상태에 정보가 계속 쌓여 희석된다. 완전히 없어지진 않지만 매우 희미해진다.

> **교수님 팁**: LSTM은 메모장에 기록하는 것. 뭐가 중요하고 뭐가 중요하지 않은지를 적어 놓지만, 메모지가 너무 많아지면 핵심을 알기 어려워진다. 반면 트랜스포머는 직접 데이터를 참조하는 방법이다. 무엇이 중요한지만 학습하고, 실제 정보는 데이터에서 직접 가져온다.

## 5. 어텐션 메커니즘과 ViT

### 5-1. 어텐션 메커니즘

이미지에는 로컬리티와 반복 패턴이 모두 존재한다. 장거리 의존성을 활용하면 로컬리티 이상의 이익을 얻을 수 있다.

핵심 아이디어: **나를 나와 유사한 것들의 가중합으로 표현한다.**

> **교수님 강조**: 여러분의 시험 점수를 친구의 시험 점수의 평균으로 대체한다. 억울하지 않으려면 친구가 나와 비슷해야 한다. 유사한 사람들을 잘 정의할 수만 있으면 나를 친구의 평균으로 정의하는 것에 문제삼을 게 없다.

세 가지 구성 요소:
- **쿼리(Query)**: 나 (집중 대상)
- **키(Key)**: 친구들 (비교 대상 패치들)
- **밸류(Value)**: 친구들의 점수 (실제 값)

**어텐션** = 쿼리와 키의 유사도. 이 어텐션으로 밸류를 가중합하여 출력을 생성. 실제 구현에서는 같은 입력을 W_Q, W_K, W_V 세 학습 가능한 변환으로 쿼리·키·밸류를 만든다.

### 5-2. 셀프 어텐션 vs 크로스 어텐션

**셀프 어텐션**: 같은 입력에서 쿼리·키 정의. 이미지 내부 패치 간 유사도를 학습. 암묵적 **클러스터링** 효과 — 누가 같은 그룹인지를 슈퍼비전 없이 배움.

**크로스 어텐션**: 다른 종류의 데이터에서 쿼리·키 정의. 텍스트→이미지 생성, 음성→이미지 매칭 등. 특정 단어가 이미지 어느 영역과 유사한지를 통해 위치까지 파악 가능.

### 5-3. ViT(Vision Transformer) 구조

논문 제목 "An Image is Worth 16×16 Words" — "A picture is worth a thousand words" 속담 패러디.

**전체 흐름**:
1. 이미지를 고정 크기 패치(16×16)로 분할
2. 선형 프로젝션으로 벡터화(임베딩)
3. **위치 인코딩** 추가 (1번 패치, 2번 패치... 이름표 부여)
4. ViT 인코더 반복 적용
5. MLP 헤드로 최종 분류

**위치 인코딩이 필요한 이유**: 어텐션은 모든 패치를 한 번에 보지만 패치가 어디서 왔는지 모른다. CNN은 깊이로 순서를 반영하지만 어텐션에는 순서 정보가 없다.

**위치 인코딩 방식들**:
- 학습 가능한 인코딩: 데이터에 최적화, 해상도 변경 시 재학습 필요
- 사인파(Sinusoidal): 해상도 변경에 유연. 이미지 생성 모델(NeRF 등)에서 많이 사용
- 상대적 위치 인코딩: 패치 간 상대 거리만 사용. 해상도 유연하나 절대 위치 필요 시 부적절
- 인코딩 안 씀: 일부 모델에서 의도적으로 미사용

### 5-4. ViT 인코더 내부 구조

1. **레이어 놈(Layer Norm)**: 배치 놈이 아님. ViT에서는 레이어 놈 사용
2. **멀티헤드 어텐션**: W_Q, W_K, W_V로 쿼리·키·밸류 생성 → 어텐션(쿼리·키) → 밸류 가중합 → 출력. 여러 헤드(관점)에서 패치 간 관계 학습
3. **스킵 커넥션**: 입력을 출력에 더함
4. **레이어 놈 + MLP(FC 역할)**: 어텐션 정보를 조합하여 다양한 특징 생성
5. **스킵 커넥션**: MLP 입력을 출력에 더함

인코더가 매우 많이 반복됨. FCN과 어텐션 모두 포함되어 파라미터 매우 많다. CNN은 깊어야 수용 영역이 넓어지지만, ViT는 모든 픽셀이 모든 픽셀을 참조하는 것이 디폴트.

### 5-5. ViT의 성능과 특성

**데이터 적으면 CNN 우수**: CNN에 로컬리티라는 귀납적 편향(inductive bias)이 내장되어 적은 데이터에서도 잘 동작. ImageNet만으로는 ResNet이 ViT보다 좋다.

**대규모 데이터 + 사전학습 필수**: 구글팀이 ImageNet-21K, JFT-300M(3억 장, 비공개)으로 사전학습 후 이미지넷 미세조정하여 비로소 ResNet 능가.

**데이터 증강·정규화 영향 큼**: CNN은 정규화 너무 세면 방해받지만, ViT는 많이 쓸수록 좋다.

### 5-6. 증류 학습(Knowledge Distillation) — DeiT

선생님 모델의 중간 예측(로짓)을 학생 모델이 따라가며 학습. 학생은 정답도 따라가고 선생님도 따라감. KL 다이버전스로 매칭.

**DeiT의 핵심**: 선생님을 더 강력한 모델이 아닌 **CNN(ResNet 등)**으로 설정. CNN의 이미지 특화 장점을 ViT가 흡수하면서 동시에 자체 학습도 수행.

**구현**: ViT에 **학습 가능한 토큰**(빈 토큰)을 추가. 이미지 패치 외에 추가 토큰이 CNN 선생님의 로짓을 예측하도록 학습.

**결과**: 증류로 성능이 데이터 증강 등보다 훨씬 크게 향상. 오래 학습하면 추가 개선, 해상도 높이면 추가 개선. ViT는 많은 데이터·오래 학습·높은 해상도에서 성능 지속 향상.

> **교수님 강조**: CNN이 헛되지 않았다. ViT는 데이터가 많으면 유효하고, CNN의 예측을 초기에 따라가면 더 잘할 수 있다.

### 5-7. Swin Transformer

ViT의 전체 어텐션은 메모리가 엄청 든다. Swin은 윈도우(블록) 내부에서만 어텐션 계산 → 다음 레이어에서 윈도우를 시프트하여 다시 계산. 시프트를 반복하면 간접적으로 전체를 보는 효과. 특히 픽셀 단위 검출(segmentation)에서 우수.

### 5-8. 현재 최고 모델들

- **ViT-22B**: 220억 파라미터. 비공개
- **DiNO v2 / DiNO v3**: 메타(Meta) 공개. ViT 구조, 이미지 특징·표현 특화 오픈소스
- **EVA-CLIP**: 상하이 AI. 비전-언어 모델
- **InternImage**: 합성곱+트랜스포머 하이브리드. 픽셀 레벨 분할에 강점. 언어로 컨트롤 가능한 비전-언어 모델
- 제로샷(처음 본 객체 인지)에서는 비전-언어 모델이 유용

ViT가 대체되기 어려운 이유: 파운데이션 모델에 사용, LLM과 호환 필요(둘 다 트랜스포머), 스케일링 우수(데이터 늘릴수록 성능 향상).

## 6. 활성화 함수

활성화 함수는 비선형성을 부여하며, 각 노드가 입력에 얼마나 반응할지를 결정한다.

### 6-1. 시그모이드(Sigmoid)

출력을 0~1 사이로 제어. 확률값 해석에 유용(로짓 → 확률).

**문제점**: (1) 입력이 극단적이면 기울기 0 → 역전파 정보 전달 안 됨(포화 구간), (2) 출력이 항상 양수(중간값 0.5)라 음의 영역을 못 써서 편향된 업데이트 발생, (3) 지수 함수 연산(현대 GPU에서는 무시 가능).

### 6-2. tanh(탄젠트 하이퍼볼릭)

출력 범위 -1~1. 시그모이드 비대칭성 해소. RNN에서 사용(학습 불안정 제어), GAN(특히 DCGAN)에서도 사용.

여전한 문제: 특정 범위 밖에서 기울기 소실. 내부 지수 함수 연산 (무시 가능).

### 6-3. ReLU

```
ReLU(x) = max(0, x)
```

양수는 그대로, 음수는 0. 양수 영역에서 포화 구간 없음. 계산 매우 빠름(max 하나). 기존 대비 **6배 빠른 수렴 속도**.

**음수 0 처리의 양면**: 뉴런 사망(dead neuron) 발생하지만, 모델 스파스화(단순화) 효과로 장점일 수도. 0 기준 대칭성 없는 것은 단점.

### 6-4. Leaky ReLU

음수 영역에 작은 기울기(0.01) 부여. 뉴런 사망 방지. 비선형성 유지(꺾임). 연산 가벼움.

0.01 값을 임의 설정해야 하고, 성능에서 ReLU보다 항상 좋지는 않다. ReLU의 뉴런 사망이 오히려 성능에 나쁘지 않다는 주장도 있다.

### 6-5. ELU

음수 영역에 지수 함수로 점진적 포화. 스파스 특성 유지하면서 모든 음수를 없애지는 않는 고도화된 ReLU 변형. 알파 파라미터 선택 필요.

> **교수님 강조**: 모델 학습할 때 일단 ReLU부터 써라. 가장 스탠더드하고 기본적으로 좋은 성능을 준다. 0.1%라도 올려야 하는 경쟁이면 개선판 시도. 시그모이드·tanh는 전문가의 영역이다. 꼭 써야 할 이유가 있을 때만 사용.

## 7. 데이터 전처리

학습과 테스트에 동일한 전처리를 적용하는 것이 핵심. 데이터 간 차이를 정규화시켜서 배워야 할 부분을 제한하는 목적이다.

기본: 센터 크롭으로 해상도 맞추고, 평균 빼고 표준편차로 나눠서 분포 정규화(평균 0, 분산 1). 그레이스케일은 3채널로 복사.

**모델별 전처리**:
- **AlexNet**: 전체 평균만 뺌
- **VGGNet**: 채널별(R, G, B) 평균 뺌
- **ResNet**: 채널별 평균 빼고 채널별 표준편차로 나눔. ImageNet의 각 RGB 채널 평균이 다르기 때문에 채널별 전략이 잘 먹혔다
- **ViT**: 채널별 전략을 취하지 않는 일반화된 방식

## 8. 가중치 초기화

> **교수님 강조**: 초기화와 학습률, 이 두 가지가 진짜 코어다.

### 8-1. 0 초기화

모든 가중치 0 → 출력 0. 로스는 만들어지지만 모든 뉴런이 동일 출력이라 부적절.

### 8-2. 작은 랜덤 초기화

가우시안 분포에서 작은 값 샘플링. **깊은 모델에서 동작 안 함**: 역전파 시 1보다 작은 W가 반복 곱해지면 기울기가 0으로 수렴. 후반 레이어에서 활성화값이 0에 몰림. 모두 0이면 기울기 정의 불가.

### 8-3. Xavier(자비에) 초기화

**아이디어**: 레이어 통과 시 데이터 차원이 바뀌면 출력 분산이 달라짐. N명 오케스트라의 소리를 일정하게 유지하려면 단원 수로 보정해야 하듯, **입력 차원으로 정규화**하여 분산을 유지.

수학적으로 입력 분산이 출력 분산으로 유지됨을 증명 가능.

**한계**: 활성화 함수가 분산을 어그러뜨리지 않는 경우를 가정. tanh(좌우 대칭)에서는 문제없지만, ReLU는 음수를 모두 소거하므로 가정이 깨짐.

### 8-4. He(허) 초기화

ReLU가 음수 절반을 제거하는 것을 반영하여 **분산을 2배 보정** (2/입력 차원). 비대칭 ReLU에서도 후반 레이어 분산 유지를 증명. ReLU 사용 시 표준.

### 8-5. ResNet의 특별한 초기화

잔차 블록에서 입력이 스킵 커넥션으로 그대로 전달되므로 추가 전략 필요.

- 첫 번째 Conv: He 초기화 (ReLU 사용)
- 두 번째 Conv: **0 초기화**

두 번째를 0으로 초기화하면 F(x) = 0이 되어 출력 = x + 0 = x (아이덴티티). 입력 분산이 그대로 전달되어 초반 학습 안정. 초기화 잘못되면 출력이 엄청 커져서 초반에 불안정해지고, 뉴럴넷은 초반이 불안정하면 후반에도 복구 어렵다. 의도적으로 아이덴티티를 만들고 점진적으로 F(x)가 업데이트되게 유도.

## 9. 정규화(Regularization)

### 9-1. 과적합과 정규화

학습 로스가 줄어도 밸리데이션 성능이 떨어지면 과적합. 모델이 학습 데이터를 과도하게 외우지 못하게 방해하여 일반적 지식을 배우게 하는 것이 정규화의 목적.

과적합은 특정 입력이나 노드를 과도하게 의지하여 해당 노드가 큰 값을 갖게 되는 현상이므로, 큰 가중치를 억제하면 방지할 수 있다.

### 9-2. L2 정규화 (Weight Decay)

가중치 제곱에 패널티. 큰 값일수록 강한 패널티. 원래 로스를 따라가면서 동시에 가중치를 키우지 말라는 제약.

### 9-3. L1 정규화

가중치 절대값에 패널티. 중요하지 않은 가중치를 0으로 만드는 **희소화(Sparsification)** 효과. 특정 상수가 살아남으면 살아남고 아니면 0.

### 9-4. Elastic Net

L1과 L2를 베타 파라미터로 혼합. 베타 키우면 L2 강화, 줄이면 L1 강화. 대부분 합쳐서 사용.

### 9-5. 드롭아웃(Dropout)

학습 중 무작위로 뉴런 비활성화. 특정 뉴런에 과도하게 의존하는 것을 방지. FC 레이어에서 특히 강력. 매번 다른 노드를 드롭하므로 여러 서브 모델 앙상블 효과.

학습 시간 증가(L1/L2도 마찬가지). **배치 정규화와 함께 사용 안 함**: 드롭아웃은 매번 다른 노드를 끄므로 배치의 평균적 특성이 매번 바뀌어 배치 놈이 일관된 통계를 잡을 수 없다. 학습 중과 테스트에서 분포가 완전히 달라진다.

**스케일 보정**: 드롭 확률 0.5면 살아남은 뉴런 출력에 2를 곱하여 학습/테스트 불일치 해소. 일반적으로 학습 때 스케일링, 테스트는 가볍게.

시계열 데이터에는 잘 안 쓰이고, 합성곱에서도 덜 쓰이는 경향.

## 10. 학습률(Learning Rate) 전략

### 10-1. 학습률의 중요성

같은 모델·절차·모듈이라도 학습률에 따라 완전히 다른 결과, 완전 실패 가능. 너무 높으면 발산(정답 계곡에서 튕김), 너무 낮으면 시간 부족(마감 불가).

### 10-2. 학습률 변경 전략

큰 값→작은 값이 기본. **반드시 변경**해야 하며 하나를 고정하지 않는다.

- **계단식(Step Decay)**: 특정 에폭마다 비율(예: 1/10)로 감소
- **코사인(Cosine)**: 코사인 함수를 따라 부드럽게 감소. 미세 조절이 부드러움
- **선형(Linear)**: 직선 감소. 사전학습/미세조정에 주로 사용
- **일괄(Constant)**: 데이터가 엄청 많을 때만 가능. 역제곱근 방식은 잘 안 씀
- **제곱근(Square Root)**: 초반 빠르게 하락하는 커브
- **웜업(Warm-up)**: 작은 값→큰 값→감소. 프리트레이닝에 사용

에폭 = 전체 데이터 1회 순회. 이터레이션 = 배치 1개 처리 + 가중치 1회 업데이트. 하나의 에폭 = 여러 이터레이션.

### 10-3. 얼리 스토핑(Early Stopping)

오래 학습하면 과적합 빈번. 학습 중 계속 가중치 저장, 밸리데이션 정확도 피크 후 하락 시 그때 가중치 사용. 나빠지면 멈추기.

## 11. 하이퍼파라미터 탐색과 학습 체크리스트

### 11-1. 파라미터 vs 하이퍼파라미터

- **파라미터**: 모델이 학습 (알아서)
- **하이퍼파라미터**: 학습 전 미리 정함. 학습 동안 고정. 예: 학습률, 변경 방식, 배치 사이즈, 에폭 수, 최적화 도구(SGD/Adam/AdamW), 가중치 감소 계수, 모멘텀, 모델 구조 등

하이퍼파라미터 선택이 성능에 엄청난 영향. 사람마다 다른 성능의 근본 이유. 배치 사이즈 키워 안정성 확보하는 게 최근 트렌드.

### 11-2. 그리드 탐색(Grid Search)

모든 조합을 다 실험. 직관적이지만 축이 중요한지 모르는데 다 해보는 건 리소스 낭비.

### 11-3. 랜덤 탐색(Random Search)

무작위로 선택. 각 축에 프로젝션하면 중요한 축에 자연스럽게 더 많은 샘플이 배정되는 효과. 다시 실험 안 해도 되는 낭비를 막음. 운이 나쁘면 어떤 일이든 일어날 수 있지만, 일반적으로 랜덤이 그리드보다 유리.

빅테크도 모든 조합을 실험하지 않는다. 아무리 많은 GPU가 있어도 항상 부족. 스마트한 방법이 필수.

### 11-4. 실전 학습 체크리스트

> **교수님 강조**: 이 전략들이 디버깅 트윗 같은 건데, 주어진 시간 안에 많은 성과를 낼 수 있게 해 준다.

**체크리스트 1 — 초기 손실 확인**: 크로스 엔트로피 사용 시, 초기 상수 랜덤 → 예측 랜덤 → 클래스 10개면 맞출 확률 1/10 → -log(0.1) = log(10) ≈ 2.3. 크게 벗어나면 레이블 문제거나 데이터 로딩 오류.

**체크리스트 2 — 소규모 과적합 테스트**: 아주 작은 샘플로 정규화 없이 **일부러 과적합** 유도. 정확도 100% 달성이 목표. 작은 데이터 과적합조차 못 하면 모델에 문제. 손실 안 줄면: 학습률/초기화/활성화함수 문제. 손실 폭발: 학습률 줄이기 → 초기화 변경. 모델 구조 오류나 시스템 버그 가능성도.

**체크리스트 3 — 학습률 탐색**: 모든 데이터 사용, **100번 이터레이션만**. 로그 스케일(10⁻¹, 10⁻², 10⁻³, 10⁻⁴)로 여러 학습률 시도. 손실 줄어드는 후보를 **여러 개** 선별.

**체크리스트 4 — 조합 평가**: 후보 학습률 + 변경 방식(계단식/코사인/선형 등) 조합을 **5에폭** 학습. 5에폭도 많은 건 아님(실제 에폭은 수백~수천). 될 것도 아닌 걸 끝까지 할 이유 없음. **검증 세트**로 성능 봐야 함(학습 로스만 보면 일반화 모름).

**체크리스트 5 — 장기 학습**: 좋은 조합(약 10개)을 **10~20에폭** 추가 학습하되, 학습률 변경을 **끄고** 현재 값 그대로 유지. 1~5에폭의 경향으로 10~20을 예단할 수 없으므로 순수 조합만으로 판단. 학습률 내리면 속도가 느려져 시간 낭비.

### 11-5. 손실 곡선 해석

학습률에 따른 손실 곡선의 이동 평균을 관찰. 학습/검증 모두 확인.

- **초반 플래토**: 초기화 문제. 정상이면 초반부터 손실 감소
- **중간 플래토**: 현재 학습률로 추가 학습 불가 → 학습률 줄여야
- **학습률 줄인 직후 플래토**: 너무 빨리 줄임. 플래토 끝까지 기다렸다가 줄여야. 정체가 아니라 학습이 느려진 것
- **검증·학습 정확도 모두 상승**: 학습 계속. 끝내면 안 됨
- **검증 정확도만 하락**: 과적합 → 얼리 스토핑 또는 정규화(드롭아웃, 배치놈, 레이어놈, L1, L2 등)
- **학습·검증 정확도 거의 동일**: 이상적이 **아님**! 공부한 것과 시험 결과가 어떻게 똑같은가? 모델의 힘이 너무 약함 → 더 큰 모델 도입. 최소한 갭은 있어야 함

> **교수님 주의**: 학습과 검증 데이터의 정확도가 붙어 있는 걸 보고 아이디얼하다고 생각하면 안 된다. 모델이 약하다는 시그널이다.

## 12. 참고 — 사전학습과 전이학습 (읽을거리)

강의 중 교수님이 사전학습(Pre-training)과 전이학습(Transfer Learning)에 대해 언급했다. 사전학습 시에는 웜업(작은 값 → 큰 값)을 사용하고, 전이학습(미세조정) 시에는 선형 감소를 주로 사용한다. 실습 시 활용하게 된다.

## 정리

| 구분 | 핵심 포인트 |
|------|-------------|
| CNN 핵심 | 이미지 구조 유지하며 로컬 특징을 계층적으로 추출. 필터 공유로 파라미터 효율적 |
| 합성곱 연산 | 필터를 이미지 위에 슬라이드하며 내적+바이어스. 필터 채널 = 입력 채널 필수 |
| 출력 해상도 | (입력-필터+2×패딩)/스트라이드+1. 필터는 홀수(센터 하나) |
| 수용 영역 | 레이어 깊을수록 넓어짐. 출력 중앙 픽셀 기준 평가. 이미지 전체 커버하도록 설계 |
| 풀링/스트라이드 | 위치 불변성 제공. 맥스 풀링은 노이즈에 강건. 스트라이드 합성곱이 최근 더 선호 |
| AlexNet | 최초 성공 CNN. 8층, ReLU·맥스풀링 도입. GPU 메모리 부족으로 2브랜치 |
| VGGNet | 3×3 반복의 직관적 설계. 풀링마다 채널 2배. perceptual loss에 현재도 활용 |
| ResNet | 잔차 블록(스킵 커넥션)으로 기울기 소실 해결. 보틀넥으로 효율화. 100층+ 학습. CNN 베이스라인 표준 |
| MobileNet | 깊이별+화소별 합성곱 분리로 연산 약 9배 절감, 성능 1~2% 하락 |
| CNN 한계 | 순서 무시(위치 관계 파악 어려움), 장거리 의존성 부족(로컬만 관찰) |
| RNN | 은닉 상태로 순서 반영. 동일 가중치 공유. 병렬 불가, 기울기 폭발/소실, 장기 기억 없음 |
| LSTM | 셀 상태 + 3개 게이트(입력/망각/출력)로 장기 기억 개선. 덧셈 경로로 기울기 안정. 시퀀스 길면 정보 희석 |
| 어텐션 | 쿼리-키 유사도로 밸류 가중합하여 새 표현 생성. 장거리 의존성 해결. 셀프/크로스 구분 |
| ViT | 이미지를 패치로 분할 → 위치 인코딩 → 트랜스포머 인코더(레이어놈+멀티헤드어텐션+MLP). 대규모 데이터에서 CNN 능가 |
| ViT 특성 | 데이터 적으면 CNN 우수. 증강·정규화 효과 큼. 증류(CNN 선생님)으로 크게 개선. 스케일링 우수 |
| Swin Transformer | 윈도우 내부 어텐션 + 시프트로 메모리 절감하면서 전역 효과 |
| 현재 최고 모델 | DiNO v2/v3(오픈소스), EVA-CLIP, InternImage 등. LLM 호환·스케일링 때문에 트랜스포머 선호 |
| 활성화 함수 | 기본 ReLU. 시그모이드(확률용), tanh(RNN/GAN), Leaky ReLU/ELU(개선판) |
| 데이터 전처리 | 학습/테스트 동일. 평균·분산 정규화. AlexNet/VGG/ResNet/ViT 전략 상이 |
| 가중치 초기화 | Xavier(대칭 함수, 입력 차원 보정), He(ReLU, 2배 보정). ResNet은 두 번째 레이어 0 초기화 |
| 정규화 | L2(큰 값 억제), L1(희소화), Elastic Net(혼합), 드롭아웃(뉴런 비활성화, 배치놈과 병용 불가) |
| 학습률 | 가장 중요한 하이퍼파라미터. 큰→작은 값. 계단식/코사인/선형/웜업. 반드시 변경 |
| 하이퍼파라미터 탐색 | 그리드(모든 조합) vs 랜덤(일반적으로 더 유리) |
| 실전 체크리스트 | ①초기 손실 확인 → ②소규모 과적합 → ③학습률 탐색(100 iter) → ④조합 평가(5에폭) → ⑤장기 학습(20에폭, 변경 끔) |
| 손실 곡선 해석 | 초반 플래토=초기화 문제, 중간 플래토=학습률 줄여야, 검증만 하락=과적합, 학습≈검증=모델 약함 |
