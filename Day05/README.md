# Day05 — 객체지향 프로그래밍(OOP) 기초

> **학습 목표**: 절차지향 vs 객체지향의 차이를 이해하고, 클래스·객체·인스턴스·메서드 개념을 통해 Python OOP의 기본 구조를 실전에서 활용할 수 있다.

---

## 1. 오늘의 핵심 요약
- Python은 **객체지향 기반 언어**이며, 모든 값은 객체이다.
- **절차지향**은 흐름 중심, **객체지향**은 데이터+행동 묶음 중심이다.
- **클래스는 설계도**, **인스턴스는 실체**이다.
- 인스턴스 메서드는 **self**를 통해 호출 주체를 구분한다.
- **클래스 변수 / 인스턴스 변수**의 범위 차이를 명확히 구분해야 한다.

---

## 2. 개념 구조 정리 (트리)

```
객체지향 프로그래밍(OOP)
├─ 프로그래밍 패러다임
│   ├─ 절차지향 (Procedural)
│   └─ 객체지향 (Object Oriented)
│
├─ 핵심 개념
│   ├─ 클래스 (Class)
│   ├─ 객체 / 인스턴스 (Object / Instance)
│   ├─ 속성 (Attribute)
│   └─ 메서드 (Method)
│
├─ 변수 구분
│   ├─ 클래스 변수
│   └─ 인스턴스 변수
│
└─ 메서드 종류
    ├─ 인스턴스 메서드
    ├─ 클래스 메서드
    └─ 정적 메서드
```

---

## 3. 절차지향 vs 객체지향

### 3-1. 절차지향 프로그래밍

**특징**
- 위에서 아래로 **흐름 중심 실행**
- 변수와 함수가 **분리**

**장점**
- 직관적
- 개발 속도 빠름
- 알고리즘 문제 풀이에 적합

**단점**
- 코드 길어질수록 **스파게티 코드** 발생
- 유지보수 난이도 증가

---

### 3-2. 객체지향 프로그래밍

**특징**
- 데이터 + 행동을 **객체 단위로 묶음**
- 설계 → 재사용 → 유지보수 최적화

**장점**
- 구조적
- 재사용성 높음
- 대규모 협업 프로젝트에 적합

**활용 전략**
- 알고리즘 → 절차지향
- 프로젝트 / 협업 → 객체지향

---

## 4. 클래스 & 인스턴스 핵심 구조

### 4-1. 클래스 = 설계도

```python
class Person:
    pass
```

---

### 4-2. 인스턴스 = 실제 객체

```python
p1 = Person()
p2 = Person()
```

- p1, p2 → 서로 **완전히 독립적인 객체**

---

## 5. 생성자 (__init__) & 인스턴스 변수

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

```python
p1 = Person("민수", 20)
p2 = Person("지민", 25)
```

**핵심 개념**
- `__init__` → 인스턴스 생성 시 **자동 실행**
- `self.name`, `self.age` → **인스턴스 변수**

---

## 6. self의 정체 (시험 단골)

```python
p1.introduce()
```

➡ 실제 내부 동작

```python
Person.introduce(p1)
```

**정리**
- self = **메서드를 호출한 인스턴스 자기 자신**

---

## 7. 인스턴스 메서드

```python
class Person:
    def introduce(self):
        print(f"안녕하세요, 저는 {self.name}입니다.")
```

```python
p1 = Person("민수", 20)
p2 = Person("지민", 25)

p1.introduce()
p2.introduce()
```

**핵심**
- 같은 메서드 → **인스턴스에 따라 결과 다름**

---

## 8. 클래스 변수 vs 인스턴스 변수

```python
class Circle:
    pi = 3.14

    def __init__(self, r):
        self.r = r
```

```python
c1 = Circle(3)
c2 = Circle(5)
```

| 구분 | 정의 위치 | 공유 여부 |
|------|-------------|-------------|
| 클래스 변수 | 클래스 내부 | 전체 공유 |
| 인스턴스 변수 | __init__ | 개별 보유 |

---

## 9. 실전 활용 예시 (카운터)

```python
class Counter:
    def __init__(self):
        self.count = 0

    def increment(self):
        self.count += 1
```

```python
c1 = Counter()
c2 = Counter()

c1.increment()
c1.increment()
c2.increment()

print(c1.count)  # 2
print(c2.count)  # 1
```

➡ **각 인스턴스 독립 관리 핵심 사례**

---

## 10. 실수 & 함정

| 실수 | 문제점 |
|--------|-----------|
| self 누락 | 메서드 오류 발생 |
| 클래스 변수 = 인스턴스 변수 혼동 | 값 공유 오류 |
| 인스턴스 없이 메서드 호출 | 실행 불가 |

---

## 11. 시험 & 알고리즘 연결 포인트

- `__init__` 호출 타이밍
- self 전달 원리
- 클래스 변수 / 인스턴스 변수 차이
- 객체 상태 독립성

---

## 12. 5분 요약

- 클래스 = 설계도
- 인스턴스 = 실체
- self = 호출 주체
- 인스턴스 변수 = 개별 데이터
- 클래스 변수 = 공유 데이터
