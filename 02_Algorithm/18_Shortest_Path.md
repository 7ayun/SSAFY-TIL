## 1. 최단 경로 개요

### 1-1. 최단 경로란

간선의 가중치가 있는 그래프에서 두 정점 사이의 경로 중 간선 가중치의 합이 최소인 경로를 말한다. 실생활에서는 내비게이션, 네트워크 라우팅, 게임 AI 경로 탐색 등에 광범위하게 활용된다.

> **강사님 강조**: 최단 경로 알고리즘은 오늘 배운 것 중 가장 중요한 고급 알고리즘이다. 그 중에서도 다익스트라는 실무에서 가장 많이 쓰이고 시험에도 가장 많이 나온다.

### 1-2. 세 가지 알고리즘 비교

| 알고리즘 | 출발점 | 음수 가중치 | 기반 | 시간 복잡도 |
|----------|--------|------------|------|------------|
| 다익스트라 | 단일 출발점 | 불가 | 그리디 + 힙큐 | O((V+E) log V) |
| 벨만-포드 | 단일 출발점 | 가능 | DP | O(VE) |
| 플로이드-워셜 | 모든 쌍 | 가능 | DP | O(V³) |

> **강사님 팁**: 시험 문제의 90% 가까이가 다익스트라다. 웬만한 기업 코딩테스트에서 어렵게 나온다 하면 거의 100% 다익스트라라고 보면 된다.

## 2. 다익스트라 알고리즘

### 2-1. 개념과 특징

하나의 시작 정점에서 다른 모든 정점까지의 최단 경로를 구하는 알고리즘이다. **그리디 기반**으로 동작하며, 현재까지 발견된 최단 거리가 가장 짧은 정점을 탐욕적으로 선택해 나간다. MST의 프림 알고리즘과 구조가 매우 유사하다.

> **강사님 주의**: 다익스트라는 탐욕적으로 선택한 정점은 뒤돌아보지 않는다. 음수 가중치가 있으면 이미 확정된 정점의 거리가 나중에 더 짧아질 수 있어 탐욕 전략이 깨진다. 그래서 음수 가중치 그래프에는 사용할 수 없다.

### 2-2. 동작 과정

1. 시작 정점까지의 거리를 0, 나머지 모든 정점은 무한대(∞)로 초기화
2. 시작 정점을 우선순위 큐(최소 힙)에 삽입
3. 큐에서 거리가 가장 짧은 정점을 꺼낸다
4. 꺼낸 정점의 인접 정점들을 순회하며 `현재까지 거리 + 간선 가중치`를 계산
5. 계산값이 기존 저장 거리보다 짧으면 갱신 후 큐에 재삽입
6. 큐가 빌 때까지 3~5 반복

> **강사님 강조**: 다익스트라는 코드도 간단하고 직관적이라 이해하기 쉽다. 최단 경로 알고리즘 중 구현 난이도가 가장 낮은데 활용도는 가장 높다. 이것만큼은 직접 구현할 수 있어야 한다.

### 2-3. 다익스트라 코드

```python
import heapq

def dijkstra(graph, start):
    # 모든 정점 거리 무한대로 초기화
    distance = {v: float('inf') for v in graph}
    distance[start] = 0

    heap = []
    heapq.heappush(heap, (0, start))  # (거리, 정점)

    while heap:
        dist, vertex = heapq.heappop(heap)

        # 이미 더 짧은 경로로 갱신된 정점이면 스킵
        if dist > distance[vertex]:
            continue

        for next_v, weight in graph[vertex].items():
            new_dist = dist + weight
            if new_dist < distance[next_v]:
                distance[next_v] = new_dist
                heapq.heappush(heap, (new_dist, next_v))

    return distance
```

```python
# 사용 예시
graph = {
    'A': {'B': 4, 'C': 2},
    'B': {'E': 8, 'D': 9},
    'C': {'B': 3, 'E': 6, 'F': 3},
    'D': {'F': 2},
    'E': {'F': 7},
    'F': {}
}
result = dijkstra(graph, 'A')
print(result)  # {'A': 0, 'B': 4, 'C': 2, 'D': 13, 'E': 8, 'F': 5}
```

> **강사님 팁**: 응용 문제로 "특정 정점 C, D를 반드시 거쳐서 A→목적지까지 최단 거리를 구하라"가 나오면, A→C→D→목적지와 A→D→C→목적지 두 경로를 각각 다익스트라로 구해 더 작은 값을 선택하면 된다.

## 3. 벨만-포드 알고리즘

### 3-1. 개념과 특징

다익스트라와 마찬가지로 단일 출발점에서 모든 정점까지의 최단 경로를 구하지만, **음수 가중치를 허용**한다는 점이 핵심 차이다. DP 기반으로 동작하므로 우선순위 큐를 사용하지 않으며, 음수 사이클의 존재 여부도 감지할 수 있다.

> **강사님 주의**: 다익스트라와 코드 구조가 비슷해 보여도 동작 원리는 완전히 다르다. 다익스트라는 탐욕적으로 한 번 확정한 정점을 뒤돌아보지 않지만, 벨만-포드는 DP 방식으로 V-1번 순회하며 계속 값을 갱신한다.

### 3-2. 동작 과정

1. 시작 정점 거리 0, 나머지 ∞로 초기화
2. 모든 정점에 대해 인접 간선을 통한 최단 거리 갱신을 **V-1번** 반복
   - 갱신이 한 번도 없으면 조기 종료
3. V-1번 이후 한 번 더 갱신을 시도해 값이 바뀌면 **음수 사이클 존재**로 판별

최악의 경우 A→B→C→D와 같이 V-1개의 간선을 통해 최단 거리가 갱신되므로, V-1번 순회가 필요하다.

### 3-3. 벨만-포드 코드

```python
def bellman_ford(graph, start):
    distance = {v: float('inf') for v in graph}
    distance[start] = 0

    for _ in range(len(graph) - 1):
        updated = False
        for vertex in graph:
            if distance[vertex] == float('inf'):
                continue
            for next_v, weight in graph[vertex].items():
                new_dist = distance[vertex] + weight
                if new_dist < distance[next_v]:
                    distance[next_v] = new_dist
                    updated = True
        if not updated:  # 갱신 없으면 조기 종료
            break

    # 음수 사이클 감지
    for vertex in graph:
        if distance[vertex] == float('inf'):
            continue
        for next_v, weight in graph[vertex].items():
            if distance[vertex] + weight < distance[next_v]:
                return None  # 음수 사이클 존재

    return distance
```

> **강사님 강조**: 음수 가중치는 처리할 수 있지만 음수 사이클은 어떤 최단 경로 알고리즘으로도 해결할 수 없다. 돌면 돌수록 거리가 짧아지기 때문에 최단 거리 자체가 정의되지 않는다.

## 4. 플로이드-워셜 알고리즘

### 4-1. 개념과 특징

모든 정점 쌍 사이의 최단 경로를 한 번에 구하는 알고리즘이다. DP 기반으로 동작하며, "A에서 B로 가는 최단 거리는 직접 가거나 중간 정점 K를 거쳐 가는 것 중 더 짧은 것"이라는 점화식을 반복 적용한다.

점화식: `dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`

> **강사님 강조**: 플로이드-워셜은 3중 포문으로 구현이 매우 간단하다. 단, V³의 시간 복잡도를 가지므로 정점 수가 많은 대형 그래프에는 적합하지 않다.

### 4-2. 플로이드-워셜 코드

```python
def floyd_warshall(graph, vertices):
    INF = float('inf')
    # 2차원 거리 테이블 초기화
    dist = {u: {v: INF for v in vertices} for u in vertices}
    for v in vertices:
        dist[v][v] = 0
    for u in graph:
        for v, w in graph[u].items():
            dist[u][v] = w

    # 모든 중간 정점 k를 순회
    for k in vertices:
        for i in vertices:
            for j in vertices:
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    return dist
```

## 정리

| 구분 | 핵심 포인트 |
|------|-------------|
| 다익스트라 | 그리디 + 힙큐, 단일 출발점, 음수 가중치 불가, O((V+E)logV) |
| 벨만-포드 | DP, 단일 출발점, 음수 가중치 허용, 음수 사이클 감지, O(VE) |
| 플로이드-워셜 | DP, 전쌍 최단 경로, 3중 포문, O(V³) |
| 알고리즘 선택 | 음수 없음 → 다익스트라 / 음수 가중치 → 벨만-포드 / 전쌍 필요 → 플로이드-워셜 |
| 음수 사이클 | 어떤 알고리즘으로도 최단 거리 정의 불가, 벨만-포드로 감지만 가능 |
| 다익스트라 중요도 | 시험 빈출 1위, 구현 필수, 실무에서도 가장 많이 사용 |
