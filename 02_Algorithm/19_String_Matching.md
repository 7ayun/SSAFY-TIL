## 1. 문자열 매치 개요

### 1-1. 개념

문자열 매치란 **본문(Text) 안에서 특정 패턴(Pattern)의 위치를 찾는 문제**다.  
Ctrl+F로 단어를 검색하는 것이 대표적인 활용 사례다.

> **강사님 강조**: 오늘의 최소 목표는 브루트 포스 구현 + 보이어-무어 동작 원리 이해다. 나머지는 이론적 이해로 충분하다.

### 1-2. 4가지 알고리즘 비교

| 알고리즘 | 핵심 아이디어 | 시간복잡도 (최악) | 시간복잡도 (평균) |
|----------|--------------|-----------------|-----------------|
| 브루트 포스 | 왼→오 순차 비교 | O(NM) | O(NM) |
| 라빈-카프 | 해시값 비교 + 롤링 해시 | O(NM) | O(N+M) |
| 보이어-무어 | 오른→왼 비교 + 스킵 테이블 | O(NM) | O(N/M) |
| KMP | DP + 부분 일치 테이블 | O(N+M) | O(N+M) |

## 2. 브루트 포스 패턴 매칭 (Brute Force)

### 2-1. 개념과 동작 원리

알고리즘 없이 **본능적으로 떠올리는 완전 탐색 방식**이다.  
패턴 비교가 실패하면 본문 포인터를 시작점 다음 칸으로 되돌리고 패턴 포인터를 0으로 초기화한다.

```
본문:  A B C A B D A B C A B C
패턴:      A B C A B C
           ^ 비교 시작 → 실패 시 한 칸 이동
```

포인터 두 개의 역할:
- `i` : 본문(Text)의 현재 비교 인덱스
- `j` : 패턴(Pattern)의 현재 비교 인덱스
- 같으면 `i += 1`, `j += 1`
- 다르면 `i = i - j + 1` (시작점 복구), `j = 0`

> **강사님 팁**: `i`와 `j`는 항상 같이 움직이므로 `i - j`를 하면 현재 비교를 시작했던 본문 위치로 돌아갈 수 있다. 이 점을 이용하면 별도 변수 없이 인덱스를 가지고 놀 수 있다.

### 2-2. 구현 코드

불일치 발생 시 `j`를 `-1`로 세팅하면, 이후 `+= 1`에 의해 자연스럽게 0이 된다.

```python
def brute_force(text, pattern):
    n, m = len(text), len(pattern)
    i, j = 0, 0

    while i < n and j < m:
        if text[i] != pattern[j]:   # 불일치
            i = i - j               # 시작점으로 복구
            j = -1                  # 아래 += 1로 0이 됨
        i += 1
        j += 1

    if j == m:
        return i - m    # 패턴 시작 인덱스 반환
    return -1           # 패턴 없음
```

> **강사님 강조**: 이중 포문으로 구현해도 시간복잡도는 O(NM)으로 동일하다. 포인터 방식은 이 방법도 있다는 걸 보여주기 위한 것이다.

## 3. 라빈-카프 알고리즘 (Rabin-Karp)

### 3-1. 개념과 동작 원리

문자열을 **해시값(정수)으로 변환**하여 비교하는 알고리즘이다.  
표절 검사처럼 하나의 텍스트에서 여러 패턴을 동시에 찾을 때 특히 유용하다.

동작 순서:
1. 패턴의 해시값을 미리 1번 계산한다
2. 본문의 첫 윈도우(패턴 길이만큼) 해시값을 계산한다
3. 슬라이딩 윈도우 방식으로 이동하며 해시값을 비교한다
4. 해시값이 같으면 실제 문자열을 한 번 더 검증한다

> **강사님 주의**: 해시값이 같다고 반드시 같은 문자열이 아니다(해시 충돌). 해시값 일치 후 반드시 실제 문자열 비교를 한 번 더 수행해야 한다.

### 3-2. 롤링 해시 (Rolling Hash)

매번 패턴 길이만큼 해시값을 새로 계산하면 브루트 포스와 다를 게 없다.  
**앞 글자를 제거하고 뒷 글자를 추가**하는 롤링 해시를 써서 O(1)에 다음 해시값을 구한다.

```
[6, 8, 4, 3] → 앞 6 제거 후 ×BASE → [8, 4, 3, 0] → 뒷 글자 2 추가 → [8, 4, 3, 2]
숫자로: 6843 → 앞 6 제거 → 843 → ×10 → 8430 → 2 추가 → 8432
```

> **강사님 팁**: BASE는 자릿수 구분용(소수), PRIME은 해시값 범위 제한용(모듈러 연산)이다. "BASE는 자릿수, PRIME은 억제기"라고 기억하면 된다.

### 3-3. 다항식 해시 함수와 구현

ASCII 코드값을 자릿수에 따라 가중합산하여 해시값을 만든다.

```python
# hash("abc") = ord('a')×BASE² + ord('b')×BASE¹ + ord('c')×BASE⁰  (mod PRIME)
BASE  = 256   # ASCII 전체 범위 커버
PRIME = 101   # 해시값 범위 제한

def rabin_karp(text, pattern):
    n, m = len(text), len(pattern)

    # 초기 해시값 계산
    p_hash = sum(ord(pattern[i]) * pow(BASE, m-1-i, PRIME) for i in range(m)) % PRIME
    w_hash = sum(ord(text[i])    * pow(BASE, m-1-i, PRIME) for i in range(m)) % PRIME
    highest = pow(BASE, m-1, PRIME)   # 최고 자릿수 미리 계산

    for i in range(n - m + 1):
        if w_hash == p_hash:
            if text[i:i+m] == pattern:   # 해시 충돌 방지: 실제 문자열 검증
                return i

        if i < n - m:
            # 롤링 해시: 앞 글자 제거 → 자릿수 이동 → 뒷 글자 추가
            w_hash = (w_hash - ord(text[i]) * highest) % PRIME
            w_hash = (w_hash * BASE + ord(text[i + m])) % PRIME

    return -1
```

## 4. 보이어-무어 알고리즘 (Boyer-Moore)

### 4-1. 개념과 동작 원리

현재 **가장 널리 사용되는 문자열 매칭 알고리즘**이다.  
VS Code, Chrome 등 대부분의 편집기에서 Ctrl+F의 기반으로 활용된다.

> **강사님 강조**: 오늘 배우는 4가지 알고리즘 중 가장 중요한 것이 보이어-무어다. 동작 원리를 반드시 이해하고 가자.

핵심 원칙:
- 패턴을 **오른쪽 → 왼쪽** 방향으로 비교한다
- 불일치 발생 시, 미리 만들어 둔 스킵 테이블을 참고해 한 번에 여러 칸을 건너뛴다

### 4-2. 스킵 테이블 생성

패턴에 있는 각 글자에 대해, **패턴 끝에서 해당 글자까지의 거리**를 저장한다.

```
패턴: A B C D E  (길이 5)
         ↓ 패턴 끝 기준 거리
A → 4,  B → 3,  C → 2,  D → 1
패턴에 없는 글자 → 5 (패턴 전체 길이만큼 점프)
```

같은 글자가 여럿 있으면 **마지막 위치 기준**으로 덮어쓴다(보수적 이동 보장).

### 4-3. 두 가지 점프 케이스와 구현

**경우 1 — 불일치 글자가 패턴에 없을 때**: 패턴 길이 전체만큼 점프

```
본문: ... E ...
패턴: A B C D A   ← E가 패턴에 없음 → 5칸 점프
```

**경우 2 — 불일치 글자가 패턴에 있을 때**: 해당 글자 위치에 맞춰 이동

```python
def boyer_moore(text, pattern):
    n, m = len(text), len(pattern)
    if m == 0:
        return 0

    # 스킵 테이블 생성
    skip = {}
    for i in range(m):
        skip[pattern[i]] = m - i   # 뒤에서 덮어쓰므로 마지막 위치 기준

    i = m - 1   # 본문 비교 위치
    while i < n:
        j = m - 1   # 패턴을 오른쪽부터 비교
        k = i
        while j >= 0 and text[k] == pattern[j]:
            j -= 1
            k -= 1
        if j < 0:
            return k + 1   # 패턴 발견

        i += skip.get(text[i], m)   # 스킵 테이블 기반 점프

    return -1
```

## 5. KMP 알고리즘 (Knuth-Morris-Pratt)

### 5-1. 개념

> **강사님 강조**: KMP는 난이도가 높고 실무 활용도도 낮다. DP를 이용한 이론적 알고리즘으로서 이해하고 넘어가자.

Knuth, Morris, Pratt 세 수학자가 동시에 고안해 이름을 합친 알고리즘이다.  
**DP를 활용**해 불일치 발생 시, 패턴의 **접두사=접미사 일치 구간**만큼 점프한다.

```
패턴: A B C D A B C E F
      ^^^         ^^^
      앞 3글자 = 뒤 3글자 → 불일치 시 3칸 점프 가능
```

### 5-2. 부분 일치 테이블 (Failure Function)

패턴의 각 위치에서 **접두사와 접미사가 일치하는 최대 길이**를 DP로 미리 계산한다.

```
패턴: A B C A B C
결과: [0, 0, 0, 1, 2, 3]

A        → 0  (앞뒤 일치 없음)
AB       → 0
ABC      → 0
ABCA     → 1  (A == A)
ABCAB    → 2  (AB == AB)
ABCABC   → 3  (ABC == ABC)
```

이전에 만든 테이블 값을 재사용하는 것이 DP의 핵심이다.

### 5-3. 구현 코드

```python
def build_failure(pattern):
    m = len(pattern)
    failure = [0] * m
    j = 0
    for i in range(1, m):
        while j > 0 and pattern[i] != pattern[j]:
            j = failure[j - 1]   # 이전 테이블 재사용 (DP)
        if pattern[i] == pattern[j]:
            j += 1
        failure[i] = j
    return failure

def kmp(text, pattern):
    n, m = len(text), len(pattern)
    failure = build_failure(pattern)
    j = 0
    results = []
    for i in range(n):
        while j > 0 and text[i] != pattern[j]:
            j = failure[j - 1]   # 점프
        if text[i] == pattern[j]:
            j += 1
        if j == m:
            results.append(i - m + 1)
            j = failure[j - 1]
    return results
```

> **강사님 팁**: KMP의 시간복잡도는 O(N+M)으로 이론적으로 가장 우수하지만, 실제 평균 성능은 보이어-무어가 더 빠른 경우가 많다.

## 6. 참고 — 알고리즘 선택 기준

상황에 따라 적합한 알고리즘이 달라진다.

| 상황 | 추천 알고리즘 | 이유 |
|------|-------------|------|
| 편집기 Ctrl+F, 일반 탐색 | 보이어-무어 | 평균 O(N/M), 가장 빠름 |
| 표절 검사, 다중 패턴 | 라빈-카프 | 해시 비교로 다수 패턴 동시 처리 |
| 최악 O(N+M) 보장 필요 | KMP | 이론적 선형 보장 |
| 간단한 구현 | 브루트 포스 | 직관적, 패턴 짧을 때 충분 |

## 정리

| 구분 | 핵심 포인트 |
|------|-------------|
| 브루트 포스 | `i-j`로 시작점 복구, 포인터 두 개(i=본문, j=패턴), O(NM) |
| 라빈-카프 | 롤링 해시로 O(1) 갱신, BASE=자릿수, PRIME=억제기, 해시 충돌 후 재검증 필수 |
| 보이어-무어 | 오른→왼 비교, 스킵 테이블, 패턴에 없는 글자면 전체 길이 점프 |
| KMP | 부분 일치 테이블(DP), 접두사=접미사 일치 구간만큼 점프, O(N+M) |
