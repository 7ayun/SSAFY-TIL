## 문제 요약

0~9로 이루어진 문자열에서 같은 번호가 인접하면 쌍으로 소거한다. 소거 후 새로 인접하게 된 같은 번호도 연쇄적으로 소거한다. 더 이상 소거할 쌍이 없을 때 남은 문자열이 비밀번호다. 테스트 케이스는 10개 고정(T를 입력받지 않음).

---

## 접근 방식

### 방법 1 — 브루트포스 (슬라이싱 + 반복)

문자열을 처음부터 순회하며 인접한 두 문자가 같으면 앞부분과 뒷부분을 슬라이싱하여 합친다. 합친 문자열을 대상으로 다시 처음부터 탐색한다. 더 이상 쌍이 발견되지 않을 때까지 반복한다.

### 방법 2 — 스택

문자를 하나씩 스택에 넣되, 넣으려는 문자가 스택의 마지막 원소와 같으면 스택에서 pop하고 해당 문자도 넣지 않는다. 다르면 그대로 push한다. 순회가 끝난 후 스택에 남은 문자가 비밀번호다.

> **강사님 강조**: 이 문제가 진짜 스택을 활용하면 간편하게 풀 수 있는 문제다. "맨 뒤의 값과 비교" + "뒤에서 삽입/제거"가 떠오르면 무조건 스택이다.

---

## 풀이 1 — 브루트포스

```python
for _ in range(10):
    N, array = input().split()
    N = int(N)

    while True:
        for idx in range(len(array) - 1):
            if array[idx] == array[idx + 1]:
                array = array[:idx] + array[idx + 2:]
                break
        else:
            break

    print(f'#{_ + 1} {array}')
```

for-else 구문을 활용한다. for문이 break 없이 완주하면 else 블록이 실행되어 while을 탈출한다. idx + 1과 비교하므로 range는 `len(array) - 1`까지만 순회해야 인덱스 에러를 피할 수 있다.

---

## 풀이 2 — 스택

```python
for _ in range(10):
    N, array = input().split()
    N = int(N)

    stack = []
    for ch in array:
        if not stack:
            stack.append(ch)
            continue
        if stack[-1] == ch:
            stack.pop()
            continue
        stack.append(ch)

    print(f'#{_ + 1} {"".join(stack)}')
```

스택의 마지막 원소(`stack[-1]`)와 현재 문자를 비교하는 것이 핵심이다. 같으면 pop으로 제거하고 현재 문자도 넣지 않으면 쌍이 자연스럽게 소거된다.

> **강사님 팁**: 이 문제의 테스트 케이스는 T를 입력받지 않고 10개가 고정으로 주어진다. 습관적으로 `T = int(input())`을 쓰면 입력이 밀려서 틀린다. 문제의 입력 형식을 반드시 확인하라.

## 핵심 패턴

### 스택을 활용한 쌍 소거

인접한 동일 원소를 제거하는 문제에서 스택은 가장 효율적인 도구다. "마지막에 넣은 것과 비교"하는 구조가 스택의 LIFO 특성과 정확히 일치한다.

### for-else 구문

Python에서 for문이 break 없이 정상 종료하면 else 블록이 실행된다. "찾았으면 break, 끝까지 못 찾았으면 else"라는 패턴으로 활용할 수 있다.

### join()으로 리스트를 문자열로 변환

`"".join(list)`는 리스트의 각 원소를 구분자 없이 이어붙여 문자열로 만든다. 스택이나 리스트로 처리한 결과를 출력할 때 필수적으로 사용된다.

## 정리

| 구분 | 핵심 포인트 |
|------|-------------|
| 입력 주의 | T를 입력받지 않음. 테스트 케이스 10개 고정 |
| 브루트포스 | 쌍 발견 → 슬라이싱 합치기 → 처음부터 재탐색 |
| 스택 | 마지막 원소와 비교 → 같으면 pop, 다르면 push |
| 효율성 | 브루트포스는 O(n²), 스택은 O(n) |
| for-else | break 없이 끝나면 else 실행. "못 찾음" 감지에 유용 |
