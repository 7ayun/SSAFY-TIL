## [문제] 비밀번호

> **활용 알고리즘:** `Stack`
> **난이도:** ★★☆☆☆

### 🔍 문제 설명
* 0~9로 이루어진 번호 문자열에서 동일한 번호가 연속으로 붙어있는 쌍을 소거함
* 소거 후 남은 문자열이 다시 연속된 쌍을 이루면 연쇄적으로 소거함. 최종적으로 남은 문자열(비밀번호) 출력

### 💡 풀이 포인트
* **문자열 슬라이싱 방식의 한계:** 문자열을 순회하며 일치하는 쌍을 잘라내고 붙인 뒤 다시 처음부터 순회하는 방식(`while`문 활용)은 인덱스 관리의 복잡성과 `O(N^2)` 이상의 속도 저하를 유발함
* **스택(Stack)을 활용한 `O(N)` 최적화:**
    * 문자를 하나씩 스택에 넣되, 스택의 최상단(`stack[-1]`) 문자와 현재 넣으려는 문자가 같으면 넣지 않고 스택의 문자를 뽑아냄(`pop`)
    * 이 방식을 사용하면 단 한 번의 순회만으로 연쇄 소거가 완벽히 처리됨

### 💻 구현 코드 (Python)
```python
def get_password(string_length, num_str):
    stack = []
    
    for ch in num_str:
        # 스택이 비어있으면 문자 삽입
        if not stack:
            stack.append(ch)
            continue
            
        # 스택의 최상단 원소와 현재 문자가 같으면 소거(pop)
        if stack[-1] == ch:
            stack.pop()
        # 다르면 스택에 삽입
        else:
            stack.append(ch)
            
    # 리스트에 남은 문자들을 문자열로 결합하여 반환
    return ''.join(stack)
```
