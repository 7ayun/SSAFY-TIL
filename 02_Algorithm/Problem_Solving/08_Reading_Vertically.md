## 문제 요약

5줄의 영어 대문자 단어가 주어진다. 각 줄의 길이는 다를 수 있다. 이 단어들을 세로(열) 방향으로 왼쪽부터 읽되, 해당 줄에 글자가 없으면 건너뛴다. 세로로 읽은 결과 문자열을 출력한다.

---

## 접근 방식

행은 5줄로 고정이므로 핵심은 열 방향 순회다. 먼저 5개 단어 중 가장 긴 길이를 구한다. 그 길이만큼 열을 순회하면서, 각 행의 해당 열에 글자가 존재하는 경우에만 결과에 추가한다. 글자가 없는 경우(열 인덱스가 해당 단어의 길이 이상)에는 건너뛴다.

일반적인 2차원 순회는 행 → 열 순서지만, 이 문제는 열 → 행 순서로 순회해야 한다. 바깥 for문에 열(col), 안쪽 for문에 행(row)을 배치하는 것이 포인트다. 접근 전에 해당 단어의 길이와 현재 열 인덱스를 비교하여 인덱스 에러를 방지해야 한다.

순회 순서를 헷갈리는 경우, 결과 문자열에 글자가 추가되는 순서를 먼저 생각하면 도움이 된다. 첫 번째로 추가되는 글자는 모든 단어의 첫 번째 열, 그 다음은 두 번째 열 순서다. 이를 코드로 옮기면 자연스럽게 열이 바깥 for문이 된다.

별도의 2차원 배열 없이 문자열 리스트 그대로 접근한다. `words[row][col]`로 row번째 단어의 col번째 글자에 직접 접근하면 된다.

> **강사님 팁**: 열 인덱스가 해당 단어의 길이보다 작을 때만 접근해야 인덱스 에러가 나지 않는다. 이 조건 하나가 이 문제의 전부다.

---

## 풀이

```python
T = int(input())
for tc in range(1, T + 1):
    words = [input() for _ in range(5)]

    max_length = 0
    for word in words:
        max_length = max(max_length, len(word))

    result = ''
    for col in range(max_length):
        for row in range(5):
            if col < len(words[row]):
                result += words[row][col]

    print(f'#{tc} {result}')
```

바깥 for문이 열(col), 안쪽 for문이 행(row)인 것이 핵심이다. `col < len(words[row])` 조건이 없으면 짧은 단어에서 인덱스 에러가 발생한다.

---

## 핵심 패턴

### 열 우선 순회 (Column-first Traversal)

보통 2차원 데이터는 행 → 열 순서로 순회하지만, 세로 읽기처럼 열 → 행 순서가 필요한 경우가 있다. 바깥 for문에 열 인덱스, 안쪽 for문에 행 인덱스를 배치하면 된다.

### 가변 길이 데이터의 안전한 접근

길이가 다른 리스트들을 같은 인덱스로 접근할 때는 반드시 범위 체크가 필요하다. `인덱스 < len(리스트)` 조건을 먼저 확인하는 습관을 들이면 IndexError를 방지할 수 있다.

## 정리

| 구분 | 핵심 포인트 |
|------|-------------|
| 입력 | 5줄 고정. 문자열이므로 int 변환 불필요 |
| 순회 방향 | 열(col) → 행(row) 순서. 일반적인 행 우선과 반대 |
| 범위 체크 | col < len(words[row])일 때만 접근. 아니면 건너뜀 |
| 최대 길이 | 가장 긴 단어의 길이만큼 열을 순회해야 함 |
