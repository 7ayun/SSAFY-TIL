## 문제 요약

두 개의 탑에 화물을 쌓는다. 각 층의 비용은 "층수 x 화물 무게"이다. 화물 개수와 두 탑의 높이가 주어질 때, 모든 화물을 쌓으면서 최소 비용을 구한다. 화물 개수 = 두 탑 높이의 합이 보장된다.

---

## 접근 방식

비용이 "층수 x 무게"이므로 무거운 화물을 낮은 층에 놓아야 비용이 최소가 된다. 이것만 파악하면 문제의 핵심은 끝난다. 따라서 화물을 무거운 순(내림차순)으로 정렬한 뒤, 현재 놓을 수 있는 층이 더 낮은 탑에 우선 배치한다.

주의할 점은 입력 테스트 케이스에서 화물이 오름차순으로 주어졌다고 해서 항상 그런 것이 아니라는 것이다. 내림차순 정렬을 먼저 수행하고 시작해야 한다. 한쪽 탑의 최대 높이를 초과하면 나머지 화물은 전부 반대쪽 탑에 배치하면 된다.

> **강사님 강조**: 문제를 보고 핵심을 파악하라. "층수 x 무게"라는 비용 구조에서 "무거운 것을 아래에"라는 결론을 끌어내는 것이 이 문제의 전부다.

---

## 풀이 1 — 두 탑 높이 비교 방식

```python
T = int(input())
for tc in range(1, T + 1):
    N, tower1_h, tower2_h = map(int, input().split())
    weights = list(map(int, input().split()))

    weights.sort(reverse=True)

    total = 0
    cur1 = 1
    cur2 = 1

    for i in range(N):
        if cur1 > tower1_h:
            total += cur2 * weights[i]
            cur2 += 1
        elif cur2 > tower2_h:
            total += cur1 * weights[i]
            cur1 += 1
        elif cur1 <= cur2:
            total += cur1 * weights[i]
            cur1 += 1
        else:
            total += cur2 * weights[i]
            cur2 += 1

    print(f'#{tc} {total}')
```

한쪽 탑이 꽉 찼는지 먼저 확인하고, 아직 여유가 있으면 현재 층이 더 낮은 쪽에 화물을 배치한다. 배치 후에는 해당 탑의 현재 층을 +1 해준다.

## 풀이 2 — 층수 리스트 매칭 방식

```python
T = int(input())
for tc in range(1, T + 1):
    N, tower1_h, tower2_h = map(int, input().split())
    weights = list(map(int, input().split()))

    weights.sort(reverse=True)

    floors = []
    for i in range(1, tower1_h + 1):
        floors.append(i)
    for i in range(1, tower2_h + 1):
        floors.append(i)
    floors.sort()

    total = 0
    for i in range(N):
        total += weights[i] * floors[i]

    print(f'#{tc} {total}')
```

두 탑의 층수를 하나의 리스트로 합친 뒤 오름차순 정렬한다. 화물은 내림차순, 층수는 오름차순으로 1:1 매칭하여 곱하면 자동으로 무거운 화물이 낮은 층에 배치된다.

> **강사님 팁**: 두 번째 방식이 더 간결하다. 탑을 구분하지 않고 "전체 층수 목록"으로 바꾸면 문제가 단순한 정렬 매칭으로 변한다.

## 핵심 패턴

### 역정렬 매칭 (그리디)

"최소 비용" 또는 "최대 이익"을 구할 때, 두 요소를 각각 오름차순/내림차순으로 정렬한 뒤 순서대로 곱하는 전략이다. 곱셈의 총합을 최소화하려면 큰 값과 작은 값을 매칭하면 된다.

### 복잡한 시뮬레이션 vs 단순 변환

풀이 1처럼 실제 상황을 시뮬레이션하는 방법과, 풀이 2처럼 문제를 수학적으로 변환하는 방법이 있다. 시뮬레이션은 직관적이지만 조건 분기가 많고, 변환은 간결하지만 아이디어가 필요하다.
