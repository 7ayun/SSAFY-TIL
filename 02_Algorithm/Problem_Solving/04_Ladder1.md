## 문제 요약

100 x 100 격자로 표현된 사다리에서 도착점(값 2)에 도달할 수 있는 출발점의 열 번호를 찾는다. 1은 사다리, 0은 빈 공간이며, 내려가다가 좌우 갈림길을 만나면 반드시 꺾어야 한다. 좌우가 동시에 연결된 경우는 주어지지 않는다.

---

## 접근 방식

### 기본 접근 — 위에서 아래로

1행에서 값이 1인 모든 열에서 출발하여 사다리를 타고 내려간다. 매 칸에서 아래, 오른쪽, 왼쪽 순으로 이동 가능한지 확인하고, 마지막 행에 도달했을 때 값이 2이면 해당 열이 정답이다.

여러 출발점에서 시도하므로 원본 배열을 변경하면 안 된다. 지나온 경로를 표시하기 위해 원본과 같은 크기의 visited 배열을 별도로 만들어 사용한다.

### 발전된 접근 — 아래에서 위로

도착점(2)에서 거꾸로 올라가면 출발점을 한 번에 찾을 수 있다. 경로가 유일하므로 visited 배열도 필요 없고 시도 횟수도 1번이면 충분하다.

> **강사님 강조**: 기본 풀이를 먼저 떠올린 뒤에 최적화를 생각하라. 도착점에서 역추적하는 아이디어는 사다리 게임의 규칙을 알기 때문에 가능한 것이다.
---

## 풀이

```python
def search_ladder(data, x, y, N):
    dxy = [(1, 0), (0, 1), (0, -1)]  # 아래, 오른쪽, 왼쪽
    visited = [[0] * N for _ in range(N)]
    visited[x][y] = 1                 # 시작 위치 방문 처리

    while x != N - 1:                 # 마지막 행에 도달할 때까지
        for dx, dy in dxy:
            nx = x + dx
            ny = y + dy

            # 조건 1: 범위 안에 있어야 함
            if nx < 0 or nx >= N or ny < 0 or ny >= N:
                continue
            # 조건 2: 사다리가 놓여 있어야 함
            if not data[nx][ny]:
                continue
            # 조건 3: 방문한 적이 없어야 함
            if visited[nx][ny]:
                continue

            # 세 조건을 모두 통과하면 이동
            x, y = nx, ny
            visited[x][y] = 1
            break                     # 이동했으면 다시 while로

    return data[x][y] == 2

N = 100
for _ in range(10):                   # 테스트 케이스 10개 고정
    tc = int(input())
    data = [list(map(int, input().split())) for _ in range(N)]

    result = -1
    for j in range(N):
        if data[0][j] == 1:           # 1행에서 사다리인 열에서 출발
            if search_ladder(data, 0, j, N):
                result = j
                break

    print(f'#{tc} {result}')
```

search_ladder 함수는 시작 좌표에서 사다리를 타고 내려가며, 마지막 행의 값이 2이면 True를 반환한다. while문을 사용하는 이유는 몇 번 이동할지 미리 알 수 없기 때문이다.

dxy의 순서가 (아래, 오른쪽, 왼쪽)인 이유는 기본적으로 아래로 내려가다가 갈림길을 만났을 때만 좌우로 꺾기 때문이다. for문 안에서 이동에 성공하면 break로 빠져나와 다시 while 루프의 처음부터 방향을 확인한다.

> **강사님 주의**: visited 배열 없이 원본을 수정하면 첫 번째 경로 탐색에서 값이 바뀌어 두 번째 출발점에서 오류가 발생한다. 여러 곳에서 시도해야 하는 문제에서는 반드시 원본을 보존하라. 이것은 이후 DFS, BFS에서도 핵심이 되는 개념이다.

## 핵심 패턴

### visited 배열

지나온 경로를 표시하기 위한 별도의 2차원 배열이다. 원본 데이터를 변경하지 않으면서 방문 여부를 추적할 수 있다. 0은 미방문, 1은 방문을 의미하며, DFS/BFS 등 탐색 알고리즘에서 필수적으로 사용된다.

visited를 `[[0] * N] * N`으로 만들면 안 된다. 리스트 곱셈은 같은 주소를 공유하므로 하나를 바꾸면 모든 행이 함께 바뀐다. 반드시 컴프리헨션(`[[0] * N for _ in range(N)]`)으로 생성해야 한다.

### Early Return (얼리 리턴)

여러 조건을 and로 묶는 대신, 각 조건을 통과하지 못하면 즉시 continue(또는 return)하는 패턴이다.

```python
# and로 묶은 방식
if 0 <= nx < N and 0 <= ny < N and data[nx][ny] and not visited[nx][ny]:
    x, y = nx, ny

# early return 방식 (조건별 분리)
if nx < 0 or nx >= N or ny < 0 or ny >= N:
    continue
if not data[nx][ny]:
    continue
if visited[nx][ny]:
    continue
x, y = nx, ny
```

> **강사님 강조**: 조건을 분리하면 디버깅이 쉬워진다. 어떤 조건에서 걸렸는지 바로 알 수 있고, 각 조건 아래에 print문을 넣어 테스트할 수도 있다. 실무에서도 많이 쓰는 방법이다.
