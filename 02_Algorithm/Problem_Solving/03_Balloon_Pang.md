## 문제 요약

N x M 격자에 풍선이 붙어 있고, 각 풍선 안에는 종이 꽃가루 개수가 적혀 있다. 어떤 풍선을 터뜨리면 안에 든 꽃가루 개수만큼 상하좌우로 추가 풍선이 터진다. 모든 풍선을 한 번씩 터뜨려 보고 가장 많은 꽃가루가 날리는 경우를 구한다.

풍선팡 2는 상하좌우 1칸만 터지지만, 풍선팡 1은 꽃가루 개수만큼 거리가 연장되어 터진다는 것이 핵심 차이다.

---

## 접근 방식

모든 좌표에서 풍선을 터뜨리는 완전 탐색이 기본이다. 각 좌표에서 터뜨릴 때 델타 탐색으로 상하좌우를 보되, 꽃가루 개수만큼 거리를 연장해야 한다.

dx, dy는 어차피 0 아니면 1(-1)이므로, 여기에 거리(dist)를 곱하면 점프 효과가 생긴다. dist가 1이면 한 칸, 2이면 두 칸, 3이면 세 칸 이동하는 식이다. 이 dist를 1부터 꽃가루 개수까지 for문으로 반복하면 된다.

범위를 한 번 벗어나면 그 방향으로는 더 멀리 가도 무조건 벗어나므로 break로 조기 종료할 수 있다.

---

## 풀이

```python
T = int(input())
for tc in range(1, T + 1):
    N, M = map(int, input().split())
    arr = [list(map(int, input().split())) for _ in range(N)]

    dxy = [(0, 1), (0, -1), (1, 0), (-1, 0)]
    max_value = 0

    for i in range(N):
        for j in range(M):                    # N x M이므로 열은 M까지
            sum_value = arr[i][j]             # 본인의 꽃가루도 포함

            for dx, dy in dxy:                # 상하좌우 4방향
                for dist in range(1, arr[i][j] + 1):  # 꽃가루 수만큼 확장
                    ni = i + dx * dist
                    nj = j + dy * dist

                    if 0 <= ni < N and 0 <= nj < M:
                        sum_value += arr[ni][nj]
                    else:
                        break                 # 벗어나면 더 먼 곳도 벗어남

            max_value = max(max_value, sum_value)

    print(f'#{tc} {max_value}')
```

`sum_value`를 `arr[i][j]`로 초기화하는 이유는 터뜨린 풍선 본인의 꽃가루도 합산해야 하기 때문이다. `dxy`를 튜플 리스트로 만들고 `for dx, dy in dxy`로 언패킹하면 별도의 인덱스 없이 깔끔하게 순회할 수 있다.

> **강사님 팁**: dxy를 튜플 리스트로 만들고 언패킹하는 방식이 range(4)로 인덱싱하는 것보다 유연하다. 방향 수가 바뀌어도 하드코딩할 필요가 없다.

## 핵심 패턴

### 델타 탐색에 거리 곱하기

기본 델타 탐색은 인접 1칸만 보지만, dx * dist처럼 거리를 곱하면 같은 방향으로 여러 칸을 탐색할 수 있다. dist를 for문으로 돌리면서 순차적으로 1칸, 2칸, 3칸을 보는 구조다.

### break를 활용한 범위 초과 조기 종료

한 방향으로 범위를 벗어나면 그 뒤는 볼 필요가 없다. dist가 순차적으로 증가하므로 한 번 벗어난 뒤의 모든 값도 벗어나기 때문이다.

## 정리

| 구분 | 핵심 포인트 |
|------|-------------|
| N x M 주의 | 행은 range(N), 열은 range(M). 습관적으로 둘 다 N으로 쓰면 오답 |
| 거리 확장 | dx * dist로 같은 방향 여러 칸 탐색. dist는 1부터 꽃가루 수까지 |
| 본인 포함 | sum_value 초기값을 arr[i][j]로 설정하여 터뜨린 풍선 자체도 합산 |
| 조기 종료 | 범위 벗어나면 break. 순차 접근이므로 이후 값도 전부 벗어남 |
| dxy 언패킹 | for dx, dy in dxy 방식으로 인덱싱 없이 깔끔하게 순회 |
