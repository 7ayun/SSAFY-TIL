## 문제 요약

N x N 배열에 파리의 개수가 적혀 있다. M x M 크기의 파리채를 한 번 내리쳐서 죽일 수 있는 파리의 최대 수를 구한다. 파리채는 배열 범위를 벗어나지 않아야 한다.

---

## 접근 방식

모든 위치에서 파리채를 내리쳐 보고 최대값을 구하는 완전 탐색 문제다. 델타 탐색이 아니라 단순 4중 for문으로 해결된다.

바깥 이중 for문은 파리채의 시작 좌표(i, j)를 정하고, 안쪽 이중 for문은 그 좌표를 기준으로 M x M 범위의 파리를 합산한다. 파리채가 배열 밖으로 나가면 안 되므로 시작 좌표의 범위는 `N - M + 1`까지로 제한된다.

> **강사님 주의**: 문제를 보고 델타 탐색을 해야 하나 고민할 수 있지만, 이 문제는 단순 for문 순회가 핵심이다. 배우는 알고리즘이 많아질수록 쉬운 문제를 어렵게 풀려는 실수가 생긴다. 문제가 요구하는 것을 정확히 파악하라.

---

## 풀이

```python
T = int(input())
for tc in range(1, T + 1):
    N, M = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(N)]

    kill_flies = 0

    for i in range(N - M + 1):       # 파리채 시작 행 (범위 확보)
        for j in range(N - M + 1):   # 파리채 시작 열
            temp_sum = 0

            for m in range(M):       # 파리채 세로 이동
                for n in range(M):   # 파리채 가로 이동
                    temp_sum += grid[i + m][j + n]

            kill_flies = max(kill_flies, temp_sum)

    print(f'#{tc} {kill_flies}')
```

바깥 이중 for문에서 `N - M + 1`로 범위를 제한하는 이유는 파리채 크기만큼의 공간을 확보해야 하기 때문이다. N이 5이고 M이 2이면 시작 좌표는 0~3(= 5 - 2 + 1 = 4, range(4))까지만 가능하다.

`temp_sum`의 위치가 중요한데, i와 j가 바뀔 때마다 0으로 초기화해야 하므로 안쪽 이중 for문 직전에 선언한다. `kill_flies`는 전체 최대값이므로 바깥 이중 for문 바깥에 선언한다.

---

## 핵심 패턴

### 변수 초기화 위치

중첩 for문에서 누적 변수를 어디에 선언하느냐에 따라 의미가 달라진다. temp_sum처럼 "현재 시작점 기준 합"은 시작점이 바뀔 때 초기화해야 하고, kill_flies처럼 "전체 최대값"은 모든 순회를 아우르는 바깥에 선언해야 한다.

### max()를 활용한 최대값 갱신

```python
# if문으로 갱신
if temp_sum > kill_flies:
    kill_flies = temp_sum

# max()로 한 줄 갱신 (동일한 동작)
kill_flies = max(kill_flies, temp_sum)
```

> **강사님 팁**: 리스트에 append 후 max를 구하는 방식은 비효율적이다. 정수 변수에 누적하고 max()로 갱신하는 습관을 들이자.

## 정리

| 구분 | 핵심 포인트 |
|------|-------------|
| 범위 제한 | 시작 좌표는 N - M + 1까지. 파리채 크기만큼 공간 확보 필요 |
| 4중 for문 | 바깥 2중(시작점 탐색) + 안쪽 2중(파리채 범위 합산) |
| 변수 위치 | temp_sum은 시작점마다 초기화, kill_flies는 전체 최대값 |
| 갱신 패턴 | max(기존값, 새값)으로 최대값을 한 줄로 갱신 |
