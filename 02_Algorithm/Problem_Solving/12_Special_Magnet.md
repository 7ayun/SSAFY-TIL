## 문제 요약

4개의 자석(톱니바퀴)이 일렬로 배치되어 있고, 각 자석은 8개의 날을 가진다. 각 날은 N극(0) 또는 S극(1)이다. 특정 자석을 한 칸 회전시킬 때, 인접한 자석과 맞닿는 날의 극이 서로 **다르면** 인접 자석이 **반대 방향**으로 회전한다. 이 연쇄 반응이 전파된 뒤, 모든 회전이 끝나면 각 자석의 12시 방향(인덱스 0)이 S극이면 점수를 부여한다(1번: 1점, 2번: 2점, 3번: 4점, 4번: 8점).

---

## 접근 방식

이 문제는 알고리즘보다 **시뮬레이션 구현**이 핵심이다.

**회전 전에 연쇄 반응을 먼저 판정해야 한다.** 회전을 하나씩 적용하면서 판정하면 이미 회전된 상태의 극으로 비교하게 되어 결과가 달라진다. 먼저 모든 자석의 회전 여부와 방향을 결정한 뒤, 한꺼번에 회전을 적용한다.

**인접 날의 인덱스:** 오른쪽으로 맞닿는 날은 인덱스 2, 왼쪽으로 맞닿는 날은 인덱스 6이다. 이 인덱스를 틀리면 전체 결과가 달라지므로 반드시 확인해야 한다.

**deque의 rotate:** `deque.rotate(1)`은 시계 방향, `deque.rotate(-1)`은 반시계 방향 회전과 같다.

**방향 전파:** 인접 자석은 항상 **반대 방향**으로 회전한다. 현재 자석이 시계 방향이면 인접 자석은 반시계, 그 다음 인접은 다시 시계 방향이 된다.

**연쇄 반응 전파:** 회전 명령을 받은 자석을 기준으로 왼쪽·오른쪽으로 각각 전파한다. 인접 극이 다르면 반대 방향 회전 예약, 같으면 전파가 멈춘다.

**구현 순서:** (1) 회전 대상 확인 → (2) 왼쪽 전파 → (3) 오른쪽 전파 → (4) 한꺼번에 회전 적용. K번 반복 후 점수 계산.

> **강사님 팁**: 이 문제는 톱니바퀴를 회전하기 전에 "누가 회전할지"를 먼저 다 정해놓고, 그 다음에 한꺼번에 회전시키는 게 핵심이다.

## 풀이

```python
from collections import deque

def solve():
    K = int(input())
    magnets = []
    for _ in range(4):
        magnets.append(deque(map(int, input().split())))

    for _ in range(K):
        num, direction = map(int, input().split())
        num -= 1

        rotations = [0] * 4
        rotations[num] = direction

        for i in range(num, 0, -1):
            if magnets[i][6] != magnets[i - 1][2]:
                rotations[i - 1] = -rotations[i]
            else:
                break

        for i in range(num, 3):
            if magnets[i][2] != magnets[i + 1][6]:
                rotations[i + 1] = -rotations[i]
            else:
                break

        for i in range(4):
            if rotations[i] != 0:
                magnets[i].rotate(rotations[i])

    score = 0
    for i in range(4):
        if magnets[i][0] == 1:
            score += (1 << i)

    return score

T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} {solve()}')
```

## 핵심 패턴

```
1. 상태 저장 (자석 4개 × 날 8개)
2. 명령 처리 (회전 K번)
   ├ 연쇄 반응 판정 (회전 전에 먼저)
   ├ 회전 적용 (한꺼번에)
   └ 반복
3. 결과 계산 (12시 방향 극 확인)
```

| 주의 사항 | 설명 |
|----------|------|
| 판정 먼저, 회전 나중 | 회전하면서 판정하면 이미 바뀐 극으로 비교하게 됨 |
| 전파 중단 조건 | 맞닿는 극이 같으면 그 너머 자석도 회전하지 않음 |
| deque.rotate | 양수: 시계, 음수: 반시계 |
