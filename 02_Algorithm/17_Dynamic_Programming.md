## 1. DP 개요

### 1-1. 개념

DP(Dynamic Programming, 동적 계획법)는 큰 문제를 작은 부분 문제로 나누되, **이전에 계산한 결과를 저장하고 재활용**하여 중복 계산을 없애는 문제 해결 기법이다.
핵심은 알고리즘보다 **점화식**에 있다 — 점화식만 구하면 코드는 그 수식을 그대로 옮기면 된다.

> **강사님 강조**: DP를 잘 풀려면 결국 많은 문제를 풀어보는 수밖에 없다. 점화식을 구하는게 DP의 본질이고, 코드 구현보다 점화식 도출이 훨씬 어렵다.

### 1-2. 탐욕 / 분할 정복 / DP 비교

세 기법 모두 최적 부분 구조(작은 문제의 해로 큰 문제의 해를 만드는 구조)를 가지지만, 부분 문제를 다루는 방식이 다르다.

| 기법 | 부분 문제 관계 | 핵심 특징 |
|------|--------------|---------|
| 탐욕 알고리즘 | 독립적 | 현재 최적 선택 = 전체 최적 |
| 분할 정복 | 독립적 | 나눈 문제를 각각 별도로 해결 |
| DP | 중복 (연관) | 이전에 구한 답을 저장해 재사용 |

> **강사님 강조**: 분할 정복은 나눈 문제들이 서로 영향을 주지 않는다. DP는 나눈 문제들이 서로 연결되어 있고, 한번 구한 해를 다른 부분에서도 재활용한다. 이 차이가 핵심이다.

## 2. 탑다운 — 메모이제이션

### 2-1. 개념

재귀 호출로 큰 문제에서 작은 문제로 내려가면서, 한번 계산한 값을 딕셔너리(캐시)에 저장해두고 재사용하는 방식이다.
재귀 깊이가 깊으면 콜 스택 오버플로우가 발생할 수 있다는 단점이 있다.

> **강사님 팁**: 메모이제이션은 캐시와 같은 원리다. 피보나치를 순수 재귀로 구현하면 같은 값을 수십 번 중복 계산하지만, 메모이제이션을 쓰면 O(N)으로 줄어든다.

### 2-2. 구현 — 피보나치 (탑다운)

```python
def fib_memo(n, memo={}):
    if n in memo:           # 이미 계산한 값이면 바로 반환
        return memo[n]
    if n <= 1:
        return n
    memo[n] = fib_memo(n - 1, memo) + fib_memo(n - 2, memo)
    return memo[n]

print(fib_memo(10))  # 55
```

## 3. 바텀업 — 타블레이션

### 3-1. 개념

가장 작은 문제부터 순서대로 해를 구하면서 테이블을 채워 올라가는 방식이다.
재귀 함수 호출 없이 반복문으로 구현하므로 속도가 더 빠르고 스택 오버플로우 위험이 없다.

> **강사님 강조**: 타블레이션이 메모이제이션보다 더 DP답다고 볼 수 있다. 점화식만 알면 그냥 반복문으로 테이블을 채우면 끝이기 때문이다. 일반적으로 타블레이션 방식으로 더 많이 풀게 된다.

### 3-2. 구현 — 피보나치 (바텀업)

```python
def fib_tab(n):
    if n <= 1:
        return n
    dp = [0] * (n + 1)
    dp[0], dp[1] = 0, 1
    for i in range(2, n + 1):   # 작은 문제부터 위로 채워 올라감
        dp[i] = dp[i - 1] + dp[i - 2]  # 점화식 그대로 코드화
    return dp[n]

print(fib_tab(10))  # 55
```

## 4. 이항 계수 — 파스칼의 삼각형

### 4-1. 개념

`(x + y)^n`을 전개했을 때 각 항의 계수를 이항 계수라 하며, 파스칼의 삼각형 구조로 나타낼 수 있다.
핵심 규칙: 양 끝은 항상 1이고, 내부 값은 바로 위 두 값의 합이다.

점화식: `C(n, k) = C(n-1, k-1) + C(n-1, k)` (단, k = 0 또는 k = n이면 1)

> **강사님 강조**: 공식을 외울 필요 없다. 파스칼의 삼각형에서 규칙을 직접 발견하고 그걸 점화식으로 만드는 과정이 DP의 핵심이다.

### 4-2. 구현 — 이항 계수 (바텀업)

```python
def binomial(n, k):
    dp = [[0] * (k + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        for j in range(min(i, k) + 1):
            if j == 0 or j == i:    # 양 끝은 항상 1
                dp[i][j] = 1
            else:
                dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j]
    return dp[n][k]

print(binomial(5, 2))  # 10
```

## 5. 동전 거스름돈

### 5-1. 개념

특정 금액을 최소 개수의 동전으로 거슬러 주는 문제다.
동전 단위가 배수 관계가 아니면 탐욕 알고리즘으로 풀 수 없어 DP가 필요하다 (예: 1, 4, 6원으로 8원 거슬러주기).

아이디어: 1원부터 n원까지 거슬러 주는 최소 개수를 하나씩 모두 구한다.
- `dp[i]` = i원을 거슬러 줄 때 필요한 최소 동전 개수
- 점화식: `dp[i] = min(dp[i - coin] + 1)` (coin ≤ i인 모든 동전에 대해)

> **강사님 강조**: 동전 거스름돈이 DP 진짜 시작이다. 각 금액의 최적해를 구할 때 이전에 구해 놓은 더 작은 금액의 최적해를 그대로 재활용하는 구조다.

### 5-2. 구현

```python
def coin_change(coins, amount):
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0                          # 0원 거슬러줄 때 필요한 동전: 0개
    for i in range(1, amount + 1):
        for coin in coins:
            if coin <= i:              # 현재 금액 이하의 동전만 고려
                dp[i] = min(dp[i], dp[i - coin] + 1)
    return dp[amount] if dp[amount] != float('inf') else -1

print(coin_change([1, 4, 6], 8))   # 2  (4원 + 4원)
```

## 6. 냅색 (Knapsack)

### 6-1. 개념

무게 제한이 있는 배낭에 물건들을 골라 담을 때 **최대 가치**를 구하는 문제다.
물건은 쪼갤 수 없고 하나씩만 존재한다(0/1 냅색).

2차원 DP 테이블 구성:
* `dp[i][w]` = 물건 1~i번까지만 고려하고, 배낭 용량이 w일 때 담을 수 있는 최대 가치
* 물건 i를 **담지 않는 경우**: `dp[i-1][w]`
* 물건 i를 **담는 경우** (wi ≤ w일 때): `dp[i-1][w - wi] + vi`
* 점화식: `dp[i][w] = max(dp[i-1][w], dp[i-1][w - wi] + vi)`

> **강사님 강조**: 냅색을 풀 줄 알면 DP를 좀 쳤다고 할 수 있다. 거스름돈과 구조는 비슷하지만 2차원 테이블로 확장되어 더 복잡하다.

### 6-2. 구현

```python
def knapsack(W, weights, values, n):
    dp = [[0] * (W + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for w in range(W + 1):
            # 물건 i를 담지 않는 경우
            dp[i][w] = dp[i - 1][w]
            # 물건 i를 담을 수 있는 경우 (더 큰 가치면 갱신)
            if weights[i - 1] <= w:
                dp[i][w] = max(dp[i][w],
                               dp[i - 1][w - weights[i - 1]] + values[i - 1])

    return dp[n][W]

weights = [2, 3, 4, 5]
values  = [3, 4, 5, 6]
W = 8
print(knapsack(W, weights, values, len(weights)))  # 10
```

## 정리

| 구분 | 핵심 포인트 |
|------|-----------|
| DP 조건 | 최적 부분 구조 + 중복 부분 문제 |
| vs 분할 정복 | 분할 정복은 독립적, DP는 부분 문제가 연관·중복됨 |
| 탑다운 | 재귀 + 딕셔너리 캐시, 스택 오버플로우 주의 |
| 바텀업 | 반복문으로 테이블 채우기, 더 빠르고 일반적으로 선호 |
| 핵심 절차 | 점화식 도출 → 초기값 설정 → 테이블 채우기 → 결과 반환 |
| 이항 계수 | 파스칼 삼각형, `C(n,k) = C(n-1,k-1) + C(n-1,k)` |
| 동전 거스름돈 | 1원~n원 최적해 순차 계산, 탐욕 불가 케이스에 사용 |
| 냅색 | 2차원 테이블, 담기/안담기 두 선택지 중 최댓값 |
