# 파이썬 수업 핵심 정리

---

## 1. 프로그래밍이란?

### 개념

* **프로그래밍**이란 사람이 컴퓨터가 이해할 수 있도록 **명령어를 순서대로 작성하는 과정**입니다.
* 컴퓨터는 우리가 작성한 명령을 **그대로, 정확하게, 순서대로 실행**합니다.

### 핵심 포인트

* 컴퓨터는 **의도를 해석하지 않음** → 작성한 명령을 **문자 그대로 수행**
* 명확하고 정확한 지시가 중요

---

## 2. 프로그래밍 언어

### 고수준 언어 vs 저수준 언어

| 구분     | 설명                              |
| ------ | ------------------------------- |
| 고수준 언어 | 사람이 이해하기 쉬운 언어 (Python, Java 등) |
| 저수준 언어 | 컴퓨터가 직접 이해하는 언어 (기계어: 0과 1)     |

### 파이썬 특징

* 문법이 **간결하고 직관적**
* 초보자가 배우기 쉬움
* 커뮤니티가 크고 자료가 풍부
* 알고리즘, 데이터 분석, AI, 웹 등 **활용 분야 매우 넓음**

---

## 3. 인터프리터(Interpreter)

### 역할

* **사람이 작성한 파이썬 코드 → 컴퓨터가 이해할 수 있는 언어로 번역**

### 구조

```
사람 → 파이썬 코드 → 인터프리터 → 기계어 → 컴퓨터 실행
```

---

## 4. 개발 환경 구성 흐름

### 실행 과정

1. VS Code에서 `.py` 파일 작성
2. 터미널 실행
3. `python 파일명.py` 입력
4. 파이썬 인터프리터가 코드 실행

### 터미널 단축키

```
Ctrl + `
```

---

## 5. 표현식(Expression)

### 개념

* **값으로 평가될 수 있는 코드 조각**

### 예시

```
3 + 5  → 8
1 * 2  → 2
```

---

## 6. 데이터 타입 (Data Type)

### 주요 타입

| 타입    | 예시             |
| ----- | -------------- |
| int   | 10, 25         |
| float | 3.14, 2.5      |
| str   | "안녕", "python" |

### 중요성

* 연산 결과 정확성
* 오류 방지
* 가독성 향상

---

## 7. 연산자

| 종류   | 기호 |
| ---- | -- |
| 덧셈   | +  |
| 뺄셈   | -  |
| 곱셈   | *  |
| 나눗셈  | /  |
| 몫    | // |
| 나머지  | %  |
| 거듭제곱 | ** |

### 우선순위

```
** → 부호 → * / // % → + -
```

---

## 8. 변수 (Variable)

### 개념

* **데이터를 저장하기 위한 이름(별명)**

### 예시

```
temp = 36.5
print(temp)
```

### 좋은 변수명 규칙

* 의미 있는 이름 사용
* a, b, x ❌
* temperature, total, count ⭕

---

## 9. 할당 & 재할당

```
a = 10
print(a)

# 재할당
a = 20
print(a)
```

---

## 10. 메모리 구조

* 변수는 **값 자체가 아니라 메모리 주소를 참조**
* `id()` 함수 → 실제 메모리 주소 확인 가능

```
x = 10
print(id(x))
```

---

# 오늘의 핵심 요약

1. 프로그래밍은 **컴퓨터가 이해할 수 있도록 명령어를 작성하는 과정**이다.
2. 파이썬은 **사람이 이해하기 쉬운 고수준 언어**이다.
3. 인터프리터는 **파이썬 코드를 컴퓨터가 이해할 수 있도록 번역**한다.
4. 표현식은 **값으로 평가될 수 있는 코드 조각**이다.
5. 주요 데이터 타입은 **int, float, str** 이다.
6. 변수는 **데이터를 저장하기 위한 이름(별명)**이다.
7. 할당은 **값을 처음 저장**, 재할당은 **값을 다시 덮어쓰는 것**이다.
8. 연산자는 **우선순위에 따라 계산 순서가 결정**된다.
