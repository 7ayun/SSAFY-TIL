## 💡 주요 개념 정리

### 1. 파이썬 실행 원리
* **고수준 언어:** 인간 친화적 언어 및 기계어 번역 과정 필수
* **인터프리터:** 소스 코드 한 줄 단위 실시간 읽기 및 실행
* **설계 철학:** 간결한 문법 지향 및 쉬운 프로그래밍 환경 제공

### 2. 변수와 메모리 구조
* **객체 참조:** 값 자체가 아닌 저장된 **객체의 메모리 주소** 저장
* **식별자 규격:** 영문/숫자/_ 조합 필수, 숫자 시작 및 예약어 사용 금지
* **재할당 동작:** 신규 값 할당 시 기존 연결 해제 및 새 주소 매핑

### 3. 데이터 타입 분류
| 분류 | 타입명 | 주요 특징 |
| :--- | :--- | :--- |
| **Numeric** | `int`, `float` | 정수 및 실수 표현 (유한 정밀도에 따른 오차 유의) |
| **Sequence** | `str`, `list`, `tuple` | 데이터 순서 유지 및 인덱싱/슬라이싱 지원 |
| **Non-Seq** | `dict`, `set` | 순서 무관 및 고유 키(Key) 혹은 집합 기반 관리 |
| **Other** | `bool`, `None` | 참/거짓 논리값 및 의도적인 빈 값 명시 |

## 💻 기능 구현 및 코드 실습

### 1. 부동 소수점 오차 해결 (Decimal)
이진수 연산 한계 기인 미세 오차 방지 및 정밀도 유지 기법

```python
# 일반 연산 시 발생하는 오차 확인 (예: 1.2 - 0.2)
print(3.2 - 3.1)  # 0.10000000000000009

from decimal import Decimal

# Decimal 객체 생성 시 숫자를 문자열로 전달하여 정확한 계산 수행
num1 = Decimal('3.2')
num2 = Decimal('3.1')
print(num1 - num2)  # 0.1
```

### 2. 시퀀스 조작 (Indexing & Slicing)
인덱스 기반 데이터 접근 및 슬라이싱을 통한 부분 추출 기능

```python
text = "hello"
my_list = [10, 20, 30, 40, 50]

# 특정 위치 데이터 직접 접근 (0번 인덱스 시작)
print(text[1])      # 'e'
print(my_list[-1])  # 50 (역방향 접근)

# 데이터 슬라이싱 [시작:끝(미포함):간격]
print(text[1:4])    # 'ell'
print(my_list[::-1]) # [50, 40, 30, 20, 10] (전체 반전)

# 가변성(Mutable) 및 불변성(Immutable) 확인
my_list[0] = 100    # 수정 성공 (List)
# text[0] = 'H'     # 수정 실패 (String: TypeError 발생)
```

### 3. 논리 연산 및 단축 평가 (Short-circuit Evaluation)
논리 확정 시점의 피연산자 즉시 반환을 통한 연산 최적화 구조

```python
# AND 연산: 선행 조건 거짓 시 즉시 해당 값 반환
print(0 and "Hello")    # 0

# OR 연산: 선행 조건 참 시 즉시 해당 값 반환
print("Apple" or "Banana")  # "Apple"
print("" or "Default")      # "Default" (빈 문자열 False 판정)
```
