## 💻 기능 구현 및 코드 실습

### 1. 부동 소수점 오차 해결 (Decimal)
이진수 연산 한계로 인한 미세 오차 방지 목적.

```python
# 일반 연산 시 발생하는 오차 확인
print(3.2 - 3.1)  # 0.10000000000000009

from decimal import Decimal

# Decimal 객체 생성 시 숫자를 문자열로 전달 (정밀도 유지)
num1 = Decimal('3.2')
num2 = Decimal('3.1')
print(num1 - num2)  # 0.1 (정확한 계산값 반환)
```

### 2. 시퀀스 조작 (Indexing & Slicing)
데이터 인덱스를 통한 부분 추출 및 역순 정렬 기능.

```python
text = "hello"
my_list = [10, 20, 30, 40, 50]

# 특정 위치 데이터 접근 (0번부터 시작)
print(text[1])      # 'e'
print(my_list[-1])  # 50 (역방향 접근)

# 데이터 슬라이싱 [시작:끝:간격]
print(text[1:4])    # 'ell' (인덱스 1, 2, 3 포함)
print(my_list[::-1]) # [50, 40, 30, 20, 10] (전체 뒤집기)

# 수정 가능 여부 확인
my_list[0] = 100    # 가변(Mutable) 객체: 수정 성공
# text[0] = 'H'     # 불변(Immutable) 객체: 수정 시 에러 발생
```

### 3. 논리 연산 및 단축 평가 (Short-circuit Evaluation)
논리 확정 시점의 피연산자를 즉시 반환하여 연산 최적화.

```python
# AND 연산: 선행 조건 False 시 즉시 해당 값 반환
print(0 and "Hello")    # 0 (뒤 조건 평가 생략)

# OR 연산: 선행 조건 True 시 즉시 해당 값 반환
print("Apple" or "Banana")  # "Apple" (뒤 조건 무시)
print("" or "Default")      # "Default" (빈 문자열 False 판정)
```
