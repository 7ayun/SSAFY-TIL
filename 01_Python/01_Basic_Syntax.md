## 1. 프로그래밍이란

프로그램은 명령어들의 집합이다. 컴퓨터는 주어진 명령을 그대로, 순서대로 실행하며 스스로 판단하지 않는다. 명령이 모호하면 의도와 다른 결과가 발생한다.

```python
# "우유 1개 사와. 달걀 있으면 6개 사와."
# 사람: 우유 1개, 달걀 6개
# 컴퓨터: 달걀이 있으니까 → 우유 6개 구매
# → 명령은 명확해야 한다
```

## 2. 고수준 vs 저수준 언어

| 구분 | 특징 | 예시 |
|------|------|------|
| 고수준(High-level) | 사람이 읽기 쉬운 언어 | Python, Java, JavaScript |
| 저수준(Low-level) | 컴퓨터가 직접 이해하는 언어 | 기계어(0과 1), 어셈블리어 |

고수준 언어는 컴퓨터가 직접 이해할 수 없으므로 번역 과정이 필요하다. Python에서 이 번역을 담당하는 것이 인터프리터(Interpreter)로, 코드를 한 줄씩 실시간으로 통역하는 역할을 한다.

## 3. Python 소개

Python은 귀도 반 로썸(Guido van Rossum)이 크리스마스 취미 프로젝트로 만든 언어다. "프로그래밍은 쉬워야 한다"는 설계 철학을 가지고 있으며, 세계 최대 규모의 커뮤니티와 풍부한 라이브러리가 강점이다.

```python
# 타입 선언 불필요 — 핵심 로직에 집중 가능

name = "hello"  # C언어: char name[] = "hello";

# 알고리즘 구현에 유리한 내장 라이브러리
from itertools import combinations, permutations
```

> **Tip:** SSAFY 시험 기준 Python 3.11을 사용하며, A형까지 Python이 필수다. 기업 코딩테스트에서도 Python이 가장 유리한 선택지다.

## 4. Python 실행 원리와 환경 변수

Python 파일의 확장자는 `.py`이며, 터미널에서 `python test.py` 명령으로 실행한다.

```bash
# 터미널 열기: Ctrl + ` (백틱, 숫자 1 왼쪽)
# 실행 명령
python test.py
```

실행 시 내부 동작 과정은 다음과 같다.

1. OS가 PATH 환경 변수에서 `python` 실행 파일 위치를 탐색한다
2. 해당 경로의 `python.exe`가 인터프리터로서 가동된다
3. `.py` 파일을 번역하고 실행한다

PATH 환경 변수는 Python 설치 시 "Add to PATH" 체크로 자동 등록된다. 체크하지 않으면 `python` 명령어를 인식하지 못하며, 이 경우 윈도우키 → "시스템 환경 변수 편집" → PATH 항목에 수동으로 경로를 추가해야 한다.

> **Tip:** `where python` 명령으로 현재 등록된 Python 실행 파일 경로를 확인할 수 있다.

## 5. 변수와 메모리

### 5-1. 변수의 본질

변수는 데이터를 저장하는 메모리 공간의 별명(alias)이다. 파이썬의 변수는 다른 언어와 달리 값 자체가 아닌, 값이 저장된 메모리 주소를 저장한다. 이 구조 덕분에 타입 선언 없이 어떤 크기의 데이터든 담을 수 있다.

```python
degree = 36.5       # degree에는 36.5가 아닌, 36.5가 저장된 주소가 들어감
print(id(degree))   # 실제 메모리 주소 확인 → 140234982651 같은 정수 출력
```

> **Tip:** `del` 명령은 값 자체를 삭제하는 게 아니라 주소(접근 경로)만 제거한다. 데이터 복구 업체에 빨리 가면 복원이 되는 이유도 이 원리 — 메모리의 실제 값은 남아있지만 접근 경로만 사라진 것이다. 시간이 지나면 다른 데이터가 덮어씌워져 복구 불가능해진다.

### 5-2. 할당과 재할당

변수에 새 값을 할당하면 기존 값을 덮어쓰는 것이 아니라, 새 메모리 공간에 값을 만들고 변수가 가리키는 주소를 바꾼다.

```python
number = 10          # ① 10을 메모리에 저장 → 주소 부여 → number에 주소 저장
double = 2 * number  # ② 20을 새 메모리에 저장 → double에 해당 주소 저장
number = 5           # ③ 5를 새 메모리에 저장 → number의 주소 변경
print(double)        # → 20 (double은 여전히 20의 주소를 가리킴)
```

### 5-3. 변수명 규칙

변수명은 영문, 숫자, 언더스코어 조합으로 구성하며 숫자로 시작할 수 없다.

```python
# 좋은 예
user_name = "홍길동"
total_count = 100

# 나쁜 예
a = "홍길동"       # 의미 불명
x = 100            # 무엇을 세는지 알 수 없음
1st_place = "김"   # SyntaxError — 숫자로 시작 불가
```

> **Tip:** `a`, `b`, `x` 같은 의미 없는 변수명은 피해야 한다. 코드를 다시 볼 때 무엇을 저장한 변수인지 알 수 없게 된다.

## 6. 데이터 타입

### 6-1. int (정수형)

정수를 표현하는 자료형이다. 10진수 외에 2진수, 8진수, 16진수 표기를 지원한다.

```python
a = 10       # 10진수 (기본)
b = 0b1010   # 2진수 (Binary) → 10
c = 0o12     # 8진수 (Octal)  → 10
d = 0xA      # 16진수 (Hex)   → 10

print(type(a))  # → <class 'int'>

# 16진수 자릿수: 0~9 이후 A(10), B(11), C(12), D(13), E(14), F(15)
print(hex(255))  # → 0xff
```

### 6-2. float (실수형)

소수점을 포함하는 수를 표현한다. 컴퓨터는 소수를 2진수로 변환해 저장하는데, 무한 소수를 유한한 비트로 표현하므로 미세한 오차가 발생한다.

```python
x = 3.14
y = 3.14e-2   # 지수 표현: 3.14 × 10⁻² = 0.0314

# 부동소수점 에러
print(3.2 - 3.1 == 1.2 - 1.1)  # → False
# 이유: 무한 소수를 약 16~17자리에서 잘라 저장 → 미세한 오차 발생

# 해결: decimal 모듈 사용
from decimal import Decimal
print(Decimal('3.2') - Decimal('3.1'))  # → 0.1 (정확)
```

> **주의:** `float` 비교 시 `==`을 직접 사용하면 안 된다. `abs(a - b) < 1e-9` 또는 `decimal` 모듈을 사용해야 한다. `decimal`은 정밀하지만 메모리와 속도 측면에서 트레이드오프가 있다.

### 6-3. str (문자열) — 불변(Immutable)

문자들의 순서 있는 시퀀스로, 한 번 생성되면 내부 값을 수정할 수 없다.

```python
# 선언 — 작은따옴표, 큰따옴표 모두 가능 (팀 내 통일 권장)
s1 = "Hello"
s2 = 'Hello'

# 중첩 따옴표
s3 = "I'm a student"     # 내부 ' → 외부 " 사용
s4 = 'He said "Hi"'      # 내부 " → 외부 ' 사용

# Escape Sequence
s5 = "Hello\nWorld"       # \n: 줄바꿈
s6 = "Tab\there"          # \t: 탭
s7 = "Back\\slash"        # \\: 백슬래시 출력

# f-string — 문자열 내 변수 삽입 (Python 3.6+)
name = "Jaden"
count = 13
print(f"안녕하세요 {name}님, 접속 횟수: {count}")
```

인덱싱과 슬라이싱으로 문자열의 특정 위치에 접근할 수 있다. 인덱스는 0부터 시작한다.

```python
word = "Hello"
print(word[0])     # → H (첫 번째)
print(word[-1])    # → o (마지막)

# 슬라이싱: [시작:끝:간격] — 시작 포함, 끝 미포함
print(word[1:4])   # → ell
print(word[::2])   # → Hlo (2칸 간격)
print(word[::-1])  # → olleH (역순)

# 불변 특성 — 인덱스로 부분 수정 불가
word[0] = 'h'      # → TypeError!
word = "hello"     # 전체 재할당은 가능 (새 객체 생성)
```

### 6-4. list (리스트) — 가변(Mutable)

여러 개의 값을 순서대로 저장하는 가변 시퀀스다. 다양한 자료형을 혼합하여 저장할 수 있다.

```python
my_list = [1, "Hello", 3.14, True, [4, 5]]

# 인덱싱, 슬라이싱은 str과 동일
print(my_list[0])      # → 1
print(my_list[-1][1])  # → 5 (중첩 리스트 접근)

# 가변 특성 — 인덱스로 값 수정 가능
my_list[0] = 100       # → [100, "Hello", 3.14, True, [4, 5]]
```

리스트 내부는 실제 값이 아닌 각 원소의 메모리 주소를 저장한다. 따라서 단순 대입으로 복사하면 같은 객체를 공유하게 된다.

```python
c = [7, 8, 9]
d = c             # d는 c와 같은 객체를 가리킴 (주소 복사)
c[0] = 10
print(d)          # → [10, 8, 9] (d도 변경됨!)
```

> **주의:** 리스트의 단순 대입 복사(`d = c`)는 알고리즘에서 가장 흔한 함정이다. 의도치 않은 값 변경을 피하려면 깊은 복사(deep copy)가 필요하다.

### 6-5. tuple (튜플) — 불변(Immutable)

리스트와 유사하지만 한 번 생성되면 수정할 수 없다. 소괄호가 아닌 쉼표가 튜플을 만드는 핵심이다.

```python
t1 = (1, 2, 3)
t2 = 1, 2, 3      # 소괄호 없이도 튜플 생성
t3 = (1,)          # 단일 원소: 반드시 후행 쉼마 필요
t4 = (1)           # → int 타입! (튜플 아님)
t5 = ()            # 빈 튜플: 소괄호 필수

t1[0] = 100        # → TypeError: 수정 불가
```

튜플의 대표적인 활용은 다중 할당과 값 교환이다.

```python
# 다중 할당
x, y = 10, 20

# 값 교환 — 내부적으로 튜플 처리 (temp 변수 불필요)
x, y = y, x       # C언어는 temp 변수가 필요하지만 파이썬은 불필요
```

> **Tip:** 변경되면 안 되는 데이터(RGB 색상, 좌표 등)에는 리스트 대신 튜플을 사용한다.

### 6-6. range (정수 시퀀스 생성기) — 불변(Immutable)

`range(시작, 끝, 간격)` 형태로 정수 시퀀스를 생성한다. 슬라이싱과 마찬가지로 시작은 포함, 끝은 미포함이다.

```python
range(5)          # → 0, 1, 2, 3, 4
range(1, 10)      # → 1 ~ 9
range(5, 0, -1)   # → 5, 4, 3, 2, 1 (역순)
range(1, 5, -1)   # → 빈 시퀀스 (방향 불일치)

# for문과 연계
for i in range(1, 10):
    print(i)      # 1부터 9까지 출력
```

> **Tip:** for문과 range만 잘 다뤄도 IM 등급, A형 통과가 가능하다.

### 6-7. dict (딕셔너리) — 가변(Mutable)

키(Key)-값(Value) 쌍으로 데이터를 저장하는 구조다. 키는 변경 불가능한 타입만 사용할 수 있고, 키 중복은 허용되지 않는다.

```python
my_dict = {
    "apple": 12,
    "list": [1, 2, 3],
    "hello": "안녕",
}

# 접근
print(my_dict["apple"])   # → 12

# 추가 / 수정
my_dict["banana"] = 50    # 새 키-값 추가
my_dict["apple"] = 100    # 기존 값 수정
```

> **주의:** 존재하지 않는 키에 접근하면 `KeyError`가 발생한다. 리스트는 가변이므로 키로 사용할 수 없다.

딕셔너리의 핵심 장점은 속도다. 리스트에서 특정 값의 포함 여부를 확인하려면 최대 N번 순회해야 하지만(O(N)), 딕셔너리는 해시값으로 즉시 접근할 수 있다(O(1)).

### 6-8. set (세트) — 가변(Mutable)

수학의 집합과 동일한 구조로, 순서가 없고 중복을 허용하지 않는다.

```python
my_set = {1, 2, 3, 3, 3}
print(my_set)   # → {1, 2, 3} (중복 자동 제거)

# 집합 연산
a = {1, 2, 3}
b = {3, 6, 9}
print(a | b)    # 합집합 → {1, 2, 3, 6, 9}
print(a - b)    # 차집합 → {1, 2}
print(a & b)    # 교집합 → {3}

# 중복 제거 활용
numbers = [1, 2, 2, 3, 3, 3]
unique = set(numbers)   # → {1, 2, 3}
```

> **주의:** 세트는 출력 순서가 보장되지 않는다. 삽입 순서와 일치하는 것처럼 보일 수 있지만 신뢰하면 안 된다.

### 6-9. None 타입

의도적으로 "값이 없음"을 표현하는 타입이다. 버그가 아닌, 아직 결정되지 않은 상태를 나타낸다.

```python
baby_name = None       # 아직 이름 미결정 (의도적)
baby_name = "아린"     # 값 결정 후 할당

# 문자열 "None"과 혼동 주의
print(type(None))       # → <class 'NoneType'>
print(type("None"))     # → <class 'str'>
```

### 6-10. bool (불린 타입)과 Truthy/Falsy

참(`True`)과 거짓(`False`) 두 값만 존재하는 타입이다. 파이썬에서는 다양한 값이 조건문에서 자동으로 True/False로 평가되는데, 이를 Truthy/Falsy라 한다.

```python
# Falsy — False로 평가되는 값들 (빈 것과 0이면 False)
# 0, 0.0, "", [], {}, set(), None, ()

# Truthy — 위 목록 외 모든 값
bool(0)        # → False
bool(1)        # → True
bool(-5)       # → True   ← 음수도 True
bool("")       # → False
bool("0")      # → True   ← 문자열 "0"은 True
bool("False")  # → True   ← 문자열 "False"도 True
bool([])       # → False
bool([0])      # → True   ← 원소가 있으면 True
bool(None)     # → False
```

## 7. 컬렉션 비교

| 자료형 | 가변 | 순서 | 중복 | 표기 |
|--------|------|------|------|------|
| str | 불변 | 있음 | 허용 | `""` `''` |
| list | 가변 | 있음 | 허용 | `[]` |
| tuple | 불변 | 있음 | 허용 | `()` 또는 쉼표 |
| range | 불변 | 있음 | — | `range()` |
| dict | 가변 | 없음 | 키 불가 / 값 허용 | `{key: value}` |
| set | 가변 | 없음 | 불가 | `{}` |

## 8. 불변 vs 가변 메모리 원리

불변 타입은 객체 내부의 값을 직접 수정할 수 없고, 가변 타입은 내부 슬롯의 주소를 교체하는 방식으로 수정이 가능하다.

```python
# 불변(str) — 내부 값 수정 불가
s = "hello"
# s[0] = 'H'  → TypeError
# "hello" 객체 자체가 메모리에 고정 → 변경하려면 새 객체 생성 + 재할당

# 가변(list) — 내부 주소 교체 가능
lst = ["hello", "a", "b"]
lst[0] = "HELLO"   # OK
# "HELLO" 새 객체 생성 → 해당 슬롯의 주소만 교체 → 리스트 자체는 그대로
```

## 9. 타입 변환

### 9-1. 암시적 형변환

파이썬이 데이터 손실 없는 방향으로 자동 처리한다.

```python
3 + 5.0       # → 8.0 (int + float → float)
True + 3      # → 4   (bool → int, True=1)
True + False  # → 1   (1 + 0)

"hello" + 17  # → TypeError (문자열 + 정수는 자동 변환 불가)
```

### 9-2. 명시적 형변환

개발자가 직접 변환 함수를 호출한다.

```python
int("3")        # → 3
int(3.9)        # → 3 (소수점 버림, 반올림 아님)
float("3.14")   # → 3.14
str(17)         # → "17"

"hello" + str(17)  # → "hello17"
```

> **주의:** `int("3.5")`는 `ValueError`가 발생한다. 소수점 문자열을 정수로 바꾸려면 `int(float("3.5"))` 처럼 두 단계를 거쳐야 한다.

> **Tip:** 암시적 형변환에 의존하지 말고 명시적으로 지정하는 것이 안전하다.

## 10. 연산자

### 10-1. 산술 연산자

```python
a, b = 10, 3

a + b     # → 13     덧셈
a - b     # → 7      뺄셈
a * b     # → 30     곱셈
a / b     # → 3.333  나눗셈 (항상 float 결과)
a // b    # → 3      몫 (정수 나눗셈)
a % b     # → 1      나머지
a ** b    # → 1000   거듭제곱
```

### 10-2. 복합 대입 연산자

`a op= b`는 `a = a op b`의 축약 표현이다.

```python
a = 10
a += 5    # a = 15
a -= 4    # a = 11
a *= 2    # a = 22
a //= 2   # a = 11
a **= 3   # a = 1331
```

> **주의:** Python에는 `a++`, `a--` 증감 연산자가 없다. `a += 1`을 사용해야 한다.

### 10-3. 비교 연산자 — `==` vs `is`

`==`은 값(Value)을 비교하고, `is`는 메모리 주소(Identity)를 비교한다.

```python
a = [1, 2, 3]
b = [1, 2, 3]   # a와 같은 값이지만 다른 객체
c = a            # a와 동일한 주소 참조

print(a == b)    # → True  (값 같음)
print(a is b)    # → False (다른 주소)
print(a is c)    # → True  (같은 주소)

print(1 == True)   # → True  (값: 1 = True)
print(1 is True)   # → False (다른 객체)
```

### 10-4. 논리 연산자

```python
True and False   # → False (양쪽 모두 True여야 True)
True or False    # → True  (하나라도 True면 True)
not True         # → False (부정)

# 활용
num = 15
print(num > 10 and num % 2 == 0)  # → False (15는 홀수)
```

### 10-5. 단축 평가 (Short-circuit Evaluation)

파이썬의 `and`/`or`는 True/False 대신 실제 값을 반환한다는 점이 다른 언어와의 핵심 차이다.

```python
# and — False(부정) 만나면 그 값 반환, 모두 True면 마지막 값 반환
print(3 and 5)    # → 5  (3=True → 5까지 확인 → 5 반환)
print(3 and 0)    # → 0  (3=True → 0 확인 → 0 반환)
print(0 and 5)    # → 0  (0=False → 즉시 0 반환, 5 미확인)

# or — True(긍정) 만나면 그 값 반환, 모두 False면 마지막 값 반환
print(5 or 0)     # → 5  (5=True → 즉시 5 반환)
print(0 or 3)     # → 3  (0=False → 3 확인 → 3 반환)
```

> **Tip:** 실무에서 단축 평가를 활용한 코딩은 자제하는 것이 좋다. 다른 언어와 동작 방식이 달라 혼란을 유발하고 가독성이 떨어진다. 단, 시험에서는 출제될 수 있으므로 규칙을 이해해 두어야 한다.

### 10-6. 멤버십 연산자

`in`과 `not in`으로 특정 값의 포함 여부를 확인한다.

```python
word = "Hello"
numbers = [1, 2, 3, 4]

print("H" in word)         # → True
print("Z" in word)         # → False
print(4 not in numbers)    # → False (4가 있으므로 not in은 False)
```

### 10-7. 시퀀스형 연산자

문자열과 리스트에서 `+`는 결합, `*`는 반복을 수행한다.

```python
# 결합
print("길동" + "홍")       # → "길동홍"
print([1, 2] + [3, 4])    # → [1, 2, 3, 4]

# 반복
print("Hi" * 3)           # → "HiHiHi"
print([1, 2] * 3)         # → [1, 2, 1, 2, 1, 2]
```

### 10-8. 연산자 우선순위

지수(`**`) → 음수 부호(`-x`) → 곱셈/나눗셈 → 덧셈/뺄셈 순서로 처리된다.

```python
print(-2 ** 4)     # → -16  (지수 먼저 → 2⁴=16 → 음수 부호 → -16)
print(-(2 ** 4))   # → -16  (동일)
print((-2) ** 4)   # →  16  (괄호로 -2를 먼저 묶음 → (-2)⁴ = 16)
```

> **Tip:** 우선순위를 외우기보다 헷갈리면 괄호를 사용하는 것이 가장 좋은 습관이다. 본인을 위해서뿐 아니라 협업 시 다른 사람이 코드를 읽을 때도 의도가 명확해진다.

## 정리

* 파이썬 변수는 값이 아닌 메모리 주소를 저장한다 — 재할당 시 변수의 주소만 변경
* `float` 비교에 `==`을 직접 쓰면 안 된다 — `decimal` 또는 오차 범위 비교 사용
* `str`, `tuple`은 불변, `list`, `dict`, `set`은 가변 — 불변은 인덱스 수정 불가
* 리스트 단순 대입(`d = c`)은 주소 공유 — 한쪽 변경 시 다른 쪽도 변경됨
* 튜플 단일 원소 선언 시 후행 쉼표 필수 — `(1,)`은 튜플, `(1)`은 int
* `==`은 값 비교, `is`는 주소 비교 — 혼동 금지
* 단축 평가는 True/False가 아닌 실제 값을 반환한다 — 파이썬 고유 동작
* Falsy: `0`, `0.0`, `""`, `[]`, `{}`, `set()`, `None`, `()` — 나머지는 전부 Truthy
* 딕셔너리/세트의 포함 여부 확인은 O(1) — 알고리즘 최적화 핵심
* 연산자 우선순위가 헷갈리면 괄호를 사용한다
