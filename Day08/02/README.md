# Day08-2 - 정렬 학습 정리

> 주제: 1차원 리스트 정렬(버블/선택/삽입/카운팅) + 시간복잡도 + 안정성/적응성/제자리

---

## 1. 강의 핵심 요약
- 정렬은 **이분 탐색(로그 N)**을 쓰기 위한 전제(정렬된 데이터 필요)
- 정렬은 **시간복잡도 감각(N² vs N log N vs N+K)**을 키우는 대표 예시
- 시험에서는 **기본 정렬 구현 + 특징(안정성/적응성/제자리)**가 그대로 출제됨

---

## 2. 개념 구조 정리
- 정렬(Sorting)
  - 왜 필요한가
    - 이분 탐색(log N) 조건
    - 시간복잡도 비교 학습
  - 정렬 평가 기준(시험 단골)
    - 시간복잡도(최악/최선)
    - 안정성(Stable)
    - 적응성(Adaptive)
    - 제자리 정렬(In-place)
  - 정렬 알고리즘
    - 버블 정렬
    - 선택 정렬
    - 삽입 정렬
    - 카운팅 정렬

---

## 3. 핵심 개념 상세 설명

### 3.1 정렬 평가 기준(필수 암기 X, 판정할 줄 알기)

#### (1) 안정성(Stable)
- **같은 값(같은 키)**끼리 정렬 후에도 **상대적 순서가 유지**되면 안정
- 예) (4A, 4B)가 있고 A가 먼저였으면 정렬 후에도 A가 앞이면 Stable

#### (2) 적응성(Adaptive)
- **초기 상태가 이미 정렬/거의 정렬**이면 더 빨라지는가?

#### (3) 제자리 정렬(In-place)
- 큰 추가 메모리 없이 **원본 리스트 내부에서** 교환/이동으로 해결

---

## 4. 정렬별 핵심 정리

### 4.1 버블 정렬(Bubble Sort)
**아이디어**
- 인접한 두 원소 비교 → 필요하면 교환
- 한 패스가 끝나면 **최댓값이 맨 뒤로 고정**

**구현 핵심(감점 포인트)**
- 비교는 `arr[j]`와 `arr[j+1]`
- 내부 반복은 반드시 **끝까지가 아니라 `...-1`까지만** (IndexError 방지)
- 패스가 늘수록 뒤쪽은 고정 → 비교 범위가 줄어듦

**특징**
- 시간복잡도: 최악/평균 `O(N^2)`
- 최선: (교환 없음 체크 넣으면) `O(N)` 가능
- 안정성: O
- 적응성: (교환 여부 체크 넣으면) O
- 제자리: O

---

### 4.2 선택 정렬(Selection Sort)
**아이디어**
- 매 패스마다 **최솟값(또는 최댓값)**을 찾아서 앞쪽 위치와 교환

**특징**
- 시간복잡도: 최악/평균/최선 모두 `O(N^2)`
- 안정성: X (멀리 있는 값과 교환하며 같은 값 순서가 깨질 수 있음)
- 적응성: X
- 제자리: O

---

### 4.3 삽입 정렬(Insertion Sort)
**아이디어**
- 정렬 구간 / 미정렬 구간으로 나눔
- 미정렬에서 하나를 꺼내 **정렬 구간에서 들어갈 위치를 찾을 때까지 뒤로 비교**
- 자리 찾으면 즉시 `break` (이게 성능 핵심)

**특징**
- 최악: `O(N^2)` (역순에 가까우면 많이 이동)
- 최선: `O(N)` (이미 정렬이면 거의 바로 break)
- 안정성: O
- 적응성: O (거의 정렬일수록 매우 빠름)
- 제자리: O

---

### 4.4 카운팅 정렬(Counting Sort)
**아이디어(정수 범위가 작을 때 최강)**
1) `count[value]`에 등장 횟수 세기
2) 안정성을 원하면 `count`를 **누적합(prefix sum)**으로 변환
3) 원본을 **뒤에서부터** 순회하며 결과 배열에 배치
   - 배치 후 `count[value] -= 1`

**왜 뒤에서부터 넣나? (안정성 확보)**
- 같은 값이 여러 개일 때, **원래의 상대 순서**를 지키기 위한 대표 방법

**특징**
- 시간복잡도: `O(N + K)`
  - `N`: 데이터 개수
  - `K`: 값의 범위(보통 max_value+1)
- 안정성: O(누적합 + 뒤에서 배치 방식)
- 적응성: (구조상 의미 작음)
- 제자리: X (결과 배열이 필요)

**언제 쓰나?**
- N은 매우 큰데 K가 작은 경우
  - 예: 점수(0~100), 제한된 등급/카테고리

---

## 5. 실수 & 감점 포인트
- 버블: 내부 루프를 끝까지 돌려서 `j+1` 범위 초과(IndexError)
- 버블: 패스가 늘수록 비교 범위가 줄어드는 이유를 모르면 구현이 흔들림
- 선택: 안정성 X / 적응성 X 를 근거 예시로 설명 못하면 서술형 감점
- 삽입: 자리 찾았는데도 break 안 걸어 불필요 비교/이동 증가
- 카운팅: `count` 크기를 `max_value+1`로 안 잡아 인덱스 오류
- 카운팅: 안정성 확보하려면 **누적합 + 뒤에서 배치 + count 감소**가 세트

---

## 6. 실전 코드 패턴(개념용)

### 6.1 버블 정렬 패턴
- 바깥: 패스
- 안쪽: 인접 비교/교환 (`j+1` 때문에 `...-1` 필수)

### 6.2 선택 정렬 패턴
- 바깥: 현재 고정 위치 i
- 안쪽: i~끝에서 최소값 인덱스(min_idx) 찾기
- 마지막: `arr[i]` ↔ `arr[min_idx]` 교환

### 6.3 삽입 정렬 패턴
- 바깥: 미정렬 구간 시작(보통 1부터)
- 안쪽: 뒤로 가며 비교, 조건 만족 시 교환/이동
- 자리 찾으면 `break`

### 6.4 카운팅 정렬 패턴(안정 버전)
- 1) max 찾기
- 2) count 배열 생성
- 3) 빈도 세기
- 4) 누적합
- 5) 결과 배열 생성
- 6) 원본을 뒤에서부터 보며 배치 + count 감소

---

## 7. 시험 직전 5분 요약(암기용)
- **버블**: 인접 비교/교환 → 패스마다 최댓값이 뒤로 고정 | `O(N^2)` | 안정 O | 적응(옵션) O | 제자리 O
- **선택**: 최솟값 골라 앞과 교환 반복 | `O(N^2)`(최선도) | 안정 X | 적응 X | 제자리 O
- **삽입**: 정렬 구간에 끼워넣기(자리 찾으면 break) | 최선 `O(N)` 최악 `O(N^2)` | 안정 O | 적응 O | 제자리 O
- **카운팅**: 빈도→누적합→뒤에서 배치 | `O(N+K)` | 안정 O(그 방식) | 제자리 X | K 작을 때 최강

---

## 8. 권장 연습(짧게)
- 버블: `j` 범위가 왜 `n-i-1`인지 말로 설명 + 직접 구현
- 선택: 안정성 없는 반례 1개 만들기
- 삽입: 이미 정렬된 입력에서 비교가 어떻게 줄어드는지 시뮬레이션
- 카운팅: (안정 버전) 누적합/뒤에서 배치를 손으로 1번 따라가기
