# [AI 특강] AI 코딩 어시스턴트 실습

**강연자:** 김구현 강사
**주제:** AI 코딩 어시스턴트를 활용한 효율적인 개발 및 역할 분리(Role Partitioning)

---

## 1. AI 코딩 어시스턴트 활용의 필요성 및 목표
* **배경:** 단순 반복 작업 감소, 생산성 향상, 개발자 채용 트렌드 변화(AI 에이전트 활용 능력 중시).
* **최종 목표:** * AI의 출력에 맹목적으로 의존하지 않고, 작업 범위와 책임을 정의하여 **통제 가능한 결과물**을 생성하는 것.
  * AI를 단순 챗봇이 아닌 '부하 직원(어시스턴트)'처럼 다루고 결과에 책임을 지는 **AI 네이티브 개발자**로 성장.

---

## 2. 기존 LLM 사용의 한계와 AI 에이전트의 등장
* **기존 방식의 한계 (단일 채팅 세션):**
  * 하나의 채팅창에서 기획, 구현, 수정, 검증을 모두 수행하면 맥락(Context)이 섞이고 혼란이 발생합니다.
  * 이전 코드를 수정할 때 의도치 않은 변경(Side Effect)이 발생하며, 어디서 잘못되었는지 책임 소재를 추적하기 어렵습니다.
* **AI 에이전트(Agent)란?**
  * 하나의 목표를 위해 **생각(Reasoning) ➡️ 행동(Acting) ➡️ 관찰(Observation)**을 반복하며 다음 단계를 시스템이 스스로 결정하는 구조입니다. (예: ReAct 기법)

---

## 3. 프롬프트 엔지니어링 (Prompt Engineering) 심화
AI가 어떻게 출력할지 안내하는 강력한 인터페이스입니다.

* **기본 원칙:**
  * **페르소나(Persona) 부여:** "10년 차 소프트웨어 아키텍트 관점에서..." (생성 확률의 범위를 좁혀 품질 향상)
  * **맥락(Context) 제공:** 프로젝트 배경, 목표, 제약 조건 명시
  * **출력 형식 지정:** 마크다운, 특정 포맷 등 원하는 형태 명시
* **고급 기법:**
  * **Few-shot Prompting:** 원하는 답변 패턴의 예시를 제공
  * **Chain of Thought (CoT):** 단계적 사고를 유도하여 논리적 추론 능력을 극대화

---

## 4. 핵심 실습: 역할 분리 (개생검: 계획-생성-검증)
복잡한 작업을 하나의 AI에게 뭉뚱그려 맡기지 않고, 전문화된 역할로 나누어 통제력을 높입니다.

1. **플래너 (Planner - 계획):**
   * **역할:** 요구사항 분석, 기능 명세, 개발 계획 수립 (마크다운 구조화)
   * **금지 사항:** 직접 코드 작성 금지, 추정 기반 기능 추가 금지
2. **제너레이터 (Generator - 생성):**
   * **역할:** 플래너의 계획(명세서)을 바탕으로 실제 코드 구현
   * **특징:** 계획을 임의로 수정하지 않고 주어진 명세에만 충실하게 구현
3. **리뷰어 (Reviewer - 검증):**
   * **역할:** 생성된 코드 검증, 요구사항 충족 여부 확인, 버그 분석
   * **금지 사항:** 코드 직접 수정 금지 (문제 발견 시 피드백만 제공하여 플래너 단계로 피드백 루프 형성)

---

## 5. 실습 도구 및 프로세스 (TypingMind 활용)
* **도구:** TypingMind (로컬 저장소 기반 웹 UI), Google Gemini 2.5 Flash API (무료)
* **진행 과정:**
  1. AI에게 각 역할(플래너, 제너레이터, 리뷰어)을 위한 최적의 프롬프트를 작성해 달라고 지시 (프롬프트를 위한 프롬프팅).
  2. 생성된 프롬프트를 **프롬프트 라이브러리**에 저장하여 재사용.
  3. **세션 분리:** 
     * [채팅 1] 플래너에게 프로젝트 계획 수립 요청
     * [채팅 2] 제너레이터에게 플래너의 결과물을 주고 코드 생성 요청
     * [채팅 3] 리뷰어에게 코드를 주고 검증 요청

---

## 6. 결론 및 향후 계획
* **결론:** AI를 단순히 코드를 짜주는 도구로 쓰는 것을 넘어, 기획-구현-검증 프로세스를 설계하고 제어하는 **오케스트레이터(Orchestrator)** 역할을 수행해야 합니다.
* **내일 예고:** VS Code + GitHub Copilot을 활용한 실제 코드 작성 및 '바이브 코딩(Vibe Coding)' 심화 실무 적용.
