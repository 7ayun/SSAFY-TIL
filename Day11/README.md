#### 2.2 주요 연산

### 3) 저수준 스택 구현 (top 포인터)

#### 핵심 구조
- `items`: 데이터 저장 배열
- `top`: 마지막 원소 인덱스
- 초기값: `top = -1`

#### push
1. 가득 찼는지 확인
2. `top += 1`
3. `items[top] = 값`

#### pop
1. 비었는지 확인
2. 값 저장
3. `items[top] = None`
4. `top -= 1`
5. 값 반환

---

### 4) 스택 응용 ① 괄호 검사

#### 핵심 원리
1. 여는 괄호 → 스택 push
2. 닫는 괄호 →
   - 스택 비었으면 실패
   - top과 매칭되면 pop
   - 아니면 실패
3. 끝났는데 스택 남아있으면 실패

#### 매칭 딕셔너리 예시
```python
matching = {
    ')': '(',
    ']': '[',
    '}': '{'
}
```

### 5) 2차원 전치·회전

#### 전치(Transpose)
```python
list(map(list, zip(*matrix)))
```

#### 90도 시계 회전
- 원리: **행 뒤집기 → 전치**
```python
list(map(list, zip(*matrix[::-1])))
```

좌표 변환:
```
(i, j) → (j, n-1-i)
```

### 6) 스택 응용 ② 계산기: 큰 그림

컴퓨터 계산 과정:
```
중위표기식 → 후위표기식 → 계산
```

예:
```
중위: 10 + 2 * 4
후위: 10 2 4 * +
```

---

### 7) 중위표기식 vs 후위표기식

- **중위표기식(Infix)**: 연산자가 가운데
  - `A + B`
- **후위표기식(Postfix)**: 연산자가 뒤
  - `A B +`

후위표기식 장점:
- 우선순위 계산 필요 없음
- 스택으로 바로 계산 가능

---

### 8) 중위 → 후위 변환 알고리즘(스택)

#### 기본 규칙
1. **피연산자** → 바로 출력
2. **연산자** →
   - 스택 top이 **나보다 우선순위 높거나 같으면** pop 후 출력
   - 그 후 push
3. **여는 괄호 `(`** → push
4. **닫는 괄호 `)`** →
   - `(` 나올 때까지 pop하여 출력
   - `(`는 버림
5. 입력 끝나면 스택 모두 pop

---

### 9) 후위표기식 계산 알고리즘

#### 규칙
1. 숫자 → 스택 push
2. 연산자 →
   - 스택에서 2개 pop
   - 계산
   - 결과 push
3. 마지막 남은 값이 결과

#### 실수 포인트(매우 중요)
- `op2 = pop()` (먼저 나온 값 = **오른쪽 피연산자**)
- `op1 = pop()` (그 다음 값 = **왼쪽 피연산자**)

### 11) 재귀 예제

#### 11.1 팩토리얼
수학:
- `n! = n × (n-1)!`
- `0! = 1`

```python
def fact(n):
    if n <= 1:
        return 1
    return n * fact(n-1)
```

#### 11.2 피보나치
- `f(n) = f(n-1) + f(n-2)`
- `f(0)=0, f(1)=1`

```python
def fib(n):
    if n == 0:
        return 0
    if n == 1:
        return 1
    return fib(n-1) + fib(n-2)
```

#### 11.3 거듭제곱
기본:
```python
def power(x, n):
    if n == 0:
        return 1
    return x * power(x, n-1)
```

최적화(분할정복):
```python
def power(x, n):
    if n == 0:
        return 1

    half = power(x, n//2)

    if n % 2 == 0:
        return half * half
    return half * half * x
```
- 시간복잡도: `O(log n)`
