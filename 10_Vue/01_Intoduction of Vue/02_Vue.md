## 1. Vue란

**사용자 인터페이스를 구축하기 위한 JavaScript 프레임워크**

- 웹사이트 UI를 쉽고 빠르게 만들 수 있게 도와주는 프론트엔드 프레임워크
- 레고 블록처럼 가능한 부품(컴포넌트)으로 화면을 조립하고, **데이터가 바뀌면 화면도 자동으로 바뀌는 반응성**이 가장 큰 특징
- 배우기 쉽고 직관적이면서도 강력해, 초보자부터 전문가까지 폭넓게 사용하는 인기 있는 기술

## 2. What is Vue?

- **Evan You**에 의해 발표(2014)
  - 학사: 미술, 미술사 / 석사: 디자인 & 테크놀로지 전공 (비전공자 출신)
  - Angular 개발팀 출신 → Angular에 대한 불편함을 느끼고 Vue를 직접 만들었음
- 최신 버전은 **"Vue 3"** (2024~)
  - 공식 문서: https://vuejs.org/
  - ⚠️ **Vue 2 문서에 접속하지 않도록 주의** (문법 구조가 다름)

### Vue 2 vs Vue 3

| 구분 | API 방식 |
|------|----------|
| Vue 2 | Options API |
| Vue 3 | **Composition API** (현재 배우는 방식) |

> "AI에게 물어봤을 때 Options API 코드를 뱉어내는 경우가 있다. Vue 2와 Vue 3 문법을 섞어서 쓰면 '혼종'이 된다. 동작은 하지만, 코드 일관성이 깨지면서 협업할 때 문제가 생기고 포트폴리오에 코드까지 공개한다면 실력을 의심받을 수 있다. **코드를 읽는 눈**을 가져야 한다."

## 3. Vue를 학습하는 이유

### 1. 낮은 학습 곡선
- 간결하고 직관적인 문법을 가지고 있어 빠르게 익힐 수 있음
- 잘 정리된 문서를 기반으로 어렵지 않게 학습 가능

### 2. 확장성과 생태계
- 다양한 플러그인과 라이브러리를 제공하는 높은 확장성
- 전세계적으로 활성화된 커뮤니티를 기반으로 많은 개발자들이 새로운 기능을 개발하고 공유
- GitHub Organizations Ranking **10위** (vuejs: ★628,788)

### 3. 유연성 및 성능
- 작은 규모의 프로젝트부터 대규모 애플리케이션까지 다양한 프로젝트에 적합

### 4. 주목받는 Client-side framework

### SSAFY에서의 Vue
1. Vue는 React나 Angular에 비해 문법이 간결하고 직관적이어서, 학습이 비교적 수월
   - 짧은 시간 내에 효율적으로 결과물을 만들어 낼 수 있음
2. 거대하고 활발한 커뮤니티를 가지고 있어 풍부한 문서, 튜토리얼, 예제 및 다양한 리소스를 공유받을 수 있음
   - 최신 업데이트 및 트렌드를 공유함으로써 지속적인 학습을 촉진

> "AI 때문에 프레임워크의 경계가 많이 무너졌다. 사이드 프로젝트로 Vue로 빠르게 만들었다가 괜찮으면 실제 프레임워크로 본격 개발하는 식으로도 활용된다. 하나의 도구만 사용하던 시대는 끝났다."

## 4. Vue 체험하기

간단한 카운터 예제로 Vue를 체험해볼 수 있다.

```html
<!-- first-vue.html -->
<div id="app">
  <h1>{{ message }}</h1>
  <button v-on:click="count++">
    Count is: {{ count }}
  </button>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>

<script>
  const { createApp, ref } = Vue
  const app = createApp({
    setup() {
      const message = ref('Hello vue!')
      const count = ref(0)

      return {
        message,
        count
      }
    }
  })

  app.mount('#app')
</script>
```

> "자바스크립트로 하면 addEventListener를 붙이고 함수 만들어서 증가시킨 다음 DOM 조작을 통해 카운트를 보여줘야 했는데, 지금은 몇 줄 안 썼다. 이게 바로 Vue다."

## 5. Vue의 2가지 핵심 기능

### 1. 선언적 렌더링 (Declarative Rendering)

- 표준 HTML을 확장하는 Vue **"템플릿 구문"** 을 사용하여 JavaScript 상태(데이터)를 기반으로 화면에 출력될 HTML을 **선언적으로** 작성
- "우리 페이지는 이렇게 생겼어요" 라고 선언하면, 데이터가 들어왔을 때 그 선언대로 화면이 보여지게 됨

> 비교: 장고 템플릿도 "데이터가 들어와서 이러한 모양으로 생길 거예요"라고 선언하는 것과 같은 원리

### 2. 반응성 (Reactivity)

- JavaScript 상태 변경을 추적하고, 변경사항이 발생하면 **자동으로 DOM을 업데이트**
- 체험하기 예제에서 count 변수가 `++`될 때마다 화면의 숫자가 자동으로 바뀌는 것이 반응성

## 6. Vue의 주요 특징 정리

| 특징 | 설명 |
|------|------|
| 반응형 데이터 바인딩 | 데이터 변경 시 자동 UI 업데이트 |
| 컴포넌트 기반 아키텍처 | 재사용 가능한 UI 조각 |
| 간결한 문법과 직관적인 API | 낮은 학습 곡선, 높은 가독성 |
| 유연한 스케일링 | 작은 프로젝트부터 대규모 앱까지 적합 |

## 7. Component

### 정의

**"재사용 가능한 코드 블록"**

- UI를 독립적이고 재사용 가능한 일부분으로 분할하고 각 부분을 개별적으로 다룰 수 있음
- 자연스럽게 애플리케이션은 중첩된 Component의 **트리 형태**로 구성됨

```
         <Root>
        /   |   \
  <Header> <Main> <Aside>
            / \       |
    <Article>x2 <Item>x3
```

### Component 예시

웹 서비스는 여러 개의 Component로 이루어져 있음

- 음악 스트리밍 서비스: 앨범 카드가 다 똑같이 생겼음 → **카드 컴포넌트**로 구성
  - 신규 앨범이 나와도 이미지와 텍스트만 바꾸면 얼마든지 재사용 가능
- Facebook: 게시물, 친구 목록, 알림 등 각각이 컴포넌트로 구성

> "각각의 구성 요소를 큰 덩어리로 관리하는 게 아니라, 잘게 나눠서 각각의 요소들을 조각조각 붙여서 하나의 큰 페이지를 만들어 간다."
