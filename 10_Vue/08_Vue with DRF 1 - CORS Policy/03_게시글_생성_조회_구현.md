# [Vue] 게시글 생성/조회 구현

---

## 1. 전체 게시글 조회 완성

CORS 해결 후, store의 `getArticles` 응답 데이터를 화면에 출력하기까지의 흐름을 정리한다.

```javascript
// store/articles.js — articles.value에 저장
const getArticles = function () {
  axios({
    method: 'get',
    url: `${API_URL}/api/v1/articles/`
  })
    .then(res => {
      articles.value = res.data   // DRF 응답 배열을 store에 저장
    })
    .catch(err => console.log(err))
}
```

데이터 흐름 요약:

```
ArticleView (onMounted)
  → store.getArticles()
    → Axios GET 요청 → DRF
      ← res.data (배열)
    → articles.value = res.data  [Pinia store]
  → ArticleList (v-for store.articles)
    → ArticleListItem (props: article)
      → 화면 렌더링
```

## 2. 단일 게시글 조회 (DetailView)

### Step 1. router에 DetailView 동적 경로 등록

```javascript
// router/index.js
import ArticleView from '@/views/ArticleView.vue'
import DetailView from '@/views/DetailView.vue'   // 주석 해제

const router = createRouter({
  routes: [
    { path: '/', name: 'ArticleView', component: ArticleView },
    {
      path: '/articles/:id',    // :id = 동적 세그먼트
      name: 'DetailView',
      component: DetailView
    },
  ]
})
```

### Step 2. ArticleListItem에 상세 페이지로 이동하는 RouterLink 추가

```vue
<!-- components/ArticleListItem.vue -->
<template>
  <div>
    <h5>{{ article.id }}</h5>
    <p>{{ article.title }}</p>
    <p>{{ article.content }}</p>
    <RouterLink :to="{ name: 'DetailView', params: { id: article.id } }">
      [DETAIL]
    </RouterLink>
    <hr>
  </div>
</template>
<script setup>
import { RouterLink } from 'vue-router'
defineProps({ article: Object })
</script>
```

`:to`에 `params`로 `id`를 전달하면, URL이 `/articles/1`처럼 동적으로 생성된다.

### Step 3. DetailView에서 useRoute로 id 가져와 Axios 요청

```vue
<!-- views/DetailView.vue -->
<template>
  <div>
    <h1>Detail</h1>
    <div v-if="article">
      <p>글 번호 : {{ article.id }}</p>
      <p>제목 : {{ article.title }}</p>
      <p>내용 : {{ article.content }}</p>
      <p>작성시간 : {{ article.created_at }}</p>
      <p>수정시간 : {{ article.updated_at }}</p>
    </div>
  </div>
</template>

<script setup>
import axios from 'axios'
import { onMounted, ref } from 'vue'
import { useRoute } from 'vue-router'
import { useArticleStore } from '@/stores/articles'

const store = useArticleStore()
const route = useRoute()
const article = ref(null)         // 초기값 null

onMounted(() => {
  axios({
    method: 'get',
    url: `${store.API_URL}/api/v1/articles/${route.params.id}/`  // URL에 id 포함
  })
    .then(res => {
      article.value = res.data    // 응답 데이터(단일 객체) 저장
    })
    .catch(err => console.log(err))
})
</script>
```

**핵심 포인트**:

| 항목 | 내용 |
|------|------|
| `useRoute()` | 현재 라우트 정보 접근 (params, query 등) |
| `route.params.id` | URL의 `:id` 동적 세그먼트 값 |
| `store.API_URL` | store에서 API_URL을 return하여 재사용 |
| `v-if="article"` | article이 null이면 렌더링 안 함, 데이터 도착 후 표시 |

## 3. 게시글 작성 (CreateView)

### Step 1. router에 CreateView 등록

```javascript
// router/index.js
import CreateView from '@/views/CreateView.vue'   // 주석 해제

routes: [
  { path: '/', name: 'ArticleView', component: ArticleView },
  { path: '/articles/:id', name: 'DetailView', component: DetailView },
  { path: '/create', name: 'CreateView', component: CreateView },   // 추가
]
```

### Step 2. ArticleView에 CreateView로 이동하는 RouterLink 추가

```vue
<!-- views/ArticleView.vue -->
<template>
  <div>
    <h1>Article Page</h1>
    <RouterLink :to="{ name: 'CreateView' }">[CREATE]</RouterLink>
    <hr>
    <ArticleList />
  </div>
</template>
<script setup>
import { RouterLink } from 'vue-router'
import ArticleList from '@/components/ArticleList.vue'
</script>
```

### Step 3. CreateView 구현

```vue
<!-- views/CreateView.vue -->
<template>
  <div>
    <h1>게시글 작성</h1>
    <form @submit.prevent="createArticle">  <!-- 기본 새로고침 방지 -->
      <label for="title">제목 : </label>
      <input type="text" id="title" v-model.trim="title"><br>
      <label for="content">내용 : </label>
      <textarea id="content" v-model.trim="content"></textarea><br>
      <input type="submit">
    </form>
  </div>
</template>

<script setup>
import axios from 'axios'
import { ref } from 'vue'
import { useRouter } from 'vue-router'
import { useArticleStore } from '@/stores/articles'

const store = useArticleStore()
const router = useRouter()
const title = ref(null)
const content = ref(null)

const createArticle = function () {
  axios({
    method: 'post',
    url: `${store.API_URL}/api/v1/articles/`,
    data: {
      title: title.value,
      content: content.value
    }
  })
    .then(() => {
      router.push({ name: 'ArticleView' })  // 작성 완료 후 목록 페이지로 이동
    })
    .catch(err => console.log(err))
}
</script>
```

**핵심 포인트**:

| 항목 | 내용 |
|------|------|
| `v-model.trim` | 양방향 바인딩 + 앞뒤 공백 자동 제거 (Python의 `.strip()`과 동일) |
| `@submit.prevent` | form 제출 시 기본 동작(새로고침) 취소 |
| `data: { title, content }` | Axios의 `data` 옵션 = HTTP Request Body (POST/PUT 등에 사용) |
| `useRouter()` | 라우터 인스턴스 접근, `router.push()`로 프로그래밍 방식 페이지 이동 |

---

## 4. useRoute vs useRouter 비교

| 함수 | 역할 | 주요 사용처 |
|------|------|-------------|
| `useRoute()` | 현재 라우트 **정보 읽기** | `route.params.id`, `route.query.page` |
| `useRouter()` | 라우터 **조작** | `router.push()`, `router.back()` |

## 5. 오늘 완성된 CRUD 범위

| 기능 | 완료 여부 | 비고 |
|------|-----------|------|
| 전체 게시글 조회 (R) | ✅ | Axios GET + store |
| 단일 게시글 조회 (R) | ✅ | useRoute + Axios GET |
| 게시글 작성 (C) | ✅ | v-model + Axios POST |
| 게시글 수정 (U) | 미구현 | Create와 구조 유사 (PUT 요청) |
| 게시글 삭제 (D) | 미구현 | Axios DELETE 요청 |

## ❓ 더 찾아볼 것
- Vue Router `useRoute().params` vs `useRoute().query` 차이
- Axios `data` 옵션과 Content-Type (application/json 자동 설정)
- `v-model` 수식어: `.trim`, `.lazy`, `.number`
- `router.push` vs `router.replace` 차이 (히스토리 남김 여부)
