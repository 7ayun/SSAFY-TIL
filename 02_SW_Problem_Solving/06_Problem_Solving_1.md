## 1️⃣ 회문 검사 (Palindrome)

### 🔹 문제 핵심
- 문자열이 **앞에서 읽으나 뒤에서 읽으나 동일**한지 판단
- 출력: 회문 → `1`, 아니면 → `0`

### 🔹 핵심 아이디어 (슬라이싱 금지 버전)
- 문자열 **양끝을 가운데로 좁혀가며 비교**
- 비교 횟수 = `len(word) // 2`

### 🔹 인덱스 공식
- 앞 인덱스: `i`
- 뒤 인덱스: `n - 1 - i`

### 🔹 필수 처리
- 입력 문자열 공백 제거
  ```python
  word = input().strip()
  ```

### 🔹 종료 전략
- 하나라도 다르면 즉시 `break`
- 끝까지 통과하면 회문

### ❌ 실수 & 함정
- `strip()` 누락 → 길이 꼬임
- 뒤쪽 인덱스 계산 실수
- 끝까지 다 비교하려고 함 (비효율)

## 2️⃣ 파리 퇴치 (Fly Swatter)

### 🔹 문제 구조
- `N x N` 격자
- `M x M` 파리채로 한 번 찍어서 잡을 수 있는 **최대 파리 수**

### 🔹 정석 풀이 구조 (4중 for)
1. 파리채 시작점 `(i, j)` 선택
2. 내부에서 `M x M` 영역 합산
3. 최대값 갱신

### 🔹 시작점 범위 (중요)
```python
i in range(N - M + 1)
j in range(N - M + 1)
```

### 🔹 변수 위치 규칙
- `temp_sum` → **(i, j)마다 0으로 초기화**
- `max_kill` → 전체에서 하나만 유지

### ❌ 실수 & 함정
- `temp_sum`을 바깥에 두고 누적
- 시작점 범위를 `range(N)`으로 둠
- 리스트에 append 후 max 계산 (비효율)

## 3️⃣ 풍선팡 1 (Balloon Pang 1)

### 🔹 문제 핵심
- 한 칸을 터뜨리면 **해당 칸의 값 K만큼**
  상·하·좌·우로 `1 ~ K` 거리까지 터짐
- 모든 칸을 시작점으로 시도 → **최대 합** 출력

### 🔹 알고리즘 뼈대
1. 모든 칸 `(i, j)`를 시작점으로 선택
2. `sum_value = array[i][j]` (본인 포함)
3. 델타 탐색 (4방향)
4. 거리 `dist = 1 ~ K` 반복

```python
ni = i + dx * dist
nj = j + dy * dist
```

### 🔹 최적화 포인트
- 한 방향에서 **범위를 벗어나면**
  → 그 방향 `dist` 반복 즉시 `break`

### ❌ 실수 & 함정
- `dist = 0`부터 시작 (본인 중복)
- `range(K)` 사용 실수 (`1 ~ K` 아님)
- 행/열 범위 혼동

## 4️⃣ Ladder1 (사다리 문제)

### 🔥 입력 관련 핵심 함정
- **테스트케이스 개수는 항상 10개 고정**
- 입력 첫 줄 숫자는 **TC 개수 아님** → 테스트 번호

```python
for _ in range(10):
    tc = int(input())
```

---

### 🔹 기본 접근 (정석)
1. **0행에서 값이 1인 모든 열**에서 출발
2. 사다리를 따라 내려감
3. 마지막 행에서 `2` 도달하면 그 열이 정답

➡ 여러 시작점을 시도하므로 **visited 배열 필수**

---

### 🔹 visited 배열 생성 (중요)
❌ 잘못된 예:
```python
visited = [[0]*N]*N
```

⭕ 올바른 예:
```python
visited = [[0]*N for _ in range(N)]
```

---

### 🔹 이동 규칙 요약
- 기본 방향: **아래 → 좌/우**
- 좌/우에 길이 있으면 **끝까지 이동**
- 다시 아래로 진행
- 무한 반복 → `while` 사용

```python
while x < N-1:
    ...
```

---

### 🔹 코드 스타일 팁 (Early Continue)
- 조건을 한 줄에 묶지 말고
- 실패 조건부터 `continue`

장점:
- 디버깅 쉬움
- 조건 누락 방지
- A형 대비에 유리

---

### 💡 고급 아이디어 (역추적)
- `2`에서 시작해 **위로 거슬러 올라가기**
- 경로가 하나뿐 → visited 부담 감소

## 5️⃣ 시험 직전 체크리스트

- 회문: `strip()` + `n-1-i` + 절반 비교
- 파리퇴치: 시작점 범위 `N-M+1`
- 풍선팡1: `dist=1~K`, 본인 포함
- Ladder1: **TC=10 고정**, visited 생성 방식
