## 2) 2차원 리스트 기본 개념

* 2차원 리스트 = “큰 리스트 안에 여러 개의 1차원 리스트(행)가 들어있는 구조”
* 접근:
  * `arr[i]` : i번째 **행(리스트)**
  * `arr[i][j]` : i번째 **행**, j번째 **열**의 값

### 행/열 용어

* **행(row)** = 가로 줄
* **열(column)** = 세로 줄
* 보통 변수 관례:
  * `i` = 행(row)
  * `j` = 열(column)
  * `r, c`도 많이 씀 (row, col)

---

## 3) 2차원 순회 패턴 3종

### A. 행 우선 순회(가장 자주 씀)

* “행 고정 → 열 이동”

```python
for i in range(n):        # 행
    for j in range(m):    # 열
        visit(arr[i][j])
```

### B. 열 우선 순회

* “열 고정 → 행 이동”

```python
for j in range(m):        # 열
    for i in range(n):    # 행
        visit(arr[i][j])
```

### C. 지그재그 순회(행 단위로 방향 반전)

* 짝수 행은 →, 홀수 행은 ←
* 핵심 아이디어: **홀짝으로 열 인덱스를 뒤집기**
  * 뒤집힌 열 인덱스: `m - 1 - j`

---

## 4) 좌표계에서 가장 중요한 포인트

* 파이썬 2차원 배열은 보통 **(행 i, 열 j)** 로 해석합니다.
* “아래로 내려갈수록 i가 증가(+1)”
  → 수학 좌표랑 헷갈리기 쉬운 지점

---

## 5) 델타 탐색(상하좌우, 8방)

### 목적

* (i, j) 한 점에서 **주변 칸(이웃 칸)** 을 빠르게 탐색하는 패턴

### 4방(오른쪽/아래/왼쪽/위) 예시

```python
dx = [0, 1, 0, -1]
dy = [1, 0, -1, 0]

for k in range(4):
    ni = i + dx[k]
    nj = j + dy[k]
```

### 범위 체크(Out of range 방지) — 필수

```python
if 0 <= ni < n and 0 <= nj < m:
    # 안전하게 arr[ni][nj] 사용 가능
```

### 8방 탐색(대각선 포함)

* 4방 + 대각선 4개를 추가하면 됩니다.

## 6) 2차원 리스트 입력 받기

### 테스트케이스 구조

* `T` : 테스트케이스 수
* 각 테스트케이스마다
  * `n m`
  * 이후 n줄에 걸쳐 m개 숫자

### 가장 많이 쓰는 입력 패턴(빠르고 안정적)

```python
n, m = map(int, input().split())
arr = [list(map(int, input().split())) for _ in range(n)]
```

#### 실수 포인트

* `input().split()`만 하면 문자열이라서 연산이 꼬임 → **반드시 `map(int, ...)`**
* `append`로 누적하는 방식도 되지만, 경우에 따라 느려서 시간 초과 가능
  → **리스트 컴프리헨션 권장**

---

## 7) 연습문제 유형 정리

### (1) 대각선 합(주대각선 + 역대각선)

* 주대각선: `i == j`
* 역대각선: `i == n - 1 - j`

주의:

* n이 홀수면 가운데가 **중복**되므로 1번 빼야 함
* n이 짝수면 **중복 없음**

---

### (2) “이웃 원소와의 차(절댓값)” 누적

* 모든 칸(i, j)에 대해:
  * 상하좌우 이웃 칸과의 `abs(arr[i][j] - arr[ni][nj])`를 더함
* 핵심은 패턴:
  1. 전체 순회(이중 for)
  2. 각 칸마다 델타 탐색(4방)
  3. 범위 체크 후 누적
  4. “칸별 누적”과 “전체 누적” 변수 초기화 위치 조심

가장 흔한 실수:

* 누적 변수를 너무 바깥에 둬서 **초기화 타이밍이 꼬임**

---

### (3) 달팽이(스네일) 채우기 핵심 아이디어

* 방향 순서가 고정: **오른쪽 → 아래 → 왼쪽 → 위** 반복
* 다음 칸으로 갈 때 조건:
  1. 범위 안
  2. 아직 안 채운 칸(예: 0 또는 None)

방향 전환:

* “못 가면 방향 인덱스 +1”
* 0~3 반복하려면:
  * `dir = (dir + 1) % 4`

---

## 8) 시험/실습에서 제일 중요한 암기/패턴

* 2차원 입력:
  * `arr = [list(map(int, input().split())) for _ in range(n)]`
* 델타 탐색:
  * `dx, dy` + `for k in range(4)` + `범위 체크`
* 범위 체크:
  * `0 <= ni < n and 0 <= nj < m`
* 역대각선:
  * `i == n - 1 - j`
* 방향 순환:
  * `(dir + 1) % 4`
